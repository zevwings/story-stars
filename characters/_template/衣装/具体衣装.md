# 人物名｜具体衣装名

> 本档只用于角色已确认持有、需要跨场景复用或维护连续性的具体衣装。它记录衣装本身的结构能力和调用语法，不代表角色在任何场景中的同意、偏好或实际行为。复制到人物的 `衣装/` 子目录后，身份与长期穿衣语法分别以上层的 `主卡.md` 与同目录 `_GRAMMAR.md` 为准。

## 定位

- **衣装性质**：[完整造型（单件主体） / 完整造型（多件组合） / 需要搭配单件 / 可独立调用单件]
- **主要用途**：[日常 / 职业 / 舞台 / 仪式 / 私密 / 运动 / 泳装 / 行动 / COS]
- **持有与复用依据**：[为什么确认属于该角色，为什么值得建立跨场景档案。]
- **搭配要求**：[必须搭配的衣层、鞋袜或配饰；完整造型可写“自足”。]

## 人物版本

- **结构与覆盖**：[衣物构成、固定方式、露肤与遮挡；不只写市场名称。]
- **色彩与材质**：[写实颜色、光泽、垂坠、弹性、摩擦与触感。]
- **与人物衣装语法的关系**：[怎样延续、偏移或反衬主衣装页中的稳定审美。]
- **现实适配**：[体型、活动、季节、清洁、收纳与经济条件。]

## 张力与互动语法（私密 / 情趣衣装按需）

> 先确定一个主导路径，最多再保留一个克制变体。不要把本节写成可随意抽取的动作菜单；普通衣装删除本节。

- **核心张力**：[例如隔而不透、贴合与阻隔、整齐外观与逐步失序；写衣装如何形成张力。]
- **材质反馈**：[隔料触感、摩擦、回弹、温度、声音、位移与褶皱怎样回应动作。]
- **主导互动**：[隔料抚摸 / 整理 / 解扣 / 掀移 / 缓慢褪下 / 保留穿着 / 快速扯开 / 一次性撕裂 / 其它；只选最适合这件衣装的一项或一条连续路径。]
- **克制变体**：[可选；不能与主导路径争夺设计重心。]
- **衣物结果**：[完整复位 / 暂时移位 / 褪下收纳 / 可修复损耗 / 一次性报废。]

### 撕裂路径附加条件（仅主导路径涉及撕裂时保留）

- **可撕结构 / 牺牲层**：[预设弱点、可替换面片或一次性版本；不把普通成衣默认写成可安全撕裂。]
- **皮肤保护**：[动作方向、受力位置和避免刮擦、勒伤的条件。]
- **预期损坏位置**：[损坏应发生在哪里，哪些固定件和主体结构不得受力。]
- **后续处理**：[替换、修补、清洗、收纳或丢弃方案。]

## 穿用与维护

- **穿脱与固定方式**：[人物可以如何独立穿脱，需要帮助时必须有正式依据。]
- **易位移与损耗点**：[走动、坐卧、潮湿、拉扯后最可能发生什么。]
- **清洁、收纳与替换**：[只写会影响连续性或人物生活质感的现实信息。]

## 调用边界

- 本档定义衣装“能承载什么”，不定义人物“必然喜欢什么”；稳定私密偏好、避让与脱换语言归 `specialties/intimacy/characters/`。
- 本档出现“可撕”只表示该版本具备安全设计条件，不表示任何场景已经授权、实际采用或损坏。
- 某场究竟选择抚摸、整理、褪下、保留穿着还是撕裂，以及顺序、授权、他人反应、损坏和事后流向，归对应专项施工或章节。
- 多人主题衣装按所有权分别写入各角色自己的具体衣装档案，不建立脱离人物 owner 的正式总套装。
