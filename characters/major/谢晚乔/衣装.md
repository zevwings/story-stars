# 谢晚乔｜衣装

> 本页定义谢晚乔跨场景稳定的衣装语法与调用边界。身份、职业、关系和契约状态以 [主卡](主卡.md) 为准；身体结构与体态见 [形象](形象.md)。

## 总体衣装口径

谢晚乔的衣装首先要让她漂亮、能认出，其次才按场景证明职业。露额深发、纵向收束的面容和一件有分量的石榴红或深樱桃红单品建立第一眼；清楚肩颈、腰线与修长比例把教练身体穿得利落而有吸引力。训练衣服从真实动作，社交与正式衣装则可以把完成度推高；功能衣与私人衣柜仍须分开，危机中也不会自动换装。

## 审美基因

- **核心色**：石榴红或深樱桃红。单套通常只用一件有面积、有结构的红色单品，不与银色组成固定战斗符号。
- **基础色**：墨黑、深海军蓝、骨白。
- **辅助色**：水洗丹宁、深棕；只负责生活层次，不另建糖果色谱。
- **材质**：训练衣重耐洗、排汗、活动量和无勾挂；通勤使用棉、牛仔、针织与低反光结构料；正式场合可用有垂度或细哑光面料，不用廉价亮片。
- **比例**：训练状态让肩线与全脚承重保持清楚；社交与正式状态允许明确腰线、肩颈和长身比例。上装不长期裁成露腰短款，下装按场景使用直筒、合体或结构裙装，不把“紧上紧下”固化为职业展示模板。

## 头发、妆容与配饰

- **头发**：自然黑至深黑棕，近中分或四六分露额。普通教学可用低马尾或低辫；持靶、对练和高强度训练用紧辫、编发盘收等更稳定方式；正式与私人场合可以放下，但不遮没脸部纵向结构。
- **妆容**：训练时以防晒、自然眉、必要的防汗处理和润唇为主，但不主动压低面部完成度。社交妆使用细净透亮的底妆，眼线、睫毛与下眼睑沿长杏眼横向整理，同时保留中等偏大的纵向开度；正式妆可进一步强化眼部黑白关系与鼻唇边界。唇色可用石榴红、深樱桃红或干燥玫瑰色，眼妆和唇妆择一主导。
- **配饰**：训练、持靶、对练和比赛时不戴硬质发夹、耳饰、项链、手链或戒指。日常配饰低频、小体量、无固定图腾；白梅发扣删除，不承担人物、关系或能力标记。
- **气味**：训练馆优先无香或低干扰洗护；不设置红梅、蜜桃、暖糖等固定香气。

## 场景衣柜

| 场景 | 稳定衣装 | 写作边界 |
| --- | --- | --- |
| 普通会员教学 | 俱乐部教练 T 恤或结构清楚的速干上衣，直筒训练裤或合体运动短裤，稳定训练鞋 | 可反复清洗、便于短示范；不以露肤和曲线建立教练身份 |
| 拳击基础／持靶 | 完全固定头发，无勾挂短袖，拳击鞋或适配地面的训练鞋；手靶、计时器与护具按课程出现 | 无首饰；器材属于工作物，不是专属武器或亲密道具 |
| 体能课 | 排汗上衣、允许深蹲跑跳的下装；按跑、举、敏捷内容换合适鞋履 | 支撑型运动内层是必要内衣，不作为第一视觉层 |
| 个人拳击训练 | 绑手、拳套、护齿、拳击鞋按训练内容出现；训练前后加拉链外套或长裤 | 不用汗湿、淤青、裸露或破损拳峰证明训练量 |
| 业余拳击比赛 | 按规则穿比赛背心、短裤、拳套、护齿与拳击鞋；红／蓝角颜色服从赛事分配 | 角区颜色不等于人物主色；辨识可放在赛前外套、毛巾或场外物品上 |
| 赛前／赛后 | 深色拉链训练外套、长裤、干燥替换层，配毛巾、饮水与基础恢复用品 | 先保温、补水、进食和处理伤情，不把赛后身体当展示 |
| 通勤 | 骨白或深色 T 恤、直筒牛仔裤、衬衫外层、短夹克与现实背包 | 红色至多一件；不把短上装加紧身裤固化成私人制服 |
| 普通社交 | 石榴红针织或短外套配黑／深蓝直筒裤；或骨白方领／窄领上衣配深红裙装 | 红色承担辨识，剪裁明确肩颈与腰线，可漂亮利落，不叠固定银饰 |
| 正式场合 | 深石榴红结构连衣裙或裤装，也可使用墨蓝、黑色；方领、不对称领或利落露肩结构择一 | 允许肩颈、腰线和修长比例完整成立，把面容推到高完成度；不照抄具体礼服，不使用红银战衣、锋刃装饰或古装意象 |
| 私人居家 | 宽松棉 T、运动长裤或舒适短裤，按季节加针织或家居外层 | 舒适和生活痕迹优先；露肤不表示亲密许可 |
| 契约危机 | 保持进入现场时原本的衣服，必要时只做现实层面的束发、换鞋或移除妨碍物 | 无自动换装、发光纹样、红银战衣或训练护具武器化 |

## 三套高识别完成造型

- **教练状态**：露额紧低辫或编发盘收，深海军蓝／墨黑教练上衣与利落训练裤，石榴红落在外套、毛巾或场外单品。脸仍是第一识别层，装备只说明她正在工作。
- **社交状态**：四六分深发放下，石榴红针织／短外套配骨白内搭，或骨白方领上衣配深红裙装；腰线和肩颈清楚，细净底妆与横向长眼妆让她从职业利落转为鲜明漂亮。
- **正式状态**：露额黑发顺直或低位收束，深石榴红结构连衣裙／裤装采用方领、不对称领或利落露肩结构；底妆清透，长杏眼明亮，深红唇形边界清楚，配饰保持小体量。重点是脸、肩颈和长身比例，不是堆叠符号。

> 三套造型定义可复用的视觉语法，不是每次出场必须原样复制的制服。

## 季节与状态偏移

- **炎热**：轻薄排汗、替换层与防晒优先；红色可落在短袖、毛巾或轻外层，不必全身高饱和。
- **降温**：深海军蓝或墨黑卫衣、针织与训练外套分层，石榴红保留在内搭或一件外层。
- **雨天**：防滑鞋底、可收纳防水外层和干燥替换物优先。
- **工作转私人**：通过洗净、放发、换掉工服与收起器材完成状态切换，不用更露或更紧作为唯一信号。
- **认真或冲突**：不必把颜色压黑；更常见的变化是摘掉多余配饰、扎稳头发、扣好外层并为动作留出空间。

## 正文调用原则

- 每场先确定她在教学、个人训练、通勤、社交、正式或危机中的哪一种职责，再调用对应衣装。
- 石榴红是稳定辨识色，不是每场必穿，也不与能力发动、感情进度或情绪高低机械绑定。
- 用换鞋、固定头发、检查绑手、套上保温外层和收起工作器材区分状态；衣服要参与真实生活流程。
- 正文每次调用一至两个有效细节即可，例如“露额低辫＋深蓝教练 T 恤”或“石榴红短外套＋骨白内搭”。
- 社交或正式场合可以直接写她漂亮、明艳或完成度高；随后用长杏眼、渐收脸形、深发、肩颈和石榴红说明她为什么仍是谢晚乔。

## 禁写误区

- 不恢复糖果红、蜜桃粉、柔粉白、莓红与冷银并列的整套色谱。
- 不恢复白梅发扣、红梅蜜桃香或红银锋刃符号。
- 不让瑜伽裤、运动内衣、压缩衣覆盖她的私人衣柜，也不把训练服和职业身体自动情色化。
- 不用万能运动鞋、无保护对练、硬质训练首饰或赛事色误写现实拳击流程。
- 不把石榴红写成性格说明书；她的判断、边界与行动效率必须独立成立。
