# 瑶瑶（暂名）｜衣装

> 本页负责陈瑶视觉原型白卡（暂名：瑶瑶）的场景造型、衣装语法与静态配饰设计。形象、身形与面容见 [形象](形象.md)。

## 衣装核心语法

1. **头身比强化**：通过清楚腰线、纵向线条或短上衣搭长裤/长裙，突出 168 cm 小头长颈、偏高腰线的清瘦比例。
2. **多风格承接**：从知性眼镜利落装、棕黑复古工装/漫画式对抗造型，到民国复古旗袍、冰雪高定与日常草地休闲装，均围绕小脸、长颈和纤细长线条组织。
3. **焦点控制**：一次只保留一处视觉焦点（如黑框眼镜、流苏抹胸、裘皮披肩或高马尾发饰），不堆砌杂乱配饰。

## 五大典型造型示例

### 1. 复古工装 / 漫画式对抗造型
- **衣装**：黑/棕色做旧皮衣或短马甲、利落内搭、硬质腰带配高腰短裤与长靴；通过材质和轮廓建立冷飒感，不固定鼓棒或乐器道具。
- **发型与妆容**：双马尾绑带发型或野性披发，眼神犀利专注，冷调舞台灯光。

### 2. 知性御姐 / 职场冷感装
- **衣装**：细/黑框眼镜、剪裁利落的西装外套、黑色/浅蓝高级感斜肩礼服。
- **发型与妆容**：微湿长发或平整盘发，唇色利落，眼神透出理性与智感。

### 3. 民国复古 / 东方古韵
- **衣装**：红色/黑色高领旗袍、搭黑色裘皮披肩或拿喜服团扇。
- **发型与妆容**：民国复古盘发或汉服蓝白长衫，耳饰为翡翠/珍珠，展现温婉而沉静的世家气场。

### 4. 冰雪高定 / 精灵梦幻
- **衣装**：冰晶蓝/纯白羽毛高定礼服，或金发独角兽仙侠造型。
- **发型与妆容**：浅色/金发或黑长直发，清透妆容，极具超凡脱俗的神圣留白感。

### 5. 阳光日常 / 随性休闲
- **衣装**：草地麻花辫配格子衬衫、雪景红斗篷、车内黑色露肩T恤或粉色蕾丝裙。
- **发型与妆容**：自然散发或麻花辫，妆容清透，展现随性、真挚与生活呼吸感。
