# 阮清黎｜衣装语法
> 本页定义阮清黎跨场景稳定的审美基因与调用边界。身份、职业、伴侣关系与权限以 [主卡](../主卡.md) 为准；身体比例见[形象](../形象.md)。

## 总体衣装口径

她的衣装任务不是把她包装成“清冷 CFO”，而是让高辨识度面容、轻长身形和正式职权同时成立。稳定轮廓是上身合体或干净、腰线明确、下装高腰而修长；颜色保持较强明暗对比，面料和结构随场合升级。她日常不必穿成整套西装，进入投委会、董事会或唐家正式场合时才精确收紧完成度。

## 审美基因

- **核心色**：黑、炭灰、墨蓝、纯白与奶油白。
- **角色色**：深咖、烟草棕、琥珀与芥末色，负责把她从连续冷色职业女性中拉开。
- **正式强调色**：深酒红、冷莓红；深青绿或墨绿只低频出现。
- **轮廓**：合体衬衫、薄针织或针织 Polo 配高腰直筒／微阔长裤；外套肩线贴合窄肩，腰部有收束，下装保留行走和久坐余量。
- **材质**：抗皱西装料、棉府绸、细针织、低光泽羊毛混纺和现实皮革；真丝与缎面只在正式或私人场景低频使用。
- **鞋包**：稳定低跟鞋、乐福鞋或简洁尖头鞋；商务包能真实容纳电脑和材料，不用迷你包维持精致幻觉。

## 妆发与配饰

- **发型**：自然黑长发以中分或柔和近中分为主。普通办公可披发、低马尾或简单夹起；重要会议收成干净低马尾／低髻；私人状态可以散开或松束。
- **妆感**：不缩小眼睛，也不靠上挑眼线制造强势。工作妆整理眉形、睫毛根部和肤色；正式场适度加深唇色，仍让大眼和清楚唇峰保持面部中心。
- **唇色**：日常可用裸玫瑰、茶棕红；重要会议或晚宴可用深酒红、冷莓红。
- **首饰**：长耳线、小圈耳环、窄表或单条细链择一；对戒是低频生活事实，不反复承担关系证明。
- **眼镜**：不是固定造型锚点。只有确有屈光矫正或长时间屏幕工作的实际需要时，才偶尔使用无框或细金属框眼镜。
- **气息**：香气如出现，只保留干净木质、微苦柑橘或低频茶木方向，不设固定主题与品牌暗号。

## 场景衣柜

| 场景 | 服装方向 | 调用重点 |
| --- | --- | --- |
| 财务办公／普通会议 | 合体衬衫、薄针织或针织 Polo＋高腰直筒／微阔长裤；需要时加软结构外套 | 日常不穿满套西装；用清楚腰线和长裤维持轻长比例 |
| 预算会／融资会 | 为窄肩定制的短至中长结构西装，内搭纯白或深酒红，高腰长裤 | 肩线准确、面料低光泽；让身体转正时的轮廓变化清楚可见 |
| 投委会／董事会 | 黑、炭灰或墨蓝套装，低马尾／低髻，唇色略深 | 完成度最高但不浓艳；大眼仍是面部中心，权威不靠冷脸 |
| 唐家产业会议 | 延续 CFO 衣柜，提高剪裁与面料完整度 | 她以高管身份出席，不改穿“伴侣社交装”，不靠唐雨宸的资源证明位置 |
| 商务差旅／通勤 | 合体上装＋宽松长裤＋长外套，配耐走鞋和现实电脑包 | 抗皱、可叠穿、能久坐行走；允许衣料折痕和妆面磨损 |
| 唐家聚会／正式晚宴 | 深酒红、黑或深绿长裙／女性套装；方领、不对称领或简洁露肩线三选一 | 腰线清楚、肩颈打开，首饰只留一个焦点；漂亮来自本人而非珠宝价格 |
| 与唐雨宸私人日常 | 琥珀、奶油白、烟草棕针织或吊带式内搭，配高腰牛仔／舒适长裤 | 颜色和材质变软，轮廓仍干净；不把普通居家穿着自动写成亲密邀请 |

## 季节与状态偏移

- **炎热**：无袖针织、清爽府绸、垂坠长裤；减少层叠但保持腰线。
- **降温**：薄高领、长外套和低光泽羊毛；外套不能把窄肩和长颈压成沉重方盒。
- **长会议／差旅后**：头发可以松、袖口和裤线可以起皱，妆面可以磨损；不以永远无瑕证明专业。
- **进入正式判断**：不必临时换装，主要通过扣好外套、收净头发、身体转正和色彩收深完成状态切换。

## 正文调用原则

- 每次只调用一个色彩、一个轮廓或一个配饰，不报完整穿搭清单。
- 优先让服装配合她的身体变化：半侧倾听时外套留出松量，转正后肩线与腰线同时清楚。
- 琥珀／芥末上装与放松牛仔、深色套装与白／酒红内搭，是可重复但不必每次出现的两组高识别组合。
- 产业会议和唐家晚宴必须分开：前者展示 CFO 权限，后者才允许裙装、露肩线与更完整首饰。

## 禁写误区

- 不固定成月白、雾蓝、冷青连续铺开的“清冷模板”。
- 不让满套西装、眼镜、文件夹代替她的职业能力和面容辨识。
- 不用高奢品牌、珠宝价格或情侣装说明职位与伴侣关系。
- 不把合体、露肩或吊带式衣装写成他人越界的原因，也不让她为避免越界承担穿衣责任。
- 不复用仙古服制、令牌、发簪体系、繁复珠翠或附属式豪门华贵套装。
