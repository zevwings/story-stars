# 人物索引

本目录存放人物静态资料。开篇／首次登场实际年龄属于人物主卡中的固定年龄锚点；实力、位置、关系变化、出场记录与观感年龄等动态状态，以 `../context/characters/` 为准。

## 分类入口

- [主要人物](major/_index.md)
- [次要人物](minor/_index.md)
- [预备人物](preentry/_index.md)
- [人物模板](_template/_index.md)（新建人物先建主卡；形象、衣装与角色专属契约档案按调用需要创建）
- 新建人物或改名时，先核对三个分层索引及相关人物主卡；正式姓名、艺名、公开身份名与稳定常用名写入人物主卡，依赖说话者或关系语境的称呼不作为人物实体别名，统一写入对应 `关系/<对象>.md` 的有向称呼表。
- 人物互称不设中央矩阵：按角色进入 `关系/<对象>.md`，在“称呼”表中按“说话者 → 对象”读取。关系档采用 owner-centric 单档，反向查找可运行 `sw rag characters address --speaker <角色>` 或 `--target <角色>`；亲密戏再按关系档指针读取 `../intimacy/characters/`。

## 登记规则

- 本页只负责人物目录路由，不重复登记具体人物。
- 每个人物只在 `major/_index.md`、`minor/_index.md` 或 `preentry/_index.md` 其中一处登记；对应分层索引是人物编号、状态与现有静态卡链接的唯一登记处。
- `M-*`、`F-*` 编号跨三个分层索引全局唯一；人物迁移目录层级时保留原编号。
- `主卡.md` 中的 `CHR-*` 是机器检索使用的永久人物身份：一经分配不得修改或复用；人物删除后保留编号空缺，新人物取全项目下一个未使用编号。`CHR-*` 不另建中央映射表，人物主卡是唯一真源。
- 分层索引按男性人物、女性人物分表，各表按编号数字升序排列；某一类无人时不建立空分组。
- `主卡.md` 是人物建档基础；`形象.md`、`衣装/_GRAMMAR.md` 按稳定调用需要创建，未创建时在分层索引中记为 `—`，不保留空文件。
- 身份、年龄、身形、外貌、衣装、关系与剧情功能等具体资料写入对应人物卡，不在索引中压缩复述；动态状态统一进入 `../context/characters/`。
