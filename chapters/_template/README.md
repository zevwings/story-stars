# 章节模板说明

> 本目录只负责章节包模板骨架。模板存在不代表章节已经发生, 也不得被当作正式章节事实。

## 文件职责

- `outline.md`: 本章结构真源, 承载章节目标、视角与信息边界、人物欲望、主动行动、现场反馈、局面变化、兑现结果、引用真源、创作抓手与通常 0—3 条硬边界；真实绝对边界更多时不得截断。
- `draft.md`: 正文草稿, 可以反复修改, 不自动进入定稿。
- `revision.md`: 修订记录或修改说明, 不替代大纲、正文或摘要。

## 使用方式

- 新建章节包时, 复制需要的模板文件到目标章节目录。
- 章号、目录名和状态必须同步登记到 `chapters/_index.md`。
- 若只需要大纲, 停在 `outline.md`; 临时试排、备选走法和未确认展开进入 `.prewrite/` 或 `.analysis/`；项目启用 `construction` 后，作者已确认且写作时必须继承的执行规格才进入配置的施工真源。
