# 楔子：锦云山结契与最低必要揭密（ch000）

> 本章是五阶段正式展开前的独立楔子，只建立两人的结契、有限发现链与第一次最低必要揭密。大纲不表示剧情节点已经由正文或定稿摘要兑现。

## 本章目标

- 本章功能位（项目使用时）：楔子 / 世界入口 / 既有伴侣关系的第一次异常共处。
- 本章阅读契约及依据：先让读者看见一对已经在交往的年轻情侣夜爬看日出，再让异常从两人的身体反应、行动和有限互证中出现；制度只通过公开救援、内部转介和最低必要说明进入，不用世界观讲解替代现场。正式剧情依据为 `PL-S-303`，`CON-0046` 只提供本次施工边界。
- 主任务：连成“普通夜爬—分别结契—现实异常—公开救援—非公开转介—最低必要揭密—分别决定接受后续评估”的完整因果链。
- 次任务：写出晏林与景雪瑶面对同一未知事件时不同但都具有主体性的真人反应；让有限发现链体现为有人观察、判断、转介和反馈，而不是系统自动识别。
- 章末状态 / 后续接口：两人知道自身异常可能属于需要保密的星辰契约现象，也知道评估、登记、支持与信息代价的大致边界；两人分别决定接受后续评估与登记安排。正式登记、评级、能力复核、控制训练、机密报备和星辰之桥均未发生。

## 视角与信息边界

- 中心视角：晏林，第三人称限知。
- 本章能够确认的事实：晏林直接感知到自己的两颗星辰、两份契约、精神之海与当时已成形的操作路径；他只能从景雪瑶的可见反应、主动表达和有限传念确认她也发生了独立异常；轮值协作者先按现实安全问题处置，随后才启动异常评估转介；管理局联络人只说明最低必要事实与可选后续。
- 本章保持为推断或开放的问题：星辰回应的客观意志；两人在契约者体系中的相对位置；星辰与能力的完整名称、等级和社会后果；管理局的完整结构、星表和其他契约者信息。
- 章末信息状态：两人获得“发生了什么、眼下有什么风险、可以得到什么支持、登记要付出什么信息代价”的最低知识，没有获得全知解释；两人对各自第一人称体验仍拥有最终解释权。

## 人物欲望与现场压力

- 中心人物当前想得到 / 保住 / 摆脱：晏林首先要确认景雪瑶是否安全，同时控制自身双重结构带来的负荷；他想弄清下一步，却不替景雪瑶回答或选择。
- 其他人物或环境当前推动的不同结果：景雪瑶要自己核对新出现的感知，并直接追问异常和后续；轮值协作者要先排除失温、疲惫、药物、疾病或意外；管理局联络人要在不公开泄密、不越过当事人选择的前提下建立评估入口。
- 中心人物率先采取的动作：依照契约自知收束自己的负荷，观察并询问景雪瑶的状态，接受普通安全检查，同时留意救援人员公开说法与实际动作之间的变化。
- 对方 / 关系 / 环境的可见反馈：景雪瑶不只接受照看，也给出自己的感知和判断，必要时纠正晏林的概括；轮值协作者先做普通救援，再把需要保密的判断收进内部联络；联络人给出范围有限但可执行的下一步。
- 双方实际发生的碰撞或拉扯：两人都想迅速理解异常，却必须在身体负荷、公共环境和信息不足中克制试探；机构需要降低现实风险，却不能把救助直接升级为强制检测或登记。
- 章末仍在生效的压力或关系距离：两人的信任仍成立，但任何一方都不能替另一方解释契约或承诺后续；接受评估意味着他们将主动进入一段带有保密与信息代价的制度关系。

## 局面变化

- 改变局面的主动动作：两人分别完成星辰回应并依照自身可知路径收束负荷；轮值协作者在完成公开救援后，把无法用普通风险完全解释的迹象转入异常评估接口。
- 动作引发的可见反馈：公开现场仍按游客身体不适处理，私下联络链开始运作；两人由被动承受异常转为主动核对自身体验并评估制度选项。
- 不能兼得的目标：既不暴露异常又立即获得完整解释；既取得专业支持又完全不留下任何身份或评估痕迹。
- 人物选择与实际代价：两人没有在公共现场逞强离开，也没有把决定合并成情侣共同表态；他们分别接受后续安排，代价是承认风险并允许必要信息进入受限的评估链。
- 形成的新状态：两人从普通观星者变成已被有限发现链接触的疑似新契约者，并拥有一个可继续但尚未实际完成的评估与登记入口。

## 本章兑现

- 情绪或人物落点：惊异不以宏大宣告落地，而以两人仍能互相询问、校正和分别作出决定落地；制度的可信度来自边界清楚的行动，而不是权威口号。
- 本章获得 / 失去 / 暴露 / 确认的结果：确认两份独立回应与晏林的双子星结构；确认异常不是普通幻觉可以完全解释；暴露足以启动最低转介的迹象，但不暴露完整能力结构。
- 兑现结果的动作、物件、反馈或关系变化：呼吸、步态、手部动作、保暖休息、下山安排、公开问话与私下联络共同承载现实层；两人用各自的描述完成有限互证，联络人用选项、代价和停止线完成最低说明。
- 局部结果留下的后果：轮值链和管理局获得处理后续评估所需的最低接触信息；两人记住这套制度第一次对待自己的方式，但不因此欠下私人恩情，也不因此预先信任整个机构。

## 社会关系链

> `[社会关系]` 本章调用的是职责型公共救援与有限转介，不是请托办私事，也不自动形成人情债。一般保暖、休息、下山和普通风险排查属于职责内帮助，不需要被叙述成当事人“授权”；涉及非必要精神检测、正式登记或进一步信息进入制度系统时，才需要两人分别知情选择。

- 现实需求：轮值协作者要在公众环境中保护两人的身体安全并避免泄密；两人需要在无法自行命名异常时获得可信的下一步入口。
- 有效链条：晏林 / 景雪瑶出现可观察异常 → 晴夜轮值协作者按公共职责救援与排查 → 协作者基于近距离迹象启动内部异常转介 → 管理局联络人在非公开环境完成最低说明 → 两人分别决定是否接受后续评估。
- 资源与边界：轮值协作者能做普通救援、安排下山、转入相对非公开的沟通位置并发起职责内联络，不能诊断完整契约、读取精神之海、代替登记或公开泄密；管理局联络人能解释最低事实、风险、支持和可选流程，不能替两人定义第一人称体验或强迫登记；两人能够接受或拒绝后续安排，不能互相代签决定。
- 真人反应形态：协作者先用普通风险语言稳定现场，再通过停顿、改口、缩小围观范围和实际联络表现判断升级；晏林公开配合但私下核对对方知道多少；景雪瑶在身体负荷缓解后主动给出自己的描述并追问；联络人用有限回答和明确停止线建立暂时可信度。具体表情、停顿、错话与补救留给写前施工，不在大纲中定死。
- 办事结果：两人获得后续评估入口，公共现场没有发生揭密、强制检测或正式登记。
- 关系 / 名声 / 知情 / 人情账结果：轮值协作者只知道异常评估所需的最低信息；两人对管理局形成谨慎而有限的第一印象；职责内救援不生成人情债，后续安排也不等于永久合作或扩大信息使用范围。

## 关键场景

### 场景一：日出之前仍是一次普通约会 - 约 15% 篇幅

- 人物欲望 / 场景目标：晏林和景雪瑶按原计划完成夜爬、等待日出；用现实安排证明两人的伴侣关系早已成立。
- 主动动作：两人分配体力、确认路线与时间，在普通游客和观景平台秩序中找到位置。
- 对方 / 关系 / 环境反馈：两人的照顾方式并不完全同步，景雪瑶会表达自己的节奏和选择；山风、困意、呼吸与仍可目视的星空提供现实压力。
- 人物选择与代价：为看到日出继续停留，但不过度消耗体力；不把此地当成神秘召唤地点。
- 场景结果 / 推向下一场的变化：黎明尚未遮蔽真实星空时，注意力从日出等待转向各自无法忽略的星辰回应。

### 场景二：两份独立回应同时压入现实 - 约 25% 篇幅

- 人物欲望 / 场景目标：晏林先稳住突然成形的双重结构，同时确认景雪瑶是否也发生异常。
- 主动动作：晏林依照契约自知收束自己的精神负荷；景雪瑶依照自己的路径处理自身回应，并主动说明她能确认的部分。
- 对方 / 关系 / 环境反馈：两人的异常都落在呼吸、姿态、动作失准或短暂失神等现实可见层面，但彼此不能直接替对方命名；周围人只能先理解为常见身体问题。
- 人物选择与代价：两人不冒险继续试验新能力，先保留行动能力并互相核对；代价是接受自己暂时无法解释这一切。
- 场景结果 / 推向下一场的变化：他们确认不是单人幻觉，却也出现足以引来同行者或轮值人员关注的现实异常。

### 场景三：伴侣互证不是替对方解释 - 约 15% 篇幅

- 人物欲望 / 场景目标：在外人介入前，尽可能区分共同现象与各自体验。
- 主动动作：晏林问具体可观察状态而非给景雪瑶下结论；景雪瑶陈述自己的感觉、纠正不准确概括，并反过来核对晏林的双重负荷。
- 对方 / 关系 / 环境反馈：两人原有默契减少恐慌，却不能消除感知差异；身体和环境压力迫使他们停止内部讨论。
- 人物选择与代价：接受公开帮助，而不是为了守住异常秘密拒绝现实救援。
- 场景结果 / 推向下一场的变化：轮值协作者以普通救援身份接手，情侣之间的私人互证暂时让位于现实排查。

### 场景四：公开救援先行，异常转介后置 `[社会关系]` - 约 25% 篇幅

- 人物欲望 / 场景目标：轮值协作者先排除可以立即伤人的普通风险，同时判断是否需要启动不能公开说明的异常接口。
- 主动动作：协作者安排保暖、休息、下山和普通风险询问；在近距离迹象无法被常规解释完全覆盖后，以职责内渠道联络异常评估接口。
- 对方 / 关系 / 环境反馈：晏林和景雪瑶配合普通检查，但分别保留对自身体验的解释；协作者公开话语保持日常，实际行动逐步缩小知情范围，不向围观者泄露判断。
- 人物选择与代价：协作者不以“可能异常”为由跳过普通救援，也不因无法公开解释而装作没看见；两人接受转入非公开沟通，代价是最低接触信息进入评估链。
- 场景结果 / 推向下一场的变化：身体风险先得到处置，公共现场没有揭密；一名职责明确的管理局联络人获得与两人进行最低说明的入口。

### 场景五：最低必要揭密与两次独立决定 - 约 20% 篇幅

- 人物欲望 / 场景目标：两人要知道异常的基本性质、现实风险和下一步代价；联络人只给出足以支持选择的信息。
- 主动动作：联络人分别说明契约现象、保密原因、可提供的评估与支持、登记进入官方星表的信息代价，以及拒绝登记不自动构成犯罪的边界；晏林和景雪瑶各自追问与自己有关的问题。
- 对方 / 关系 / 环境反馈：联络人承认机构不知道两人的完整第一人称体验，也不声称是机构教会了他们基础操作；有限回答使两人能够判断，而不是要求盲信。
- 人物选择与代价：晏林与景雪瑶分别决定接受后续评估与登记安排；这只是一项可撤回到具体流程边界的下一步决定，不扩大为对未来全部检测、信息使用或合作的概括许可。
- 场景结果 / 章末状态：楔子停在选择已作出、正式流程尚未开始的位置；既不预演后续前史，也不制造五阶段案件钩子。

## 需要回收的设定 / 伏笔

- 晏林的双子星两契同时成立，但本章只写他能直接确认和当场收束的部分，不展开完整权柄表。
- 景雪瑶拥有独立回应、独立操作自知和独立选择；她不是晏林异常的旁证或附属后果。
- 公开救援与私下异常评估之间存在由真人判断完成的有限接口，为后续管理局制度现实提供第一处可追溯经验，但不承诺紧接下一章回收。

## 创作抓手

- 写活动作、空间或物件：夜爬节奏、山风、呼吸、观景平台的人流距离、头灯或手机光、保暖与下山安排；物件按现场需要择取，不把锦云山写成玄幻祭坛。
- 写活人物之间的反馈与关系距离：让两人用询问、答错、纠正、暂停和分别表态表现既有亲密；让协作者通过公开话术与私下行动的差异表现职业判断。
- 允许正文自由发挥的细节：一次性岗位称呼（不新增持续角色）、具体公共身份称谓、常规救援物件、下山交通、非公开沟通空间与逐句对白；新增细节不得扩大其权限或制造私人请托、人情债和强制检测。

## 硬边界

- 锦云山望江峰是普通公共观景平台；两人在黎明前仍能目视真实星空时分别结契，关系在结契前已经成立。
- 全章保持晏林单一限知视角；两人只拥有各自的契约自知，轮值人员只凭现实症状和最低迹象行动；公开救援必须先于私下揭密，现场不得强制精神检测、登记或拘捕。
- 章末只到两人分别决定接受后续评估与登记安排；不得完成登记、评级、能力复核、控制训练、机密审批、星辰之桥或五阶段案件接口。
