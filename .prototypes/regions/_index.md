# 地区原型索引

> 本页只登记已经开始分析或已经确认的地区原型；地区正式事实仍以 `worldbuilding/regions/` 为准。

现实原型、对应关系与现实专名只在本目录维护。正式真源只保存架空名称、内部空间关系与已经确认的城市功能，不反向引用本目录。

证据等级分为三类：

- **显式映射**：迁移前的正式文件曾直接登记现实对应，可视为既有创作决定。
- **高置信分析**：由名称、空间组合与功能共同指向，但项目没有留下直接拍板记录。
- **复合候选**：只能识别多个参考簇，不应收束为单一现实地点。

原型隔离与专名碰撞是两件事：本项目当前执行的是“现实原型名不进入正式真源”，不要求架空专名与所有现实历史称呼绝对零碰撞。“江州”“云间”“兰纳”的历史同名风险保留在各自原型档供回查，但不构成当前改名任务；只有作者另行提高命名标准时才启动高半径改名。
