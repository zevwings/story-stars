## 总体结论

- [角色优化] 章若楠承担温婉的主要面容结构、表情动态和基础视觉气质，不再降级为“局部相似”或“部分面容参考”。
- [图片支持] 主要迁移上中部舒展而下半脸收口的小脸、清亮圆杏眼、紧凑鼻唇、不笑时清醒直接以及笑开后整张脸明显变亮的状态变化。
- [视觉推断] 原型最有价值的视觉气质是柔和、清亮、没有主动攻击性，但中性表情并不迟缓、困倦或软弱。
- [角色优化] 温婉的职业动作、警务成熟度、虚构身材、制服状态和私人衣装独立设计；它们负责把高识别面容转化为小说角色，不负责削弱原型。
- [角色优化] 正式卡必须允许她第一眼就很漂亮。不能因为她是正式民警、主要配角或不进入伴侣结构，就把她降成普通耐看型职业女性。

### 精修与高完成度素材

- [角色优化] 不再把精修、美颜、调色或完整妆发视为排除条件。
- [视觉推断] 高完成度照片负责确定角色应当漂亮到什么程度，以及黑发、肤色、眼唇、脸型和造型如何共同放大识别。

- [图片支持] 正面、四分之三、低头、说话、笑开和全身活动素材负责校验稳定结构、表情顺序和动作。

- [角色优化] 两类素材权重并存：高完成度决定美感上限，多角度动态决定结构连续性。

## 跨素材稳定特征

### 面容结构

- [图片支持] 脸长中等，上中部相对舒展，面颊有柔润体积，下颌从面颊下方较快收向小巧下巴。
- [视觉推断] 稳定识别不是“短圆脸”或“尖瓜子脸”，而是正面柔润、下半脸明显收口的轻心形关系。
- [图片支持] 颧区不靠外突制造锋利，笑时面颊体量会明显增加。
- [图片支持] 鼻部紧凑、鼻尖保留圆度；唇峰清楚，下唇有柔软体积。

### 眼睛与表情

- [图片支持] 眼睛为开度清楚的圆杏形，眼轴平直至轻微上扬；中性状态可以直接、稳定地看向对象。
- [图片支持] 笑容不是只抬嘴角。面颊先发生变化，随后眼下收紧、眼睛弯起、唇角打开。
- [视觉推断] “不笑清醒、笑开骤亮”比“永远甜”“缓落注视”更能保留原型识别。
- [视觉推断] 高完成度妆发可以显著提高漂亮程度，但不需要把圆杏眼拉长、下颌削尖或鼻尖改锐。

### 发貌、肤色与视觉气质

- [图片支持] 深色头发与明净偏白的面部形成稳定高对比，能同时承载淡妆和高完成度妆造。
- [视觉推断] 露额或收发状态更适合温婉的正式民警身份，也能把眉眼和额面完整交给镜头。
- [视觉推断] 原型的柔和来自面容和表情活动，不等于低反应、困倦、无边界或持续照顾他人。

### 身形与衣装证据边界

- [待确认] 公开样本不用于推导章若楠的现实身高、体重、围度或罩杯。
- [角色优化] 温婉的身体数据全部是虚构制衣设计：170 cm、52—53 kg、约 85/70/63/90 cm、70C。
- [角色优化] 私人衣装借用的是高完成度、清亮色面和年轻比例，不复刻活动礼服、影视造型、品牌单品或现实穿搭身份。

## 原型迁移职责

### 原型负责

1. 上中部舒展、下半脸快速收口的轻心形小脸。
2. 清亮圆杏眼、紧凑鼻唇和深发浅肤形成的面部高对比。
3. 不笑时清醒直接，笑开时面颊、眼周和嘴部依次发生变化。
4. 柔和、清亮、没有主动攻击性，但并不迟缓或软弱的基础视觉气质。
5. 淡妆与高完成度妆造下仍能保持同一张脸的漂亮上限。

### 角色化优化

1. 露额轻侧分或自然中分作为稳定发貌，警务场使用低马尾、低束或盘束。
2. 以“分区—退回—转交”建立综合研判民警的职业动作。
3. 将私人松弛限制在坐姿、动作密度和非紧急回应，不影响警务反应。
4. 虚构身材采用 170 cm、52—53 kg、85/70/63/90、70C 的纤秀轻曲线。
5. 制服完整合规，私人衣柜保留奶白、雾蓝、浅牛仔、烟粉与莓红等清亮漂亮，不降成全套实用暗色。
6. 灵犀没有瞳色、光效、动物纹样或动物簇拥等稳定外显。

### 明确不继承

- 章若楠的身份、出生日期、经历、职业、性格、关系、公众评价与现实身体数据。
- 影视角色、台词、表演身份、活动礼服、品牌合作和具体造型。
- “初恋脸”“治愈系”“清纯”等营销标签。
- 由单张照片推导的性格、警务能力、生活习惯和关系倾向。
- 精修图中的具体瘦脸、透视、滤镜和失真五官；保留美感上限，不复刻技术形变。

## 虚构角色结果

### 面容

- 中等长度轻心形小脸，额头饱满，上中部舒展，下颌快速收口。
- 清亮圆杏眼，眼白与深瞳对比清楚；自然柔直眉。
- 紧凑鼻部、圆润鼻尖、清楚唇峰和略柔满下唇。
- 明净偏白中性肤色，自然黑至极深棕长发，稳定露额。
- 不笑时清醒直接；真笑时面颊先抬，随后眼睛和唇角完整亮起。

### 身形

| 项目 | 虚构结果 |
| --- | ---: |
| 身高 | 170 cm |
| 体重 | 52—53 kg；基准 52.5 kg |
| 肩宽 | 约 38 cm |
| 胸围 | 约 85 cm |
| 下胸围 | 约 70 cm |
| 腰围 | 约 63 cm |
| 臀围 | 约 90 cm |
| 罩杯参考 | 70C |

- 纤秀轻体量、腰腹薄净、胸部曲线适中、髋腿不丰厚但线条完整。
- 肩背、核心和下肢只保留现实训练所需的薄而连续的稳定性，不发展成行动型肌肉。
- 制服收住身体轮廓，私人合身衣装才呈现清楚腰线与自然轻曲线。

### 视觉状态

- **第一眼**：明确漂亮，露额深发、圆杏眼和小巧下半脸先进入画面。
- **外人面前**：嘴角中性、目光直接、距离完整，不以陪笑承诺额外责任。
- **工作状态**：材料分区、缺项停笔、文件退回；动作紧凑及时。
- **熟人私下**：坐姿下沉、动作减少、头发披下或夹起；真笑完整出现。
- **情绪泄漏**：笑意先撤、解释缩短、材料更快回到责任人一侧。
- **灵犀使用**：先普通观察，再低位侧向接近并保留动物退路；无视觉特效。
