## 面部与角色转译

以下结论只用于面部与妆造，不延伸到真人身体。

### 面容骨相

- 多组样本稳定呈现**窄小鹅蛋偏柔心形**：额头完整但不过宽，颧区不外扩，下半脸从颧下开始干净内收，脸宽与下颌体量都控制得很紧。
- 下巴小而精致，正面仍有圆钝底，不是削成点状的尖 V；斜侧能看见连续的下颌转折。
- 显小感主要来自紧凑脸幅、平滑颧颊软组织、醒目的眼面比例与笑开后的面颊变化，不等于儿童式短面中或未发育轮廓。
- 童颜高保真采用“窄小鹅蛋偏柔心形＋小而有圆底的下巴”，保留正常面长和完整鼻唇段，不为避撞型改成普通长脸。

### 眼睛、眉鼻唇与笑容

- 眼睛偏大且横向长度明确，是醒目而非幼圆的杏眼；内眼角清楚，眼尾轻微上提，深瞳与清楚睫缘共同形成聚焦感。
- 眉形平直、眉峰低，眉尾自然收细；鼻梁窄直，鼻尖小而带圆度，不采用明显上翘鼻；唇峰清楚，下唇饱满，唇宽与窄面协调。
- 不笑时嘴唇自然闭合，目光可以稳定对镜头，不呈持续求助感；轻笑先从嘴角和面颊启动，笑开后下眼睑才明显收窄。
- 童颜紧张时先压住唇线、确认对方是否说完；准备开口时下颌松开，目光回正，再提出完整问题。
- 把“清甜笑意”改成具体顺序：确认答案 → 呼气 → 嘴角抬起 → 面颊和下眼睑跟上 → 笑声出来。笑不是常驻表情，也不以缩肩、歪头或睁大眼睛加强年龄反差。
- 结构样本没有重复显示位置稳定、可核验的浅色小痣；正式设计删除这一通用装饰，不让它替代面容结构。

### 肤色与皮肤质感

- 自然结构层无法由活动粉底、采访灯光和美颜确认精确冷暖；理想化审美层则稳定指向明亮、匀净、细腻的成片肤感。
- 童颜采用中性偏明亮的白皙底色与清透成片上限；近景仍保留毛孔、唇部干湿、通勤日晒与季节变化，不把“漂亮”误写成塑料无瑕。
- 疲惫、睡眠不足和伤痕只作为阶段状态与现实后果，不构成稳定审美锚点。

### 身形与体态

- 中等身量、中小骨量；肩宽偏窄但不塌，胸廓紧凑而非极窄。
- 上身可以明显丰满，但降为轮廓特征，不承担第一辨识位。
- 腰腹保留呼吸、久坐和弯腰时的自然起伏；骨盆、臀腿与足底具有足够承重体量。
- 手腕、脚踝可以纤细，但不以四肢纤细证明全身娇小。
- 早期后脚朝向出口、包不离手和轻收肩背属于环境警觉；不能自动解释为回避身体注视。
- 获得安全后，重心应逐渐落进座椅和骨盆，步幅、转身和主动取物范围同步扩大。

### 动态气质

- 核心不是“怯生生”，而是“先确认，再开口”。
- 她看完门、人员和距离后，会把目光重新放回交谈者，并提出具体流程、结果或时间问题。
- 安全后的高反馈来自问题增多、笑声出来、主动换位置和开始自己的事情，不只是黏近某个人。
- 独立后能够看时间、起身、背包、赶车、上课或继续自己的工作，不等待别人宣布场景结束。

### 妆造承载力

- 原型在淡妆、活动妆和精修成片中都依赖窄脸、大而横向舒展的杏眼、清楚唇峰与深发量成立；妆容可以提高精致度，但不应改掉这些核心比例。
- 日常以清楚睫缘、平直低眉峰和自然水红唇保持辨识；正式场允许更匀净的底妆、精细眼线与鲜明但不压暗的唇色，把漂亮上限直接拉高。
- 深色丰量长发为稳定发貌，优先中分或柔和侧分、露出额头，长度到肩胛附近；半束发和自然大弧度可提高完成度，厚重齐刘海不作为常态。

## 身体参数审查

### 成年骨架与轮廓

- 165 cm 保留为中等身量 形成轻而不失完整承重的成年轮廓。
- “小骨架”校准为“中小骨量”：肩线适度偏窄但不缩成极窄，胸廓紧凑且保留正常前后深度。
- 明显沙漏由丰满上身、清楚腰线和有体量的骨盆臀腿共同成立，不采用上重下轻的拼接比例。

### 重心、承重感与自然软组织

- 胸部具有自然重量，穿戴承托衣物前后轮廓会变化；不固定为高位、圆球状或自行悬浮。
- 腰腹和臀腿保留自然软组织，坐下、呼吸、弯腰和转身时允许真实变化。
- 成年感来自完整身体重量和动作控制，不来自胸围大小。

### 对活动与衣装的影响

- 丰满上身如果保留，日常需要正确尺码和稳定承托，但不能无依据地赋予背痛或其他健康问题。
- 跑步、体育课和快速移动需要高支撑运动内衣。
- 梭织上装按胸围选码后，可对肩宽、袖窿和衣长进行正常改衣；针织需要弹性和恢复性。
- 校服、衬衫、针织和运动装不得通过绷扣、透肤、错误尺码或失去活动余量制造展示。
- 早期收肩首先属于环境警觉；若某场确实因被注视而回避，必须写清具体触发，不与前者混写。

### 现有数值

- 96 cm 胸围减 71 cm 下胸围为 25 cm，在一种常见罩杯算法下可以对应 G 杯，数值并非算术矛盾。
- 罩杯随品牌、测量方法和胸型分布变化，不适合作为稳定小说事实。
- 已确认虚构制衣基线为 **165 cm／96-71-65-94 cm／约 70G**；不同品牌试穿可落到 75F 等相邻尺码。
- 这是一组明显审美优化、现实中较少见但结构可成立的紧凑沙漏，不用真人图片证明，也不在正文集中报数。
- 70G 保留为内部合体参考而非正文标签；自然胸型必须有底盘、重量与承托变化，臀围 94 cm 和正常腿部软组织负责平衡整体重心。

## 视觉状态层

### 第一眼

- 第一眼同时包含年轻与成年：柔长窄鹅蛋和面颊软组织使她显小，闭口时稳定的视线、正常面长与清楚下颌转折把年龄感拉回年轻成人。
- 她会先短暂确认门、人员和距离，再把注意力完整还给交谈者。
- 手机、证件或钥匙掌握在自己手里，站姿有真实落地感。

正文接口：

> 她的面颊还留着年轻的柔软，下颌却收得干净而清楚；看过门锁后，那双横向舒展的深色眼睛稳稳转回来。

### 外人面前

- 确认出口、门锁、人员手位、座位和流程标识。
- 早期后脚保留退路，包在伸手可取的位置，优先选择能看见门的座位。
- 保持约一臂距离，询问具体流程、结果、时间和下一步，不只寻求抽象保证。

正文接口：

> 她看完门和走廊，才把目光重新放回值班老师脸上：“如果今天补不齐材料，最晚什么时候还能交？”

### 熟人私下

- 目光停留变长，问题变多，笑声真正出来。
- 肩向下松，重量落进骨盆和椅面，包可以放远，手脚不再全部收拢。
- 能背对门坐，主动拿水、开窗、换位置或开始自己的事。

正文接口：

> 她把钥匙放到桌角，书包从膝上挪到旁边的椅子，腰背才真正靠下去。

### 情绪泄露

- 害怕被拒绝时先说“没关系”，目光却没有离开；手先碰包带或手机，身体停在留下与离开的交界。
- 真正想要时反而直视并把目的说清；主动敲门、说明来意、等待回答。
- 被拒绝后仍能自行拿钥匙、离开或继续个人安排，拒绝不会让她退回没有生活能力的状态。

## 成长阶段的视觉变化

### 受控时期

- 环境扫描频繁，动作幅度缩小，物品不离手。
- 后脚保留退路，坐下前先确认门；这是保护姿态，不是稳定柔弱气质。
- 不把伤痕、睡眠不足、含肩、制服或被控制状态写成审美焦点。

### 暂住与生活重建时期

- 仍会看门，但开始询问生活规则、把日用品从包里拿出来、在固定位置充电和晾衣。
- 物品不再随时保持可打包状态，是比“笑得更甜”更重要的安全变化。
- 坐姿开始舒展，但面对陌生流程仍保留现实警觉。

### 恢复教育和个人日程后

- 书包、交通卡、课程表、闹钟和同学消息进入动作链。
- 她会因为赶车、作业、课程或朋友邀约主动结束谈话。
- 学生证和校服只承担出入、教育身份与稳定日程，不承担低龄反差。

### 拥有现实离开能力后

- 进入空间后不再每次完整扫描；能按熟悉程度选择座位和放置物品。
- 看时间、起身、背包、独自出门和返回成为稳定成年动作。
- 可以主动表达成人欲望，也可以在拒绝后保留自己的当天安排。
- 成长不写成越来越敢展示身体，而写成选择、进入、停留和离开都由本人完成。

## 最终辨识锚点

1. **窄小鹅蛋偏柔心形与醒目眼唇比例**：下半脸干净收束，小下巴保留圆底；大而横向舒展的深色杏眼轻抬眼尾，清楚唇峰与饱满下唇使闭口状态也有辨识度。
2. **先找路，再组织具体问题**：确认出口、人员和距离后，把目光完整还给交谈者，并开口询问流程、结果或时间。
3. **闭口凝视到整张脸笑开**：安静时目光稳、唇线闭合；确认安全后先松嘴角，再抬面颊、收下眼睑，笑声最后出来。独立后这一变化不再依赖某个人许可。

三个锚点均不依赖胸部。明显沙漏是稳定成年身体轮廓，但不是唯一辨识来源。

## 发型、妆容与衣装

### 发型与妆容

- 深棕至黑色丰量长发，长度到肩胛附近；中分或柔和侧分露出额头，保持原型面部轮廓的高辨识度。
- 学习和劳动时低束或完整扎起，安全私下可自然散开，正式场可半束或整理出大弧度。
- 不把刘海、编发、发夹或长发作为少女感证明。
- 日常使用素颜或极淡妆，保留真实肤质；正式场可整理眉形、均匀肤色并使用清楚水红、莓红或其他不压暗眼面比例的唇色。
- 不通过锐利眼线、重修容或浓艳红唇强行制造成年感。

### 场景衣柜

| 场景 | 候选处理 |
| --- | --- |
| 受控时期 | 衣物由场所安排，只表现“不属于她”和功能受控；不通过错误尺码、透肤、绷扣或伤痕制造画面吸引力。 |
| 暂住初期 | 少量耐洗单品反复组合，尺码正确；拥有自己的抽屉、洗衣顺序和替换内衣比昂贵采购更重要。 |
| 复学／学校 | 先确定学校真实制服体系；按规定穿着，必要时选择适合胸围的上装并正常调整肩宽、袖窿和衣长。学生证、书包和雨具只服务教育与日程。 |
| 学习／图书馆 | 适合久坐、抬臂、背包和通勤；正文写查课表、推袖口、收头发和换座位，不以胸线为焦点。 |
| 劳动／整理 | 袖口、发丝、鞋底和口袋服从动作安全；承托稳定，不以汗、旧衣或经济困难建立情色感。 |
| 普通日常 | 建立可洗、可重复、能独自补购的基础衣柜；颜色不长期锁在浅粉、浅紫和奶白。 |
| 朋友外出 | 能试穿、比较预算、拒绝不舒服尺码并接受朋友意见；晏林只是反馈来源之一。 |
| 正式场合 | 通过肩线、面料和合体程度提高完成度，不突然化成成熟名媛，也不依赖低领和深唇。 |

### 衣装成长回路

候选回路：

> 被安排 → 学会维护自己的物品 → 建立预算与日程 → 按场合和身体需要选择 → 决定何时、向谁以及是否展示。

保留“从衣服由别人安排，到自己选择如何被看见”的原意，但不把成长过度组织在男性观看周围。学校、朋友、劳动、预算、通勤和个人日程必须共同塑形衣柜。
