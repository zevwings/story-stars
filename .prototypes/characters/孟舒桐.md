## 1. 总体判断

- 评估重点是识别度与漂亮程度，不以“是否精修”作为淘汰标准。
- 精修肖像、正式妆发和活动成片负责确定理想形象与漂亮度上限；公开视频和现场图负责校验哪些脸部关系、表情变化和身体重心能够跨状态存续。二者职责不同，不互相否定。
- 杨雨潼最有价值的不是抽象“清秀感”，而是紧凑柔和的脸、偏大的圆杏眼、饱满面颊、快速收窄但不尖削的下半脸，以及笑开后全脸同时活动的组合。
- 这套组合在精修头像、采访、直播与活动动态里具有足够稳定性，能够承担孟舒桐的主要面容识别；若只保留“面中有软组织、笑时颊部变化”，会把原型削弱成通用年轻女性。
- 孟舒桐的实际年龄、虚构身体、职业动作、户外测试痕迹、私人衣柜与创始人承担感由角色事实独立设计。这些优化不削弱强主视觉原型，而是让原型面容进入小说职责。

## 2. 正式人物事实与改造边界

以下内容来自正式人物与组织真源，不属于真人推断：

- 孟舒桐是野人户外联合创始人、设计与产品总监，已有约五年创业与产品协作经验。
- 她负责服装、帽子、软性配件、品牌视觉、品类统筹与产品整体表达。
- 她与晏林共同评审需求，但不替代产品经理对用户、场景、测试目标和优先级的判断。
- 她参与核心鞋履外观与使用场景评审，不负责鞋楦、底模和量产工艺签字。
- 她与方成越为稳定伴侣、共同创业者，私人关系不替代专业结论。
- 野人服务城市至近郊轻徒步，不进入专业高山硬壳和极端环境装备。

由此确定：

- 面容保留杨雨潼的明亮、柔和与高辨识结构，不为了“设计总监”改成长脸、细眼、冷脸或老成面容。
- 职业成熟度由观察顺序、样衣动作、结论承担、身体承重和场合妆造建立。
- 身材不复制真人公开数据；虚构为170 cm、中等骨架、胸廓与臀腿有支撑的成年体型。
- 衣装分为私人日常、工作评审、品牌商务与轻户外测试四套系统，不把山系品牌颜色穿成个人制服。

## 4. 强主视觉原型的识别锁

以下五项必须成组保留；只保留其中一两项仍会退化为“部分相似”：

1. **紧凑柔心形短椭圆脸**
   - 上半脸与面颊舒展，下颌从面颊下方较快收窄，下巴短而圆润。
   - 不改成长鹅蛋脸、窄长脸、方下颌或尖削锥子脸。

2. **偏大的圆杏眼**
   - 眼睛纵向开度醒目，外眼角接近水平，双眼皮线自然可见。
   - 正式妆可以加强睫毛和眼唇对比，但不拉成细长凤眼或锐利猫眼。

3. **饱满面颊与短下半脸**
   - 苹果肌与面中软组织支撑在笑与说话时仍然存在；下半脸收得快但不薄。
   - 不用过度瘦脸、阴影和尖下巴制造“高级感”。

4. **纤细鼻部与圆润鼻尖**
   - 鼻梁清楚但不粗重，鼻尖小而带圆，不是强雕塑感的攻击性鼻型。
   - 鼻部为眼睛和笑容提供中轴，不升级成第一视觉焦点。

5. **宽幅笑容与明亮—专注切换**
   - 真笑时面颊先抬、嘴角横向打开，随后眼睛变窄；说话与听人时口型、目光和头部都有活动。
   - 孟舒桐进入判断状态时，让笑意完整停止、目光落到结构点，不用眯眼和冷脸替代职业专注。

## 5. 虚构优化结果

### 年龄与面容

- 孟舒桐当前28岁，具体数字进入动态状态。
- 静态视觉年龄为26—29岁：笑开和私人状态偏向下沿，工作判断与正式商务偏向上沿。
- 肤色为中性偏白、清透有血色；正式妆造可达到接近瓷白的高完成度，户外允许出现晒热、汗意与正常色差。
- 头发为深黑棕中长发，锁骨以下至肩胛上缘；稳定造型露出额面，工作与测试常用中高马尾，厚齐刘海不作为长期造型。

### 虚构身体

| 项目 | 确认结果 | 设计作用 |
| --- | --- | --- |
| 身高 | 170 cm | 中等偏高，保留正式全身纵线但不与更高角色争夺身高标签 |
| 肩宽 | 约39.5 cm | 支撑准确肩线、外套与样衣评审动作 |
| 胸围／下胸围 | 约89／74 cm | 成年上身有支撑，供衬衫、西装与礼服结构参考 |
| 腰围 | 约66 cm | 腰线清楚但不追求极端纤细 |
| 臀围 | 约94 cm | 建立稳定下盘与裤裙承重 |
| 内衣参考 | 75C | 只供虚构内搭、礼服和制衣参考 |

- 身体为中等骨架、肩背清楚、腰胯完整的成年曲线，不复制真人身体，也不使用统一纸片模板。
- 能承担反复站立、蹲起、样品搬动和近郊轻徒步；不发展成专业高山运动员。
- 数值只服务制衣、生图和连续性，正文不逐项报数。

### 体态与职业动态

- 公开场合知道怎样站进完整构图，肩颈打开、重心居中，不因是配角就躲到人群边缘。
- 样衣评审遵循“退开看整体—要求试穿者运动—靠近查结构—给出取舍”。
- 面对供应商把样品放在双方中间，讨论落到材料、动作、成本、交期与责任边界，不靠气场词或声量。
- 户外测试根据路况缩短步幅、降低重心，只测试城市至近郊轻徒步产品。
- 私下肩腰松开、笑容完整打开，可以靠近熟人但不缩小身体，也不取消专业独立。
- 情绪泄漏顺序为笑意停止、视线停在样品、同一段边缘被压平两次、语言缓冲减少。

## 6. 四套衣装系统

### 私人日常

- 核心色为暖骨白、墨蓝、旧黑、炭灰和烟草棕；茶玫瑰、珊瑚红、深酒红与氧化铜可直接承担提亮和漂亮度。
- 稳定轮廓为露出脸与颈线的领口、相对合体的上装、有长度和重量的直筒裤或长裙。
- 旧棉衬衫、针织、牛仔、羊毛外套、平底皮鞋和普通运动鞋都可进入，不要求每件衣服带户外功能。

### 工作与样衣评审

- 选轮廓清楚、可蹲起、可抬臂、不会干扰样品观察的上装与裤裙。
- 发型常用中高马尾，鞋履以平底皮鞋、薄底训练鞋或耐站短靴为主。
- 软尺、剪刀、色卡和布样只在任务需要时出现，不做挂件、首饰、手茧或职业身份证明。

### 品牌与商务正式场合

- 允许结构连衣裙、完整西装、长裙、本季重点设计件、清楚唇色、完整睫毛、盘发或高马尾与正式首饰共同提高完成度。
- 不机械限制视觉焦点数量，也不为证明现实或专业主动降低精修、正式妆与漂亮构图。
- 一至两件品牌单品可以和成熟城市衣装共同完成整体，不把本人穿成产品陈列架。

### 轻户外测试

- 只把本轮测试件作为变量，其余使用熟悉旧装备。
- 产品范围为快干上衣、轻量徒步裤、防晒外层、轻量风衣、轻薄保暖层与低帮／中帮轻徒步鞋。
- 不使用专业高山三层硬壳、冰雪技术鞋和重型登山靴冒充野人现有能力。

## 7. 职业道具清理

| 旧元素 | 处理结果 | 原因 |
| --- | --- | --- |
| 腰间软尺挂件 | 删除 | 软尺是具体尺寸复核工具，不是设计总监首饰 |
| 随身裁剪剪刀与食指薄茧 | 删除 | 裁样、打版并非她的常驻职责；职业动作应落到评审与取舍 |
| 左耳下小痣 | 删除 | 无原型证据，也会和真正有效的面容结构争夺辨识 |
| 固定抓夹与卷袖 | 降为情境动作 | 只在头发、温度或操作需要时出现 |
| 色卡与布料常驻手中 | 降为场景工具 | 材料评审时调用，不作为永久造型 |
| 雪松、苔藓、新布料气味 | 删除固定设定 | 前两者是山系包装，后者属于现场环境 |
| 苔绿、竹青、燕麦私人制服 | 删除 | 品牌季节色不能吞掉个人审美 |
| 专业高山硬壳与重型登山靴 | 删除常态 | 越过野人城市至近郊轻徒步产品边界 |

- 去重不通过降低孟舒桐的美貌、妆造完成度或原型相似度完成。
- 面容结构、身体比例、表情切换、职业观察对象和动作顺序共同承担差异。
