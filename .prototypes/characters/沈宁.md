## 总体判断

- **朱珠应当作为沈宁的完整高识别视觉底板，不做“部分相似”的降格迁移。**
- 最有价值的是一整套互相增益的组合：柔润舒展的鹅蛋脸、浓眉长眼、挺直鼻梁、丰润唇形、笑开后出现的一对梨涡、丰厚偏分黑发、醒目腰线、成熟曲线，以及艳丽与松弛同时成立的动态。
- 沈宁保留这套成熟浓艳的漂亮，不以职业身份遮蔽；管理局副局长的可信度由履历、判断、站位和签责动作建立。
- 原型负责“看上去是谁”，角色经历负责“她为什么这样站、这样看、这样作出决定”。两者叠加，不用职业化消解原型辨识度。

## 原型的完整视觉识别组合

### 面容骨相

- 脸型是舒展柔润的鹅蛋形，略带心形收势。额头饱满，颞部和颧区过渡完整，面中有成熟软组织，下颌柔和内收而不削薄。
- 正面漂亮来自额面、眉眼和面中共同展开；转侧时才由鼻梁、唇峰和下颌收势补出精致感。
- 这张脸的识别度不依赖极小、极窄或极尖，而在“丰润但不钝、舒展但不松散”。

### 眉眼、鼻唇与笑态

- 眉毛浓密、有自然弧度，眉尾清楚；它与深色头发共同构成面部上半区的高对比。
- 眼睛偏长，同时保留明显纵向开度，属于大而长的杏眼；外眼角轻扬，放松时有慵懒感，直视时则明艳清醒。
- 鼻梁挺直清楚，鼻尖精致但保留圆度，不是细削刀锋型。
- 唇峰鲜明，上下唇都有体积，下唇尤其丰润；深玫瑰、浆果和复古红能强化识别，但淡唇时唇形本身仍然成立。
- 笑意通常比目光慢半拍出现；真正笑开后，眼睑、面颊和嘴角一起变化，嘴角下方的一对梨涡随之显出，艳丽会迅速转为鲜活亲近。

### 黑发、肤色与浓艳对比

- 丰厚深色发量是核心识别资产。偏分长发和大幅波浪最能完成标志性成像，束发、盘发和短发只改变正式度，不消灭面容辨识。
- 白净明亮的肤色与黑发、浓眉、清楚眼线和丰唇形成鲜明对比。
- “浓颜”不是需要拆掉的公众标签，而是面容结构、发量和妆造对比共同形成的有效设计结论。

### 身形与体态

- 识别核心是纤长比例里有成熟曲线：肩颈舒展，胸腰胯过渡完整，腰线醒目，身体不是清直纸片。
- 静止时不会持续绷紧肩背，站姿有松弛和轻微侧转；这种柔和流动与高完成度礼服并不冲突。
- “漂亮”来自长线、曲线和松弛共同成立，而不是只靠裸露或单一围度。

### 动态气质

- 看人时目光会停得略久，却不形成逼视；笑意后到，肩颈和嘴角先后松开。
- 转头、侧身和走动时保持流动感，身体不会像军姿一样一直锁死。
- 原型的风情不是刻意勾引，而是浓艳五官、丰厚黑发、慢半拍笑意和身体松弛共同产生的自然吸引力。

## 迁移职责

4. 纤长比例、醒目腰线与成熟曲线并存的身体观感。
5. 稳定长视线、慢半拍笑意、笑开后突然鲜活的动态。

## 沈宁的虚构优化结果

### 面容

- 保留柔润舒展的鹅蛋脸和略带心形的下颌收势；额面饱满，面中有承托，正面与转侧都不变薄，笑开后嘴角下方显出一对浅梨涡。
- 浓眉、大而长的轻扬杏眼、挺直鼻梁和丰润唇形共同承担识别，不降成普通长眼职场脸。
- 丰厚偏分黑发为稳定标志。工作时可以低束、盘起或压低卷度，但发量和面部对比不被消灭。
- 白净明亮的肤色正常保留；工作妆也可以使用玫瑰棕、浆果或低饱和红，不强制裸妆化。

### 状态层

- **第一眼**：先成立为一位浓艳、漂亮、高挑的成熟女人；职位在她开口和处理材料后才进入画面。
- **管理工作**：艳丽处于受控状态。目光依次落到材料、发言者和记录者；让人说完，再把结论收回事实、边界和责任。
- **行动现场**：进入空间后有半步确认，随后肩背打开、重心落稳；没有战斗架势，也不失去长线与曲线。
- **正式社交**：可以完整释放偏分大波浪、深唇、黑裙或高饱和深色礼服，成为高识别完成态。
- **与徐清私下**：发尾和肩背完全放松，主动靠近、依偎或撒娇；柔软不是换人格，漂亮也不只为伴侣存在。
- **疲惫泄露**：笑意先消失，视线仍稳；翻页和整理材料的速度变慢，指尖短暂收紧，真正安全后肩背才下沉。

## 衣装迁移结论

### 统一审美

- **核心色域**：象牙白、墨黑、深海军蓝、祖母绿、酒红、深莓色。
- **扩展色域**：烟草棕、暗紫、深铜、香槟色、灰蓝和暖灰。
- **轮廓**：合身肩线、开放而不过度裸露的领口、清楚腰线与长裤线或长裙线；曲线可见，但不靠全身紧绷制造权威。
- **材质**：低光泽精纺、垂坠衬衫料、细针织、真丝、哑光缎面和有重量的礼服面料。
- **发型**：丰厚偏分为底，工作低束或盘起，正式场合完整释放大波浪。
- **妆面**：浓眉和长眼始终清楚；唇色从豆沙、玫瑰棕到浆果、复古红按正式度变化。

### 场景语法

| 场合 | 设计方向 |
| --- | --- |
| 局内工作 | 合身西装、开领衬衫、细针织、高腰直筒或微阔裤；象牙白与深色形成清楚对比，漂亮不被公务隐藏 |
| 重大会议 | 完整深色套装或收腰长裙式套装；发型收净但保留发量，唇色可见，配饰只留一处 |
| 正式社交 | 黑裙、大波浪和深红唇可以作为标志性高完成度模式；祖母绿、酒红、深莓和香槟色提供同等成立的替换组 |
| 特殊行动 | 合身低反光外套、利落功能长裤和防滑短靴；腰背有活动余量，不做战术制服 |
| 普通私下 | 真丝衬衫、针织、牛仔、长裤、裹身裙和柔软开衫；漂亮与生活感并存 |
| 伴侣私域 | 黑色吊带长裙、柔软居家裙、裹身针织与丝袜均可正常存在；它们是衣柜选项，不承担人格依附证明 |
