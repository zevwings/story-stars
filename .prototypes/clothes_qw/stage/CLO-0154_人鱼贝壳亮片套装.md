## 一、身份与结论

- **推荐名称**：深海塞壬幻彩贝壳亮片套装
- **原始作品／角色／款式**：小玥玥素材（人鱼/海神风格）
- **官方明示**：无
- **视觉推断**：深海人鱼主题舞台装，贝壳 + 亮片 + 水晶三重复合装饰
- **一句话视觉定义**：虹彩亮片贝壳胸衣（扇贝壳 + 鱼尾下摆），配水晶贝壳冠冕（放射尖刺 + 蝶翼 + 水晶垂链）、多层银链胸链、满镶水钻宽臂环与手背链，深海塞壬风格。

## 二、整体设计

### 轮廓

- 上下体量关系：上重下轻，胸衣与冠冕形成视觉焦点
- 腰线与纵横比例：胸衣收腰，鱼尾下摆微散
- 静态轮廓：贝壳杯型胸衣 + 低腰鱼尾裙，人鱼曲线
- 动态轮廓：水晶垂链与流苏随身步摇曳

### 色彩

1. 主体色：虹彩渐变（蓝/紫/粉/黄）
2. 结构色：银色（金属链、臂环基底）
3. 点睛色：白色（扇贝壳、珍珠）、蓝色（水晶、宝石）
4. 阴影／对比来源：虹彩亮片的变色光泽与银色金属的冷光对比

## 三、分件拆解

### 妆发与头部

- **水晶贝壳冠冕**（画面确认）：放射状尖刺骨架，镶嵌透明/蓝色亚克力水滴与扇贝形装饰片，中心嵌白色大贝壳 + 珍珠，两侧延伸透明蝶翼/鱼鳍状薄翼片，垂挂多串水晶珠链

### 上身主体

- **虹彩亮片贝壳胸衣**（画面确认）：抹胸式比基尼上装，杯面覆盖虹彩亮片（蓝/紫/粉/黄渐变），每杯中央装饰白色扇贝壳 + 珍珠，下摆呈不对称尖角鱼尾剪裁
- **透明网纱颈圈**（画面确认）：紧贴颈部的宽项圈，蓝色亮片面料，边缘波浪/扇贝形，半透明网纱基底
- **多层银链胸链**（画面确认）：从颈圈向下延伸至胸衣的多层细银链，呈 Y 形/网状分布，含小珍珠点缀

### 袖、披帛与外层

- 无袖设计，肩部裸露

### 腰胯结构与饰件

- **腰腹珍珠垂链**（画面确认）：从胸衣下摆/腰部垂下的极细透明线 + 小珍珠/水晶珠，散落至小腹
- **亮片鱼尾腰裙**（画面确认）：低腰围裹式裙装，蓝色/银色亮片面料，腰际装饰珍珠串链，裙摆呈鱼尾/层叠剪裁，半透明薄纱内衬

### 下装与安全层

- 鱼尾裙下摆层叠，薄纱内衬（画面确认）

### 鞋履、手部与手持物

- **满镶水钻宽臂环**（画面确认）：宽约 3-4cm，银色金属基底，佩戴于上臂，左右各一
- **手背链 + 宽版流苏手链叠戴**（画面确认）：每只手腕叠戴 3-5 条细银链 + 1 条宽版满镶水钻流苏手链，右手有手背链连接戒指
- **超长多层流苏耳坠**（画面确认）：多层链式结构，含蓝色/透明水晶珠、菱形切面珠、银色金属链节

## 四、材质与动态

| 层次 | 材质观感 | 动态作用 | 现实风险 |
|---|---|---|---|
| 亮片胸衣 | 虹彩亮片缝制于弹力网布基底，扇贝壳为树脂/亚克力 | 亮片随身形折射变色，贝壳固定不动 | 亮片边缘可能刮皮肤 |
| 冠冕 | 金属骨架 + 亚克力水滴 + 树脂贝壳 + 水晶珠链 | 水晶垂链随身步摇曳，蝶翼片轻微晃动 | 尖刺骨架需圆滑处理防刮 |
| 银链胸链 | 极细银色金属链 + 小珍珠 | 链体随呼吸与动作微晃 | 链径极细，避免拉扯 |
| 臂环 | 银色金属基底满镶水钻 | 固定于上臂，随手臂动作反光 | 需弹性内衬防滑落 |
| 手背链 | 细银链连接戒指与手链 | 手指动作时链体滑动 | 戒指需合适尺寸 |

## 七、现实制作

- 承重与固定：胸衣靠弹力网布 + 后背系带固定，冠冕用发夹/发箍固定于头顶
- 活动与安全：亮片边缘需包边处理，冠冕尖刺需圆滑，手背链不影响手指弯曲
- 穿脱与整理：先穿胸衣与腰裙，再佩戴颈圈、胸链、臂环、手链，最后戴冠冕与耳坠
- 收纳与运输：冠冕需独立盒装防压，亮片衣物平铺或悬挂，链饰分袋收纳防缠绕
- 清洁与修补：亮片手洗或干洗，金属链用软布擦拭，贝壳装饰避免溶剂

## 八、候选调用

- 展示顺序：冠冕特写 → 胸衣与贝壳细节 → 银链胸链 → 臂环与手背链 → 全身
- 动作锚点：水晶垂链在转身时的摇曳；手指轻触扇贝壳的冰凉触感；手背链随手指张合的滑动
- 正文锚点：虹彩亮片在光线下的变色折射、扇贝壳的弧形轮廓、银链的冰凉触感与细响、水晶垂链的叮咚轻响
