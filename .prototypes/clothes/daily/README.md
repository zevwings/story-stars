# 日常衣装原型

本目录收录不依赖舞台、仪式、亲密、运动、游泳或行动任务才能成立的现实生活常服，包括居家、城市外出、约会、聚会、发布活动和普通职场穿着。

- 日常是广义“常服”，不等于休闲、低完成度或低性感度。
- 现实成衣、活动造型与品牌搭配写入“来源类型”；品牌、职业、活动身份和穿着者经历未经确认时不补推。
- 职业用途需要稳定的工作场景，不因西装、衬衫或制服元素自动成立；社交造型也不自动生成职业身份或礼仪岗位。
- 社交、职业、舞台与情趣只是兼容用途时写入衣装档，不建立副本。
- 正式采用时按角色身形、职业、色彩语法和生活环境重写，不继承现实身份与品牌语境。
