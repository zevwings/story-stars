# 礼仪／正装衣装原型

本目录收录主要依靠婚礼、庆典、颁奖、正式宴会、典礼仪式或明确正装礼制才能成立的衣装。

- 礼服、晚礼服、燕尾服与 Black tie／White tie 等明确礼制正装可进入本类。
- 普通职场西装、日常社交套装或只有正式感的活动造型仍归入 `daily/`；用于表演时优先归入 `stage/`。
- 头纱、冠饰和礼服结构只能支持礼仪意象，不自动证明人物关系或仪式事实。
- 双人或套组衣装仍使用一个 `CLO-*`，在条目内记录共同语言与差异件。
- 正式采用时必须重新确定人物组合、仪式性质和各自差异。

从 [礼仪／正装衣装索引](_index.md) 进入具体条目。
