## 二、重点细分场景与特征清单

### 1. `action/` 行动与战术类（优先级：最高）
- **极速机车 / 狂飙赛车皮衣**：黑红/黑黄拼接高弹真皮连体服、立领斜拉链、紧绷包裹配碳纤维护膝与长筒机车靴。
- **特勤保镖 / 隐藏枪套套裙**：深黑抗撕裂弹力小西装 + 侧开衩包臀裙 + 大腿内侧隐藏式战术枪套与微型耳机。
- **暗夜潜行 / 灰黑机能服**：哑光吸光消音高弹面料、高领露背半截手套、战术多功能腰封与软底作战靴。

### 2. `swimwear/` 泳装与水域度假类（优先级：高）
- **私汤温泉 / 透水和风浴衣**：极薄透水雪纺/纯白真丝短浴衣，单根宽腰带系结，遇水半透明贴体。
- **游艇名媛 / 奢华度假泳装**：香槟金/金属质感微光深V连体泳衣 + 白色微透真丝大罩衫 + 超大宽檐防晒草帽。
- **竞技冲浪 / 紧身水母服**：前胸拉链半开、高领修身高叉、吸湿快干面料，强调肌肉紧致感与下肢线条。

### 3. `stage/` 舞台与演艺会所类（优先级：高）
- **K-Pop 千禧机能风女团打歌服**：解构斜肩短背心 + 金属链条金属扣 + 低腰百褶迷彩短裙 + 绑腿厚底靴。
- **高端私人会所调酒 / 荷官制服**：深酒红/黑缎面紧身燕尾小马甲 + 衬衫小领结 + 黑色包臀超短裤配吊袜带。
- **电音节赛博朋克发光短裙**：变色反光 PVC 抹胸 + 镭射伞状短裙 + 荧光线条与发光发圈。

### 4. `ceremonial/` 社交权势与名利场类（优先级：中）
- **律政女合伙人 / 商界高管三件套**：修身羊毛小马甲（直接贴身单穿）+ 垫肩修身小西装 + 垂坠高腰阔腿西裤。
- **老钱风名媛茶会套装**：法式米金小香风圆领短外套 + 同款及膝包臀裙 + 珍珠多圈锁骨链。
- **艺术拍卖会极简重磅真丝曳地裙**：斜单肩极简纯黑/香槟色重磅真丝长裙，大露背无内衬垂坠剪裁。

### 5. `cos/` 二次元与经典反差类（优先级：中）
- **禁欲系暗黑修女装（二次元COS款）**：立领修女袍配超高开衩与镂空深V、合金大十字架吊坠。
- **和风改良超短巫女服**：短款白衣露肩剪裁 + 正红分体系带百褶袴裙 + 注连绳发饰。
- **赛博机械战姬装**：紧身电路印花高领连体服 + 局部机械外骨骼装甲配件。

### 6. `daily/` & `intimate/` 特殊气候与材质补充（优先级：日常维护）
- **高奢皮草 / 冬日雪地辣妹装**：纯白短款白鸭绒羽绒服/短款皮草 + 高腰加绒无痕瑜伽裤 + 厚底雪地靴。
- **雨天透视雨衣湿身装**：磨砂半透明长款连帽 PVC 雨衣 + 内部吊带热裤。
- **特种乳胶连体衣 (Latex Suit)**：高光黑色乳胶全包裹、前置双向全开拉链、极致紧绷塑形。
- **奢华长款羽毛晨袍**：珍珠白双绉真丝大袍 + 袖口与下摆镶嵌鸵鸟羽毛 + 超细吊带睡裙。

## 三、建档与补充指引

1. 新建服装原型统一遵循 `_template.md` 规范，从当前全局最大编号后顺延编号。
2. 依据主要使用场景准确归入对应分类目录，避免因多用途而在多个目录复制文件。
3. 保持单品解构（上衣、下装、套装/连体、内搭、配饰）与材质动态分析的完整性。
