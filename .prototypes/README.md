# 创作原型参考层

`.prototypes/` 保存人工维护、需要长期回查、但不进入小说事实读取链的创作原型资料。

## 定位

- 本目录不是故事事实或正式真源。
- 本目录不是 `.rag/` 一类可以自动重建的派生缓存。
- 正文、剧情规划、普通人物查询、普通世界观查询与 GraphRAG 默认不读取本目录。
- 只有任务明确涉及原型研究、人物形象修改、地区视觉设计、生图设计或撞型检查时，才从相应 `_index.md` 进入目标原型档。

## 引用方向

- 原型档可以单向链接 `characters/` 或 `worldbuilding/` 的正式目标。
- 正式人物卡与世界观文件不得把本目录列为事实来源。
- 原型档中的现实人物、现实地区、图片、账号、经历、数据和妆造都不自动属于小说对象。
- 作者确认后的最终结果必须同步到正式文件；人物外观以 `characters/` 为准，地区与空间事实以 `worldbuilding/` 为准。

## 年龄分层覆写规则

- 角色的实际年龄必须以固定叙事锚点写入静态 `characters/**/主卡.md`，例如“开篇 27 岁”或“首次登场 20 岁”；不随剧情时间滚动维护。
- `context/characters/` 不登记当前实际年龄，只可按需维护会随疲惫、伤病、妆造、精神与处境变化的“观感年龄”。
- 原型档中既有的“当前年龄迁入动态档”“动态年龄档”等迁移记录均由本规则统一覆写，只作为旧执行历史，不再作为现行同步指令。

## 目录

- `characters/`：人物视觉原型、参考年龄阶段、迁移职责、角色化优化、视觉状态层与撞型边界。
- `regions/`：地区、地貌、建筑、交通与环境原型，以及架空化改造边界。
- `cache/`：临时下载的检索图片，不提交版本库。

新增其它类别时必须已经存在真实内容，不为预想用途创建空目录。
