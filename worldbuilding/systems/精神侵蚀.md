# 精神侵蚀

> 精神侵蚀是契主经精神连接向他人施加污染、控制或结构破坏的黑暗行为体系。星辰异变是同源异化，星辰之印是种印完成后的精神约束结构；其中强种与控制性使用属于黑暗行为。

## 一、定义

精神侵蚀以污染、控制或破坏目标精神结构为目的。它不是独立的黑暗能量，星辰之力本身仍然中性；未经同意建立精神连接或进入梦境本身不自动归入精神侵蚀，仍须看施术实际造成的效果。

**精神入侵**描述施术者投入精神之力、越过目标未主动开放的精神边界实施探查、进入或干涉的行为；**精神侵蚀**描述以污染、控制或结构破坏为目的，并实际形成对应权柄作用的黑暗行为。未经允许的精神入侵属于越界行为，但不因“未经允许”自动等同于已经造成精神污染、人格控制或结构破坏。

精神入侵受到目标固有精神边界排斥时，入侵者自己投入的精神之力可能沿侵入路径回弹；回弹进一步破坏入侵者人星协调时，可能触发《星辰回响》。这一风险不要求目标主动反击，也不表示目标实施了精神侵蚀。

## 二、建立条件

精神侵蚀必须以精神连接为通道。欲望放大、非法激励、精神抑制、精神循环、信息回响、响应钝化与信息孤悬等干涉可以在锁定目标并形成相应连接后开始；造成精神污染与种印需要更深的精神通道。普通入梦同样需要织梦权柄所能建立的连接，但不因是否取得同意改变能力类型。

- 施术者的基础权柄或个人星辰权柄必须覆盖对应支配范围，并已形成相应具体能力：记忆篡改可以由已经掌握的高阶基础记忆技巧起效；织梦入侵需要织梦权柄，绘影欺骗需要绘影权柄，欲望放大需要欲望权柄；非法激励、精神抑制、精神循环、信息回响、响应钝化与信息孤悬分别需要能够干涉既有目标动力、已有精神反应强度、精神过程重复、既有信息复现、刺激响应阈值，以及既有信息与判断体系的关联；篡心需要塑心方向的个人星辰权柄及对应具体能力，未经同意的强制种印需要能够干涉精神连接、控制结构或人格边界。精神污染不是独立权柄；它只能由深层侵入中仍在维持的外来来源或已成立结构造成，包括持续的基础侵蚀连接、具有结构破坏效果的具体能力、药剂残留或非法印记。基础侵蚀只能沿持续连接磨损结构，不能在通道中断后独立留下会自我扩散的污染。清醒、自愿且边界明确的星辰之印属于可训练的高控制建立技巧，不按精神侵蚀处理，也不要求特定个人权柄适配。
- 精神侵蚀会使施术者暴露可被逆向利用的通道。
- 具体连接深度见《精神之海》和《战斗规则》。

除已经固化的星辰之印外，普通精神侵入、能力控制与药剂作用都只在持续连接、实际施术、有效药效或既有触发条件成立时生效，不能自行转化为脱离条件的长期稳定控制。重复用药可以造成耐受、依赖或条件化反应，但不使药剂替代星辰之印成为永久控制结构。

## 三、类型

| 类型 | 作用 | 主要后果 |
| --- | --- | --- |
| 织梦入侵 | 进入、构筑或扰动梦境 | 感知、判断与自我边界受干涉 |
| 记忆篡改 | 遮蔽、删除、重组或植入具体记忆 | 经历记录与事实判断被改写 |
| 绘影欺骗 | 覆盖或替换目标清醒状态下的当下感知 | 对现实环境、对象与危险作出错误判断 |
| 欲望放大 | 强行放大已有欲望 | 欲望对判断与行为的支配上升 |
| 奖励诱导 | 改变特定刺激的奖励循环与满足阈值 | 形成依赖、戒断、耐受与刺激升级 |
| 精神循环 | 强迫已有精神活动反复启动 | 念头、选择或行为难以自主退出 |
| 信息回响 | 使已有精神信息脱离主动调用而重复浮现 | 记忆、声音、画面、梦境或情绪反复侵入当前意识 |
| 响应钝化 | 提高精神结构对特定刺激作出反应的阈值 | 情感、危险、奖赏、痛苦或关系响应迟缓衰减 |
| 信息孤悬 | 使已经接收并保留的信息脱离当前推理、归因与决策通路 | 事实仍在，却难以修正现有判断与解释 |
| 篡心（强制塑心） | 未经知情同意重塑人格结构、自我认知、信念或价值判断 | 身份认同、判断依据或行为选择受扰动 |
| 精神污染 | 在深层侵入后污染并破坏目标的精神之海 | 内部结构持续失稳、扩散与崩损 |
| 种印 | 植入约束结构 | 形成星辰之印；未经同意的强种属于黑暗控制 |

具体能否使用，受基础权柄、个人星辰权柄、具体能力、精神之海、星辰控制与连接条件约束。

## 四、精神污染

精神污染不是独立权柄，也不是向目标注入的独立黑暗能量。它是外来侵入路径、药剂残留、非法印记或其他已成立能力结构在目标精神之海内部造成并维持的活动性失序，及其留下的异常残留。侵入路径中断且外来来源或结构被移除后，污染停止新的扩散；已有残留和结构损伤仍须分别净化与修复。“掠夺星辰之力”不属于现行能力类型；催化星辰异变由专门药剂实现，不属于精神污染或星辰契约能力。

覆盖净化方向的星辰权柄可以识别、抑制、剥离并排出仍在活动的污染，覆盖修复方向的星辰权柄可以处理污染已经造成的结构损伤。净化不自动完成修复，修复也不能在污染源仍然存在时永久维持结果。

被剥离的污染不是可储存、转移或再次利用的独立物质；它脱离目标精神结构并失去原侵蚀通道与施术结构维持后，会崩散为无结构的力量余波并自然消退。净化者会因深层连接暴露在污染结构与原通道面前，可能承受精神过载或通道反向侵入，但不会自动吸收或替目标储存污染。

## 五、施术与反向风险

精神侵蚀在实际发动、持续输入或追加干预时，需要施术者调用自身星辰之力。强制种印完成后，已经固化的星辰之印维持存在本身不再持续消耗种印者的星辰之力；追加命令、主动触发惩戒、重新加固或另行实施人格干预仍属于新的主动施为。施术者还需要承担自身精神过载、通道暴露与星辰异变加深风险。精神侵蚀本身不会自动造成永久能力损失。

精神连接是双向通道，可能出现通道反侵入与反向种印。具体结算受双方精神边界、控制精度、连接状态与第三方干预影响，不设置固定公式。

## 六、边界

- 精神侵蚀是行为总类，不是星辰异变的另一名称。
- 不设「反噬」这一正式术语；连接被逆用一律用通道反侵入、反向种印等直述。
- 精神之力回弹是入侵者自身投入的精神之力遭固有边界排斥后沿侵入路径返回，不属于通道反侵入、倒卷、能力返还或精神侵蚀。
- 种印是建立星辰之印的行为，完成后的控制结构见《星辰之印》。
- 精神侵蚀不承载黑暗场的叙事立场与亲密专项规则。
- 黑暗 / 强制亲密不成立共鸣：经精神连接对精神之海的侵害走本体系（非共鸣），受害方本能闭海，任何一方都得不到共鸣式的承载磨练收益。
