# 星辰回响

> 本文是星辰回响的定义、触发、显症、持续与长期风险边界正式真源。精神之力与精神边界见《精神之海》，星辰之力的正常调用见《星辰之力》，正常塑形与回收见《星辰控制》，长期同源异化见《星辰异变》。

## 一、定义

**星辰回响**是契主实施精神入侵时，自身投入的精神之力遭目标精神边界排斥并沿侵入路径回弹；回弹超过入侵者自身承受与稳定能力后，使其精神之海及人星协调失序，继而使星辰之力未经正常调用与塑形进入精神之海，并沿入侵者已有的个人星辰权柄方向向内显现的急性失控。

星辰回响适用于所有已经成立星辰契约的契主。普通人可以承受精神之力回弹、精神过载、精神污染与结构损伤，但没有星辰契约，不会发生星辰回响。

本文所称**人星协调**，只描述精神之力维持精神结构、精神边界与星辰契约通道稳定，使星辰之力能够被正常承载、引导和塑形的状态；它不是新的力量、权柄、连接类型或可计量资源。

## 二、三层关系

| 层级 | 来源与职责 | 与星辰回响的关系 |
| --- | --- | --- |
| 精神之力 | 属于精神之海自身，维持精神结构、自我边界、精神通道与人星协调 | 精神入侵失败后的回弹首先冲击入侵者自身精神之力 |
| 星辰之力 | 来自真实星辰，经星辰契约通道进入契主精神之海 | 人星协调失序后，可能未经正常调用与塑形进入精神之海 |
| 权柄作用 | 星辰之力经已有权柄权限与星辰控制塑形后形成的具体能力效果 | 星辰回响中的向内显现没有完成正常塑形，不属于已经形成的外发权柄作用 |

精神之力不是星辰之力，也不是另一种蓝条。星辰回响不会把二者混合成第三种力量。

## 三、触发条件

星辰回响必须同时满足：

1. **契约前提**：承受回弹者已经成立星辰契约。
2. **主动入侵**：承受回弹者主动投入精神之力，越过目标精神边界实施探查、进入或干涉。被动感知、普通接触、自愿开放与自愿共鸣不构成精神入侵。
3. **边界排斥**：目标精神之海没有向该范围主动开放，入侵力量受到其固有精神边界排斥。目标不需要主动攻击、发动权柄或实施反制。
4. **精神之力回弹**：入侵者自己投入的精神之力沿侵入路径返回并冲击自身。回弹不是目标精神之力转移到入侵者体内。
5. **超过稳定能力**：回弹强度超过入侵者当时的承受与稳定能力，使其精神之力和精神之海失序。

精神入侵受到排斥时都可能发生不同强度的精神之力回弹，但只有回弹进一步破坏入侵者的人星协调，才会触发星辰回响。

精神之海五境只描述承载深广。评级差、靠近、对视或被动感知本身不会形成被动压制，也不自动触发回弹或星辰回响；实际结果仍受精神边界状态、入侵深度、双方当时状态与入侵者投入强度影响。

## 四、固定因果链

```text
契主主动实施精神入侵
→ 自身投入的精神之力越过目标精神边界
→ 目标固有精神边界形成排斥
→ 入侵者投入的精神之力沿侵入路径回弹
→ 回弹超过入侵者自身承受与稳定能力
→ 入侵者精神之力与精神之海失序
→ 人星协调失配
→ 星辰之力未经正常调用与塑形进入精神之海
→ 沿入侵者已有的个人星辰权柄方向向内显现
→ 形成星辰回响
```

精神之力回弹是精神入侵失败后的固有风险，不是星辰主动惩罚，也不是目标主动发动的攻击。

## 五、显症边界

- 星辰回响只沿契主已经持有的个人星辰权柄方向显症，不调用观测、记忆、镜像、静默、侵蚀与传念六项基础权柄形成公共症状。
- 同一契主具有多个个人星辰权柄时，具体显症只取自其已有权柄方向；是否同时显现不建立全员固定规则，回到人物契约登记。
- 回响不会新增、复制、放宽或强化个人星辰权柄，也不会形成永久增益。
- 回响默认向契主自身精神结构结算，不自动向外无差别攻击，不直接造成现实物理爆炸或环境破坏。
- 权柄向内显现不等于主动施展完整具体能力，也不要求存在一个正在承受外发效果的目标。
- 情绪、欲望、梦境、感知或其他精神反应的失序不能替角色作出决定；身体反应不等于同意，求生配合也不改写真实意愿。

每名角色的具体回响显症只写入对应人物的契约真源，不建立全员共用症状表。

## 六、持续与停止

精神入侵停止、侵入路径中断或入侵者撤回投入后，只会停止新的精神之力回弹，不会立即清除已经形成的星辰回响。

回响已经触发后，会持续到入侵者的精神之力、精神之海与人星协调重新稳定，星辰之力恢复正常承载、引导和退出秩序。持续时间不设固定数值，取决于回弹强度、精神之海当前状态、结构损伤、污染叠加及稳定条件。

处置对象是精神负荷、精神边界与人星协调，不是补充力量或清除某种黑暗能量。停止复杂施为、隔离刺激、重新定锚、现实看护与合法医疗可以帮助恢复；具体恢复边界见《精神之海》。

星辰回响本身不是外来污染，净化权柄不能直接把回响“清除”。若同时存在精神污染或结构损伤，须分别净化、修复和稳定。自愿共鸣只能在已有情感、信任与自愿开放的前提下提供软性稳定，不恢复星辰之力、不提高星辰控制，也不得为了停止回响而索取亲密。

## 七、与相邻机制的边界

- **不是精神连接本身**：普通精神连接、自愿开放和自愿共鸣不触发回响；触发行为是越过精神边界的精神入侵。
- **不是精神侵蚀**：精神入侵描述越过边界的行为，精神侵蚀描述以污染、控制或结构破坏为目的并实际形成相应效果的黑暗行为；二者不能仅凭“未经允许”互相替代。
- **不是断流或倒卷**：精神之力回弹发生在精神入侵与固有边界之间，不要求目标持有连接干涉权柄，也不是已经形成的权柄作用被中止或返还。
- **不是能力返还**：回弹的是入侵者自己投入的精神之力，不是目标把某项能力原样施加给入侵者。
- **不是信息回响或回响权柄**：星辰回响是人星协调失序形成的系统状态，不是“信息回响”侵蚀效果，也不是名为“回响”的个人星辰权柄。
- **不是星辰异变**：回响是稳定后可以退去的急性失控；星辰异变是星辰之力对契主形成的长期同源异化。
- **不是第二代价轴**：星辰异变仍是唯一的星辰契约代价轴；星辰回响属于精神入侵失败后的急性风险。

## 八、长期失衡、污染与星辰异变

精神之力与星辰之力在正常契约状态下不是互斥关系。精神之力负责维持精神结构、精神边界与人星协调，使星辰之力能够被正常承载、引导和塑形。

长期精神之海失衡，或精神污染、结构损伤长期未被清除和修复，可能使精神之力持续无法稳定人星协调，使契主自身星辰之力更频繁地失去正常引导并作用于其精神结构。由此产生的是**星辰异变发生或加深概率上升**，不是必然进程：

```text
长期精神之海失衡
或精神污染、结构损伤长期未清除
→ 精神之力持续无法稳定精神结构与人星协调
→ 星辰之力更频繁地失去正常引导
→ 契主精神结构反复受到自身星辰之力同源作用
→ 星辰异变发生或加深的概率上升
```

精神污染不是星辰异变，不会把星辰之力污染成另一种能量。污染只能通过损伤精神结构和破坏人星协调间接提高异变风险；污染被净化后，已经形成的星辰异变也不会因此被清除。

反复发生星辰回响可以成为人星协调长期失配的风险信号，但回响次数不构成异变进度条，也不自动累积成星辰异变。

## 九、设定边界

- 不设置星辰回响数值、固定概率、全员严重度分级或公开战力等级。
- 不把普通疲劳、情绪波动、睡眠变化或欲望变化写成星辰回响。
- 不把五境评级写成高境界对低境界的被动精神压制。
- 不用净化、药剂、性爱或共鸣一键消除回响。
- 不借回响新增能力、绕过连接条件、恢复力量或兑现战斗输出。
- 不把精神污染写成星辰异变本体或第二种星辰契约代价。
