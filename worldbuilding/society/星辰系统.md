# 星辰系统

> 本文是星辰系统的定位、访问、能力申报、事项受理、个案协查、权限与责任边界的正式世界观真源。运营与处置主体见[《星辰管理局》](../factions/星辰管理局.md)；能力档案见[《能力申报与复核》](能力申报与复核.md)；社会保密见[《保密与公开性》](保密与公开性.md)；地下匿名网络见[《暗色星辰》](暗色星辰.md)。

## 一、定位与核心原则

星辰系统是星辰管理局统一建设、认证、运营并承担制度责任的官方系统，用于登记服务、能力申报与证据状态、异常报告、个人支持、个案协查、临时授权、材料移交与责任审计。它不是星辰契约能力或契约自知的来源，也不是所有契约者共享的公共社交网络。

系统的治理原则是**外松内硬**：对普通契约者的日常生活、正当能力使用和协查选择保持克制；对星表、精神介入、强制措施、个案材料、权限越界和人格支配保持硬边界。

官方秩序的核心是：

> **契约自由，使用有责；人格不可支配，侵害必须追究。**

星辰契约的存在与正当使用不受禁止。任何人不得利用星辰契约实施非正当伤害、未经授权的精神控制，或建立剥夺他人人格自主与退出权的支配关系。

## 二、系统分层

星辰系统使用统一的官方身份与审计体系，但不同区域的数据和权限严格隔离。

```text
星辰系统
├─ 核心业务区：星表、登记、精神海评级、控制画像、能力档案、复评、案件、监管、审批与审计
├─ 个人服务端：本人摘要、能力补报、预约、支持、协查邀请与申诉
└─ 临时协查工作区：按事项、职责、人员与时限开放
```

### 核心业务区

核心业务区只向管理局正式人员和当次获得必要内部权限的人员开放。民间协查者不因接受委托进入核心业务区。

### 个人服务端

完成登记的契约者可以取得个人账号，查看本人的普通登记摘要，提交补报、复评、健康、恢复、异常报告和申诉事项，也可以接收并回复个案协查邀请。

星契动物虽登记为非人契主，但不取得个人账号、协查资格或任务邀请。照护者不是动物的系统代理人；确有长期安全管理需要时，只能通过现实联络接口获得照护、异常报告、复评与紧急联系所需的最低信息，详细边界见[《星契动物》](星契动物.md)。

个人账号不展示其他契约者的名单、位置、能力、星辰、工作单位、私人关系、出勤状态或协查经历。星辰系统不设契约者公开资料目录、全局用户搜索、常设论坛、私聊、同城频道或公开社交关系。

### 临时协查工作区

个案协查成立后，管理局按当次职责开放临时协查工作区。工作区保存脱敏摘要、成员、职责、权限、已知风险、中止条件、现场接口、升级记录与移交要求。事项结束后，临时权限失效，必要材料按归档规则转入核心业务区。

## 三、身份与访问

- 系统后台以管理局登记身份为准，不另设“契约存在凭证”等超凡认证机制。
- 完成登记只产生本人服务权限，不自动产生协查资格、案件权限或出勤义务。
- 正在办理登记的新契约者由联络人以现实工作渠道承接，不预设担保即可进入系统的临时社区账号。
- 拒不登记者不取得系统账号；知情普通人和外部专业人员也不因个案知情取得契约者账号。
- 星契动物没有系统账号；照护者不因所有权、收养、救助或长期照护关系继承其契主权限。
- 外部专业人员需要参与处置时，优先通过其原有职业系统或现实工作渠道取得最低必要信息，不为便利扩大星辰系统身份范围。

## 四、事项受理与个案协查

星辰系统接收管理局内部、公安知情接口、医疗与其他公共机构、契约者本人、家属或其他已获授权联络人，以及集团普通业务按行业边界转交的方向级提示。来源不等于事实成立，普通业务数据也不因同属集团自动进入星辰系统。

近场精神异常筛查设备产生的提示只作为地点与时间窗口内的低精度线索。它必须经过现场人工复核、现实接触与权限判断，才可以转入登记引导、正式检测或个案受理；系统不得将其自动转化为个人档案、跨点追踪记录或风险认定。

登记、预约、福利兑换、普通恢复支持与无异常结论的咨询属于个人服务事项，不得为制造任务数量而改称为协查任务。

只有完成来源记录、异常初筛、目标确认、权限划分并指定负责人的事项，才能转为正式个案协查。论坛、聊天、传闻、个人描述或能力感知只能构成受理线索，不自动证明事实、责任与犯罪成立。

常见事项包括：

- 新契约者登记、复评与生活适应；
- 精神状态、能力痕迹、药剂、设备或场所的异常筛查；
- 稳定、恢复、医疗转介与短期保护；
- 公共场所失控、异常痕迹和外泄风险的现场处置；
- 星契动物的目击核查、照护支持、风险管理、迁移、捕获、救援及人类利用调查；
- 失踪、失联、护送、保护和受控材料追索；
- 精神侵害、非法控制、违禁药剂、黑市交易与现实犯罪叠加的联合调查；
- 契主被狩猎保护、夺契中止、原契主救治、残契承载者复评与限制、夺契责任链追查；
- 处置后的医疗、复评、保密、监管、保护、权限回收与现实生活回归。

上述事项不以“能力失控”为共同前提。登记核查、材料比对、失踪协寻、保护、恢复、非法控制调查和星契动物照护都可以独立成立；只有具体事件确实出现失控表现时，才按对应能力、诱因、影响和现实后果建立个案机制，不设置可反复套用的统一“失控实体”或异常目标池。

### 个案风险等级

个人服务事项不参与风险评级。正式个案协查成立时，系统根据已经掌握的事实给出 `D—S` 初始风险等级；等级只描述当次事件需要的处置权限、人员规模、联动范围、监督强度和升级条件，不代表契约者战力、任务难度、履历声望或报酬档次。

| 等级 | 内部定位 | 适用边界 |
| --- | --- | --- |
| D | 核查级 | 目标明确、环境受控，尚无明确持续伤害；以材料核验、观察、复查和受控检测为主。 |
| C | 个案级 | 单人或小范围异常，可能仍在持续，但对象、地点与保护条件基本可控。 |
| B | 现场级 | 存在活动性危害、多人受影响、公众暴露或现场不确定性，需要现场安全、保密、医疗或治安接口。 |
| A | 联合级 | 已出现严重伤害、持续控制、人格支配或现实犯罪，需要管理局与公安、医疗等正式联合处置。 |
| S | 重大级 | 存在大范围、跨区域或组织化侵害，大规模精神控制与人格奴役，核心系统性风险或其他需要多部门统一指挥的危害。 |

初始等级按当前证据能够支持的最高风险维度确定，不以事项数量机械累加。评级至少综合持续伤害、影响范围、人格自主受损、公众暴露、现实犯罪与组织化程度、跨区域性、信息不确定性和后果可逆性；正在发生的多人控制、人格奴役或系统性侵害可以直接触发高等级处置，不必从低等级逐级经过。

风险等级随事实变化动态升降。升级必须同步负责人、权限、中止条件与外部联动，降级必须有危险解除、对象稳定或证据排除依据，不得以节省资源为由下调。协查邀请和临时工作区除显示当前等级外，还必须提供与受邀职责直接相关的明文风险摘要和行动边界，不能要求协查者仅凭字母等级判断是否接受。

## 五、协查匹配与成员成立

管理局在系统后台按属地、带证据状态的已登记能力、控制表现、现实专业资格、当次任务资格、当前健康状态与可出勤情况进行匹配。候选人只看到向本人发出的定向邀请；需要扩大候选范围时，管理局可以向符合条件的有限人群发布脱敏征集，不向所有账号展示常设任务大厅。能力已经申报但未经相应条件验证，不得被系统自动当作稳定任务能力。

契约者可以在个人服务端声明可接受的事项方向、时间与安全边界，也可以申报已有稳定搭档或联合接受邀请。是否采用由管理局按个案职责审核，私人关系和过往合作不自动生成官方权限。

星辰系统不允许用户自行发布官方任务、搜索其他契约者、自由拉人更换成员、自行分配强制处置权限或在用户之间直接结算。私人互助、训练、交流与组队可以在现实生活中自行成立，但不因此成为官方协查。

协查邀请可以拒绝。拒绝本身不降低登记权益、不触发复评，也不产生后续无限出勤义务。

## 六、协查权限与标准流程

个案协查成立时，必须明确：

- 事项目标与当次负责人；
- 可接触对象和现场范围；
- 可读取的脱敏材料；
- 可使用的能力、现实专业行为与工具；
- 材料保存、复制和移交范围；
- 安全中止、风险升级与退出条件；
- 现场、公安、医疗、保密和后续响应的责任主体。

民间协查者不自动取得调查、搜查、拘捕、讯问、持枪、精神检测、强制处置或普通警务资料权限。救人、稳定、检测、取证、抓捕、保密和恢复分别授权，不因同时发生在一个地点就交给同一个人。

标准流程是：

```text
来源记录
→ 初步分流
→ 指定负责人并成立权限
→ 定向邀请或有限征集
→ 协查者接受或拒绝
→ 开放临时协查工作区
→ 现场执行、中止或升级移交
→ 医疗／公安／管理局分别承接
→ 结算、恢复、权限回收、复盘与归档
```

紧急情况允许先保护人员、中止正在发生的危害，再补齐必要记录和移交。星表查询、精神介入、强制措施、现实执法、材料复制和对外泄露仍属硬权限，不能因事后补记而把无权行为改写为合法。

## 七、能力使用与人格自主红线

管理局处理的核心不是契约者是否拥有或使用能力，而是其使用是否造成不正当伤害、精神侵害、非法控制、人格支配、恶性外泄或其他现实危害。未经许可进入他人精神边界属于越界，但具体行为仍按实际效果、目的、授权、紧急性与现实后果分别定性，不把一切未经允许的精神进入自动合并为精神侵蚀。

制度明确禁止：

- 故意利用能力实施非正当伤害；
- 强制种印、伪授权种印和超出原授权的印记扩张；
- 篡改记忆、欲望、判断、人格、自我认知或退出意愿以取得服从；
- 剝夺他人拒绝、撤回、离开、求助或向外披露的能力；
- 通过精神控制实施拘禁、勒索、性侵害、人员转移、犯罪利用或其他持续支配；
- 把他人的人格、身体、能力或社会关系当作可支配、可交易或可实验的资源；
- 夺取他人原始星辰契约，持有、使用、撮合或交易由非法夺契形成的残契，以及为此提供明知的目标情报、拘禁、药剂设备、承载安排或结果掩护；
- 利用能力销毁证据、威胁证人或阻止受害者求助。

正当防卫、紧急救援和依法处置中的必要限制必须具备明确权限或紧急必要性，手段与风险相称，不超出停止危害所需范围，在危险解除后停止，并接受记录与事后复核。它不能被扩张为对无关精神内容的读取、人格干预或长期控制。

星契动物同样拥有自身精神边界。照护者或机构不能代替动物开放精神之海；物种适配的当下接受与紧急介入边界见[《精神之海》](../systems/精神之海.md)和[《星契动物》](星契动物.md)。动物不能理解长期抽象条款，不适用以自愿为前提的监管印或其他长期精神约束。

## 八、结算、履职记录与申诉

管理局负责协查报酬、交通、住宿、误工、必要设备、任务损伤的医疗恢复和后续处置。委托来源人、当事人与民间协查者不直接建立官方任务的私下结算关系。

系统不建立公开信誉、用户星级、战力排行或击杀数。管理局可以保存非公开履职记录，内容限于是否履行职责、隐瞒已知重大风险、越权、及时中止与上报、完成材料移交及当前是否适合继续协查。记录只服务于资格与安全判断，不向其他契约者展示。

契约者和协查者可就登记摘要、账号、任务边界、结算、损伤承接、越权调取和违规处置提出申诉。涉及承办人本人、近亲属、伴侣或其他利害关系时，必须回避或引入独立复核。

残契承载者的账号、协查资格、敏感资料接触与能力使用可以基于具体风险临时限制。限制决定必须写明证据、对象、范围、期限、复核条件和申诉路径；残契存在本身不自动证明承载者参与夺契，也不允许系统把其永久标记为罪犯。原契主作为受害者，不因失去契约或精神损伤自动丧失账号、申诉、保护与恢复支持。

## 九、风险摘要与追索

星辰系统可以按资格、属地和当次需要，向有限协查者发布正式通缉的脱敏风险摘要、对失控或失联人员的风险协寻，以及对设备、药剂、星表材料或异常连接载体的物品追索。

夺契案件的风险摘要可以提示目标保护要求、已知执行条件、疑似残契调用表现与必须避免的接触方式，但不能公开原契主完整星表或把方向性精神痕迹写成实时定位。残契衰减状态只能来自最近一次合法检测、承载者陈述或事件表现，不由系统自动持续追踪。

摘要只显示完成当次保护、报告、搜寻或移交所需的最低信息，不公开完整星表、精神之海评级、全部能力、证人、家属和完整证据链。任何摘要都必须明确“仅报告”“禁止靠近”或“开放有限协查”等行动边界。

对疑似犯罪者的正式通缉继续服从普通公安、司法程序和管理局专项风险判断；风险协寻不预设目标犯罪，物品追索也不授权私人抢夺、搜查或非法拘禁。

## 十、与外部系统的边界

- 公安负责普通现场、现实证据、搜查、拘捕、讯问和司法程序；管理局负责契约身份、能力痕迹、精神侵害、保密、复评与专项危害处置。两套材料按案对应但不整库互通。
- 桷洲城市投资集团及外部合作机构按本职提供医疗、安保、物业、信息、交通、场地与恢复支持，不因承办外围业务进入星表、完整案件或契约者账号数据。
- 契约者之间的私人交流、互助群、现实通信工具和其他圈层社区不属于星辰系统；管理局不因登记身份自动读取这些私人活动。
- 暗色星辰不属于星辰系统，也不是星辰系统的地下分区、泄露镜像或失控分支。两者在运营主体、身份结构、数据权限和责任承担上完全分离。

## 十一、不得写偏

- 不把星辰系统写成异能公会、悬赏榜、全民契约者社区或自由交易市场。
- 不为系统设置用户星级、战力排名、经验值、击杀数、能力掉落或亲密换战力。
- 不把星契动物写成任务怪物、悬赏猎物、击杀资源或可由照护者代为操作的能力单位。
- 不让普通契约者浏览星表、完整登记档案、他人能力资料、正式案件卷宗或管理局内部指挥，也不把系统档案写成能够复制契主第一人称契约自知的知识库。
- 不把个人求助、传闻、能力感知或用户自发组队直接写成官方任务。
- 不把基层灵活执行写成无为而治、人情豁免、越权合法化或只要不出事就不追责。
- 不把星辰系统或管理局写成能够自动发现所有觉醒者、读取全部外部数据、预防所有侵害或实时锁定暗色星辰用户的全知系统。
