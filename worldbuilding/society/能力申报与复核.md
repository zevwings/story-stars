# 能力申报与复核

> 本文是管理局如何获知、记录、核验和修订契约者能力信息的正式社会制度真源。精神之海评级技术见《精神检测与复评技术》；登记与星表入口见《觉醒与登记》；契主自身的操作知识见《契约自知》；个案风险等级见《星辰系统》。

## 一、制度定位

契主通过契约自知掌握自身已经成形能力的第一人称操作方法；管理局不能直接取得这份内在知识，也不能通过设备扫描出完整权柄和全部能力。

管理局建立的是用于登记、支持、异常处置与任务匹配的**能力档案**。档案来自契主申报、受控演示、专项复核、历史资料对照与事件证据，是带来源、证据状态和时间边界的人类解释，不是权柄本体的绝对真相。

能力申报与复核不负责决定契约者善恶。法律责任、制度许可、保密要求和案件结论由行为、权限、证据与现实后果另行判断。

## 二、信息来源

管理局可以通过以下渠道了解能力：

1. **本人申报**：契主说明契约结构、权柄方向、已经成形能力、操作前置、已知限制与负荷表现；
2. **受控演示**：在明确目标、环境、记录范围与中止条件下，观察某项能力是否能够重复成立；
3. **专项复核**：由受训人员结合精神海状态、控制表现、连接条件和演示结果进行解释；
4. **星表与历史对照**：将契约星辰、相似权柄、家族旧谱和既往事件作为方向级参考；
5. **事件证据**：从现场痕迹、当事人陈述、医疗材料、现实证据和能力交锋结果推定可能作用；
6. **后续补报与复评**：契主形成新能力、原能力明显变化或事件暴露新表现后更新档案。

任何单一来源都不能自动推出完整权柄、全部能力、稳定上限或未来发展。

## 三、证据状态

每一项权柄判断、能力表现和关键限制分别标记证据状态，不以“已登记”覆盖差异：

| 状态 | 含义 |
| --- | --- |
| 本人申报 | 由契主主动提供，尚未经过完整复核 |
| 受控演示 | 已在限定条件下重复观察到，结论只覆盖当次条件 |
| 专项复核 | 经授权测试、人工解释与材料交叉后形成的管理结论 |
| 事件推定 | 依据事件结果和痕迹推断，尚未由契主确认或受控复现 |
| 存疑 | 不同来源冲突、表现无法复现或存在误导因素 |
| 机密封存 | 已有合法记录，但只向具备具体任务权限的人员开放 |

证据状态描述管理局知道到什么程度，不评价能力强弱。普通业务摘要可以只显示最低必要方向；更完整内容进入受控补充档案时，不构成失实登记。

## 四、能力档案

一份能力档案至少区分：

- 契约星辰与契约结构；
- 已申报或已确认的个人星辰权柄；
- 已经成形的具体能力；
- 仍属于潜在方向、尚未成形的推测；
- 能力成立所需的连接、目标、距离、环境或其他条件；
- 已观察到的范围、持续时间、复杂度与回收表现；
- 负荷、失控征兆、异常记录与安全中止方式；
- 每项内容的证据状态、信息来源、复核时间和保密层级。

档案只保存管理所需的可说明信息，不要求契主把无法语言化的全部内在体验交给管理局。管理局对能力的正式命名与分类是制度工具；名称可以修订，不能反过来限制权柄本体。

## 五、四套评价不得混用

### 精神之海评级

泉境、湖境、川境、海境、浩瀚境只描述精神之海承载深广，由精神检测、标准连接测试与人工复核形成。

### 控制能力画像

控制能力按精度、复杂度、稳定性、持续性与回收力分别记录。管理局可以根据受控演示、职业应用和事件表现形成描述性结论，但不设置全员统一的综合控制等级。

### 能力档案

能力档案记录已经成形的能力、成立条件、已知边界与证据状态。能力数量、权柄数量和档案保密级别都不构成战力等级。

### 个案风险等级

`D—S` 只描述一次正式个案协查所需的处置权限、人员规模、联动范围与监督强度。它评价事件，不评价人物。

上述四套信息可以共同支持任务匹配和风险判断，但不得合并为一条人物战力排名。

## 六、受控演示与专项复核

受控演示必须明确：

- 本次要验证的具体能力或限制；
- 可以接触的对象、精神区域与现实环境；
- 允许记录的现象与材料去向；
- 中止条件、恢复安排与现场责任人；
- 结论能够覆盖的条件范围。

演示能够证明某项能力在特定条件下成立，不能证明契主只拥有这一项能力，也不能证明其在所有现场都能达到相同结果。拒绝无必要的演示不自动构成隐瞒或风险升级。

精神检测只负责精神之海评级、状态与合法范围内的结构反应；它不能替代能力演示，不能读取契主的操作自知，也不能直接识别完整权柄。

## 七、更新、误差与隐瞒

能力档案是时间快照。新能力成形、控制表现变化、损伤、异变、长期停用和现场条件变化，都可能使旧记录失效。

本人补报、事件暴露、协查表现超出登记范围或不同来源冲突时，管理局可以先进行人工核验，再按必要性要求补报、受控演示或专项复核。修订时保留原结论、来源与变更理由，不能把后来的认识伪装成管理局早已全知。

契主可以因为隐私、家族压力、反情报、生存风险或违法目的选择隐瞒、模糊描述或虚假申报。隐瞒本身与利用能力造成伤害必须分别判断；只有与现实危害、非法控制、恶性外泄或持续逃避合法监管结合时，才据行为风险升级处置。

## 八、星契动物

星契动物无法按人类制度完整自述。其能力档案主要来自长期观察、重复行为、受控环境中的自愿表现、照护记录、有限传念、精神状态复核与事件证据。

照护者可以提供事实材料，但不能代替动物申报意愿、开放精神边界或同意能力演示。人类对动物能力的名称与解释始终是外部模型，应明确区分已经观察到的动作与研究者推测的权柄方向。

## 九、设定边界

- 管理局不教授契主最基础的精神海操作和已成形能力使用方法；它提供制度说明、比较知识、控制训练、异常识别、风险演练与任务资格训练。
- 星表、设备、档案、家族旧谱和事件痕迹都不能直接取得契主完整的契约自知。
- “管理局知道”必须能落到具体信息、证据状态、保密层级与时间点，不能作为全知叙事捷径。
- 契主知道怎样使用自己的能力，不代表管理局相信其申报，也不代表其使用合法、安全或符合任务权限。
