# 世界观共享模板

> 本目录只保存可复制骨架, 不保存项目事实。公共模板提供最低结构; 具体题材字段由项目在本地扩展。

## 模板索引

- [分类索引](category-index.md)
- [普通条目](entry.md)
- [机制专题](system.md)

## 使用规则

- 新建分类前, 先确认该分类是否真的需要长期维护。
- 新建条目后, 同步更新对应分类 `_index.md`。
- 未确认设定、候选机制和方案比较先放入 `.analysis/blueprints/` 或待确认区。
- 不为了套模板补写未定事实。
- 世界观条目只依赖 `BIBLE.md` 与其他世界观条目，不把人物卡、剧情节点、章节或动态上下文列为正式真源引用。
- 组织条目保存组织结构、岗位、权限与业务边界；具体人物任职、控制与个人责任由人物侧引用组织条目，不从组织条目反向依赖人物卡。
