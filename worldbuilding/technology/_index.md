# 技术索引

本目录存放与星辰契约稳定交叉的人为技术。现有正式条目包括药剂、精神检测与登记复评，以及近场精神异常筛查。普通通信、医疗、安保、交通和战术设备继续按现实物理层运行；只有当某项技术稳定改变契约者的检测、证据、处置或监管边界时，才单列正式条目。能力申报、受控演示与证据状态属于社会制度，不是检测设备功能，见[能力申报与复核](../society/能力申报与复核.md)。

人为技术不属于星辰契约能力。技术可以记录、比对或辅助判断已经在合法观测范围内显现的现象，也可以利用具体能力既有的成立条件参与现实处置；它不能赋予或转移星辰权柄、制造契主，也不能独立强制解除或夺取星辰契约，不能自动读取完整精神之海、识别全部能力或定位所有契约者。夺契所用的药剂、设备与现实控制手段只能辅助特定个人星辰权柄已经发动的过程，不能替代权柄、停止残契基础衰减或把残契修复为正常契约。不存在无视具体能力成立条件、能够统一屏蔽或隔离全部能力的通用技术；现场防护必须回到已知能力的视线、接触、语音、气味、通信或环境条件分别处理。
