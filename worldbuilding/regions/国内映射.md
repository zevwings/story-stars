# 国内映射

> 本页登记本作已确认的国内城市映射。未启用候选名、临时讨论名与待确认命名，不在本页作为正文引用依据。

## 一、映射原则

- 国内设置 34 个省级行政区；已启用城市之间的位置、交通和功能关系按各自正式地区页理解。
- 城市、地区与专名统一使用架空名称，不直接写现实地名。
- 现实原型、对应关系与现实专名不在正式真源登记。
- 辨识度较低的城市第一次出现时，应同时交代其城市身份或功能。

## 二、当前正式城市

| 正式名称 | 正式定位 |
| --- | --- |
| 桷洲市（通称桷洲，别称雾都、山城） | 西南两江之城，第一卷主场 |
| 槐京市（通称槐京，别称京城，功能称谓首都） | 本国首都与权力中心；星辰家族主要腹地、星辰管理局总部所在地 |
| 玉兰市（通称玉兰，别称魔都） | 沿海金融都会与资本线城市 |

## 三、边界

- “槐京市”是首都的正式名称，日常行文使用“槐京”；“京城”是其通行别称，“首都”是其功能称谓，均指同一座城市。正式机构名称使用已登记专名，如“槐京大学”。
- “玉兰市”是沿海金融都会的正式名称，日常行文使用“玉兰”，别称“魔都”；“玉兰国际邮轮港”是该城已启用的港口名称。
- “桷洲市”是西南主城的正式名称，日常行文使用“桷洲”，读作 jué zhōu；“雾都”和“山城”是其通行别称。后续任何新城市不得复用该名称。
- 其他地区按剧情需要启用，确认后再补入本页与对应专题页。
