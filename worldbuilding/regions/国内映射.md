# 国内映射

> 本页登记本作已确认的国内城市映射。未启用候选名、临时讨论名与待确认命名，不在本页作为正文引用依据。

## 一、映射原则

- 国内设置 34 个省级行政区；已启用城市之间的位置、交通和功能关系按各自正式地区页理解。
- 城市、地区与专名统一使用架空名称，不直接写现实地名。
- 现实原型、对应关系与现实专名不在正式真源登记。
- 辨识度较低的城市第一次出现时，应同时交代其城市身份或功能。

## 二、当前正式城市

| 正式名称 | 正式定位 |
| --- | --- |
| 江州（别称雾都） | 西南主城，第一卷主场 |
| 京城 | 本国首都与权力中心；星辰家族主要腹地、星辰管理局总部所在地 |
| 云间 | 沿海金融都会与资本线城市 |

## 三、边界

- “京城”是城市正名，与“首都”这一通称指向同一座城市。
- “江州”只指本作当前主城；后续任何新城市不得复用该名称。
- 其他地区按剧情需要启用，确认后再补入本页与对应专题页。
