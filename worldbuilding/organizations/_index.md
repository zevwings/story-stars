# 机构索引

## 引用边界

- 机构页只定义组织本体、稳定业务、权限、责任和运行边界，不登记具体剧情节点、节点 ID、事件顺序或人物后续结果。
- 正式剧情线可以引用并应用机构页；机构页不得反向引用剧情线，也不得以“承载某条剧情”为理由改写组织事实。
- 组织控制人、负责人及长期稳定的组织间关系可以作为机构事实登记；其具体出场、选择与关系变化仍由人物卡和剧情线承接。
