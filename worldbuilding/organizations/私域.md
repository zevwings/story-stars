# 私域

> 私人会员制会所正式设定。原经营期由顾清言控制；阶段五完成查封、旧体系终止与司法处置前置，尾声才完成新经营重置。本页只保存私域的场所结构、经营分层、组织接口与责任边界；具体人物事实归人物目录维护。

## 一、场所定位

- 原经营期的私域是顾清言实际控制的三家会所之一，也是其中唯一进入裴家—齐心现有黑产责任链的核心会所。
- 私域位于江州近郊一处背山临水的半山台地，前临安静水湾，后接低山林地；独立道路连接城区，地形、林木与园区退距共同隔开外部视线。
- 场所采用完成审核并缴纳会费后统一取得资格的私人会员制，以高度保密的封闭商谈、私人宴请、核心客户维护和高端社交为主要定位，面向经过筛选的高消费熟客、权贵客户和私人项目，不对普通散客开放。
- 会员资格不按身份等级或楼层逐项开通区域。会员可以正常使用园区会员公共区域、外围运动设施及主楼一至六层的会员空间；具体包厢、套房和设施仍服从预约、容量、时段、实际占用、隐私与现场安全规则，闭门会议和当次限定活动另按邀请进入。
- 会员准入与当次项目准入分开：会员可以独自预约、独自到场，也可以携带当次受邀来宾；受邀艺人、模特、演出人员和其他成年项目参与者可以按当次安排独自到场，但不因此取得会员身份。
- 原经营期由顾清言担任最终负责人并主要在私域活动；30 岁的店级负责人杨钰琪处理会员接待、空间预约、晚会执行、人员分流、异常处置与现场记录，不能因此切断顾清言对核心客户、人员接口、重大调度、离场安排与经营记录的实际控制。

## 二、园区与主楼

- 私域由一栋七层核心主楼、地下停车与后勤空间、内庭及外围会员运动场地组成。运动场地和必要的低调服务用房属于同一会所园区，不构成私域分店或独立经营机构。
- 主楼采用顺应山地高差的折线围院与逐层退台结构，不是垂直方盒子。低层横向围合内庭，四层以上逐步向临水一侧收窄，七层只保留退台式小体量私属空间；从入口侧观察时，林木、坡地和退台共同削弱完整七层的高度感。
- 园区外围配置高尔夫、马术、网球及其他会员运动空间。运动设施服务于会员休闲、非正式会面和园区景观隔离，不单独出售会员资格，不承接面向公众的赛事、旅游、团建或大众培训，也不把私域改写为高尔夫度假区或体育俱乐部。
- 高尔夫场地沿缓坡和临水草地展开；马术训练、马匹照料与林间骑行空间靠近背山一侧；网球及其他高频运动空间布置在较靠近主楼、但不干扰高私密楼层的位置。

### 主楼分层

| 楼层 | 稳定功能 |
| --- | --- |
| 地下空间 | 会员及受邀车辆停车、室内落客、设备、仓储、厨房后勤和员工服务空间 |
| 一层 | 门厅、会员核验、公共会客、酒廊及与内庭相连的公共空间 |
| 二层 | 会员娱乐与休闲，包括普通棋牌、台球、私人观影及酒吧休闲 |
| 三层 | 私宴包厢、封闭商务会面、小型演出或展示空间 |
| 四层 | 高私密包厢、休息套间、更衣及私人活动空间 |
| 五至六层 | 少量会员套房、短期留宿套间，以及顾清言用于经营事务的办公与核心客户接待空间 |
| 七层 | 顾清言本人专用的私属办公、休息与私人活动层，包括私人书房、小型会客与起居空间、独立休息套间、洗浴更衣空间、恒温无边泳池、内凹式私密露台、遮雨廊亭、屋顶庭园、下沉休息区和临水观景露台 |

- 七层不进入普通会员服务系统，普通会员、店级管理人员和项目参与者都不能凭职务、会员资格或其他楼层预约自行进入；访客只能由顾清言本人授权。
- 七层可以供顾清言办公、会客、洗浴、更衣、短时睡眠或偶尔过夜，但不设置完整的长期家庭生活体系，不构成她的固定住宅。

### 七层私属空间

- 七层室内与退台屋顶共同构成一个连续的私属控制区。专用电梯先进入双门前室，访客授权在前室完成；普通会员动线、员工巡场动线和其他楼层房间都不能穿过七层。
- 临水一侧设置恒温无边泳池、池畔平台和临水观景露台；建筑退台内部设置四周受遮挡、只向天空开放的内凹式私密露台，背山一侧设置可闭合格栅与厚帘的遮雨廊亭，屋顶庭园、短步道和下沉休息区连接各处。开阔观景露台与高遮蔽活动区分开，不用一片无分隔平台同时承担全部功能。
- 建筑体量、高女儿墙、错层退台、绿化和可调格栅共同切断来自低层露台、园区道路、运动场地、山侧道路、水面和远处建筑的直视线；高遮蔽区域可以看见天空与水光，但外部观察点不能看清其中人员与活动。
- 七层内部、泳池、廊亭和私密露台不设置联网摄像、智能音箱或自动云端记录设备。必要安保只覆盖专用电梯外厅和独立维护入口，镜头不得越过双门前室或拍入私属区域。
- 设备、泳池和园艺维护使用独立后勤入口，进入须经顾清言授权并形成提示；维护人员没有在有人使用七层时自行进入的日常权限。紧急通道保持可用，但开启前须在七层内部产生明确警示。
- 私密露台、泳池和廊亭均在数步内接回室内洗浴、更衣、清洁、饮水、保暖与休息空间。室外灯光使用檐下、墙脚和池水低位暖光，不以强背光向远处暴露人物轮廓；现实门禁、遮挡、隔音和退出路线负责形成私密条件，不调用星辰契约能力制造安全假象。
- 七层可以承载由成年参与者另行、逐次确认的私人活动；进入七层、使用泳池、留宿或曾经发生过身体关系，都不产生下一次活动、拍摄、观看、器物或具体身体行为的概括授权。

## 三、已确认业务

- 表层业务包括会员宴请、私人酒局、封闭商务会面、小型演出或展示、包厢服务与核心客户维护；场所可以提供宴会包厢、会面空间、休息与更衣空间及当次活动所需的基础服务。
- 私域可以向会员及当次获准的来宾提供套房和短期留宿，但住宿只附属于会所活动、商谈、宴请或经确认的私人行程，不面向普通旅客开放，也不承担旅游、商务出差或长期居住等常规酒店业务。
- 高尔夫、马术、网球及其他运动项目属于正常会员服务，可以承载运动、休闲与非正式会面；运动预约不产生已被他人占用的包厢、套房或闭门活动进入资格。
- 涉案业务包括成年人有偿陪侍、场外色情交易、欲望诱导订单及特殊目标接口；当次自愿交易、能力诱导、债务控制和明确强迫必须分别判断。
- [风归](江州风归数字内容有限公司.md)是原经营期成年模特、Coser、主播与活动人员的主要稳定职业来源；其中部分成年人另行选择承接会所社交陪同、有偿陪侍或场外私人交易。
- 万安影视文化另向私域提供部分成年艺人、模特和私人活动项目；独立从业者及其他来源仍分别存在，风归与万安都不是全部人员的统一入口。
- 酒店私人活动场地、私人宴请地点和其他临时合作场所按单调用，不属于私域分店，也不计入顾清言实际控制的固定场所数量。

## 四、准入边界

- 私域准入要求真实、持续的高消费记录和场所侧审核，不因一次消费、一次介绍或与某名服务人员发生关系而自动取得。
- 审核通过并缴纳会费后，会员可以在有效期内正常进入园区会员公共区域、外围运动设施及主楼一至六层的会员空间，不需要为不同楼层逐项取得进入权限；具体包厢、套房和设施仍按预约、实际占用和现场规则使用。
- 会员独自到场不需要临时拼成酒局、情侣或多人同行；单人预约只确认场所使用资格，不自动附带陪侍、演出、身体交易或其他人员安排。
- 会员可以登记成年受邀来宾；来宾可以按同行安排使用园区会员公共区域、外围运动设施及已预约空间，但不因此取得会员身份。艺人、模特、演出人员和临时工作人员等项目参与者可以按当次安排独自到场；两类身份都不扩张活动、陪伴、拍摄、观看或身体行为的权限。
- 一至六层不按会员等级逐层解锁；已被预约或专属占用的包厢、套房、闭门会议与当次限定活动仍服从房间隐私和邀请边界。七层只由顾清言本人授权，后勤、员工与档案空间按工作职责管理。
- 教练、球童、骑手、马匹照料人员、兽医及其他专业工作人员只取得排班和任务范围内的工作区域权限，不因长期服务接触会员隐私或进入主楼高私密空间。
- 云顶 KTV 店级负责人可以从稳定熟客中提出推荐，但推荐不等于会员资格，也不能替私域完成最终审核。
- 小鱼儿等自由兼职交易者可以提供普通圈层接触，不拥有替客人授予私域准入的权限。

## 五、人员、授权与留痕

- 会员宴请、商务会面、演出展示、社交陪伴、拍摄保存、第三方观看和具体身体行为分别成立；参加其中一项不自动授权其他项目。
- 会费和会员资格不购买任何具体人员的陪伴、演出、拍摄、观看或身体权限；涉及他人的项目必须由相关参与者另行、逐项授权。
- 风归对本人经手的招募、合同、账号、商务、排期、结算和会所项目转接承担责任；私域对人员接收后的入场核验、空间安排、现场调度、客户接口、离场控制与场所记录承担责任。顾清言同时控制两端时，不能用公司与场所主体分开切断其实际行为。
- 万安影视文化对其招募、签约、职业资源、项目安排和人员提供承担责任；私域对人员接收后的入场核验、空间安排、现场调度、客户接口、离场控制与场所记录承担责任。双方不能用“公司已经安排”或“场所只负责接待”切断各自实际行为。
- 场所正常运行可以分别形成会员审核与预约、来宾或项目登记、运动项目预约、空间与套房使用、人员排班、车辆与人员出入、结算及异常处置记录。记录只能证明对应环节，不能单独证明当事人对陪伴、拍摄、观看或身体行为的授权。
- 项目参与者独自到场、独自离场或单独结算，均不自动证明其是会员、自由交易者或已经同意项目中的全部安排。

### 契约安全巡查

- 私域设有固定的契约者安全巡查机制，用于保护高保密商务会面、发现未经授权的精神能力介入及处置契约能力失控风险；“固定”指职责和汇报链长期存在，不等于由同一人常驻或对每名会员持续扫描。
- 巡查只能在已经出现明显精神反应时被动记录某人的精神之海反应异于普通人、疑似契约者；不能为了确认身份、评级或能力而主动探查、刺激、试探或安排后续精神接触，也不能仅凭一次接触确认对方的星、具体权柄、登记状态、真实来意、思想内容或是否涉案。
- 被动标记只在对应场次的安全记录中留痕，直接报顾清言或私域核心后台，不进入普通会员推荐、前台接待、会员准入或项目服务流程。普通员工、来宾及云顶店级负责人于静不知道巡查者的契约者身份，也接触不到相关判断和记录。
- 精神反应异于普通人只构成当场安全提示，不是精神疾病判断，也不自动触发追加排查、拒绝准入、授予更高权限、证明犯罪或替任何关系与身体行为产生授权。

## 六、责任边界

- 原经营期的私域与云顶 KTV 是裴家—齐心共同控制并分利的两处固定实体场所；共同经营不等于两方全部产业合并。
- 顾清言控制的另外两家正常会所不自动进入私域业务、客户、人员、账目或犯罪责任链。
- 普通会员、运动教练与服务人员、正常商务活动、真实运动消费及成年人私人交往不因发生在私域而自动被定性为犯罪；经营方实际组织、调度、抽成、控制或掩护的行为另行认定。

## 七、阶段五后的司法处置与经营重置

- 顾清言在进入疗养监管前，向晏林交代一笔已经具备表面正常使用条件、但本质仍来自黑产收益的匿名账户及取用线索。晏林不接收、转移或使用该笔资金；账户由司法系统冻结，顾清言主动申报，资金经审查确认为黑产收益后进入追缴与私域案件专项处置账户。
- 该笔藏款继续保留顾清言的责任灰度，不承载上游定罪不可替代的唯一证据；追缴后用于受害者补偿、未涉案员工工资、合法项目善后和私域历史责任清理，不作为晏林的竞价款。
- 顾清言可以表达“如果私域最终未被拆除，希望晏林愿意让它换一种方式继续存在”的个人愿望；这是关系余痕，不产生资产处分、返回、房间、经营或收益权。
- 原经营主体、旧黑产项目、旧人员控制链、旧会员与结算接口及由此产生的准入和调度权限全部终止。场地和可保留设施完成取证、权属清理、评估与追缴后，因契约者活动记录、会员隐私和敏感设施进入有资格门槛的附条件限制竞价。
- 晏林的协查贡献只支持非公开处置通知、安全与保密资质背书及同等条件优先承接，不减免评估价、成交价或经营审查。他以合法自有资金或正常融资参与竞价，成交款进入司法处置账户，再以新主体重新申请许可、组建团队与会员体系。风归、万安、原会员、员工、合作方和项目参与者都不因旧身份自动进入新经营体系。
- 重置后的私域继续作为长期私人会员制会所运营，可以承载宴请、运动、短期留宿、私人聚会及成年人之间另行成立的自愿私人活动；会所不再组织有偿陪侍、撮合身体交易、承接欲望诱导订单、利用债务控制人员或出售他人的选择。
- 后续经营方向、会员范围与空间使用由晏林决定，日常店务可以交给新的职业管理团队；七层既有泳池、露台、廊亭、庭园和室内私属设施可以保留或重置用途。顾清言不保留股份、收益权、经营权、专属房间、七层权限或自动进入资格；原七层私属权限及她曾向任何访客作出的进入授权都随旧经营体系终止。

## 八、不得写偏

- 不把私域写成顾清言全部场所的总称、连锁品牌或统一总部。
- 不把私域写成面向公众的酒店、度假区、高尔夫俱乐部、体育培训中心或大型公开赛事场地；运动和短期住宿始终从属于私人会所。
- 不把外围运动场地写成任意公众可以进入的公共区域；会员可正常使用，来宾须由会员登记或取得当次活动邀请。
- 不把一至六层写成按会员等级逐层解锁的权限体系，也不以临时补款打开楼层；房间预约、实际占用、闭门活动邀请、后勤职责与七层私属边界仍分别成立。
- 不把七层写成普通会员楼层、会所统一指挥中心或顾清言的长期家庭住宅。
- 不把七层的露天感写成可被低层会员、工作人员、道路行人、运动场人员或水面来客实际看见；出现未经同意的第三方进入、可见或可听风险时，私人活动必须立即停止并转入室内处置。
- 不把云顶推荐写成自动入会，也不让单个服务人员拥有会员审批权。
- 不把契约安全巡查写成公开或隐蔽的入会测试、对所有来客的持续读心、主动精神探查，或能够一次识别星、权柄与真实动机的全知能力；被动标记不得发展成针对晏林的精神试探。
- 不把单人预约、单人到场、项目受邀或公司安排写成会员资格、陪侍安排或身体授权。
