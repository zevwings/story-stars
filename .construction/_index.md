# 施工真源索引

> `.construction/` 保存作者已经确认、写作时必须继承的执行规格。它是真源，但不是长期正典；若与 `BIBLE.md`、正式目录或已定稿章节冲突，服从更高层真源。

## 收录边界

- 收录已经确认的场次顺序、衣装、对白议程、章节分配与其他具体执行规格。
- 不收录候选、待确认项、方案比较、确认过程、废案或历史分析；这些内容保留在 `.analysis/`。
- 稳定人物事实、关系变化、世界规则与跨章状态必须同步进入对应正式目录，不能只依赖施工文件。
- 正文或定稿完全取代某份施工规格后，将对应施工单元转为 `consumed`，默认检索不再返回。

## 生命周期

- [active](./_status/active.md)：已确认并生效；普通检索默认读取。
- [bound](./_status/bound.md)：已挂接具体章节或场景；仅匹配目标时读取。
- [consumed](./_status/consumed.md)：已被定稿或更高层真源完整吸收；默认排除。
- [superseded](./_status/superseded.md)：已被另一施工单元替代；默认排除。
- [retired](./_status/retired.md)：已取消；默认排除。

每个施工文件使用稳定 `CON-xxxx` ID，并且必须恰好登记在一份状态文件中。不记录“已读／未读”；只记录规格是否仍生效、挂接、兑现、替代或取消。标准流转为 `active → bound → consumed`；只兑现一部分时继续保持 `bound`，或先拆成更小施工单元。

施工索引以 `_status/` 中登记的路径为内容清单。`active`、`bound` 建立完整正文索引；`consumed`、`superseded`、`retired` 只保留状态、兑现位置与源路径，历史正文需要复查时再按源路径读取。目录遍历只用于发现漏登记文件，不作为内容入口。
