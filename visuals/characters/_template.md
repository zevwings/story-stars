# 角色视觉资料创建模板

按当前任务选取需要的部分；省略未指定栏目，不创建空目录或占位条目。目录职责与创建时机见 [视觉资料说明](../README.md)，创建与批准流程由角色视觉生产协议及任务 Skill 执行。

## 角色根 README.md

长期偏好段只记录作者明确要求长期保留的差异；公共模块只引用，不复制正文。单次场景、动作与临时衣装不放在这里。

```markdown
# <角色名> · 视觉说明

## 正式资料
<本次所需正式人物资料的链接，不复制人物事实>

## 默认表现
<相对公共默认的画风、妆发、完成度或构图差异>

## 公共模块
- <模块 ID 与相对 visual_root 的路径>

## 适用范围
<适用任务和必要例外>
```

## 角色根 README.md 中的参考资料段

按身份或场景用途追加到同一角色 README，图片目录不另建 README。只收录参考时只填参考资料段，不推定长期表现偏好；按图片编号关联用途和状态。

```markdown
## <身份／场景>参考

图片：<相对角色 README.md 的图片目录或文件链接及对应编号>
用途：<参考哪些内容>
状态：<来源图片的实际状态，不把收录写成批准主脸>
```

## 角色根 README.md 中的生产记录导航

已有生产记录或复用模板时，在同一 README 中追加实际链接；不另建只承担导航的 records/README.md。批准身份仍以 records/identity/current.json 为准，不在 README 维护第二套批准指针。
