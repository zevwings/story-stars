## 人物专属表现偏好

### 五官参考范围

定脸时优先使用已收录的陈瑶图片，参考入口为 [身份参考池](images/sources/identity/)。重点借鉴眼睛相对面部的比例、柔和颊面，以及鼻唇到下颌的连续关系；这三组关系构成参考生成的保留范围。正式卡已规定的结构与年龄始终按卡执行，参考只补充相容的视觉细节。卡片未确定且不破坏上述关系的次级结构可在候选中探索，由定脸选图确认；不要求整张真人面貌复刻，也不把参考图片直接作为批准主脸。

参考池内 01–04 四张图片为普通参考，尚未批准为景雪瑶主脸。按以下用途选择，实际使用哪些图片由当次 Prompt 列明：

- `02-front-oblique.jpg`：辅助观察近正面的五官布局与眼面比例。
- `01-front-tilted.jpg`：补充面部轮廓与颊面体积，观察时区分偏头造成的投影变化。
- `03-left.jpg`、`04-right.jpg`：辅助观察左右侧转时鼻唇、颊面与下颌的衔接。

这些图片作为不同朝向的视觉参考，不作为严格正侧面的测量图。图片中的衣装、妆发、背景和调色不随之采用。

### 结构与呈现

实际 Prompt 从正式形象卡提取相互制约的结构关系，将脸部尺度与颊面体积、眼睛开度与横向长度、下颌收束与下巴过渡配对表达，避免只叠加“小脸、大眼、精致”等标签。本文件不另存一套五官参数。

风格化 3D 的动漫化程度服从人物结构与正式成年年龄，保留成年面部比例；漂亮度通过干净妆面、清晰五官焦点、柔和皮肤质感和连贯体积提升，不依靠继续缩短面部、放圆眼睛或削尖下巴。定脸比较时保持角度、光线与妆造接近，使差异落实到本次允许探索的结构。

### 定脸与表情复核

首次正脸以头部摆正、放松表情建立清楚的结构基准。静态、专注与笑开分别作为独立画面要求，不在一张图中同时表现。需要表情复核时，沿用同一候选或批准主脸，按正式形象卡检验眼睑、面颊与嘴形的协调变化。

现有四张参考主要支持静态与轻微微笑观察，尚不足以验证充分笑开时的形变；该项以正式形象卡为目标，在实际表情图中检查。表情复核按需进行，不作为作者批准正脸的前置要求。

### 批准后的复用

已有批准主脸后，以该身份为后续生图依据；外部参考仅在当次明确需要时辅助，不随每次生图重新塑造五官。日常、旗袍与幻想舞台的具体呈现沿正式衣装资料选择，保持同一身份的连续性。
