## 一、结论

当前的“6 位核心＋5 位非核心长期伴侣”实际是 **8 个需要持续维护的长期关系单元**：

1. 苏璃—唐雨薇；
2. 苏晚乔；
3. 安若曦—江岚；
4. 孙雅琪；
5. 许知夏—许知秋；
6. 白玥；
7. 童颜；
8. 楚辞。

[晏林关系档索引](../../characters/major/晏林/关系/_index.md) 还登记了大量阶段情人、付费关系与低频私人关系。因此，真正的问题不是“6＋5 这个数字好不好看”，而是作品同时背负了：

- 多个终局关系的独立建立、复选、排期、危机知情和结局协商；
- 大量阶段关系的独立边界与后果；
- 三条“脱控／获救—自由复选—进入长期关系”的重复结构。

### 明确推荐

结合作者对日常常驻结构的确认，当前推荐目标调整为：

> **5 位核心长期伴侣＋3 位非核心长期伴侣**

- 核心保留：苏璃、唐雨薇、安若曦、江岚、孙雅琪；
- 非核心长期保留：许知夏、许知秋；白玥仍须通过责任与独立生活条件门；
- 已确认移出终局长期伴侣：苏晚乔、童颜；
- 当前下一项：确认楚辞是否移出长期伴侣。若按本文推荐移出，最终为 `5＋3`；在楚辞确认前，已确认结果对应的暂定规模是 `5＋4`。

这不是删除苏晚乔或童颜。两人的职业、事件、友情、教育、恢复与阶段关系都可保留；只取消“必须进入终局共同伴侣秩序”的默认终点。

许家姐妹的保留理由不只是“双胞胎共同关系”的类型卖点。许知夏常驻野人产品工作，许知秋常驻工作室运营；两人分别覆盖晏林持续的工作、住所和普通人日常，是长期生活结构的一部分。这个事实足以支持长期关系，但仍须保证两人拥有分别确认的欲望、岗位、拒绝权和人物变化，不能把两席写成一个可互换套餐。

## 二、判断标准

设定多、节点多或已投入很多文件，只能证明改动半径大，不能证明人物必须保留长期席位。本文按五项判断：

1. **独立欲望**：离开晏林与亲密关系，是否仍有可追踪的外部目标；
2. **不可替代因果**：移出长期关系后，是否会切断开篇、主线或终局因果；
3. **横向关系**：是否与晏林之外的人存在能改变选择的关系；
4. **终点含义**：长期伴侣是否真正完成人物命题，还是削弱“可以离开”与“帮助不需要用身体偿还”；
5. **长期维护价值**：后续关系场是否会产生新变化，还是只重复“这一次也是她自己选的”。

## 四、关键移出方案

### 4.1 童颜：重要回归型私人关系，不进入长期伴侣秩序

作者已确认：童颜移出长期伴侣，但不降为与俞予安、王诗悦、宁悠悠相同的低频炮友。当前建议关系名称为 **“重要回归型私人关系（非长期伴侣）”**；关系强度登记为“重要回归”。正式命名可在实施时按人物关系模板收口，但以下边界已经成立。

她的最佳终点是获得独立安全生活与离开能力；她可以自由回来，但“回来”不再被用来证明救援、住所或资助最终换得了长期伴侣席位。

| 边界 | 俞予安／王诗悦／宁悠悠 | 童颜 | 长期伴侣 |
| --- | --- | --- | --- |
| 关系主轴 | 低频、私人、非承诺的成人玩伴关系 | 持续存在的个人情感与生活联系，亲密可低频回归但不是维系关系的条件 | 共同秩序中的稳定情感与责任关系 |
| 回归方式 | 单人或闺蜜组合按次邀约，可只在尾声／番外回声 | 可独立联系、在假期或空档来访；不依赖组局，也允许完全非性的回归场 | 按共同日程、必要事实与长期协商持续参与 |
| 非亲密联系 | 不承担固定情绪陪伴或生活义务 | 可以关心学业、工作、住所和日常，但双方不承担伴侣式随叫随到义务 | 存在稳定互助、必要知情和协商义务 |
| 终局权限 | 无固定排期、共同生活或长期席位 | 无固定排期、共同生活权、危机参与权、完整内圈知情权或“候补转正”预期 | 按正式关系参与共同生活与关键协商 |

这一区分必须通过行为实现，而不是只换标签：童颜要有自己的住所、课业、账户、同学朋友和日程；即使某次回来没有发生亲密，两人的联系也依然完整。尾声不安排她与晏林共同居住或长期常驻，可以让她在假期／空档主动来访，随后按学校和自己的安排离开；是否偶发留宿或亲密只按当次选择成立，不能再建立高频稳定回路。

- 保留 `PL-I-054—PL-I-056` 的初次交易、身体关系与梦魇显影，作为结构失衡事件；
- 保留 `PL-S-095`、`PL-S-163—PL-S-176` 的求助、安置、复学、独立生活和家庭责任线；
- `PL-I-057` 可替换为“独立生活后的主动回归确认”，重点验证她能离开、也能在无交换条件下回来；
- `PL-I-058` 可保留一次充分独立后的自由选择，但它不自动生成长期回路；
- `PL-I-059` 的“高需求”、`PL-I-061` 的“稳定可暂停回路”应退役，不再把她推回高频长期关系；
- `PL-I-060` 如保留，只处理“哥哥／爸爸”等称呼脱离救助依赖后的边界重认，不再作为稳定色情角色或伴侣身份的认证；
- 尾声优先展示独立生活与主动回归，亲密只是可选结果，不能成为她回归的唯一内容。

### 4.2 楚辞：以职业自由作为完整终点

- 保留 `PL-S-262—PL-S-264` 的会所交易、暂留训练与邮轮同行；
- 保留 `PL-I-084`、`PL-I-085` 的脱离订单后有限自主加入和私人选择；
- 保留 `PL-S-223—PL-S-225` 的职业承接、解约与复位；
- 退役或改写 `PL-I-080`、`PL-I-081` 的长期关系确认与首次兑现；
- 可以主动维持联系或完成阶段关系告别，不进入终局共同秩序。

### 4.3 苏晚乔：保留人物，取消核心终局席位

作者已确认：苏晚乔移出核心长期关系。这里的“移出”只指移出核心／长期伴侣阵容，不删除人物。

- 保留阶段一至二的认识、关系与自保训练；
- 让这段关系完成一次清醒分流，不再进入全员排期、危机知情和终局协商；
- 保留训练馆和苏晚乔的重要朋友／训练盟友位置；
- 不机械降级为“非核心长期伴侣”，因为那只改名称，不减少维护成本。

这会改动 BIBLE 的四核心关系簇、内圈知情次序、六核心协商节点、阶段弧线与时间线，属于高半径改动，不与童颜、楚辞的节点退役混成一批。

### 4.4 许知夏、许知秋：保留长期，但必须保持两条人生

作者已确认两人保留为非核心长期伴侣。理由是她们并非在阶段事件后偶尔回归，而是一直存在于晏林的现实生活：许知夏常驻野人产品与项目协作，许知秋常驻工作室运营，两人也持续参与共同生活。

这个决定推翻本文早先“质量优先时整组移出”的建议。保留后的重点不是继续证明双胞胎卖点，而是让两人分别成立：

- 许知夏的长期存在主要通过野人产品、项目协调、户外测试和安静的共同日常体现；
- 许知秋的长期存在主要通过工作室运营、异常升级、来访接待和活跃的共同日常体现；
- 共享住房、共同场景与双胞胎默契不能覆盖各自的工作合同、身体授权、拒绝、矛盾和长期选择；
- 每人至少保留一条独立于姐妹组合亲密的变化轴，避免“两个人占两个名额、实际只有一个角色单元”。

## 五、为什么条件保留白玥

白玥的大量节点来自案件、旧账、记录、程序和责任，长期关系并非案件线成立的必要条件。保留她的理由是，她可以承载一个其他长期伴侣没有的问题：

> 一个曾经主动伤害别人、后来也被控制的成年人，能否在责任不被抹消的前提下，仍然拥有重新建立关系的权利？

保留条件：

1. 监管、保护、案件责任与私人关系继续彻底隔离；
2. 晏林不能成为她唯一的住房、收入、社交与安全来源；
3. 补一条不依赖晏林的职业／生活恢复轴；
4. 长期关系不以监管解除、责任豁免或能力关闭作为交换；
5. 早期倒卷与身体关系的累计观感必须通过组合审读，不能只靠授权条文自证。

如果不准备落实这五项，白玥也应移出长伴，只保留为案件核心角色与阶段关系。

## 八、确认后的正式实施边界

只有作者完成一项明确确认后，才将对应改动进入正式实施计划：

1. 冻结当前工作树快照，避免覆盖已有人物、关系和剧情节点修改；
2. 用 `character-builder` 同步人物层级、关系档与索引；
3. 用 `plotline-manager` 退役、替换或改写真正依赖长期关系的节点，不批量删掉职业和事件节点；
4. 同步施工单元，不保留指向旧终局的隐性结果；
5. 用 `outline-generator` 同步 BIBLE、阶段弧线、时间线、梳概与结局共同秩序；
6. 使用 `story-review` 审查候选改动，再执行结构校验。

验收至少包括：

```bash
git diff --check
sw plotline validate --root "$PWD"
sw rag construction validate --root "$PWD"
sw check links --root "$PWD"
sw check references --root "$PWD"
```

当前工作树已有多组未提交改动；正式实施时必须按人物／节点限定路径，不做整文件回退，不把其他在途改动混入阵容精简批次。
