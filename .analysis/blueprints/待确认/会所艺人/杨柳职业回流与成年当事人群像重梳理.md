# 杨柳职业回流、新型药剂替代与成年艺人群像施工

> 本页保存已经确认但尚未升格正式人物卡、世界观与剧情节点的施工结构，不作为正式正典。当前正式边界仍以杨柳、乔宁既有人物卡、白玥相关正式节点及 `CON-0032` 为准。

## 一、事件接续

1. 杨柳明确拒绝裴怀山订单后，白玥仍越界施术；晏林完成完整逆流并立即追赶白玥，杨柳当晚由私域压下。
2. 白玥其后主动进入管理局程序，完成真实问询、保护接入与有限监管印；管理局再安排受控外部出现，使黑市外围形成她被强制带走的抓捕假象。
3. 白玥不知道裴家控制匿名平台，也不知道具体客户和上游；她是断头执行端，不参与回线钓鱼或药剂替代。
4. 裴家因能力执行端失败、失联和暴露风险，改用更容易由普通外围人员转交的新型违禁精神药剂；该方法比能力执行更稳定，却留下医疗、采购、运输、场所和批次痕迹。
5. 黑市接口向客户提供成品药剂，说明其催情、持久、致幻或控制用途，同时以“无明显副作用、不会成瘾”为口径隐瞒长期依赖与批次不稳。

## 二、杨柳与霍临川

- 杨柳自主离院后只恢复处理收入、合同和职业资源所需的有限工作联系；这不恢复原团队对私人安排、身体边界或案件陈述的概括权限。
- 霍临川三十六岁，是一家美妆公司的 CEO。他以旗下品牌广告代言为商务入口接触杨柳，掌握代言签约、曝光与续约资源。
- 霍临川通过黑市接口取得成品药剂，知道药剂用于催情、致幻或削弱选择，但黑市向他隐瞒成瘾、耐受、戒断与批次不稳。
- 霍临川是后续药剂事件的直接使用责任人；广告代言、赴约、资源获益、身体反应或药物造成的欲望都不构成杨柳的有效同意。
- 杨柳承担多次事件后的身体、记忆、职业与医疗后果，女性当事人一侧只写后果与证据，不细写侵害过程。
- 杨柳是否提供材料、提供到何种范围，由她逐项决定；她不成为卧底、诱饵或完整供应链证明人。
- 杨柳最终继续原职业、转签、停工或退出行业均不预先锁死，保持开放结局。

### 已废止的霍临川旧方案

- 删除“与核心犯罪链无直接关系”的定位。
- 删除前两次邀请被拒后停止、第三次由杨柳主动接受的三次邀请结构。
- 删除重度 C 总授权、场内完全主导和停止信号等正向或自愿交易施工。
- 不再用霍临川测试“当次授权不等于未来概括授权”；他现在是明知药剂用途后实际使用的黑暗线责任人。

- 黑市接口向鲁林霞隐瞒成瘾、耐受、戒断与批次不稳；这只拆分长期风险责任，不免除她明知用途仍实际使用的直接责任。

## 五、新型违禁精神药剂

### 定位

- 新品属于新型违禁精神药剂，是现实药物与毒品犯罪线，不属于星辰权柄，也不恢复或增幅星辰之力。
- 短期显性副作用相对较低，但需要长期、重复使用才能形成较稳定的控制和依赖；新品药效仍不完全稳定。
- 长期风险包括耐受、依赖、戒断、记忆或判断损伤及职业生活后果；不得用“低副作用”写成真正无害。

### 分类

药剂按两个维度组合，不把所有名称混成同一级：

- **适用版本**：女用型、男用型。
- **功能偏向**：催情型、持久型、致幻型及多种作用并存的混合型。

同一批次可以同时具有适用版本和功能偏向。新品存在功能串扰、持续时间偏差与个体反应差异，燕舒负责显影这种不稳定性。

### 供应与责任

`裴家推动药剂替代 → 黑市接口取得并向客户提供成品 → 黑市隐瞒成瘾与批次不稳 → 霍临川、鲁林霞等客户明知用途后实际使用 → 艺人后果、医疗记录与现实留痕反向显影`

- 黑市接口承担交易、虚假说明和隐瞒长期风险的责任。
- 霍临川、鲁林霞分别承担本人实际使用药剂及其后续侵害责任。
- 万安影视文化及相关经纪、私人项目接口按本人实施的筛选、包装、安排、施压和封口行为分别负责。
- 白玥不参与、不知情，也不能凭本人订单记录证明药剂上游。
- 不在本施工页细写药剂制造、取得、投放或规避调查的可模仿流程。
