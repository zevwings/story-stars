# 才艺与情欲写作工具优化方案（blueprints）

> 本文件为低于顶层真源（`BIBLE.md` 与 `STYLE.md`）的方法层与施工规划蓝图，属于派生分析层，不是正式正典。
> 本方案严格承接 [`BIBLE.md`](../../../../BIBLE.md) 的内容边界与三轴归属判据，以及 [`STYLE.md`](../../../../STYLE.md) 关于“深度情色欲小说”、正向 HD 主色带兑现、五感感官矩阵与“低频调味”词汇口径的要求。

---

## 1. 方案背景与目标

根据项目定位，本书定义为**深度情色欲小说**，以贴身跟男主为默认的第三人称多视角限知，其中**情欲与身体兑现是主色带**（高频、连续、有美感、写到底）。

为解决底层 AI 写作易陷入“干瘪流水账”、“旧网文词汇硬套”或“规则过度过滤导致表达别扭”的断层问题，本蓝图旨在建立一套**贯通角色设定与 Prompt/Skill 工具链的完整优化落地方案**。

### 核心指导原则
- **避免硬过滤**：不设死板黑名单，将旧套路词汇改为“**低频自然调味**”，重点把控重复频率与实感质感。
- **实体化转译**：将角色才艺/技能从“台前噱头”转译为“前奏拉扯、温度感知与信任交付”的情感介质。
- **双向轴落地**：在微观描写中兼顾五感感官实感与性心理防线拉扯。

## 2. 模块一：故事内“角色才艺/技能”的情欲化解构与转译

在深度情欲向写作中，角色的才艺（如职业技能、触觉敏锐度、声音控制、手艺、体能柔韧度等）绝不写成反差萌噱头、台前炫技或吸引力手段，而是作为**前奏拉扯、身体知觉与信任交付的自然载体**。

### 2.1 常见才艺的情欲转译矩阵

| 原始才艺/技能 | 旧网文处理（禁弃） | 深度情欲向转译（本方案） |
| :--- | :--- | :--- |
| **声音 / 歌唱** | 上台驻唱、舞台展示、吸引眼球 | 贴耳微吟、呼吸变调、喘息声线、情致拉扯与失控时的求饶/命令语气。 |
| **护理 / 手法 / 兽医 / 咨询** | 医术玄幻化、神医反差噱头 | 转译为对身体温度、肌肉紧张度、呼吸停顿的敏锐感知，提供极高安全感与支配/抚触介质。 |
| **舞蹈 / 柔韧 / 身姿** | 舞台跳舞、艳舞展示 | 转译为特定体位下的肢体张力、支配臣服中的肢体表达与物理沉浸感。 |
| **理性分析 / 逻辑** | 冰山学霸、冷漠说教 | 转译为理智崩溃前的别扭拉扯、羞耻挣扎与本能失陷的反差感。 |

### 2.2 四档色带中的才艺调度

1. **暖色带（日常/前奏）**：利用日常职业性格与小才艺互动，制造日常松弛感、拉扯与情欲前奏；
2. **主色带（正向 HD）**：将身体与感官才艺融入五感矩阵，写出有温度、有水汽、有物理摩擦力的写实 HD（参见 [`story/genres/18+HD纯肉.md`](../../../../story/genres/18+HD纯肉.md)）；
3. **深色带（暗色情趣）**：结合肢体掌控与心理引导才艺，实现双方成立、可喊停的绝对主导与臣服（参见 [`story/genres/深色情欲带.md`](../../../../story/genres/深色情欲带.md)）；
4. **黑暗压迫场（仅对敌/反派）**：严禁才艺美化，严格执行“双声部铁律”（参见 [`story/genres/黑暗压迫场.md`](../../../../story/genres/黑暗压迫场.md)）。

## 3. 模块二：Prompt & Skill 级工具链优化（低真源方法层）

在低于根目录真源的 Prompt 模板、`story-writer` runtime skills 与派生层（如 `.prewrite/`）中，构建 3 套核心微观生成模块。

### 3.1 18+ 五感矩阵 Skill 模块

在生成 B 场（正向 HD）或亲密高潮段落时，自动拓展五感维度：
- **触觉与物理量**：必须包含皮肤温差（微凉/滚烫）、汗水黏潮、肌肉收缩/紧绷、床褥/衣物摩擦感、重力量对比与包裹感。
- **听觉与呼吸**：低语、短促粗重的呼吸、湿润的碰撞声、压低的求饶或恶劣的试探。
- **视觉微镜头**：局部特写（锁骨起伏、泛红的眼角、咬住的下唇、收紧的指节）、肢体折角与光影。
- **嗅味与体温**：体温烘出的气息、颈侧发间的味道、津液交换。

#### 3.1.1 五感黄金配比与动态演变规则
1. **静态黄金配比（4:3:2:1 梯队）**：
   - **触觉与物理量（40% · 基石）**：温差、肌肉收缩、力量撞击与包覆感（撑起物理实感）。
   - **声音与语言/淫语（30% · 灵魂）**：耳畔低语、呼吸变调、别扭拉扯与叫声（注入情致与性心理）。
   - **视觉微镜头（20% · 点睛）**：仅抓改变情绪与姿态的特写（锁骨、下唇、指节、泛红眼角）。
   - **嗅味与环境沉浸（10% · 辅助）**：体温烘出的微香与津液吐息。
2. **五步推进中的动态比例演变**：
   - **前奏段**：声音/语言 40% + 视觉 30% + 触觉 20% + 嗅味 10%（主打视线与语言拉扯）；
   - **确认与升级段**：触觉 50% + 声音/喘息 30% + 视觉特写 15% + 嗅味 5%（触觉绝对统治）；
   - **高潮与收束段**：触觉（瘫软体温）40% + 声音（倦意低喃）30% + 视觉 20% + 嗅味 10%（转为温存余韵）。
3. **配比失衡避坑红线**：
   - 严禁“语言/对话占 70%”（沦为单薄台词本）；严禁“视觉姿势占 70%”（沦为冰冷摄影）；
   - 必须保持“触觉为底，声音贯穿，视觉点睛”的黄金架构。

### 3.2 微观性心理双向轴 Skill 模块

在动作推进中穿插心理防线动态变化：
- **主导方**：占有欲膨胀、恶劣试探、看对方失控的愉悦、克制之后的爆发、怜惜与掌控的交叠。
- **被动方**：理智防线崩解、羞耻感挣扎、感官超载的迷失、主动迎合与别扭拉扯。
- **交互拉扯**：求饶与不予、理智完全沦陷前的最后一次推拒（非真实非自愿）。

### 3.3 词汇应用规则（低频调味口径）

完全取消一刀切黑名单，执行以下三条词汇应用细则：
1. **允许低频使用**：在需要营造特定美感、古典意象或贴贴局部感官时自然使用套路词（如“娇躯”、“樱唇”、“花蕊”等），不强制替换。
2. **拒绝高频堆砌**：避免在同一章节或同一场 HD 兑现中连续、密集地重复使用相同词汇。
3. **结合实感与部位混搭**：不论是否使用套路词，必须搭配具体的温度、汗水、肌肉紧张度，并与“锁骨起伏”、“咬住的下唇”、“发烫的颈侧”、“收紧的指节”等实感微动作混搭使用，保持语言的鲜活与实感。

## 4. 模块三：角色亲密特征卡与模板建设

在项目 `intimacy/references/` 与 `characters/` 衔接层，补充各女主的“亲密身心特征卡”。

### 4.1 特征卡字段规范
每位核心女主须定义以下 4 项亲密特征：
- **声音与语气调子**：前奏/高潮/事后余温时的不同声音表现与对话习惯。
- **身体物理敏感与触觉倾向**：敏感部位、体温变化规律、对力量与体位的偏好。
- **羞耻锚点与别扭逻辑**：触发羞耻感的核心心理机制、口硬心软的表现形式。
- **深色情欲授权档位**：在 A/B/C 档中的具体授权边界（遵循 `深色情欲带.md`）。

### 4.2 详略节奏生成控制
在生成大纲或正文时，按节点控制详略：
- **里程碑场（首次/破防/关系质变）**：完整写满“前奏 → 确认 → 升级 → 收束 → 余波”五步 HD 兑现。
- **日常兑现场**：采用前奏 + 升级重点 + 软切黑/写实含蓄承接，保持呼吸留白，防止匀速堆肉。

## 5. 施工落步与验证计划

1. **第一阶段（模板与口径齐平）**：
   - 本蓝图文档存入 `.analysis/blueprints/才艺与情欲写作工具优化方案.md`。
   - 确认低频调味词汇口径与角色才艺转译矩阵。

2. **第二阶段（工具与参考库集成）**：
   - 在项目 `intimacy/references/` 下细化各女主的亲密身心特征索引。
   - 更新派生写作 prompts 与 `story-writer` runtime 规则配置。

3. **第三阶段（试写与核验）**：
   - 选取一处 B 场（正向 HD）重点段落进行试写，核验五感矩阵、性心理双向轴与低频调味词汇的实际呈现效果。
