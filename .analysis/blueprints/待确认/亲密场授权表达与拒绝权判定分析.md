# 亲密场授权表达与拒绝权判定分析

> **文件定位**：本文件为 `.analysis/blueprints/待确认/` 下的机制分析文档，用于讨论正向亲密、结构失衡下自愿与黑暗压迫场之间的判定口径，以及未来 `intimacy/context/` 的场次记录方式。
>
> **真源状态**：待确认分析，不直接修改 `BIBLE.md`、《深色情欲带》《黑暗压迫场》或人物亲密卡。正式采用前须再决定哪些内容升格为全局机制、哪些只进入专项上下文模板。

## 一、待解决的问题

当前项目一方面强调知情、自愿、可拒绝、可撤回，另一方面又需要让人物的亲密互动保持自然，不能把每一个动作都写成逐项口头谈判。因此需要回答四个问题：

1. 亲密意愿可以通过哪些语言与行为方式成立？
2. 「一方做了，另一方没有反对」在什么条件下可以视为接受？
3. 试探、接受、修改、拒绝和撤回应怎样区分？
4. 黑暗场究竟由「没有说同意」触发，还是由「拒绝权失效」触发？

本分析的核心方向是：

> 正向场不要求所有同意都以口头形式表达，但选择必须存在、回应必须可辨认、拒绝必须能够真实生效。黑暗场不以「有没有说同意」为唯一判据，而以真实不愿意、撤回后仍继续、选择能力被剥夺或拒绝事实上不能生效为核心。

## 二、正向亲密可以采用的成立方式

亲密不必只有「提出—口头同意—执行」一种流程。只要当事人仍能判断、选择、修改、拒绝和停止，可以存在以下成立方式：

| 成立模式 | 典型表现 | 判定要点 |
| --- | --- | --- |
| 商议确认 | 双方事前或当场讨论，同意、修改或拒绝具体内容 | 最清晰，适合高风险、留痕、第三方和会关闭表达通道的事项 |
| 询问回应 | 一方询问，另一方以语言或清楚动作回应 | 回应须能区分接受、犹豫、修改与拒绝 |
| 本人主动发起 | 她／他主动亲近、提出或开始某项互动，对方主动承接 | 主动发起只覆盖本人发起的范围，不自动开放相邻项目 |
| 试探—接受 | 一方发起低风险、可逆、能立即停下的试探，另一方主动靠近、回吻、回抱或继续 | 接受来自主动承接，不只是没有阻止 |
| 试探—修改 | 对方接受方向，但调整力度、称呼、姿势、对象或范围 | 修改后的范围成立，原试探范围不得继续外推 |
| 试探—拒绝 | 对方躲开、推开、说不要、收回回应或使用停止信号 | 对方须立即停止、换项或退出，不得反复磨拒绝 |
| 既有默契下自然进入 | 此前已经成立且可复现的范围，本次不从零谈判 | 既有默契允许自然发起，不取消当次拒绝与撤回权 |
| 行为性接受 | 一方开始后，对方以清楚、主动、持续的行为参与 | 必须能辨认出「本人选择参与」，不能只依据身体反应 |

由此可形成一条通用规则：

> 正向场允许商议、主动发起、临场试探、行为接受和既有默契下的自然进入；同意不必全部口头化，但不能把沉默、僵住、受压顺从、求生配合或纯粹没有反对写成愿意。

## 三、「做了，对方不反对」的三种不同情况

### 1. 没有反对，并且主动承接

如果对方在拥有拒绝能力和退出通道的情况下，出现以下可辨认行为，可以视为行为性接受：

- 主动靠近、回吻、回抱；
- 主动调整位置以继续互动；
- 清楚地引导力度、速度或范围；
- 主动复述、回应或把动作继续下去；
- 中断后由本人再次发起；
- 在可以离开的情况下明确选择留下并参与。

这里真正构成接受的不是「没有反对」，而是「正在主动参与」。

### 2. 没有反对，但也没有可辨认回应

以下表现不能直接视为同意：

- 完全静止或僵住；
- 持续沉默；
- 目光回避、明显失神；
- 没有推开，但也没有承接；
- 因害怕、权力压力或不知如何处理而顺从；
- 只有非自主身体反应，没有人物选择证据。

这种状态应当记为「状态不明」，而不是正向接受或自动黑暗。推荐流程是：

```text
试探
→ 没有可辨认回应
→ 停顿、降速或询问
→ 得到接受／修改／拒绝
```

如果一方在状态不明时不断升级，导致对方实际无法使行为停止，则会从模糊状态转向拒绝权失效。

### 3. 没有反对，因为没有拒绝权

如果当事人存在以下情况，「没有反对」不具备授权价值：

- 已经拒绝，但拒绝不会使行为停止；
- 拒绝会立即触发足以迫使其配合的惩罚、伤害或控制；
- 无法说话、无法动作，且没有其他有效停止通道；
- 断片、昏迷、无反应或完全不能判断与选择；
- 被精神控制到不能形成或表达真实选择；
- 只是在求生、减轻伤害或完成被强迫的脚本。

行为发生、身体配合或身体反应都不能反向证明意愿成立。

## 四、拒绝权的操作性定义

「拥有拒绝权」不能只看理论上能否说出一个“不”字，而应同时满足：

1. **能够形成选择**：当事人仍能理解当下行为、判断自己是否愿意。
2. **能够表达选择**：语言、动作或另设信号中至少有一个有效通道。
3. **表达能够被识别**：信号不会与普通挣动、闭眼、抓握或角色台词混淆。
4. **拒绝能够使行为停止**：说不、撤回、僵住或使用停止信号后，对方会停下或降速确认。
5. **拒绝不会被即时强迫性后果架空**：不会因为拒绝立即遭受足以迫使其违背真实意愿继续的惩罚。

因此，「可拒绝」不是人物纸面上拥有一个选项，而是拒绝在场景中确实能够产生效果。

## 五、黑暗场的建议判定

### 1. 推荐定义

黑暗场可以围绕「拒绝权失效」统一，但需要写成精确判据：

> 任意一方真实不愿意、已经撤回、完全不能形成或表达选择，或者现实中无法使拒绝生效，而另一方仍让亲密行为发生或继续，即进入黑暗压迫场。

拒绝权失效可以分为三类：

| 类型 | 表现 |
| --- | --- |
| 表达被无视 | 已经拒绝、撤回或喊停，对方仍继续 |
| 表达通道被剥夺 | 无法说话或行动，也没有可用停止信号，对方仍继续 |
| 选择能力被剥夺 | 断片、昏迷、精神控制或完全不能判断与选择 |

另有一类需要按实际作用判断：

| 类型 | 判定 |
| --- | --- |
| 拒绝伴随代价 | 如果当事人仍真实愿意且拒绝会使亲密停止，属于结构失衡下自愿；如果威胁或代价实际把不愿意压成被迫配合，则拒绝权已经失效，进入黑暗场 |

### 2. 与当前正式真源的关系

当前 `BIBLE.md` 已经把「真实不愿意或撤回后仍继续」和「选择被完全剥夺」列为黑暗压迫场判据，也明确结构失衡、债务、利益、生计和身份压力本身不自动触发黑暗场。

如果正式采用「拒绝权失效」作为统一上位概念，需要确认它是否只是对现有判据的重新表达，还是要扩大黑暗场范围：

- **最小调整方案**：拒绝权失效只是现有两项判据的统一解释，不改变结构失衡下自愿的范围。
- **扩大判据方案**：只要当事人现实中没有可生效的拒绝权，即使正文没有明确写出真实不愿意，也直接进入黑暗场。

推荐采用最小调整方案。否则需要同时重写 `BIBLE.md` 的结构失衡、自愿交换场、威胁与有限知情口径，并重新审查云顶 KTV、债务关系、公司安排和付费关系等大量正式内容。

## 六、试探权限不等于完成权限

「所有内容都可以试探」不能按字面扩展到所有行为。试探本身也会产生后果，因此应按可逆性和风险分层。

### 1. 可以通过临场试探建立的内容

通常包括低风险、可逆、能够立即停止的行为：

- 靠近、拥抱、亲吻；
- 称呼、姿态和轻度角色表达；
- 已有关系范围内的节奏、位置与轻度力度变化；
- 不关闭拒绝通道的低风险触碰；
- 此前已成立项目的自然复现。

试探后必须允许接受、修改、拒绝或中止。

### 2. 必须事前商议或明确确认的内容

以下行为不能依靠「先做，再看是否反对」建立：

- 拍摄、保存、传播；
- 第三方观看、第三方加入；
- 药物推动；
- 精神读取、精神介入；
- 明显伤害、持续疼痛或难以恢复的留痕；
- 窒息、颈部受力；
- 无法快速解除的束缚；
- 会夺走语言和动作表达通道的玩法；
- 命中此前明确拒绝的对象、动作或场域。

这些行为一旦发生，后果无法通过事后拒绝撤销，或者会关闭拒绝通道，因此必须先取得清楚授权并建立替代停止信号。

### 3. 默认同意的准确含义

关系中的「默认」建议定义为：

> 既有默契可以产生默认发起权或默认试探权，不产生不可撤回的默认完成权。

即使此前已经多次成立，对方本次仍可不回应、修改、降速、拒绝或中途撤回。

## 七、结构失衡下自愿与黑暗场的分流

建议继续保留三个独立判断层：

### 1. 正向亲密

- 当次真实愿意；
- 能够判断与选择；
- 有可用的拒绝和停止通道；
- 拒绝会被尊重；
- 文本不把身体反应代替人物选择。

### 2. 结构失衡下自愿

- 当次真实愿意；
- 拒绝能够使亲密行为停止；
- 同时存在付费、生计、债务、合同、身份落差或职业压力；
- 当次自愿不证明结构自由，也不产生后续授权；
- 外围责任和现实后果必须继续承接。

### 3. 黑暗压迫场

- 真实不愿意或已经撤回，行为仍继续；或
- 完全不能判断、选择或表达，行为仍发生；或
- 威胁和控制使拒绝事实上不能生效，只能被迫配合；
- 身体反应和求生配合不构成同意；
- 必须走黑暗场的文本立场、双声部和后果承接。

## 八、`intimacy/context/` 的场次记录建议

`intimacy/context/` 可以作为亲密专项的「场次记录＋当前摘要」层。它不保存完整露骨正文，也不独立创造授权；每项重要变化应回指正式剧情节点、定稿章节或明确登记的项目初始状态。

### 1. 当前摘要建议

```md
## 当前摘要

- 当前关系阶段：
- 当前调用强度：
- 可直接复现：
- 可临场试探：
- 须先商议：
- 当前禁用：
- 已建立的停止通道：
- 影像与第三方权限：
- 最近一次变化：
- 最后同步来源：
```

### 2. 单场授权过程建议

```md
## 本场授权过程

- 发起方式：本人主动／对方主动／双方自然进入
- 起始依据：临场试探／口头商议／既有默契
- 对方回应：主动接受／接受并修改／拒绝／状态不明
- 拒绝通道：语言／动作／离场／另设信号
- 拒绝是否有效：是／否／未触发
- 中途变化：升档／降速／换项／撤回／中止
- 最终定性：正向／结构失衡下自愿／黑暗
```

### 3. 分项记录建议

```md
| 内容 | 发起方式 | 对方回应 | 本场结果 | 后续继承 |
| --- | --- | --- | --- | --- |
| 某称呼 | 临场试探 | 主动回称 | 本场成立 | 后续可再次试探，不是永久默认 |
| 某动作 | 本人主动 | 对方承接 | 成立 | 可在同等条件下复现 |
| 影像 | 事前询问 | 明确拒绝 | 未发生 | 后续仍无权限 |
```

### 4. 场次记录的继承边界

- 本场接受不自动变成永久许可。
- 可复现表示可以自然发起或在同等条件下调用，不取消当次撤回权。
- 新对象、新场域、新第三方、新留痕方式与新风险等级分别判断。
- 「状态不明」不能登记为已确认。
- 明确拒绝应登记为当前禁用或须重新商议，不允许反复越界试探。
- 黑暗场只记录侵害、求生反应与后果，不产生正向关系授权或亲密默契。

## 九、建议形成的四级调用状态

未来可以不只记录 A／B／C，还给每项内容增加调用状态：

| 状态 | 含义 |
| --- | --- |
| 可直接复现 | 既往已成立，可以在同等条件下自然发起；仍可当次拒绝或撤回 |
| 可临场试探 | 尚未形成稳定默契，但可以用低风险、可逆方式试探 |
| 须先商议 | 高风险、留痕、第三方或会关闭拒绝通道，必须先取得明确确认 |
| 当前禁用 | 已明确拒绝、条件未成立或项目硬边界禁止，不得继续试探 |

A／B／C 只表示当前强度基线，不负责代替上述分项授权状态。
