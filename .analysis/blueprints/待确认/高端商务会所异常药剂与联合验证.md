# 高端商务会所异常药剂与联合验证｜待确认方案

## 候选定位

- **原登记 ID**：`PL-S-010`；撤出正式层后不作为有效剧情节点使用。
- **当前层级**：`.analysis/blueprints/待确认/`
- **候选功能**：会所异常药剂事件从现实违法疑点推进为普通调查与管理局协查共同验证的入口。
- **未决核心**：事件是否保留、目标场所身份、最终归档主体、与训练馆异常补剂及其他案件的因果关系。
- **候选中心人物**：晏林、顾清言及相关成年接触对象。

## 候选前置状态
- **人物前置**：晏林以协查者身份提供受限精神反制协助；普通调查负责现实犯罪与外围安全。
- **关系前置**：场外受害者可自主选择去向、求助和信息转交范围。
- **世界观 / 势力前置**：药剂、精神侵蚀与现实犯罪分别核查，不互相替代；目标会所属于裴家—齐心共同控制、由顾清言公开经营的多场所网络之一，但不是两家全部黑产的统一总部。
- **线索前置**：阶段二异常药剂与撤回陈述进入正式调查入口；晏林此前由多名成年关系对象的普通聊天与入梦取得多场所、万安项目和债务入口的主观核查方向。

## 候选必须发生
- 普通调查核查药物控制、强迫陪侍、交易与隐私侵害等现实事实。
- 管理局核查未登记精神能力与外泄风险，不把推测写成定罪。
- 会所公开经营层与只向少数会员开放的黑产层被现实证据区分；普通员工和合法业务不因场所涉案被整体推定为共犯。
- 成年场外服务女孩在脱离会所即时控制后，重新选择去向、是否求助、是否联系官方及可以转交的信息范围；获救不使她自动依附晏林、工作室或任何机构。
- 联合验证确认顾清言是会所实际管理者，场所、门禁、排班、客户和交接记录首先形成指向她的第一环现实责任，同时发现万安私人项目、章绍衡债务对象与裴家—齐心共同分利的外围痕迹；刘秉文不构成本场所日常控制接口。
- 联合验证确认白玥是与 KTV 管理方长期合作的欲望契约者；她只能提供处理后任务包和个别目标异常后续入口，不能独立证明人口转运、药物供应或上游完整关系。
- 会员、公司挂账、车辆、门禁、用工、医疗、药剂和人员调度记录形成可以继续追查的现实证据组合；精神材料只提供能力痕迹与线索辅助，不单独替代现实证据。
- 晏林前期梦境材料不直接进入证据链，也不能据此把梦境对象定性为受害者、证人或嫌疑人；普通调查须在不知道或不依赖具体梦境内容的条件下独立核实对应现实事实。
- 晏林须说明梦境线索的来源性质与主观局限，但只披露与犯罪、现实危险或本案调查目标直接相关的必要部分，不交出无关私人内容；梦中材料仍不能代替现实证据。
- 管理局将晏林在联合验证中超出登记梦境方向的实际效果记为一次可归档的能力边界疑点；具体表现与发生场景留章节施工确定。
- 会所违法业务进入查封、资产处置与黑产接口拆除，齐心及上游责任继续交由反派主线追查。

## 候选变化
- **人物变化**：晏林在现实证据与精神风险之间承担受限协查责任。
- **关系变化**：受害者、证人和协查者之间的授权与告知边界进入正式流程。
- **知情范围变化**：不同机构按任务权限分层取得信息。
- **世界观 / 势力变化**：会所成为现实黑产与精神控制交叉验证的固定接口。
