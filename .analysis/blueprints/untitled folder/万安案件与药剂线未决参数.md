## 一、药剂轴的最低现实证明结构

`PL-M-022`、`PL-S-184`—`PL-S-186` 中与药剂有关的部分，尚需在后续药剂线专项中确认：

1. 什么现实材料分别证明不同药剂的研发、小批量生产、流转、使用、对外出售和责任人控制权。
2. 裴家核心责任人在研发、小批量生产、国内使用和对外出售中的各自位置。

已确认但不再展开的边界：药剂由裴家境外医疗机构自行研发、小批量生产与出售；国内分为黑市和裴兰馨直接下场两个渠道；艺人线由裴兰馨亲自用药及“裴兰馨吩咐—助理执行—反馈”闭合，不再另设批次销售桥。

## 二、药剂线专项留待后续讨论的参数

1. 裴家药剂除内部使用与少量委托外，是否形成稳定的个案式黑市服务。
2. 功能性需求除裴家自用外，是否包括齐心委托和独立黑市客户。
3. 裴怀山如何阅读和使用药剂反馈，同时不越界成为医学专家。
4. 强迫调用是否形成一次性订单、期限服务、对象交付三类少量黑市委托。
5. 不同匿名黑市入口之间是共享规则、有限互认，还是完全独立运行。
6. 裴家的对外订单是自有封闭入口，还是经外部匿名入口调用中介与执行者；无论哪种都不得把裴家写成公共黑市入口的控制者。

## 三、只在命中章纲时决定的单章参数

以下内容不阻塞线路闭环，不应预先升格为世界观或长期剧情事实。

### 3.1 万安艺人调查与保护

1. 合同条款的具体措辞与金额，以及作品、品牌、项目和媒体的虚构名称。
2. 首轮询问对象、代表性片段、可见材料和发现顺序。
3. 个案的精确次数、严格总排序、章序与章尾停点。
4. 对外停工或休养口径，以及安全住所、联络方式和探望安排。
5. 承载风险升级的具体可见事件。

### 3.2 药剂

1. 药剂外观、包装与非操作性检查细节。
2. 具体症状组合、发生次数，以及询问、医疗或记录发现的章序。
3. 客户、项目和媒体的虚构名称。
4. 侯瑞驰面对鲁林霞权力标记时的具体触发组合；不得改写成对女性的性吸引。
5. 调查方取得某项药剂记录的具体方式；不写可模仿的规避取证、身份伪造、潜入、诈骗或药剂操作方法。

### 3.3 风归回流与艺人线交叉

1. 钱韵说情场的具体对白，以及顾清言是否以触碰晏林胸口完成调情与判断。
2. 各次回流采用完整场景、压缩交代还是背景回声。
3. 六人的单场衣装、空间、项目名与具体身体范围；面向晏林的接待已固定为非付费，不再保留费用参数。
4. 止损、风归回流、钱韵缺席与楚辞初遇在具体章纲中的交叉方式。
