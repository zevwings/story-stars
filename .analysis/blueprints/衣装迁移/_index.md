# 衣装体系迁移｜施工入口

> 本目录是衣装体系升级的施工层，不是正式人物真源。正式衣装事实仍以 `characters/*/衣装.md` 为准；本目录只保存迁移方法、批次、检查项与尚未执行的工作。

## 迁移目标

把当前容易被正文机械调用的“代表色＋固定款式”写法，升级为：

> 稳定审美基因＋可变化的现代衣柜＋场景组合逻辑。

迁移不是为每个人建立完整商品清单，也不是删除已经成立的辨识锚点。最终要做到：

- 同一人物在职业、通勤、私人、正式和专项场景中能够自然换装。
- 不依赖单一代表色或固定套装，仍能从材质、轮廓、搭配方式和动作判断人物。
- 衣装页只保存跨场景稳定事实；具体某场穿什么、怎么脱卸、事后如何处置，不固化为静态人物真源。
- 新人物直接使用新版模板；现有正式衣装页全部进入迁移闭包，按问题强度处理，不做无差别全文换壳。

## 文档分工

1. [全量范围与迁移基准](全量范围与迁移基准.md)
   - 枚举当前全部 21 份正式人物衣装页。
   - 定义已有衣装页的存量闭包与未来新增衣装页的准入条件。
   - 为每个人记录保留、改写、迁出／核实项和迁移强度。

2. [公共模板迁移](公共模板迁移.md)
   - 定义新版 `characters/_template/衣装.md` 的结构。
   - 说明 `characters/_template/README.md` 需要补充的使用协议。
   - 固定正式人物衣装页与亲密施工层的边界。

3. [亲密内容迁出规则](亲密内容迁出规则.md)
   - 判定旧衣装页中的亲密内容应保留、迁入亲密档案、迁入场景施工、进入章级专项还是删除。
   - 明确迁出不等于机械搬运，不为搬运建立第二真源。

4. [女主分批迁移](女主分批迁移.md)
   - 覆盖 7 位核心女主与 5 位非核心长期伴侣。
   - 按重构、扩展、轻量对齐三个批次推进。
   - 记录每个人的保留项、主要缺口与迁移重点。

5. [男性角色迁移](男性角色迁移.md)
   - 覆盖当前已经建立正式 `衣装.md` 的男性角色。
   - 与女主共用同一个公共模板，不建立男性专用模板。
   - 尚未建立衣装页的人物不因本次迁移批量补档。

6. [迁移执行与验收](迁移执行与验收.md)
   - 规定每一批实际修改的顺序。
   - 提供逐文件检查、引用检查、差异检查与完成判据。
   - 防止迁移过程中制造新的固定大清单或第二真源。

7. [迁移验收记录](迁移验收记录.md)
   - 记录 21 份正式衣装页的实际处理结论。
   - 记录亲密内容去向、横向撞位与全局验收结果。

## 真源边界

| 内容 | 归属 |
| --- | --- |
| 通用衣装页字段、填写方法 | `characters/_template/衣装.md`、`characters/_template/README.md` |
| 角色稳定色彩谱系、材质、轮廓、职业衣装与禁区 | 对应 `characters/*/衣装.md` |
| 公共亲密衣装安全规则、材质和结构边界 | `intimacy/mechanisms/` 中对应正式机制 |
| 角色长期稳定的亲密偏好 | 已启用的角色亲密档案 |
| 某一场具体服装、选择原因、穿脱动作、退场与事后流向 | `.analysis/blueprints/` 或具体亲密场景设计 |
| 迁移顺序、方案比较、检查记录 | 本目录 |
