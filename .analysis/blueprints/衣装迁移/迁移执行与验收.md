# 衣装迁移执行与验收

> 本文用于后续正式修改时控制范围。每一批迁移都是独立任务；没有作者明确开始指令时，不修改正式模板或人物衣装页。

## 一、执行阶段

### 阶段 0：冻结任务范围与建立迁移基准

每批开始前列出本批允许修改的精确路径。默认不修改：

- `主卡.md`
- `形象.md`
- `契约.md`
- `context/`
- `story/plotlines/`
- `worldbuilding/`
- 正文章节

如果衣装迁移暴露职业、关系或世界事实冲突，只列问题，不顺手改其它真源。

全量范围、增量准入与逐人初始判断见 [全量范围与迁移基准](全量范围与迁移基准.md)。当前已有正式衣装页的 21 人全部进入存量闭包；尚无衣装页的人物只在满足准入条件后按需建档。

### 阶段 1：升级公共模板

目标文件：

- `characters/_template/衣装.md`
- `characters/_template/README.md`

要求：

- 只建立结构和填写协议。
- 不把任何具体女主的颜色、材质或款式写入公共模板。
- 不要求所有角色填写相同场景。
- 不建立第二个衣装模板或兼容别名。

状态：已完成。正式结构以 `characters/_template/衣装.md` 为准，迁移目标与验收记录见 [公共模板迁移](公共模板迁移.md)。

### 阶段 2：判定亲密内容去向

逐人物改写前，先按 [亲密内容迁出规则](亲密内容迁出规则.md) 将旧内容判为：

1. 保留在普通衣装页。
2. 迁入已有亲密角色档案。
3. 迁入具体场景施工。
4. 迁入已确定的章级专项。
5. 删除／不继承。
6. 待核实。

不得把“迁出”理解为机械搬运，也不得为保存旧内容临时建立第二真源。

### 阶段 3：逐人迁移

每个人按相同顺序处理：

1. 从旧页提取已经成立的稳定审美。
2. 标记职业事实和真实生活场景。
3. 把固定色名改成色彩谱系。
4. 把固定单品改成组合逻辑。
5. 增加必要的天气、季节与状态偏移。
6. 保留少量辨识锚点，取消强制每次出现。
7. 将过度具体的亲密施工从静态页收缩。
8. 保留原有禁写边界，不因结构升级丢失授权和职业伦理限制。

### 阶段 4：批次验收

一批完成后立即检查，不等全部人物修改完再统一返工。

角色批次不再等同于全量范围。实际执行按 [全量范围与迁移基准](全量范围与迁移基准.md) 的强度与依赖拆分，至少覆盖：

1. 第一批女主整体重构：唐雨薇、江岚、苏璃、童颜。
2. 第二批女主局部扩展：安若曦、温婉、苏晚乔、白玥、楚辞。
3. 第三批女主轻量对齐：林芷兰、许知夏、许知秋。
4. 第四批男性角色迁移：唐雨霖、唐雨宸、齐心、晏林、徐清。
5. 其他既有衣装页：沈宁、阮清黎、陆佳凝、顾清言。

## 二、单角色验收清单

### 真源

- [ ] 新内容只来自已确认人物身份、职业与现有审美。
- [ ] 没有新增未确认关系、赠物、品牌合作、制服制度或职业权限。
- [ ] 没有把候选穿搭写成角色已经拥有的确定单品。
- [ ] 没有在衣装页维护剧情进度或关系阶段状态。

### 现代多样性

- [ ] 核心色域之外存在合理邻近色与低频强调色。
- [ ] 禁用项描述的是错误用法，而不是无必要地封死整个颜色。
- [ ] 至少两种不同轮廓都能保持人物成立。
- [ ] 职业、普通日常、正式和私人场景之间有真实差异。
- [ ] 天气或状态变化能改变层次，而不是只更换颜色名称。

### 人物辨识

- [ ] 不写代表色时，仍能从材质、比例、动作和正式度判断人物。
- [ ] 稳定锚点只作轻点，不要求每次出现。
- [ ] 与色谱相近的其他女主有清楚差异。
- [ ] 服装没有替代人物性格、职业能力或关系事实。

### 私密边界

- [ ] 只保留跨场景稳定偏好与禁区。
- [ ] 没有固定某场脱卸顺序、具体破损结果或事后衣物流向。
- [ ] 公共职业服装不自动变成情趣服装。
- [ ] 衣装便利性不构成亲密授权。

## 三、横向撞位检查

每批完成后至少比较以下组合：

| 组合 | 重点 |
| --- | --- |
| 安若曦／江岚／楚辞／白玥／林芷兰／阮清黎 | 冷白、蓝灰与长线轮廓是否仍然撞位 |
| 苏璃／苏晚乔／童颜 | 粉、白、浅紫是否被写成同一种青春甜感 |
| 唐雨薇／苏晚乔 | 红色、行动感和贴身衣装是否混同 |
| 温婉／许知夏／许知秋 | 暖白、针织和生活感是否缺乏职业差异 |
| 许知夏／许知秋 | 是否在迁移中擅自建立稳定差异 |
| 唐雨宸／唐雨霖／齐心 | 西装、深色和社会位置是否写成同一种商务男性 |
| 晏林／徐清 | 浅色、干净和温和是否写成同一种文职气质 |
| 沈宁／顾清言／陆佳凝 | 成熟女性、职业完成度与管理位置是否写成同一种深色正式气质 |

横向比较优先看：

1. 色彩明度与饱和度。
2. 材质光泽和重量。
3. 纵向／横向、宽松／收束、短促／长线的轮廓。
4. 配饰密度。
5. 职业场景。
6. 穿衣动作和整理习惯。

## 四、文件与引用检查

每批完成后执行：

1. 检查目标文件 Markdown 标题层级和相对链接。
2. 搜索旧小节名是否仍被其它文件直接引用。
3. 检查双胞胎两份衣装页是否保持同步。
4. 检查是否误修改任务范围外文件。
5. 检查空白、尾随空格与差异格式。
6. 只报告本批实际修改与未验证项。

## 五、完成定义

整个迁移只有同时满足以下条件才算完成：

- 公共模板和说明已经升级且职责一致。
- 当前全部 21 份正式人物衣装页均已迁移或完成新版验收。
- 已确认职业都有现实衣装接口。
- 主要角色间的色谱撞位已经通过材质、轮廓、场景和明度关系拉开。
- 具体亲密场景施工不再挤占普通静态衣装页。
- 没有为了“多样化”建立穷举式大衣柜清单。
- 没有新增第二模板、兼容别名或并行真源。
- 没有为尚无正式衣装页的人物批量补档。

状态：以上条件已经完成，逐人处理和横向验收见 [迁移验收记录](迁移验收记录.md)。
