# 公共衣装模板迁移

> 本文记录正式模板的迁移目标与验收口径。目标结构已落入 `characters/_template/衣装.md`；后续以正式模板为当前真源，本文不作为第二模板使用。

## 一、迁移原则

### 1. 固定审美，不固定完整套装

人物可以保留少量稳定锚点，例如发型习惯、小体量耳饰、常见轮廓或职业动作。禁止的是同一场景每次机械调用同一组上装、下装、鞋履和配饰。

### 2. 写组合逻辑，不写库存清单

正式衣装页应说明：

- 什么轮廓适合这个人。
- 上下装通常怎样形成比例。
- 正式度怎样升降。
- 天气变化时怎样加减层次。
- 当人物收束或松弛时，衣装怎样变化。

可以列举少量现代单品帮助调用，但不能穷举完整衣柜，也不能把举例写成唯一搭配。

### 3. 色谱写成范围

不再只写“主色／禁用色”，而采用：

- 核心色域：高频、最能代表人物的色彩关系。
- 邻近色域：与人物审美相容的日常扩展。
- 强调色：低频、小面积或特殊场合使用。
- 场景偏移：工作、私人、正式、行动时如何变深、变浅、变暖或变冷。
- 禁用方式：禁止哪些饱和度、面积和组合方法，而不是轻易绝对禁止整个颜色。

### 4. 场景按人物实际生活保留

职业、普通城市日常、正式社交和私人居家是常用基础场。危机、追逃、舞台、户外、夜场等只在人物确实拥有对应生活轨迹时保留，不给所有人统一配置动作片式行动装。

### 5. 静态人物真源只留稳定事实

`characters/*/衣装.md` 可以保存：

- 稳定的审美与材质偏好。
- 轮廓、露肤、包裹和配饰倾向。
- 职业衣装的现实要求。
- 跨场景都成立的亲密衣装偏好与禁区。

不应长期保存：

- 某场固定穿脱顺序。
- 谁先解哪一颗扣子。
- 某件衣物在一场戏后的流向。
- 只有特定关系阶段才成立的完整玩法。
- 候选款式、方案比较和未确认清单。

## 三、模板说明需要补充的协议

`characters/_template/README.md` 后续应明确：

1. `衣装.md` 是静态人物真源，不是完整衣柜清单。
2. 正文可以在不违反色谱、材质、轮廓和禁区的前提下调用同类现代款式。
3. 稳定锚点允许存在，但不得演变成每次出场都必须复刻的完整套装。
4. 新人物不为模板完整度填写不存在的职业、危机或亲密场景。
5. 具体亲密衣装与剧情用途不写入普通衣装模板。

## 四、旧页迁移映射

| 旧结构 | 新结构 | 处理方式 |
| --- | --- | --- |
| 总体衣装口径 | 总体衣装口径 | 保留并压缩为可执行原则 |
| 审美底色／主色 | 审美基因／色彩谱系 | 从固定色名升级为色域与使用方式 |
| 材质 | 材质与触感 | 区分日常、职业和正式材质 |
| 场景调用 | 场景衣柜 | 从单品列表改为组合逻辑 |
| 危机／行动场 | 人物专项场景 | 只有实际需要者保留 |
| 私密补充项 | 不进入普通衣装模板 | 稳定私密偏好进入亲密卡，具体场景施工继续下沉 |
| 正文调用方式 | 正文调用原则 | 保留并增加天气、状态和层次变化 |
| 禁写误区 | 禁写误区 | 保留，删除已经失效的旧项目清理痕迹时须逐项确认 |

## 五、模板迁移完成判据

- [x] 不把“胶囊衣橱”写成必须出现在正文里的项目术语。
- [x] 模板允许少量稳定锚点，但明确禁止固定完整套装。
- [x] 色彩字段能够表达范围、场景变化和禁用方式。
- [x] 场景小节按人物实际生活删减，不要求全量填写。
- [x] 普通衣装模板不设置私密衣装字段，稳定私密偏好直接读取亲密卡。
- [x] 模板说明与模板正文职责一致。
