## 一、决策口径

每条不一致只允许采用下列一种处理：

1. **接口成立**：在缺失的一侧补回反向接口。
2. **接口不成立**：从多登记的一侧删除该接口。
3. **接口应改归其他单元／节点**：先明确唯一承接方，再同步两侧。
4. **施工职责过宽**：先拆分施工单元，再分别建立双向接口。

逐项确认时必须回读对应正式节点和施工源文件，不能只根据标题或 ID 自动判断。本文快照共登记 **62 条 `CON → PL` 未回写**与 **11 条 `PL → CON` 未登记**。
