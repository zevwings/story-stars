# 艺人案件模块化调查结构

> 本文位于 `.analysis/blueprints/`，用于把万安影视文化艺人案件拆成职责清楚、证据范围有限、可以并行推进的调查模块。本文不是正式正典。

## 一、核心结论

调查不能按“询问一个艺人，再由她带出下一个艺人”的人物接力运行。人物提供个案入口，组织模式必须由多个独立模块通过现实记录交叉形成。

保护、医疗、咨询、异常核验、普通刑事调查和职业安置分别运行。任何模块都不能单独完成全案定性。

## 二、调查模块

### 2.1 异常核验模块

**负责方**：星辰管理局。

**核验内容**：

- 裴兰馨压低警觉、求助紧迫感或拒绝强度的具体作用；
- 任群限制少数关键行为的具体作用；
- 记忆遗失、精神干预痕迹及能力与药剂的区分。

**不能单独证明**：合同违法、项目导流、身体侵害、客户责任或整个公司性质。

### 2.2 个案事实模块

每位当事人分别建立最小案件包：

1. 如何进入项目或客户关系；
2. 本人明确同意、拒绝或不知道什么；
3. 谁作出安排、接触和具体行为；
4. 出现哪些身体、记忆、医疗、职业或公开形象后果；
5. 本人愿意提交哪些材料、愿意进入何种程序。

一个人的案件包只证明本人经历，不代替其他人的历史，不自动生成组织模式。

### 2.3 职业控制模块

**材料范围**：合同版本、补充协议、垫付款、结算、排期、选角、撤换、账号权限、素材授权、公关方案和内部沟通。

**目标**：证明正常经纪权利如何被转化为私人服从、退出障碍和报复性资源冻结。

**边界**：职业控制记录不能单独证明具体私人行为获得同意，也不能把全部合同、项目或经纪人统一犯罪化。

### 2.4 私域项目导流模块

**材料范围**：私人项目名单、客户需求、经纪调度、车辆、行程、场所预约、出入、房间、人员排班和结算。

**目标**：证明对象怎样从公开职业项目进入私人项目或场所接口，以及万安、场所与客户之间怎样发生调度和收益连接。

**边界**：进入场所、接受商务活动、获得资源与具体身体行为分别授权；任何一项都不能自动推出下一项。

### 2.5 药剂调查模块

药剂需求、供应、转交、直接使用、医疗后果和批次交叉由独立蓝图承接。艺人个案提供入口，但不由任何一名艺人独自证明完整供应链。

### 2.6 交叉验证与责任归属模块

重复模式至少需要两类以上不同来源相互印证：

```text
个案事实
  + 职业控制记录
  + 私域导流记录
  + 药剂与医疗记录
  + 异常能力核验
  = 组织方法、责任接口与行动门槛
```

最终分别核验：

- 裴兰馨的招募、包装、隔离、私人项目与能力使用；
- 任群的合同、公关、舆论、解约施压和有限行止；
- 具体经纪人、项目负责人和场所经营者的执行行为；
- 客户的需求、明知、取得、使用和后续侵害；
- 药剂供应者、转交者和直接使用者的本人责任。

## 三、模块接口

| 输出模块 | 可以交给下游 | 不得扩大为 |
| --- | --- | --- |
| 异常核验 | 必要异常结论、痕迹范围、风险方向 | 完整能力档案或司法定罪 |
| 个案事实 | 本人陈述、材料和授权边界 | 其他艺人的共同经历 |
| 职业控制 | 职业关系、资源奖惩和退出障碍 | 身体行为已经发生或获得同意 |
| 私域导流 | 人员、项目、场所和收益流向 | 完整客户主观知情 |
| 药剂调查 | 批次、转交、医疗后果和使用责任 | 所有艺人受害的共同原因 |
| 交叉验证 | 重复方法、责任名单和行动建议 | 对普通员工和合法项目整体定性 |

## 四、推进顺序

1. 乔宁异常记忆遗失形成机密上送方向，管理局与警方分别启动。
2. 警方先从现实可取得的项目、场所、车辆、资金和人员记录建立调查面。
3. 程叙、乔宁及其他人物只在可承受和愿意授权的范围内补充本人个案。
4. 职业控制与私域导流模块形成第一轮对应关系。
5. 燕若淇等人的药效漂移打开药剂批次、客户和医疗接口。
6. 多个个案经不同现实记录交叉后，`PL-S-251`、`PL-S-252`、`PL-S-260`、`PL-S-261` 才具备独立完成条件。
7. 调查形成具体人员、项目、资料和场所的行动清单；是否收网另按风险与证据门槛决定。

该顺序是调查因果，不是全部侵害的历史时间顺序，也不预先固定询问章序。

## 五、行动门槛

### 局部行动

满足以下条件之一，可以先保护具体对象、控制直接危险或保全特定资料：

- 存在可识别的再次侵害、转移或封口风险；
- 特定设备、账户或记录即将被删除、迁移或伪造；
- 已能识别直接实施者且等待会造成新增现实危险。

### 统一收网

统一行动至少需要形成：

- 涉案管理层和关键执行人的责任清单；
- 需要同时控制的人员、场所、设备和资料接口；
- 合法业务与涉案项目的初步切割方案；
- 当事人保护和医疗承接方案；
- 防止跨线转移、删证和责任切割的同步安排。

## 七、当前需要确认

### 阶段内需要决定

1. 第一轮现实记录从项目、场所、车辆、结算中的哪一项进入；
2. 谁负责职业控制记录，谁负责私域导流记录，双方如何有限共享；
3. 首个形成“个案事实＋现实记录”闭合的人物是谁；
4. 局部行动和统一收网的具体审批接口。

### 单章执行时决定

- 首轮询问对象与可见材料；
- 每次询问或记录发现指向的下一模块；
- 具体章尾停在风险升级、材料闭合还是责任人显影。
