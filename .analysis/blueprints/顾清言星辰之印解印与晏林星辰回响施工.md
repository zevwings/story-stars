## 一、正式承接

本施工继承以下正式边界，不在施工层重新定义：

- 星辰之印是中性的精神约束结构；顾清言身上的强种、越权控制与退出权剥夺属于齐心的非法使用。
- 顾清言之印已经固化，不会因晏林截断新增输入、协助闭海或短时压印而自然消失。
- 晏林只能处理中途仍在传递的作用，不能拆除已经固化的印记核心，也不能把已经落地的精神损伤逆流给齐心。
- 顾清言必须在恢复理解、表达与撤回能力后，主动开放明确区域并持续授权；普通医疗同意、管理局命令、不抵抗或昏迷都不能替代本人授权。
- 安若曦只有在印记核心已经暴露、可辨认、能够实际接触且顾清言持续授权时，才能尝试核心剥离；条件消失必须安全中止。
- 解印、治疗、证言、责任认定与顾清言—晏林的私人吸引分别运行，解印不建立身体权限，也不消除顾清言此前主动犯罪及受印后仍有自主空间的责任。

## 二、机制口径

### 1. 黑水只作视觉签名

- 齐心精神之海中的黏稠黑海继续保留。
- 顾清言的环形回廊中，齐心留下的控制结构可以呈现为覆在印记、路径与回廊节点上的黑色水膜、淤积或缓慢下沉感。
- 黑色显影只帮助人物辨认“这处结构来自齐心的篡心与种印”，不构成外部负面力量、接触传染或被动腐蚀。
- 晏林不会因为看见黑水、进入顾清言主动开放的局部内景或触碰视觉显影而必然受污染。

### 2. 星辰之印是锚点与入口

- 印记核心保存已经写入的行为约束与惩戒结构。
- 齐心追加命令、主动触发惩戒、重新加固或再次实施篡心时，须沿原有精神通道形成新的主动输入。
- 新增作用正在传递时，晏林才能截断或尝试逆流；印记已经固化的部分不因此自动消失。
- 本案不把星辰之印写成能够自行生成新命令、自动攻击第三方或自动复制第二枚印记的万能陷阱。

### 3. 外来侵蚀与星辰回响分别结算

- 齐心沿印记通道主动施加的篡心、基础侵蚀或控制加固，属于外来精神干涉。
- 晏林若停留在顾清言明确开放的局部区域，只做截断、压印与协助闭海，不触发星辰回响。
- 晏林若为了追查、反制或阻止齐心而沿原通道反向深入，越过齐心未开放的精神边界，才构成对齐心的精神入侵。
- 齐心固有精神边界排斥晏林投入的精神之力；回弹超过晏林当时的承受与稳定能力后，触发的是晏林自己的星辰回响。
- 星辰回响不是齐心黑水传染、顾清言污染转移、逆流返还或星辰之印附赠效果，净化权柄也不能把回响本身一键清除。

## 三、执行顺序

### 第一段：既有止损继续成立

1. 顾清言在会所排异期只开放最低限度的连接。
2. 晏林截断仍在传递的新增作用，协助她有限闭海。
3. 疼痛停止继续加剧，清醒窗口延长；固化印记、既有命令与篡心解释仍在。
4. 三至四次止损只证明晏林能够形成短暂窗口，不提前进入核心，不发生星辰回响，也不完成解印。

### 第二段：隔离后的黑箱辨认

1. 顾清言脱离会所监视、齐心接触与原有工作环境，管理局分别建立现实限制、保护、风险评估与记录。
2. 顾清言在能够理解和撤回的状态下，逐次授权接触印记所在局部区域。
3. 她以本人记忆、现实证据和自我认同维持锚点，区分：
   - 已经发生的客观事实；
   - 本人原有判断与主动行为；
   - 齐心通过篡心固定的退出、反抗、风险与获救解释；
   - 星辰之印写入的两条核心约束及惩戒结果。
4. 晏林只截断新增输入、协助闭海并保持安全退出通道；安若曦辨认残余控制入口、通道残留、外来控制结构与既成损伤。
5. 本段不使用“外围污染”概括全部异常；若没有独立污染来源，统一按残余入口、控制残留、篡心结构与精神损伤分别处理。

### 第三段：核心暴露与齐心主动加固

1. 安若曦在顾清言持续授权下，逐步清理外围干扰，使印记核心达到可辨认、可接触状态。
2. 核心受到触动后，可以先触发印中已经写入的疼痛、行动中断或约束收紧；这仍只作用于顾清言。
3. 齐心通过原通道察觉核心状态异常，主动重新加固印记或追加篡心解释。
4. 新增加固沿原通道传递，形成晏林可以截断或逆流的时机窗。
5. 晏林优先截断新增输入，为顾清言和安若曦争取继续授权、退出或安全中止的选择时间。

### 第四段：晏林越界追索与星辰回响

1. 为阻止齐心持续加固、确认控制来源或争取核心剥离窗口，晏林保留原通道并尝试反向追索。
2. 齐心的篡心作用可以推动晏林把“继续深入才是在保护顾清言”“由自己承担最安全”误认成完全出自自己的判断，但不能替他自动作出决定。
3. 晏林越过顾清言已经开放的区域，沿通道进入齐心未开放的精神边界。
4. 齐心的海境精神边界形成排斥；晏林投入的精神之力沿侵入路径回弹。
5. 回弹压过晏林当前稳定能力后，人星协调失序，其自身星辰之力沿已有个人权柄方向向内显现，形成星辰回响。
6. 本段不预写具体显症。亮星梦境／幻境与暗伴星截断／逆流如何向内显现，须在待确认项拍板并回写晏林契约后才能进入正文。

### 第五段：断开、剥离与分别处置

1. 晏林优先自断或由外部协助终止继续追索，停止新的精神之力回弹；已经形成的星辰回响不会立刻消失。
2. 管理局负责现实看护、隔离刺激、风险记录与退出条件；晏林的回响按精神负荷、边界与人星协调失序单独稳定。
3. 若顾清言仍能理解、表达并持续授权，安若曦可以利用齐心加固被截断后的窗口继续核心剥离；顾清言撤回或任一安全条件消失时立即中止。
4. 核心剥离只解除顾清言身上的外来约束结构，不解除齐心的原始星辰契约，也不把印记或损伤转移给晏林。
5. 核心剥离后，安若曦依据顾清言仍然保留的原始结构、稳定锚点与自我认同，分次修复人格边界、精神连接与承载结构损伤。
6. 晏林若同时承受齐心主动输入留下的外来控制残留与自身星辰回响，两部分必须分别处理：外来残留可按对应能力净化或剥离；星辰回响只能等待精神之力、精神之海与人星协调重新稳定。

## 四、人物与线路变化

### 顾清言

- 她不是被动治疗容器，而是局部开放、触发测试、撤回授权、维持自我锚点和交代本人责任的行动主体。
- 她能够区分“我做过什么”“我当时如何解释”“哪些解释被齐心固定”，但解印不自动恢复全部判断、不删除记忆，也不替她免责。
- 她拒绝继续解印、拒绝晏林或终止私人关系，不影响保护、证据评价、治疗与责任分层。
- 核心剥离后，长期受控、反复排异与既成损伤留下的精神结构失衡继续存在；她与晏林可以确认关系真实成立，但不发生身体兑现、不建立等待承诺。
- 她在责任落地后的收监阶段完成告别并退出主角关系线，是全书唯一与晏林强关联却明确下线的人物；尾声不安排主动回归、出狱复选或亲密兑现。

### 晏林

- 常规止损继续保持克制有效；真正代价来自他在关键时刻再次选择“由自己多走一步”。
- 星辰回响使其保护欲与暗伴星的反制结构第一次形成自身风险，但不新增权柄、不提供升级，也不替他完成齐心追查。
- 越界事故必须产生后续复评、能力暴露或内圈告知压力，不能只作为一次短暂晕眩。

### 安若曦

- 只负责识别并剥离可接触的外来控制结构、处理对应残留与修复既成损伤。
- 不负责截断齐心持续输入，不治疗星辰异变，不清除星辰回响，不恢复星辰之力，也不替顾清言或晏林作选择。
- 这一事件强化的是她在五位核心女主中的复原与边界功能，不另起一条治疗后恋爱线。

### 齐心

- 危险来自篡心、印记约束、主动加固与对晏林保护欲的利用，不来自无条件扩散的黑暗能量。
- 晏林沿通道追索只形成齐心控制结构与来源的调查方向；案件仍须由场所、资金、通讯、人员、交接与证言等现实材料独立证明。

## 五、不得写偏

- 不写成晏林进入顾清言精神之海便必然被黑水传染。
- 不把齐心的黑色内景升级为外部负面力量实体。
- 不让星辰之印自动生成新命令、自动攻击第三方或无条件复制印记。
- 不把晏林的星辰回响写成齐心权柄原样返还、逆流失败的同义词或新的契约代价轴。
- 不让净化权柄清除星辰回响，也不让亲密或共鸣一键恢复晏林。
- 不让晏林的越界事故替代顾清言的授权主体性、核心剥离流程或司法责任分层。
- 不让安若曦凭一次施为同时完成截断、解印、修复、稳定与责任认定。
- 不在安若曦进入个案的制度条件、晏林回响显症与防拆反馈未确认前，把对应参数写入正式节点或正文。
