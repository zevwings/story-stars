# 药剂供应与责任链调查

> 本文位于 `.analysis/blueprints/`，用于梳理新型违禁精神药剂在演艺资源案件中的需求、供应、转交、使用、医疗后果、批次交叉和逐人责任。本文不是正式正典，不补写配方、剂量、商品名或投放操作。

## 一、核心结论

药剂线不是艺人控制线的最终答案，而是现实控制失败后升级为直接侵害的一条独立责任链。

供应结构已经拆为两轨：万安内部涉案接口向旗下艺人项目定向供药，由项目、健康管理与随行人员执行；黑市外围向鲁林霞、霍临川等外部客户提供成品。乔宁、燕若淇进入公司内供，侯瑞驰、杨柳分别通过鲁林霞、霍临川进入黑市外供。

本线中的“药剂”不限定为口服药物。可调查对象由三部分组成：活性制剂、饮食／外用／空气与香氛等释放载体，以及涉案人员用于维持清醒或压低显性反应的配套抑制制剂。香薰本身不是能力；必须证明具体设备、环境暴露、制剂痕迹与人员行为之间的连接。

调查必须把以下行为拆开证明：

```text
客户或项目需求
  → 订单与供应安排
  → 药剂取得和转交
  → 直接使用
  → 后续侵害
  → 医疗与长期后果
```

供应者、隐瞒者、转交者、直接使用者和后续侵害者分别承担本人责任。上游虚假宣传和批次隐瞒不免除直接使用者责任。

## 二、调查模块

### 2.1 需求端

核验：

- 谁提出需要降低判断、延长反应、制造幻觉或取得表面顺从；
- 需求通过私人项目、客户、中间人还是黑市后台进入；
- 需求者是否知道药剂的现实用途；
- 是否针对具体人物、适用版本和项目时间提出要求。

不能只凭客户出现在同一场所推定其提出用药需求。

### 2.2 供应与订单端

核验：

- 谁接受订单、匹配产品和安排交付；
- 黑市订单后台怎样连接客户、中间人、万安接口和外围供应；
- 万安健康的药品、试剂、冷链、病历或研究接口是否被具体人员调用；
- 不同批次怎样流向不同项目、客户或场所。

万安影视文化不是全部黑市的统一后台；万安健康的合法业务也不能因存在涉案接口而整体犯罪化。

### 2.3 转交与保管端

核验每一次现实持有和控制：

- 谁领取、保管、携带或交给直接使用者；
- 交接发生在项目、车辆、场所、医疗或私人空间中的哪一接口；
- 包装、库存、运输和结算记录能证明到什么范围；
- 转交者知道的是普通药物、违禁用途还是具体侵害计划。

转交行为与直接使用、后续侵害分别判断，不能为了责任链完整把所有中间人写成同等知情。

### 2.4 直接使用端

核验：

- 谁实际决定并实施使用；
- 对象是否知情并有效同意；
- 使用者知道何种催情、致幻、持久或混合作用；
- 使用后是否继续实施身体、拍摄、传播、转移或其他侵害。
- 是否利用房间、车辆或封闭空间的空气与香氛系统形成环境暴露；
- 哪些人员能够控制释放设备、离开空间或提前使用清醒维持／显性抑制制剂。

药剂造成的欲望、生理反应、幻觉、表面顺从和求生配合均不构成有效同意。

### 2.5 医疗与后果端

分别记录：

- 急性身体异常；
- 记忆和判断损伤；
- 耐受、依赖、戒断或持续时间偏差；
- 多次使用后的表现漂移和长期累积；
- 工作、公开形象、关系与后续医疗影响。

“成瘾”不能只凭两至三次事件或一句“离不开药”成立。记录时拆为：

- 耐受，即需要更强或更长暴露才出现相近效果；
- 身体依赖与戒断，即停止后出现可观察的身体或精神反应；
- 心理／功能性依赖，即把某种制剂、环境或状态误当作维持工作和生活的必要条件；
- 条件化反应，即对特定人物、气味、空间、声音或权力标记出现自动反应；
- 强迫性寻求，即明知伤害仍反复追逐制剂、情境或奖赏。

两至三次高强度暴露可以支持急性损伤、累积伤害、早期适应或条件化反应，不能单独支持稳定成瘾。若需形成长期依赖，更合理的底层结构是数月低水平环境暴露与两至三次定向高强度暴露叠加。

主要后果优先落在精神、情绪、睡眠、判断与记忆异常；性欲或奖赏寻求只作为部分人物的差异化表现，不统一分配。

医疗记录可以支持身体和精神后果、接触时间及连续治疗，不能单独判断谁使用药剂或完整司法责任。

### 2.6 批次交叉端

批次交叉不要求发明统一编号或精确药理表。可以通过以下现实差异形成：

- 适用版本与功能偏向；
- 包装、交付时间和来源接口；
- 症状组合、持续时间偏差与异常串扰；
- 多名对象在不同项目中出现的相似长期后果；
- 对应库存、订单、结算和医疗记录。

批次相似只能建立供应方向，仍需具体交接和使用证据确定逐人责任。

## 三、证据矩阵

| 材料 | 可以证明 | 不能单独证明 |
| --- | --- | --- |
| 订单、聊天、客户需求 | 需求内容、时间和参与接口 | 药剂已经实际使用 |
| 库存、冷链、领取和交接 | 药剂流转和控制范围 | 最终对象与具体后续行为 |
| 场所、车辆、项目和出入记录 | 人员与药剂可能交汇 | 当事人同意或直接使用者 |
| 当事人陈述 | 本人感受、经历、拒绝和后果 | 完整上游供应链 |
| 医疗记录 | 症状、治疗和长期后果 | 配方、批次或责任人全貌 |
| 实物或检验 | 药剂类别、成分方向或同源关系 | 谁提出需求、谁实施侵害 |
| 资金和结算 | 订单、收益和项目连接 | 每一参与者的主观知情 |

## 四、人物分工

| 人物 | 药剂线功能 | 边界 |
| --- | --- | --- |
| 燕若淇 | 多次用药后的表现漂移、个体差异与长期累积 | 不负责主动保存完整转运线索 |
| 乔宁 | 记忆缺页、莫名感伤与偶发非定向欲望高涨；本人能够确认的车辆、房间、转运、医疗和药剂有限材料 | 大多数时间正常且保有自控，不写成不可自制，也不独自证明完整供应链 |
| 杨柳 | 外部项目入口、明确拒绝后的用药侵害，以及面对霍临川时出现的条件化服从反应 | 反应不是实际主奴关系或真实 M 倾向；她能够识别、克制、拒绝和离开 |
| 侯瑞驰 | 男用版本、女性直接使用者，以及面对与鲁林霞相似权力标记时的自主神经恐惧反应 | 颤栗不是吸引、性欲或同意，也不泛化为见到所有富裕女性都异常 |
| 程叙 | 证明能力与职业控制造成退出失败 | 不改写成药剂批次受害者 |

### 4.1 差异化后果锚点

- **燕若淇**：承担批次不稳。不同事件可分别突出记忆、判断、睡眠、情绪或身体异常，长期损伤不断累积，但不设定对某个具体施害者的驯化反应。
- **乔宁**：大多数时间能够正常工作和选择，偶尔出现突然但不指向特定人物的欲望高涨；她可以独处、等待消退或另行选择亲密。更稳定的异常是记忆错位、缺页、莫名感伤，以及“有些事像是自己选的，但后半段不像自己选过”的不适感。
- **杨柳**：与霍临川再次安全相遇时，可能自动降低声音、等待指令或产生服从冲动；她同时清楚自己不愿意，并能通过后退、拒绝、离场或中断动作克制。该表现定义为“针对特定施害者的条件化服从反应”，不是主奴关系。
- **侯瑞驰**：本人对女性没有性兴趣；面对具有鲁林霞相似年龄、身份、注视、声音、香气、珠宝或助理传令方式的特定权力标记组合时，可能出现无法解释的颤栗。具体触发组合留待单章决定，不把反应写成性吸引。

## 五、与其他线路的边界

### 艺人控制线

合同、资源、债务和公关先证明退出障碍；药剂只证明部分案件已经升级为直接人身侵害。没有药剂的个案仍可成立组织性压迫。

### 人体实验线

艺人药剂可以通过批次、医疗记录和订单后台指向万安健康，但普通艺人侵害与实验对象筛选分别成立。只有具体记录证明对象被评估、转运或接收时，才能进入人体实验线。

### 人口转移线

合法出境文件、车辆或项目安排不能自动证明人口转移。必须存在具体名单、交接、限制退出、失联或境外接收材料。

## 六、推进顺序

1. 白玥能力执行端停止响应后，裴家转向普通外围和客户可使用的新型违禁精神药剂。
2. 客户或私人项目产生具体需求，供应与订单接口开始留下现实记录。
3. 不同人物的侵害在调查介入前分别发生，不按同一批次或相同表现处理。
4. 调查显影顺序固定为乔宁、程叙、侯瑞驰、燕若淇、杨柳；该顺序不等于实际受害时间顺序。
5. 乔宁助理记忆与现实记录先打开公司内供；侯瑞驰现场救下打开黑市外供；燕若淇、杨柳再分别扩展两条路径。
6. 订单、交接、场所、医疗和个案材料交叉后，才能连接客户、外围供应、万安健康与裴家后台。
7. 逐人责任形成后进入局部抓捕、资料保全或统一收网接口。

## 七、当前需要确认

### 阶段内需要决定

1. 首个可供警方现实追查的药剂入口是实物、医疗记录、交接记录还是资金记录；
2. 万安健康具体哪一类接口被涉案人员调用，但不提前确定完整制造端；
3. 乔宁随行助理的姓名、公司内部具体下令人及对应职务；
4. 鲁林霞现场局部控制的精确行动窗口与证据组合。

### 单章执行时决定

- 药剂外观、包装与检查细节；
- 具体症状组合和发生次数；
- 询问、医疗或记录发现的章序；
- 客户、项目和媒体使用的虚构名称。

## 八、不得写偏

- 不补固定配方、统一剂量、万能检测或无痕效果。
- 不让所有艺人案件共享同一药剂原因。
- 不把两至三次事件自动写成稳定成瘾，不用“性成瘾”概括全部精神与记忆异常。
- 不把空气或香氛载体写成无须活性制剂、设备和现实痕迹的万能控制。
- 不因施害者也出现损伤而冲淡其知情、控制、预防和继续侵害的责任。
- 不让药剂产生真实爱情、有效同意、星辰权柄或能力增幅。
- 不把训练馆补剂写成并行来源。
- 不因供应链存在而免除直接使用者和后续侵害者责任。
- 不把普通医疗、合法药品供应或万安健康全部业务整体犯罪化。
