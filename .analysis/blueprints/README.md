# 设计蓝图

本目录保存尚在分析、比较或迁移过程中的故事设计，包括机制方案、线路规划、人物设计、结构论证与正式化蓝图。内容可以提出候选方向和分析依据，但不是故事真源，写作任务不得直接继承为既定事实。

## 当前项目收口入口

- [项目剩余工作索引](项目剩余工作索引.md)：当前未完成事项、依赖关系和专题路由的唯一总入口。
- [项目后续讨论与暂缓项蓝图](项目后续讨论与暂缓项蓝图.md)：统一保存作者决定后续讨论或暂缓的开篇、主角目标与远期容量问题；当前不回写正式真源。
- [当前候选变更审查与提交收口](当前候选变更审查与提交收口.md)：先审查、验证并隔离当前未提交的大范围正式真源候选。
- [开篇施工与正文闭环蓝图](开篇施工与正文闭环蓝图.md)：处理开篇阻塞项、施工拆分、章节绑定和首批正文试运行。
- [阶段一后半段收口蓝图](阶段一后半段收口蓝图.md)：处理 `PL-S-201` 与阶段一后半段即将消费节点。
- [终局解释权与阶段四五结构债蓝图](终局解释权与阶段四五结构债蓝图.md)：处理解释权概念、终局制度对象和远期容量压缩。
- [白玥关系与监管重构分析](白玥关系与监管重构分析.md)：处理白玥 `BY-01`—`BY-05`，不与开篇或当前关系批混写。

旧的[项目诊断](story_project_analysis_20260808.md)与[项目修改实施计划](story_project_modification_plan_20260808.md)保留诊断依据和历史顺序；当前续接时先读“项目剩余工作索引”，不再从旧文中自行推断最新待办。

## 放入本目录

- 需要比较多个整体方案的机制或结构设计。
- 尚未拆分到明确正式目标的剧情、人物或世界观规划。
- 涉及多份正式文件的迁移方案、冲突分析与完整论证。
- 仍需继续推演、但尚未形成关键决策门的候选设计。

## 不放入本目录

- 已经确认的世界规则、人物事实、剧情变化或施工规格。
- 已有明确目标、不同选择后果和最迟决策点的延迟选择；这类问题进入 `story/decisions/`。
- 可以安全留给章纲或正文临场决定的普通场景细节。
- 审计报告、会话导出或已经失效的历史方案。

方案确认后，按内容分别路由到 `worldbuilding/`、`characters/`、`story/plotlines/` 或 `story/construction/`。完成正式迁移后，应删除已经被吸收的重复内容；确有长期论证价值的历史方案可转入 `.analysis/archived/`。
