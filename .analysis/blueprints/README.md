# 设计蓝图

本目录保存尚在分析、比较或迁移过程中的故事设计，包括机制方案、线路规划、人物设计、结构论证与正式化蓝图。内容可以提出候选方向和分析依据，但不是故事真源，写作任务不得直接继承为既定事实。

## 放入本目录

- 需要比较多个整体方案的机制或结构设计。
- 尚未拆分到明确正式目标的剧情、人物或世界观规划。
- 涉及多份正式文件的迁移方案、冲突分析与完整论证。
- 仍需继续推演、但尚未形成关键决策门的候选设计。

## 不放入本目录

- 已经确认的世界规则、人物事实、剧情变化或施工规格。
- 已有明确目标、不同选择后果和最迟决策点的延迟选择；这类问题进入 `story/decisions/`。
- 可以安全留给章纲或正文临场决定的普通场景细节。
- 审计报告、会话导出或已经失效的历史方案。

方案确认后，按内容分别路由到 `worldbuilding/`、`characters/`、`story/plotlines/` 或 `story/construction/`。完成正式迁移后，应删除已经被吸收的重复内容；确有长期论证价值的历史方案可转入 `.analysis/archived/`。
