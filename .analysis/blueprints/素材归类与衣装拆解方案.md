# 人物素材归类与衣装逐人拆解方案

> 状态：分析层执行协议
> 适用范围：项目外部人物图片、视频及其截图组
> 非正典声明：本文只规定素材筛选、取证和衣装观察方法，不提供故事事实，不创建人物衣装、Construction、章节事实或 `CLO-*`。

## 一、目标

每次只处理一位目标人物的素材，在来源可回查、画面证据可复核的前提下：

1. 排除明显不是目标人物的画面；
2. 从图片和视频中提取有效衣装证据；
3. 将换装、多人和局部衣装拆成独立观察；
4. 使用中文衣装类型归类；
5. 只把少量真实例外留给作者判断。

本流程追求“当前人物的衣装证据闭合”，不追求一次处理全库，也不把每份素材强行解释成完整一套衣装。

## 二、任务单位

- 一个目标人物对应一个独立任务。
- 当前人物完成并验收后，才开始下一人物。
- 不跨人物建立混合批次、混合接触表或统一人工队列。
- 不因文件名相近、同一账号、同一活动或同一拍摄场地推定是同一人物或同一套衣装。
- 单人物任务可以包含该人物名下的全部图片和视频，也可以由作者限定来源范围。

任务开始时必须明确：

| 项目 | 内容 |
| --- | --- |
| 目标人物 | 本任务唯一人物 |
| 素材范围 | 文件、目录或明确清单 |
| 已有结果 | 可用于查重的既有分析，不自动继承结论 |
| 停止条件 | 全部素材处理完成，或出现无法继续的真实阻塞 |

## 三、写入与目录边界

- 原始图片和视频保持原位，不移动、不重命名、不删除。
- 本方案直接保存在 `.analysis/blueprints/`，不为方案创建独立目录。
- 临时抽帧、接触表和裁切图只用于当前任务，放入临时位置，不进入正式目录或 catalog。
- 单人物结果默认在当前任务中交付；只有作者明确要求落盘时，才在 `.analysis/blueprints/` 根层创建独立 Markdown，不自动创建人物子目录。
- 本阶段不分配 `CLO-*`，不写 `specialties/clothes/references/catalog/`。
- 人物名、账号名、活动名和拍摄地只用于来源回查，不进入项目人物或故事事实。

## 四、素材盘点

只盘点当前人物任务范围内的输入：

- 图片：记录路径、尺寸、方向和可解码性；
- 视频：记录路径、时长、分辨率、帧率和可解码性；
- 拼图或多人图片：先确认能否拆出独立主体区域；
- 重复素材：标记完全重复或明显同源，不重复制造独立衣装结论；
- 无法解码、零字节或严重损坏：记录异常，不凭文件名补造画面内容。

文件名、标题和字幕只提供定位线索，不能单独证明人物身份、换装、衣装类型或材质。

## 五、主体判断

主体判断只负责筛选当前人物的可用衣装证据，不建立现实人物身份事实。

| 状态 | 判定 | 处理 |
| --- | --- | --- |
| 目标主体明确 | 脸、连续镜头或其它当前画面证据足以确认 | 继续衣装判断 |
| 目标主体大概率 | 没有完整露脸，但连续镜头、体态、造型和来源上下文没有冲突 | 可保留衣装观察，身份只记为大概率 |
| 明显错误主体 | 当前画面明确是另一人物 | 舍弃该帧，并从同一素材重新抽取 |
| 多主体混合 | 同时出现多人 | 分主体记录；无法分离时标为证据不足 |
| 无法判断主体 | 遮挡、远景、低清或剪辑导致无法判断 | 衣装清楚时可保留纯衣装观察；不得写成身份确认 |

不要求百分之百看到脸。脸不可见不构成舍弃理由；只有画面明确属于错误人物，或衣装主体无法分离时，才舍弃受影响的观察。

## 六、抽帧与补抽

### 6.1 首轮取证

- 图片直接查看足以判断结构的原图；缩略图只用于定位。
- 视频先覆盖完整时间轴、转场前后、正面、侧面、背面、静止全身和明显动作段。
- 不把“全量扫描”理解为长期保存每个编码帧；可以临时密集检查，但只保留能够支持判断的证据帧和时间点。
- 短视频、快速变装或动作密集片段可以临时逐帧或高频抽帧。
- 灯光、滤镜、镜像、姿势和镜头距离变化本身不算换装。

### 6.2 错误主体

- 抽到明显错误人物时，只舍弃该帧，不立即舍弃整个视频。
- 优先从同一时间段前后重新抽取，寻找目标人物实际出现的画面。
- 同一素材始终没有目标人物时，才将该素材标为错误来源。

### 6.3 证据不足

按缺口定向补抽，不机械重复原时间点：

- 缺上身：补正面或上身较清晰画面；
- 缺腰部连接：补腰线、闭合和上下连接；
- 缺下身：补裙摆、裤腿、腿口或鞋履；
- 多人遮挡：补主体分离画面；
- 疑似换装：补转场前后；
- 动态结构不清：补静止或动作幅度最大处。

最多进行两轮定向补抽。两轮后仍不足时标为“证据不足”，不继续消耗素材，也不猜测。

## 七、衣装观察规则

### 7.1 局部衣装可以成立

- 只清楚看到上装，可以记录“上装”。
- 只清楚看到下装，可以记录“下装”。
- 鞋袜或穿戴配饰独立清楚时，可以单独记录。
- 局部观察不补造未出现的另一半，也不强行形成完整套装。

### 7.2 连体类必须连续可见

确认以下类型时，必须同时看到上身、腰部连接和下身结构：

- 连衣裙：上下连续，以下摆为裙装主体，没有分离裤腿；
- 连体裤：上下连续，并有两条分离裤腿；
- 连体衣：上下连续，没有独立裙摆或分离长裤腿；
- 连体泳衣：上下连续，且画面支持泳装用途与腿口结构。

只看到上半身、腰部被遮挡或下身结构不清时，不得确认具体连体类型；记录为“疑似连体”，并进入定向补抽。

### 7.3 分件、换装与多人

- 能看到上装与下装的物理分界时，分别记录，不把普通搭配称为连体。
- 同一视频出现不同衣装时，按转场或稳定造型拆成多条观察。
- 同一画面出现多人时，每条观察必须标明对应主体，不能跨人物拼接衣装。
- 加减外套、鞋袜、腰带或关键配饰时，记录实际变化；不自动视为全套换装。
- 古风层叠衣装能看出上衣与裙／裤层次时，按分件记录；不因长下摆直接推定连衣裙。

## 八、中文衣装类型

当前分析允许使用：

```text
上装 | 下装 | 连衣裙 | 连体裤 | 连体衣 | 连体泳衣 |
泳装上装 | 泳装下装 | 袜类 | 鞋履 | 配饰 | 疑似连体 | 无法判断
```

这是素材观察词，不等于 catalog 已建档。后续若进入 catalog，必须再按项目九种 `piece_type` 和 `set | piece` 门禁重新判断。

## 九、证据等级

每条观察只使用以下等级之一：

1. **画面确认**：当前图片区域或视频时间点直接支持；
2. **画面大概率**：结构较可信，但受遮挡、滤镜、动作或压缩影响；
3. **证据不足**：无法稳定判断，且已达到补抽上限或没有可补画面；
4. **舍弃**：明显错误人物、无法分离的无效主体、损坏素材或没有有效衣装画面。

不得把精确尺寸、纤维成分、隐藏内层、暗扣、硅胶条、骨条数量、丝袜 D 数或不可见五金写成画面确认。

## 十、单条观察格式

每条衣装观察至少记录：

| 字段 | 含义 |
| --- | --- |
| 来源 | 原文件相对路径 |
| 画面定位 | 图片区域或视频时间点／时间段 |
| 主体状态 | 明确、大概率、无法判断或错误主体 |
| 衣装类型 | 中文衣装类型，可多项 |
| 可见范围 | 上身、下身、上下连续、局部或无有效画面 |
| 可见描述 | 分件、轮廓、颜色区间、表面和层级 |
| 证据等级 | 画面确认、画面大概率、证据不足或舍弃 |
| 补抽状态 | 不需要、第一轮、第二轮或已达上限 |
| 备注 | 换装、多人、遮挡、重复或异常说明 |

一份素材可以产生零条、一条或多条观察；一条观察只能对应一个明确主体和一个稳定衣装阶段。

## 十一、单人物执行流程

1. 锁定目标人物和素材范围；
2. 盘点当前范围内的图片、视频、异常和重复；
3. 查看图片并覆盖视频时间轴；
4. 排除错误主体，保留可用的纯衣装证据；
5. 按局部、分件、连体、换装和多人规则建立观察；
6. 对疑似连体、遮挡和主体混合进行定向补抽；
7. 合并完全重复观察，但保留来源回查；
8. 输出中文分类、证据说明和少量真实例外；
9. 完成验收后关闭当前人物任务。

## 十二、验收标准

- 当前任务只包含一个目标人物；
- 每份输入都有已处理、证据不足、错误来源或无法解码等明确结果；
- 明显错误人物没有进入目标人物衣装结论；
- 不露脸但衣装清楚的有效画面没有被误删；
- 上装或下装局部证据可以独立成立；
- 连体类型都有上身—腰部—下身连续证据；
- 多人和换装没有被合并成虚假套装；
- 两轮后仍不清楚的内容保持证据不足；
- 原始素材移动、重命名和删除为零；
- 新建或更新的 `CLO-*`、人物衣装、Construction 和章节文件为零；
- 临时抽帧、接触表和裁切图没有进入正式目录。

## 十三、后续收录边界

单人物任务完成只表示素材观察可复核，不表示衣装实体已经成立。

- 至少两个物理独立核心分件具有稳定成套身份时，才可能候选为 `set`；
- 一个物理独立且具有复用价值的实际衣物或穿戴配饰，才可能候选为 `piece`；
- 普通上装与下装的一次搭配只是临时搭配，不自动成为 `set`；
- 连衣裙、连体裤、连体衣和一件式泳装仍是一个 `piece`；
- 只有作者之后明确要求“收录”“建档”或“创建／更新 CLO”时，才进入 `clothes-decomposer` 的 catalog 查重、预留 ID 和验证流程。

## 十四、任务启动模板

```text
目标人物：<人物名>
素材范围：<目录或文件清单>
本轮目标：只做衣装观察与中文归类
主体规则：明显错误人物舍弃并补抽；不要求完整露脸
局部规则：仅上装或仅下装也可成立
连体规则：必须看到上身、腰部连接和下身
补抽上限：两轮
写入边界：不创建 CLO、不写人物衣装、不移动原始素材
交付：分类结果、证据不足项、错误来源和异常
```
