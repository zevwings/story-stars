# 持续主线与异步线索显影蓝图

> **状态**：作者已确认本页作为持续主线叙事方法的分析入口；仍属分析层，不提供故事事实。
>
> **职责**：只保存黑色线如何异步显影、如何限制视角、如何把局部线索转成可验证推进。
>
> **正式入口**：长期时序见 [`story/timeline.md`](../../story/timeline.md)，阶段职责见 [`story/arcs/`](../../story/arcs/_index.md)，状态变化与责任边界见 [`story/plotlines/`](../../story/plotlines/_index.md)，已确认执行规格见 [`story/construction/`](../../story/construction/_index.md)。与正式层冲突时，以正式层为准。

## 一、核心命题与使用边界

持续贯穿全书的不是万能掮客、统一黑市后台或晏林不断认识新的案件女性，而是同一种问题不断升级：

> 有人把他人的欲望、债务、职业、身体、契约价值和行动自由，逐步改写成可控制、可转移、可分类、可消耗的资源。

本页只负责“怎么讲”，不重复登记“发生了什么”：

- 不复述五阶段事件、人物责任、组织关系、证据结论或裁判结果。
- 不新增角色、犯罪产业、`PL-*`、`CON-*`、章号或场次。
- 不把读者认知顺序误写成犯罪业务顺序；人员转移、实验、药剂和园区责任继续按正式真源分别成立。
- 不让单一人物、记忆、账号、账本或能力读取证明整条网络。
- 不让晏林私人追查、审讯、查账或跨境追捕；他只承接正式授权范围内的专业接口。
- 黑色线完成冲突和后果后，叙事必须回到人物关系、日常选择与亲密主调，不能扩写成重型刑侦主线。

## 二、四轨异步模型

| 轨道 | 叙事职责 | 禁止承担 |
| --- | --- | --- |
| A｜反派行动 | 让反派完成选择、转移、规训、切割、灭证、换线或接收，制造当前冲突并改变计划状态 | 解释全局、主动泄露下一关、替其他主体认责 |
| B｜后果与局部供线 | 由当事人、家属、幸存者、灰度参与者或外围从业者呈现局部后果，并基于自身动机给出一段方向 | 全知证言、一次说清上下游、用受害或立功自动免责 |
| C｜现实验证 | 由管理局、警方、医疗、企业和客观记录核实异常、合同、资金、行程、场所与人员接口 | 用能力读取替代现实证据、把相关性直接写成裁判证明 |
| D｜晏林承接 | 让晏林识别重复方法、完成限定任务、把结果交回制度，并承担个人与关系后果 | 私人接管全链、靠结识女性推进所有案件 |

固定公式：

> **人给方向，物证定事实，多源交叉定责任，官方完成接管。**

四轨不必同章会合。有效接力应形成以下循环：

`反派行动 → 人物后果 → 局部方向 → 部分验证 → 新的制度门槛或限定任务 → 反派调整`

反派调整可以制造新痕迹，但不能写成反派故意给主角留下线索。

## 三、章节级施工语法

### 3.1 五拍接力

同一线索可以跨章完成，不要求连续写完：

1. **行动拍**：反派作出具体决定，改变某个人、物或计划的状态。
2. **后果拍**：另一视角只看到身体、职业、债务、失联、记忆或关系后果。
3. **提供拍**：知情人基于自保、救人、求利、赎罪、报复或履职等独立动机，交出本人掌握的一段信息。
4. **验证拍**：独立材料证实其中一部分，同时修正原解释并保留尚未证明的部分。
5. **转向拍**：官方形成新的核查／行动门槛，晏林承接限定任务，或反派因压力改变计划。

每一拍都必须留下可继承变化；只有气氛、威胁或说明而没有状态变化，不算推进。

### 3.2 两种信息引擎

每个命中章纲选择一种主引擎：

- **秘密悬念**：读者与中心 POV 同时只见后果，不知道实施者或用途。
- **戏剧反讽**：读者通过有限知情人物先知道某个动作已经发生，中心 POV 尚不知道。

同一场不能一面隐藏实施者，一面由无来源旁白确认幕后真相。需要保密的核心反派不给全知视角；需要提前显影的行动交给只知道自身接口的下层执行者、当事人或现实记录承载。

### 3.3 章纲必填项

涉及黑色线的章纲至少回答：

- 本章使用秘密悬念还是戏剧反讽。
- 中心 POV 知道什么、误判什么、绝对不知道什么。
- 哪个行动改变了什么状态。
- 谁提供局部方向，其独立动机和代价是什么。
- 当前材料能证明什么、不能证明什么。
- 章尾把哪个问题交给哪条异步线承接。
- 本章如何回到关系、日常或亲密主调，而不是停在程序说明上。

## 四、角色与线索检查

### 4.1 反派出场

每次反派出场必须同时满足：

- **即时冲突**：当场有人失去、争夺或保护一项具体东西。
- **计划推进**：至少完成一次筛选、转送、加固、切割、灭证、换线或接收。
- **新增显影**：读者第一次看见一个接口、方法或责任位置。
- **保留未知**：当前视角仍不知道至少一个关键上游、下游或真实用途。

男女反派都必须承担实质决策、执行、经营或资源授权责任；不能固定成“男性决策、女性诱惑／交证”的单一模板。具体责任归属只读取正式人物与剧情节点。

### 4.2 线索提供者

现有角色能够承接时，不新增贯穿全书的情报贩子。只有出现正式证明缺口时，才允许增加单接口人物，并同时满足：

- 有独立于晏林的目标。
- 只掌握本人接触到的具体接口。
- 提供信息需要承担现实代价、风险或责任后果。
- 信息能够改变下一步行动，而不只解释过去。
- 仍有至少一类独立材料负责验证。

## 五、尚未决定的三个参数

当前没有阻塞正式剧情或开篇工作的决定。以下参数只在命中对应章纲前处理：

| 参数 | 推荐 | 最迟决定点 |
| --- | --- | --- |
| 阶段二是否出现反派 POV | 不出现；让管理局内部残留比对承担一次有意识的留白 | 阶段二异常下注相关章纲开始前 |
| 阶段四是否保留一次有限知情执行者视角 | 保留一次，用于实时显出人员改向或异常物资交接，但不展示核心后台 | 相关阶段四施工单元绑定章节前 |
| 阶段四药剂个案如何分配篇幅 | 分成少量完整“后果拍”和其余简报承接，避免重复调查流程 | [`万安艺人显影线`](../../story/construction/万安艺人显影线/_index.md)首次绑定章节前 |

具体 POV、场景、对白、记录类型、切镜方式、章尾钩子和回收间隔均属于单章执行决定，不继续写入本蓝图。

## 六、正式化与删除条件

候选得到作者确认后，按影响范围进入唯一目标：

1. 跨阶段叙事边界进入 [`story/arcs/`](../../story/arcs/_index.md)。
2. 新的跨章可继承状态变化才进入 [`story/plotlines/`](../../story/plotlines/_index.md)；现有节点足以承接时不新增。
3. 信息引擎、POV 边界、来源／证明分工和反派出场要求进入命中的 [`story/construction/`](../../story/construction/_index.md)。
4. 只影响一章的参数进入该章 `outline.md`。
5. 章节定稿或作者明确触发线索整理以前，不在 `clues/` 预登记尚未实际埋设的线索状态。

当第五节三个参数都已写入对应阶段、施工单元或章纲后，本页不再保留独立职责，应从蓝图目录删除。
