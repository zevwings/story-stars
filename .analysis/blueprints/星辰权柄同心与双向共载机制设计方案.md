## 一、设计目标

「同心」是一项关系与连接方向的纯辅助个人星辰权柄。它服务四个目标：

1. 在两名清醒、自愿且主动开放的契约者之间建立高深度、低失真的精神共鸣；
2. 让双方在保持精神之海、星辰之力、人格与权柄独立的前提下相互承载精神结构；
3. 使长期共鸣能够按既有规则较快磨练双方精神之海的承载度与结构广度；
4. 通过同心印与同心星辰之间的权柄归属回响，在严重危险已经发生时提供不受物理距离限制的粗粒度示警。

本机制不设置世界唯一对象或固定绑定名额，也不提供力量共享、承载借用、替伤、定位、读心、预知或远程救援。

## 二、术语与层级

### 1. 同心权柄

「同心」是新增女主持有的个人星辰权柄，不是基础权柄、公共技巧或所有契约者都能训练获得的能力。

- **支配对象**：由双方自愿开放并经同心印固定的双向共鸣接口，以及共鸣中双方实际开放、相互承载的精神结构。
- **核心规则**：在不合并两片精神之海的前提下，降低双方结构接触时的失真与冲突，使彼此承载、节律校准和安全收束能够稳定成立。
- **星辰性质倾向**：回应希望在保留双方独立性的前提下真正理解、接纳并承担彼此真实重量的人；不回应占有、吞并或借他人成全自身力量的欲望。

「同心」属于连接与关系方向，与同调、共感、精神之锚和预兆分属不同机制，具体辨析见第八节。

### 2. 同心印

「同心印」是同心权柄持有者依照自愿星辰之印规则，与另一名契约者共同建立并固定的双向精神结构。

同心印不是第二份星辰契约，也不把另一方变成同心权柄持有者。普通受训契约者能够建立一般自愿印、共担印或生死绑定结构，但不能复制同心权柄提供的高深度共鸣校准与「知心」示警。

### 3. 双向共载

「双向共载」只指双方在自愿共鸣中相互承载对方已经开放的精神结构。它不表示：

- 把甲正在施展的个人权柄拆给乙完成；
- 把乙的承载上限借给甲；
- 合并、转移或共享星辰之力；
- 共享个人星辰权柄、记忆、感官、人格或控制权限；
- 由一方替另一方承担伤害、污染、异变或现实后果。

### 4. 知心

「知心」是同心权柄依托同心印形成的远距危险示警能力，不是第二项个人星辰权柄，也不是预兆、共感、读心或定位。

## 三、同心印的建立与权限

### 1. 建立条件

建立同心印必须同时满足：

- 双方均为已经成立星辰契约的成年人；
- 双方清醒理解印记性质、持续方式、示警范围、运行风险与解除路径；
- 双方分别明确同意，并主动开放建立印记所需的有限精神区域；
- 同心权柄持有者具备足够精神之海承载、星辰控制和印记训练，能够完成权柄塑形与安全收束；
- 双方精神结构至少达到相容，互斥状态下不能依靠同心权柄强行建立；
- 印记明确写入共鸣、示警、暂停、封闭与解除边界，不取得任何概括性精神权限。

建立同心印不要求双方已经是伴侣，但同心权柄不能制造信任、欲望、爱情或服从。没有真实关系基础与主动开放时，只能形成失败或不稳定结构，不能获得高深度共鸣。

### 2. 持续与数量规则

同心印建立后不会因时间、距离、关系降温、关系结束或长期静置而自然消退；暂停与封闭都不等于解除。这里的“永久”只表示印记没有自然期限，不表示不可撤回或不可解印。印记只有经过正式解印、被外力摧毁或随一方死亡转为残留结构，才会失去再次启动的可能。

同心权柄不设置世界通行的固定绑定名额或唯一对象规则。每一枚同心印都是独立的双向结构；能否继续建立，由持有者当前精神之海承载、星辰控制、既有印记复杂度与各对象的主动开放分别结算。

本书实际人物关系中，新增女主是否只与晏林建立同心印，属于人物选择与关系事实，不升格为世界通则，也不据此宣布晏林存在唯一灵魂伴侣或最高关系位。

### 3. 权限状态

同心印建立后分为三种运行状态：

- **静置**：印记保留，但不建立当次共鸣，不读取、共享或传递任何内容；
- **启动**：双方当次主动开放后建立共鸣接口，按明确范围进行双向共载；
- **封闭**：任一方均可单独关闭自己的接口，阻止后续启动；封闭不等于解印，也不触发强制剥离后果。

每次启动都需要双方当次主动开放。任一方可以随时缩小范围、暂停或撤回；另一方必须立即停止并安全收束。既往同意、亲密关系、同心印长期存在、昏迷、不抵抗或第三方代为同意，都不能替代当次开放。

### 4. 精神之海显影

同心印可以在双方精神之海内景中显影为带有对方精神节律的**互嵌节点**或**印记接点**。两边显影不要求外形相同，但在共鸣与知心示警时应存在可辨认的对应变化。

该显影只是既有同心印在内景中的呈现：

- 不是精神之锚、核心锚点或新生稳定锚点；
- 不要求双方具有罕见的精神之锚；
- 不改变精神之海基础内景；
- 不因被看见、触碰或攻击就自动产生能力效果；
- 只在实际进入相应开放范围时可见，不能被普通被动感知直接看见；
- 没有现实世界中的纹身、光纹或其他外在形态。

## 四、高深度共鸣与成长结算

### 1. 共鸣性质

同心权柄不会改变双方天然的精神适配类型，也不能把互斥强行改写为相引。它能够减少相容关系的磨合失真，并在双方已经形成稳定信任与主动开放后，使共鸣更容易进入高深度、稳定且可安全收束的状态。

同心印长期存在不等于共鸣长期运行。身体接触、亲密行为、同处一室或情绪激动都不会自动启动同心共鸣。

### 2. 成长归类

同心共鸣仍属于《精神之海》已经定义的**自愿共鸣入口**，不新增第三种成长通道。

- 双方实际相互承载精神结构，因此承载度与结构广度可以较普通相容关系更快地缓慢成长；
- 这种“较快”来自更深、更稳定、更少失真的真实承载，不设置倍率、数值或固定时间；
- 共鸣只磨练承载，不提高任何一方的星辰控制精度；
- 同心权柄持有者主动调用同心权柄时，可以按普通权柄使用规则磨练自身星辰控制；另一方不会因此取得同心权柄或控制成长；
- 同一关系内重复共鸣仍有边际递减，真正有效的是承载结构的复杂度、深度与差异，不能靠重复次数刷成长；
- 超过个人承载边界的强行共鸣只会造成过载、失稳或结构损伤，不形成稳定成长。

### 3. 因果与亲密边界

因果方向锁死：先有双方真实成立的欲望、情感、信任与自愿开放，后有共鸣及其成长结果。不得为了扩张精神之海、提高评级、稳定异变或取得其他收益而索取关系、亲密或身体行为。

同心印与稳定的 M 倾向可以在人物关系中互相呼应，但不能互相制造：同心权柄不制造 M 倾向，M 倾向也不构成建立、启动或扩大同心印权限的概括授权。

## 五、「知心」远距危险示警

### 1. 成立机制

同心印由同心权柄调用星辰之力完成塑形，因此印记保留与同心星辰之间的权柄归属回响。当任一方遭遇足以显著扰动生命状态、精神之海核心边界或同心印本体的现实事件时，异常不沿普通精神连接跨越空间传递，而是沿印记的权柄归属返回同心星辰，再由星辰使另一方精神之海内的对应同心印产生示警。

因此，「知心」不受普通精神连接的距离限制，也不因双方位于不同城市、地区或海外而自然衰减。这个无视距离的例外只适用于预先写入同心印的严重危险示警，不适用于共鸣、共载、交流、观测、定位、能力支援或其他精神干涉。

### 2. 双向性

同心印在双方精神之海内都保存对应结构，因此严重危险示警可以双向触发。非持有者收到示警，只代表同心印向其呈现预设状态，不代表其取得同心权柄、调用同心星辰或沿印记反向施术的资格。

任一方可以单独暂停自己对外开放的知心示警；暂停只关闭自己的危险状态向另一方回响，不拆除同心印，也不影响另一方是否继续开放其自身示警。

### 3. 触发范围

知心只在危险已经跨过严重阈值时触发，允许范围为：

- 危及生命的现实伤势或生理状态；
- 精神之海严重过载、核心边界破坏或结构性崩溃趋势；
- 星辰异变进入急性失控状态；
- 同心印遭遇未经授权的强制侵入、剥离、封锁或结构破坏。

普通疲劳、疼痛、恐惧、争吵、情绪低落、轻微受伤、被跟踪、潜在威胁、对方说谎或尚未发生的风险都不能触发知心。

### 4. 可获知信息

知心只能让另一方确认：

- 严重危险已经发生；
- 危险大致属于骤发还是持续恶化；
- 危险回响仍在持续还是已经停止。

知心不能提供：

- 对方的位置、距离或移动方向；
- 危险原因、施害者身份或事件经过；
- 对方的感官、记忆、思想、情绪内容或主观判断；
- 尚未发生的未来危险；
- 远程通信、追踪、定位、控制、共载、治疗、救援或力量传递。

知心是对**已发生严重状态变化**的示警，不是预兆权柄。接到示警后，角色仍须依靠现实通信、组织协作、调查、交通与行动寻找和救援对方。

### 5. 失真与失效条件

物理距离不会削弱知心，但以下条件可能造成延迟、失真或失效：

- 同心印核心已经被破坏、有效解印或主动关闭对应示警；
- 同心权柄持有者的人星协调严重失序，无法正常承接同心星辰回应；
- 接收者本人处于昏迷、精神之海结构性崩溃或无法形成主观感知的状态；
- 危险没有实际扰动到知心规定的生命、精神核心或印记结构阈值。

不得写成知心绝对及时、绝不误判或必然促成成功救援。

## 六、运行风险与解除后果

本机制不新增星辰契约代价轴。星辰异变仍是唯一的星辰契约代价轴；同心的建立、运行与解除只产生既有的精神负荷、双向暴露、连接反冲、边界破坏、结构损伤与人星协调失序，并可能经由长期失衡间接催化星辰异变。

### 1. 建立风险

- 双方必须开放建立印记所需的有限深层结构，并承担双向暴露；
- 建立初期需要适应对方节律，可用承载可能暂时下降；
- 建立失败可能造成连接反冲、短期失稳、边界损伤或结构损伤；
- 建立失败本身不自动等于星辰异变，只有进一步破坏人星协调时才可能间接催化异变。

### 2. 启动风险

- 双向共载意味着双方都真实承担精神负荷和连接暴露；
- 一方失稳、受到外来能力影响或连接突然中断时，另一方可能承受结构冲击，但污染、伤害与能力效果不会无条件自动转移；
- 只有已经开放且正在共同承载的结构可能受到牵连，未开放的记忆、人格、欲望与权柄结构不会自动暴露；
- 过度依赖同心共鸣可能使角色在独自承担高复杂结构时出现短期节律不适，但不会永久降低其原有承载上限。

### 3. 暂停、封闭与解除

任何正式解印都不能无痕完成，必然产生一次轻重不一的结构结算。结算强度取决于印记持续时间、历次共鸣深度、双方当前状态、拆解精度与是否配合；它属于既有的精神负荷、边界扰动和结构损伤风险，不构成新的星辰契约代价轴。

- **暂停当次共鸣**：任一方撤回即可成立；双方安全收束当前连接，只结算已经形成的普通负荷，不产生解印级损伤；
- **单方封闭接口**：阻止后续再次启动，印记继续存在；可能出现短时节律落差，但不能被另一方强行重新开启；
- **双方协商解印**：逐层卸载印记并重新定锚；双方必然经历一段轻重不等的承载紊乱、印记残感或复杂施为稳定性下降，通常可以逐步恢复；
- **单方要求正式解除**：另一方不得继续调用同心效果。完整拆除仍须由同心权柄持有者或具备对应结构识别与拆解能力的解印者实施；拒绝配合时，要求解除者可以持续封闭接口并寻求第三方解印。拆解完成后，双方仍按实际连接深度承担相应结构结算；
- **强行剥离或外力摧毁**：可能造成精神反冲、边界破坏、结构损伤、能力方向暂时失能，极端情况下发生结构性崩溃；不写成必死或原始星辰契约解除。

### 4. 一方死亡

- 同心印处于静置或封闭状态时，一方死亡不会自动使另一方精神之海坍塌；对应印记转为无法再次启动的残留结构，另一方需要后续受控解印，并可能经历明显的节律落差与适应失衡；
- 双向共载正在运行时一方死亡，正在共同承载的结构会骤然失去一端，另一方可能遭受严重过载、连接反冲和长期结构损伤；
- 死亡不会使幸存者继承对方的星辰、权柄、力量、记忆或人格，也不会把原始星辰契约转移给幸存者。

## 十、实现验收标准

正式落地后必须同时满足：

- [ ] 同心是个人星辰权柄，知心只是其具体能力；
- [ ] 同心印继承自愿星辰之印规则，不是第二份星辰契约；
- [ ] 文档中不存在固定绑定名额、唯一绑定或世界唯一设定；
- [ ] 双向共载只处理双方主动开放的精神结构，不拆分个人权柄负荷；
- [ ] 高深度共鸣只加快承载度与结构广度的缓慢成长，不提升控制、恢复力量或直接增加战力；
- [ ] 知心明确无视物理距离，但只报告严重危险已经发生，不提供位置、原因、感官、未来或远程干预；
- [ ] 同心印可以在精神之海显影，但不被写成精神之锚或新生锚点；
- [ ] 任一方能够单独暂停当次共鸣、封闭接口并关闭自己的对外示警；

- [ ] 解除与死亡后果回到精神过载、边界破坏、结构损伤和人星协调失序，不新增契约代价轴；
