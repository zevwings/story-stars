# 星辰任务体系分析

> **文档状态**：分析蓝图，不是正式正典。
>
> **用途**：统一收拢星辰管理局任务、管理局契约者内网、自由组队、星辰通缉令、异常清理、星契动物与主人责任等讨论结果，为后续世界观正式化、阶段编排和剧情节点设计提供依据。
>
> **真源边界**：正式事实仍以 [`BIBLE.md`](../../BIBLE.md)、[`worldbuilding/`](../../worldbuilding/_index.md)、[`story/arcs/`](../../story/arcs/_index.md) 与 [`story/plotlines/`](../../story/plotlines/_index.md) 为准。本文中的新机制尚未正式升格；与正式文件冲突时服从正式文件。

## 一、分析目标

当前阶段一、阶段二已经分别建立“安若曦截断与关系点燃”“关系稳定与异常下注显影”的正式弧线，但人物关系、日常、职业场和管理局事件仍容易并排运行，缺少能够反复交叉的公共行动载体。

星辰任务体系需要同时解决五个问题：

1. 让管理局不是只在大案中突然出现，而是拥有登记、支持、筛查、协查、处置和善后的稳定日常。
2. 让契约者通过管理局内网中的论坛、聊天、任务系统和自由组队建立职业联系、私人熟悉与长期合作。
3. 给故事提供大小不同、真假混杂、可以反复调用的都市异常任务，不把每次异常都升级为主线阴谋。
4. 建立星辰通缉、异常清理和星契动物任务，使任务线具备调查、探索、对抗、捕获、救援与恢复的完整循环。
5. 让任务最终回到日常、工作、关系、知情和共同秩序，而不是压过本书“亲密为主、日常为次、修行最辅”的定调。

本体系可以参考《诡秘之主》中地方常驻单位、辖区任务、专业能力拼队、风险升级、上报转交、危险资源管控和行动善后的结构，但不复制其教会、序列、封印物或战力体系。

## 二、现有正式边界与本轮确认

### 1. 管理局与公安

- 管理局负责星表、登记、复评、能力风险、精神侵蚀、保密、民间协查、监管与专项处置。
- 公安负责普通接处警、现场控制、现实证据、搜查、抓捕、讯问与司法程序。
- 江州市公安局综合研判七组只承担异常警情复核与公安侧协调，不建立自己的民间契约者网络。
- 民间协查者由管理局按案委托，协查是松散、有偿、可拒绝的关系，不构成管理局编制或固定执行队身份。
- 民间协查者不自动取得搜查、拘捕、讯问、持枪、普通警务资料或管理局内部档案权限。

### 2. 网络边界

- 现有正式真源已经明确：管理局使用受控专网处理登记、星表、复评和事件协查，民间协查者不自动取得内部档案和完整专网权限。
- 本轮进一步确认：管理局内网应由管理局统一建设、认证、运营和维护，并设置面向契约者的协作区，而不是另建脱离管理局的半官方社区。
- 内网采用权限分区：管理局正式人员进入核心业务区；通过资格核验的契约者进入契约者协作区；接受具体任务后，再按职责取得对应任务房间的最低权限。
- 星表、完整登记档案、复评、监管、正式案件卷宗和内部指挥仍只存在于核心业务区，不向普通契约者账号开放。
- 契约者协作区承载有组织的论坛、聊天、任务系统、城市频道和自由组队。
- 星辰家族保有各自的内部系统。
- 地下匿名网络的正式名称确认为“暗色星辰”；黑市是依托暗色星辰与现实产业运行的非法交易生态，不是该网络的正式别名。公开加密通信工具另属现实互联网渠道。

因此，现有“受控专网不是所有圈内人共享的公共网络”仍然成立，但其含义应收紧为“不向契约者开放核心业务区与完整资料”，不能再据此推出论坛和任务系统必须建在管理局之外。后续需要补充的是管理局内网面向契约者开放的低权限协作区；它与核心业务区属于同一组织体系，但资料、权限和审计边界严格隔离。

### 3. 能力与战斗边界

- 星辰之力中性，行为正邪取决于使用方式、知情自愿和现实后果。
- 星辰契约不提供肉体力量和速度强化。
- 精神能力负责感知、控场、干扰和创造现实窗口；现实伤害、抓捕和放倒仍由物理层结算。
- 星辰异变是契主被自身力量同源异化，不是外部黑暗能量或负面实体。
- 亲密和共鸣不提供战力掉落、能力升级或任务收益。

### 4. 阶段一、二现有边界

- 阶段一酒吧事件不进入警方或管理局记录；温婉不与晏林相识；管理局不掌握安若曦事件。
- 阶段二异常下注只在管理局内部完成多份残留比对，不调用晏林、不启动温婉协查、不锁定赌场与执行者。
- 若阶段一、二加入新的星辰任务，必须与安若曦酒吧事件、异常下注材料和阶段三赌场协查分开，不能提前消费既有主线。

## 三、任务体系总定位

管理局任务不是公开异能公会委托，也不是每天刷新的讨伐榜。它处理的是普通医疗、警务、工作、公共场所和私人生活无法独立处理的星辰契约异常。

大多数任务的现实表面仍然是：

- 心理或精神异常；
- 医疗转介；
- 酒吧、商场、训练馆、物业或交通事故；
- 家庭冲突、宠物异常与野生动物事件；
- 失踪、失联、偷拍、网络传播与隐私侵害；
- 赌博、债务、合同、勒索与能力犯罪；
- 新契约者登记、复评、失控和恢复；
- 黑市设备、药剂、资料和人员转移。

一项典型任务的完整循环是：

```text
普通生活入口
→ 异常筛查
→ 任务权限成立
→ 临时人员组合
→ 现场处置或外围核查
→ 医疗／公安／管理局分别移交
→ 保密、恢复、复盘和现实生活回归
```

不是所有任务都会走完整条链。大量任务会在“确认只是普通事件”“只需低风险支持”或“证据不足，保留观察”处结束。

## 四、管理局内网的分区结构

### 1. 总体结构

管理局内网不是单一资料库，而是一套按身份和任务切分权限的组织基础设施：

```text
管理局内网
├─ 核心业务区：正式人员办理登记、复评、案件与内部指挥
├─ 契约者协作区：论坛、聊天、任务系统、资源服务与自由组队
└─ 临时任务房间：按任务、职责和时限开放的最低必要信息空间
```

三个区域可以使用同一身份体系和统一入口，但账号看见的内容完全由身份、登记状态、专业资格和当次任务权限决定。契约者能够进入内网，不等于进入管理局内部档案系统。

### 2. 核心业务区

只供管理局正式人员与当次取得必要内部权限的人员使用。

主要内容：

- 星表与登记档案；
- 正式案件材料；
- 复评、监管与收容记录；
- 公安联合任务；
- 高风险能力资料；
- 内部指挥、审批与权限审计。

民间协查者参加任务时，只通过临时任务房间看到与当次职责直接相关的最低材料，不进入核心业务区。

### 3. 契约者协作区

这是管理局内网面向契约者开放的协作区域，只向经过资格验证的星辰契约者开放。它既承载契约者社会，也承担管理局的通知、支持、任务分发和风险回收功能；不承载星表、完整登记资料和正式案件卷宗。

主要功能：

- 契约者论坛；
- 私聊、群聊与同城频道；
- 个人求助；
- 专业服务；
- 管理局任务系统；
- 自由组队；
- 风险提示与星辰通缉摘要；
- 登记、复评、训练、医疗和恢复资源；
- 工作、生活、伴侣知情和保密经验交流。

采用“管理局统一运营、后台实名核验、前台允许使用昵称”的模式。管理局负责账号资格、版面秩序、任务审核、风险升级、违规处置和安全审计；论坛管理员、城市值班人员与任务审核人员均属于明确岗位，而不是依赖用户自发维持。

内网可以保留日常聊天和私人交流，但“属于管理局内网”不等于管理局可以无条件读取一切私人内容。普通社区治理、系统安全审计、任务留痕和依法调取应分开设计，具体隐私边界仍需后续确认。

### 4. 论坛文化与社区调性

契约者协作区不只是办公系统，而是一个有温度的社区。除了官方公告和专业讨论，日常灌水、争论、求助、吐槽、晒宠物、约饭、分享经验和互相调侃都是常态内容。管理局保留治理权，但社区氛围以用户自组织为主，版务互动和用户关系构成基层社区感。

这种活跃社交有两个叙事功能：一是当某个用户突然沉默、发帖异常或被多人举报时，社区本身成为风险早期信号；二是论坛和城市频道为角色提供不需要物理在场的自然互动场景，线上互动可以延伸到线下的吃饭、接送、训练和恢复。

### 5. 暗色星辰、公开通信与黑市

现实互联网、公开加密通信工具和暗色星辰都在管理局内网之外，三者不能合并处理。

- **暗色星辰**是地下匿名网络的正式名称，俗称地下网络。它提供匿名连接和可视化服务空间，不等同于黑市。
- **黑市**是依托暗色星辰与现实产业形成的非法交易生态。人物口语可以笼统把地下网络称为黑市，正式分析必须区分。
- **公开加密通信工具**是公开可取得、使用门槛较低的通信渠道，不需要先进入暗色星辰，也不属于黑市基础设施。

契约者可以在管理局内网认识后转向现实私人联系，也可能因截图外泄、现实暴露或主动进入暗色星辰中的非法服务而被黑市参与者盯上。管理局能够管理自己的内网，却不能因此掌握契约者在所有外部网络和通信工具中的活动。

#### 暗色星辰不是统一平台

暗色星辰由大量无法被完整识别的独立节点共同维持，没有总运营者、总服务器、总后台或全网管理员。基础网络原则上任何人都可以进入和退出，具体服务则通过目录、流传地址、邀请、担保或现实关系被局部发现。

网络通过图形化客户端呈现。具体服务可以是市场、频道、群组、论坛、任务页、订单房间、私聊或媒体空间，并拥有自己的匿名经营者、局部账号、规则、封禁、评价、托管和争议处理方式。服务经营者只控制自己的空间，不取得暗色星辰的全网权限。

暗色星辰不建立全局账号、全局搜索、全局信誉、全局仲裁、统一货币、统一结算或统一交易规则。具体服务采用什么准入、支付和履约方式由各自决定；本分析不预先建立固定目录、地址、邀请、担保或结算格式。

#### 黑市不是暗色星辰的别名

黑市不能设计成“管理局内网的黑色版本”，也不是暗色星辰上的一家总站。它由暗色星辰上的多个独立服务、现实中间人和长期产业资源节点共同形成，主要可以覆盖：

1. 情报、目标资料与委托信息；
2. 非法能力服务；
3. 暴力、暗杀、绑架与伤害委托；
4. 人员控制、转移、拘禁与强迫服务；
5. 非法色情产业、非自愿影像与相关侵害；
6. 毒品、非法药剂与地下医疗；
7. 器官、人体材料与非法移植；
8. 身份、记录与跨境掩护；
9. 赌博、债务与地下金融。

某个服务被关闭只代表一批交易和一组关系暴露，不等于暗色星辰或整个黑市被关闭。不同服务即使出现相似的需求方、情报方、资源方、经营者、中间人、执行者和受益者位置，也不构成全网统一部门。

#### 黑吃黑与履约风险

黑市没有稳定的全网履约保障：付款不保证交付，交付不保证真实，任务完成不保证结算。局部评价、担保、托管与仲裁可以被伪造、操纵或拒绝承认；买方、卖方、中间人、担保人和服务经营者都可能吞款、调包、勒索、反向识别或剪裁放料。

因此，不能再把黑市交易写成“提交订单—后台派发—完成—自动结算”的可靠流程。具体交易是否成立、谁保留副本、谁拒绝付款或反向要挟，只能由当笔交易的参与者和现实条件决定。

#### 网络匿名与现实归责

暗色星辰的网络路径、服务地址和匿名账号不能直接反查现实身份，但它不能抹除现实因果。参与者设备、交易对手或服务经营者保留的内容副本、现实履约、付款兑付、场所记录、人员接触和重复资源调用仍可交叉形成责任链。

统一边界是：**网络身份不可直接追溯，具体交易仍可通过现实证据归责。**

管理局与公安不需要找到暗色星辰的总运营者，也不存在可供查封的全网总站。个案追查只能从具体服务、现实参与者和产业接口入手；白玥等单一执行者提供的局部记录不足以直接证明上游，但可以与其他案件材料交叉。

#### 裴家的黑市位置

裴家是黑市中的家族化综合产业节点和高频使用者，不是暗色星辰或黑市的管理者，也不拥有面向外部的“裴家订单后台”。

裴家使用不同身份进入不同独立服务，可以发布试探性能力任务、购入实验对象和其他资源、出售药剂，并在交易关系稳定后转入长期私下联系。裴家保留自身决策、授权、物资、场所、付款、通信和现实履约自然产生的记录，但这些是交易参与者的内部材料，不是平台后台数据。

裴家在不同交易中可以承担不同位置：

| 交易位置 | 裴家承担的作用 |
| --- | --- |
| 需求方 | 发布能力任务，购买人员、实验对象、情报或其他资源 |
| 真实客户 | 裴怀山等具体责任人成为某笔交易的实际需求和受益主体 |
| 人员供应 | 万安影视文化承担成年目标筛选、包装、关系隔离和定向提供 |
| 医疗与实验 | 万安健康承担药物控制、拘禁、实验分类、记录处理及相关资源调用 |
| 卖方 | 通过独立药剂服务、分销者或其他局部交易关系向外部客户提供药剂 |
| 资源中转 | 与齐心的出售和实验委托、陆佳凝的境外转送及其他接口发生连接 |
| 责任切割 | 利用自己掌握的真实但不完整记录，把局部责任压向中间人或执行者 |

齐心、陆佳凝、裴家、顾清言及具体中间人、服务经营者和执行者可以合作、共同获利或长期往来，但不能合并成一个由裴家统治的统一黑市组织。

裴家与白玥的使用链、白玥现实暴露、长期匿名通信及药剂部署时间线已经完成正式迁移。阶段材料不得再把“黑市上层责任”作为责任主体，应按齐心—陆佳凝先行控制、裴家与朱岑郁独立证据分轴闭合的正式结构读取。

## 五、管理局契约者内网

### 1. 访问资格

契约者协作区需要证明登录者确实是契约者，但不应向其他用户公开其具体星辰结构。

候选机制：由管理局或合法登记终端生成“契约存在凭证”，只证明账号对应主体具有有效星辰契约，不公开具体星辰、权柄、精神之海评级或完整登记资料。

账号可以分为：

- **正式账号**：已完成登记的契约者；
- **临时账号**：正在办理登记，由公开联络人担保，权限有限；
- **临时任务权限**：附着在已有管理局人员或契约者账号上，只进入某个临时任务房间，不开放额外社区资料。

完全拒绝登记者原则上无法正常取得管理局内网账号，只能停留在线下私人群、灰色渠道或黑市网络。普通人即使因个案知情，也不取得契约者协作区账号；需要参与现实处置时，由承办人员通过现实工作渠道提供最低必要信息。

### 2. 用户公开资料

可以显示：

- 内网昵称；
- 所在城市或大致活动区域；
- 能力大方向；
- 现实专业能力；
- 可以承担的任务类型；
- 已取得的训练或协查资格；
- 历史协作可靠性；
- 是否接受有偿邀请；
- 当前是否可出勤。

不得默认显示：

- 具体星辰；
- 完整权柄；
- 精神之海评级；
- 现实住址与私人关系；
- 未公开工作单位；
- 参与过的保密案件；
- 可用于针对性攻击的能力弱点。

### 3. 论坛与聊天体系

论坛不是一块无管理的匿名留言板，而是按“官方信息—专业交流—城市生活—任务协作”组织的内网社区。不同板块由管理局对应岗位或通过审核的契约者版务人员维护，重要内容可以被标记为官方答复、风险提醒或待核实经验。

#### 官方公告与办事区

- 登记、复评和培训通知；
- 制度变更与风险通报；
- 医疗、恢复、法律与保密资源入口；
- 城市管理局值班窗口；
- 账号申诉、违规举报和任务争议处理。

#### 城市频道

- 本地日常；
- 风险提醒；
- 临时求助；
- 线下活动；
- 本地医院、训练、寄养、交通与恢复资源。

#### 能力与适应

- 能力控制经验；
- 星辰异变；
- 精神之海状态；
- 能力与工作冲突；
- 家属和伴侣知情；
- 协查后恢复。

#### 普通聊天区

- 工作吐槽；
- 城市生活；
- 恋爱与保密；
- 复评请假；
- 任务后夜宵、接送和恢复；
- 宠物、衣装、装备、车辆与店铺；
- “伴侣不知道我是契约者怎么办”等圈层日常。

聊天可以包括公开频道、主题群组、固定队伍群和私聊。任务相关决定不能只停留在私人聊天中；接单、成员变更、风险升级、退出、交接和结算必须回到任务系统留痕。

### 4. 正式任务系统

任务系统与论坛相连，但不等同于论坛发帖。论坛帖子、个人求助和聊天中的异常线索，可以提交给任务审核岗；只有完成来源确认、风险初筛、权限划分和责任归属后，才转化为带编号的正式任务。

任务系统至少包括：

- **任务大厅**：展示可见范围内的管理局委托、经审核个人求助和专业协作任务；
- **资格匹配**：按城市、现实专业、登记能力方向、训练资格和可出勤状态筛选报名者；
- **报名与邀请**：允许公开报名、定向邀请和管理局建议组队；
- **任务房间**：集中保存摘要、成员、职责、风险变化、退出记录、现场接口与交接要求；
- **升级通道**：低风险任务一旦出现犯罪、精神控制或公共危险，可以立即转交管理局正式处置；
- **结算与复盘**：处理报酬、补助、评价、损伤恢复、权限回收和材料归档。

普通用户不能自行把私人恩怨包装成“官方任务”，也不能绕过审核公开他人的现实身份、住址、能力细节或未经核实的犯罪指控。

### 5. 自由组队

允许：

- 一次性任务队；
- 城市互助群；
- 固定两三人搭档；
- 某类能力讨论组；
- 恢复与训练小组；
- 夜间场所互助联系人；
- 长期专业合作群。

自由组队不等于取得调查、搜查、拘捕、精神检测或强制处置权限。

基本流程：

```text
发布任务
→ 任务系统完成风险初筛
→ 成员申请或邀请
→ 建立临时任务房间
→ 确认目标、费用、边界与退出条件
→ 线下执行
→ 完成、取消或升级上报
→ 评价、结算、恢复与归档
```

出现现实犯罪、持续精神控制、完全失去选择能力、大范围外泄、非法种印、违禁药剂、拘禁、失踪或重大风险隐瞒时，自由队伍必须停止自行扩大调查并升级管理局或公安。

#### 常见失败模式

任务体系需要为失败留出充分空间。以下失败类型均可作为故事素材：

- **队员隐瞒风险**：未告知关键信息导致任务升级，触发信任危机和关系裂痕；
- **任务目标落空**：异常只是普通事件，白忙一场，但过程中暴露其他问题或建立新的人际连接；
- **队内理念冲突**：两人因能力使用边界或任务判断分歧中途拆伙，形成后续被迫合作的张力；
- **报酬与归属纠纷**：结算争议触发角色价值观碰撞和长期摩擦；
- **队员受伤与恢复期**：照护关系、工作补偿、误工责任成为日常戏份入口；
- **任务后现实反扑**：请假、补班、车辆维修、误工补偿等后续事务打乱私人安排和约定。

任务不应被写成通关式打怪。每次任务失败、意外或冲突都应回到人物关系、日常生活或后续认知。

### 6. 评价与奖励

不设置战力排行榜、等级经验或击杀数。

评价只记录：

- 是否按时出现；
- 是否遵守职责与边界；
- 是否隐瞒重大风险；
- 是否按约完成；
- 是否发生越权；
- 是否在风险升级后及时上报；
- 是否完成现实交接和任务后恢复。

合法奖励可以包括：

- 法定货币报酬；
- 误工、交通和住宿补助；
- 协查信誉；
- 医疗与恢复额度；
- 专项训练名额；
- 受控设备借用资格；
- 更高风险任务的报名资格；
- 契约者公共服务优惠。

不得获得：

- 新权柄；
- 星辰之力补充；
- 精神之海经验值；
- 怪物能力掉落；
- 吞噬或夺取星辰；
- 亲密换战力。

## 六、任务来源

### 1. 管理局公开委托

经过审核后向符合条件的民间协查者开放，例如：

- 新契约者陪同登记；
- 低风险能力测试；
- 精神状态复评；
- 已知地点异常筛查；
- 现场疏散辅助；
- 受影响者短期陪护；
- 训练与恢复支持；
- 特定现实专业咨询；
- 星契动物观察、迁移和保护。

管理局任务必须附带编号、报酬、权限、风险摘要和退出条件。

### 2. 契约者个人求助

例如：

- 反复做同一个梦；
- 怀疑精神之海存在外来残留；
- 能力开始影响工作；
- 需要陪同复评；
- 不敢独自办理登记；
- 怀疑某件物品或场所存在异常；
- 需要安全训练；
- 寻找相近能力方向的人交流。

个人描述只构成任务入口，不保证事实成立。

### 3. 专业服务委托

例如：

- 法律咨询；
- 心理与医疗转介；
- 运动康复；
- 保密与设备检查；
- 车辆和交通保障；
- 搬迁、寄养和临时住宿；
- 舆情处理；
- 协查后的恢复支持。

专业服务首先服从现实职业资格，能力不能替代执业边界。

### 4. 自发探索与互助

例如：

- 核查都市怪谈；
- 调查异常传闻；
- 搜索失联契约者；
- 观察疑似星契动物；
- 收集公开材料；
- 参加城市互助活动；
- 对低风险异常地点进行外围确认。

### 5. 普通社会转入

任务还可能从普通系统进入：

- 医院和心理咨询转介；
- 公安异常警情编码；
- 物业、安保和动物管理记录；
- 普通兽医和宠物行为问题；
- 社交平台、失物招领和本地新闻；
- 家属、伴侣或雇主求助；
- 城投集团公开业务发现的最低风险方向。

普通业务数据不自动进入管理局档案，必须达到明确异常门槛后按最小必要原则流转。

## 七、任务类型

### 1. 登记与适应

- 新契约者登记；
- 能力边界测试；
- 保密教育；
- 健康检查；
- 工作与生活适应；
- 家属和伴侣最低知情；
- 普通体能和安全训练。

### 2. 异常筛查

判断事件属于：

- 普通医疗或心理问题；
- 药物、毒品或设备问题；
- 契约者自身失控；
- 星辰异变；
- 外来精神侵蚀；
- 现实犯罪叠加能力犯罪；
- 星契动物事件；
- 暂时无法判断。

筛查的任务是分流，不是直接破案。

### 3. 稳定、净化与恢复

- 中止持续精神输入；
- 稳定精神之海；
- 清除可辨认的外来残留；
- 修复剥离后的原生损伤；
- 安排医疗、心理、住宿与安全保护；
- 建立复诊和复评。

处置、证据调查和责任判断必须分离。

### 4. 现场控制与外泄处置

- 人员疏散；
- 现实伤员处理；
- 危险物体控制；
- 现场封锁；
- 影像和异常痕迹封存；
- 舆情降温；
- 知情普通人分层处理；
- 必要时申请有限记忆干预。

记忆干预不是常规收尾工具。

### 5. 个案调查与能力痕迹

- 精神残留检测；
- 多份独立痕迹比对；
- 梦境或记忆碎片复盘；
- 能力大方向判断；
- 登记摘要核查；
- 药剂、设备和交易入口核查；
- 与现实监控、转账、通信和证言交叉。

能力材料只能提供方向，不能直接替代施术者身份、完整过程、现实证据与责任认定。

### 6. 失踪、失联与搜索

- 契约者失联；
- 任务队伍未按时返回；
- 新觉醒者逃避登记；
- 被控制或转移的当事人；
- 星契宠物走失；
- 野生星兽进入人口区域；
- 遗失设备、药剂或保密数据追索。

失联可能是私人选择、普通事故、能力失控、黑市或现实犯罪，不能预设答案。

### 7. 异常物品与设备

- 非法观星设备；
- 精神检测设备；
- 违禁精神药剂；
- 星辰异变催化药剂；
- 保留异常连接的物件、影像或数据载体；
- 被能力长期作用的现实设备。

任务可以是发现、封存、运输、检测、拆除和移交，但不把所有物品写成具有独立人格的封印物。

### 8. 保护与护送

- 护送当事人前往医疗或疗养机构；
- 转移知情普通人；
- 护送材料和受控设备；
- 陪同登记和复评；
- 保护准备作证的人；
- 公开活动中的能力暴露防护；
- 将高风险协查者安全带离现场；
- 星契动物迁移、寄养和保护。

### 9. 联合调查与抓捕

只有现实犯罪和能力犯罪门槛同时成立后，才进入公安与管理局联合任务。

可能包括：

- 非法种印者抓捕；
- 黑市交易点封控；
- 被控制人员救出；
- 危险契约者行动限制；
- 定向记忆复核；
- 多地点同步保护；
- 重大外泄处置。

民间协查者只完成任务书限定的专业或能力职责。

### 10. 后续监管与责任

- 契约者复评；
- 受害者恢复；
- 协查者健康检查；
- 临时权限解除；
- 监管印复核；
- 保密义务更新；
- 能力使用责任分层；
- 普通司法程序继续；
- 工作、住房、医疗和关系回归；
- 任务记录和权限审计。

## 八、任务风险分层候选

不按战斗力评级，而按持续伤害、影响人数、现实犯罪和外泄风险判断。

| 候选级别 | 典型任务 | 权限与风险 |
| --- | --- | --- |
| 0级：服务 | 登记、训练、健康支持、普通恢复 | 无正在发生的异常 |
| 1级：个案 | 单人筛查、稳定、复评、低风险动物观察 | 目标明确、环境受控 |
| 2级：现场 | 公共失控、多人目击、临时撤离、动物进入人口区 | 需要现场安全与保密 |
| 3级：联合 | 能力犯罪、持续控制、警方联合调查 | 需要正式案件权限 |
| 4级：重大 | 大规模污染、核心机密外泄、跨区域组织行动 | 多部门指挥与高层授权 |

级别只决定权限、人员、监督和升级条件，不代表角色战力或任务经验值。

## 九、任务参与身份

### 1. 管理局正式人员

负责立项、权限、星表、能力风险、保密、监督、后续监管和结算。

### 2. 公安与普通公共机构

公安、医院、消防、社区、林业、动物管理等继续承担现实职责，不因发现异常自动取得星表和管理局内部权限。

### 3. 集团业务人员

城投医疗、健身、安保、物业、新闻等板块先按普通职业运行；达到专项门槛后，个别人员才按案成为知情协作者。

### 4. 民间协查者

已登记契约者按具体任务接受有偿委托，可以拒绝，只取得最低必要信息，任务结束后临时权限失效。

### 5. 外部专业人员

律师、心理咨询师、医生、兽医、车辆与后勤、设备、舆情和平台协调人员可以参与，但不因此取得完整星辰契约知情。

## 十、任务标准流程

### 0. 体制感说明

江州管理局是地方基层单位，不是军事化中枢。整体体制感是松散的实用主义：流程和制度存在，但执行时会根据人手、紧急程度和现场情况灵活处理；部分基层负责人是无为而治的风格，只要不出大事故就不会严格追究每个细节。

这种体制特性给故事留出空间：角色可以在紧急或人情驱动下做出"违规但合理"的选择，体制摩擦来自具体的人和具体的情况而非抽象的制度对抗，人情关系和实际信誉往往比正式流程更能推动事情。

但松散不等于没有后果——违规、越权和失职仍会被追责，只是追责更像事后复盘、内部谈话、暂停资格或口头警告，而非即时自动化惩罚。

### 1. 来源登记

记录任务来自公安、医疗、契约者报告、管理局内部、城投业务、公开传播、家属、主人或动物异常等哪一个入口。来源不等于事实成立。

### 2. 初步分流

先判断：

- 是否存在即时人身危险；
- 是否可能涉及星辰契约；
- 是否需要普通警务、医疗或动物救助先行。

### 3. 权限成立

明确：

- 任务目标；
- 可接触对象；
- 可读取资料；
- 可调用能力；
- 材料保存范围；
- 安全中止条件；
- 现场责任主体。

### 4. 人员组合

按任务临时组合，不建立全能固定小队。简单任务可能只有一名正式人员、一名专业人员和一名民间协查者；复杂任务再增加公安、医疗、外泄与保护人员。

### 5. 现场执行

救人、稳定、检测、取证、抓捕和保密分别授权，不能因为同时发生在一个地点就交给同一个人。

### 6. 移交

根据结果转入普通医疗、公安案件、管理局复评、疗养、监管、动物保护或无异常结案。

### 7. 复盘与恢复

核查越权、外泄、协查者损伤、当事人保护、动物安置、临时权限解除和材料保留。

## 十一、星辰通缉体系

### 1. 正式通缉对象

- 涉嫌严重能力犯罪后潜逃的契约者；
- 非法种印者；
- 多次实施精神侵蚀者；
- 携带高风险违禁设备或药剂者；
- 拒绝管制且持续制造公共危险的契约者；
- 黑市关键中介和能力执行者；
- 劫走受控材料、危险物品或案件对象者；
- 已被普通司法机关通缉且具有能力风险者。

### 2. 契约者内网公开摘要

可以显示：

- 代号或依法公开的身份；
- 外貌与现实身份摘要；
- 已确认危险行为；
- 能力大方向；
- 最后出现区域；
- 接触风险；
- “仅报告”“禁止靠近”或“开放协查报名”；
- 报告入口与有效期。

不得公开完整星辰档案、精神之海评级、全部能力细节、证人、家属、完整案情和证据链。

### 3. 三种任务文书

- **正式通缉**：存在犯罪嫌疑或持续公共危险，目标是发现、保护、追踪并移交司法。
- **风险协寻**：对象可能是失控失联者、受害者、携带危险物品但不知情者或被黑市转移者，不预设犯罪。
- **物品追索**：追索设备、药剂、星表资料、异常连接载体和泄露数据。

### 4. 奖励边界

报酬对应有效目击、保护、材料回收、正式搜寻、能力协助和安全移交，不奖励私刑、绑架、未授权精神侵入或击杀。

## 十二、异常清理与“刷怪”循环

### 1. 基本原则

任务体系可以提供“接任务—组队—进入异常区域—调查或对抗—回收与救援—领取报酬”的循环，但不建立怪物掉落、战力升级和野外无限刷新。

可以反复处理的目标包括：

- 梦境中的重复映体；
- 幻境节点；
- 情绪聚集与群体失控；
- 御物失控区域；
- 非法种印残留；
- 黑市异常设备；
- 星契动物及其能力形成的危险区域。

“失控映体”仍是候选术语。它指能力、精神侵蚀或控制结构形成的重复执行表现，不是独立生命，也不是外部黑暗实体。

### 2. 清理任务循环

```text
异常帖子或现实记录出现
→ 用户提供目击与公开材料
→ 平台标记风险
→ 自由组队进行外围核查
→ 确认普通事件，任务结束
或
→ 确认星辰异常
→ 申请正式协查权限
→ 进入现场控制、清理、捕获或救援
→ 回收材料并移交
→ 管理局复核、结算和恢复
```

清理不默认等于杀死目标。星契动物事件优先驱离、迁移、捕获、治疗和保护。

## 十三、星契动物与星辰怪物

### 1. 已形成的方向

少数动物也可以在目视真实星空时得到星辰回应，成为非人契主。

它们：

- 继续服从一星一契；
- 需要拥有稳定个体意识与持续、本属于自身的本能意向；
- 不能因短暂饥饿、惊吓或群体反射自动结契；
- 不因契约获得人类语言、人格、道德、法律理解或网络访问能力；
- 仍按原物种认知、本能和普通训练理解世界；
- 也会承受星辰异变与能力失控风险。

当前正式《星辰契约》仍将契约定义为“人与真实星辰之间的联系”，因此动物结契尚属于待升格的重大机制变化。

### 2. 术语候选

- **星契动物**：管理局与研究档案使用的中性正式称呼；
- **星兽**：契约者圈层俗称；
- **星辰怪物**：对能力已经威胁人员、环境或公共安全的星契动物的任务俗称。

“怪物”不是物种名，也不代表动物邪恶。

### 3. 结契条件

动物必须：

- 直接看见真实星空；
- 感知星辰回应；
- 具有足以承载契约的精神结构；
- 形成持续而稳定的个体意向；
- 被星辰主动选择。

可能承接契约的本能愿望包括守护领地、找回幼崽、逃离捕食、追踪气味、返回巢穴、留住主人、隐藏自己、获得食物或驱逐入侵者。

### 4. 不开智边界

星辰契约不能：

- 让动物说话或读写；
- 赋予人类人格；
- 让动物理解法律、任务、星表和管理局；
- 让动物制定超出物种认知的复杂计划；
- 让动物自动理解自身权柄；
- 把动物转化为妖族或智慧种族。

动物可以通过普通训练识别名字、熟人、路线、简单指令和固定信号，这属于正常学习，不是开智。

### 5. 能力使用特征

- **本能触发**：害怕、追捕、护崽、受伤、争夺领地或分离焦虑时启动。
- **表达单一**：通常只形成少量直接能力表达，不发展人类式完整工具箱。
- **控制粗糙**：难以准确选择目标、范围和结束时机，受惊时可能把救援者也视为威胁。
- **可条件训练**：能够把声音、地点、装备或熟人和“停止、防御、返回安全区”等行为联系起来，但不能理解抽象授权和复杂能力配合。

动物作为契主原则上仍受公共权柄、承载、控制、连接和物理层规则约束；其认知能力限制了能够实际塑形出的复杂能力。

### 6. 星辰异变

动物异变仍是同源异化，不是外部污染，也不自动使动物邪恶。

可能表现为：

- 守护型动物无法容忍任何目标接近；
- 追踪型动物无法停止追踪已消失的目标；
- 隐藏型动物持续降低存在感并拒绝正常接触；
- 恐惧型动物把所有陌生生命视为捕食者；
- 领地型动物不断扩大驱逐范围；
- 方向型动物被互相冲突的路线淹没；
- 御物型动物失去施力尺度。

动物更依赖环境调整、熟悉的人和同类、普通行为训练、低刺激隔离、兽医与管理局联合观察。异变只能稳定、延缓和管理，不能治愈。

### 7. 中立原则

星契动物伤人可能来自领地、护崽、疼痛、受惊、异变、药剂催化、非法控制或人类利用。管理局首先判断动物是否受伤、是否仍在失控、是否能够驱离、稳定、捕获、治疗或迁移，不因伤害结果直接把动物定义成黑暗生物。

### 8. 不掉落原则

动物死亡后：

- 星辰契约终止；
- 对应星辰未来可以重新回应其他契主；
- 尸体仍是普通动物遗体；
- 不产生权柄结晶或星辰资源；
- 不能夺取、吞噬或继承能力；
- 后代不自动继承星辰契约。

“食用星兽器官获得能力”“杀死星兽可以指定夺星”“繁殖星兽形成能力血统”只能作为黑市骗局、错误认知或非法实验动机。

## 十四、星契动物的发现

### 1. 异常聚合原则

管理局没有覆盖全部动物的自动检测系统。星契动物通常不是被主人主动登记，而是通过重复异常、外围观察和事件处置被动发现。

```text
第一次异常：巧合
→ 第二次异常：主人觉得奇怪
→ 多次重复：形成公开记录或现实损失
→ 契约者注意到异常聚合
→ 外围观察
→ 确认星辰契约迹象
→ 管理局建立隐秘非人契主档案
```

主人不因没有发现宠物结契而承担未登记责任。

### 2. 常见异常表现

- 门窗、食盆、玩具等物品反复自行移动；
- 摄像头在动物行动时持续失焦或遗漏；
- 动物总能从封闭空间离开；
- 走失动物从不可能的路线返回；
- 捕捉、追踪和定位反复失效；
- 附近动物同步焦躁或安静；
- 陌生人进入后产生异常恐惧；
- 主人在固定情境下反复做同类梦；
- 动物持续提前阻止某种危险；
- 高处物品、车辆或现实事故反复在最后时刻偏离。

普通主人往往先理解为动物聪明、设备故障、训练问题、特殊感官、运气或都市怪谈。

### 3. 发现渠道

- 宠物论坛、社交平台、小区群、短视频、失物招领和本地新闻；
- 普通兽医发现反复无法解释的行为异常；
- 物业、安保、林业、动物救助和交通记录；
- 公安收到多次动物相关异常警情；
- 契约者在公开材料中发现异常聚合；
- 黑市先于管理局注意到能力价值。

普通兽医、物业和基层人员不一定知道管理局，只通过隐蔽风险编码或合作机构完成最低转介。

## 十五、主人知情结构

主人是否知道动物结契，是星契动物案件的第一判断轴；主人知道后如何选择，是责任判断的核心。

### 1. 主人不知道

主人只看见反复怪事，不知道星辰契约存在。

原则上：

- 不承担未登记和隐瞒契约责任；
- 不因动物意外施术自动承担能力犯罪；
- 只对普通饲养疏忽、现实伤害和已经能够合理预见的危险承担普通责任；
- 管理局优先确认、保护、降低风险并决定是否需要最低告知。

### 2. 主人知道并保护

主人可以选择：

- 停止刺激动物；
- 不公开异常影像；
- 接受环境和行为调整；
- 配合低风险观察；
- 不利用能力牟利；
- 出现异常时及时报告。

这是合法共处。风险可控时，动物继续留在原家庭，管理局只建立隐秘档案和应急接口。

### 3. 主人知道但隐瞒风险

可能表现为：

- 删除事故记录；
- 拒绝必要检查；
- 继续带动物进入高刺激场所；
- 多次伤人后仍谎称普通意外；
- 明知能力失控仍不采取措施。

需要区分主人只是害怕失去宠物，还是已经明知风险、能够避免并持续放任。隐瞒可能产生管理、赔偿、过失或更严重责任，但不自动等于故意犯罪。

### 4. 主人知道并主动利用

主人通过普通训练、奖励、惩罚、药物或环境刺激，让动物在固定信号和情境下使用能力。动物不需要理解犯罪，只需要学会收到信号后接近、携带、驱赶、攻击、制造混乱或返回。

可能涉及：

- 盗窃和非法进入；
- 跟踪、偷拍视频和定位；
- 恐吓、催债和破坏财物；
- 干扰比赛、活动或商业经营；
- 携带违禁物品和隐蔽交接；
- 非法狩猎与动物争斗；
- 直接攻击和故意诱发失控；
- 拍摄星兽对抗、刺激施术并牟利；
- 向黑市出售动物能力、影像或实验资格。

真正作出违法决定并承担责任的是指使者、训练者、获利者和控制者。

### 5. 知情是动态过程

```text
主人不知道
→ 发现第一次异常
→ 怀疑动物不同寻常
→ 主动或被动验证
→ 确认能力
→ 选择报告、保护、隐瞒或利用
```

真正的关系分岔点不是动物何时结契，而是主人确认力量以后把动物当成家人、风险、秘密还是工具。

## 十六、主人责任与证据

### 1. 动物不是共犯

星契动物没有人类式法律理解和完整犯罪意图，因此：

- 不列为犯罪嫌疑人；
- 不进入星辰监管所；
- 不发布刑事通缉令；
- 不把训练服从视为同意被利用；
- 可以作为被利用动物、风险对象、能力痕迹来源和需要保护或暂时隔离的生命处理。

### 2. 主人责任五问

1. 主人何时知道动物具有异常能力？
2. 主人是否知道能力可能造成什么后果？
3. 动物行为来自自主本能，还是固定训练、命令或刺激？
4. 主人是否从结果中获利、报复或实现其他目的？
5. 事后主人是求助、补救，还是隐瞒、转移和继续利用？

### 3. 证据边界

动物不能提供人类证言。灵犀只能理解动物当前情绪和简单趋避意向，不能读取完整记忆，也不能直接成为司法证据。

现实证据需要包括：

- 监控与行动时间；
- 主人反复使用的训练信号；
- 奖励与惩罚模式；
- 任务地点和动物行为的重复对应；
- 通信、付款和黑市联系；
- 专门购置的运输、拍摄或刺激设备；
- 事后掩盖、转移和获利行为；
- 动物身上的药剂、伤痕或控制结构；
- 多次事件中的相同能力痕迹。

能力痕迹只能证明异常效果存在，不能单独证明主人下达命令。

## 十七、星契动物任务与处置

### 1. 任务类型

- 目击核查；
- 领地边界调查；
- 搜索与追踪；
- 驱离与迁移；
- 捕获与救援；
- 栖息地协调；
- 家养动物风险管理；
- 黑市盗猎、控制和实验调查；
- 动物能力造成的异常影响清理；
- 主人违法利用调查。

### 2. 风险处置梯度

- **观察**：远离人群、风险很低，只记录活动范围；
- **共存**：城市附近活动但风险可控，通过路线、食物和环境调整降低冲突；
- **驱离与迁移**：能力开始影响居民、交通或公共设施；
- **捕获与稳定**：持续攻击、受药剂或控制影响、无法自行退出能力状态；
- **紧急处置**：正在造成重大伤亡且无法驱离、麻醉、限制或稳定时，才允许致命处置。

### 3. 主人告知分层

- **完全不知情**：风险低，无需主人改变照护；
- **现实理由告知**：通过兽医、行为专家或物业给出环境和照护建议；
- **最低异常知情**：说明存在特殊异常、不得刺激和传播，出现征兆时联系指定机构；
- **完整圈层知情**：主人本身是契约者，或长期安全管理、黑市威胁和现实合作确实需要完整说明。

普通主人即使成为知情普通人，也不因此取得管理局契约者内网账号。

### 4. 通缉与协寻

违法主人可以进入正式星辰通缉；同行动物应发布“高风险星兽协寻”或“星兽警示”，明确动物不是犯罪主体、不得猎杀或刺激，优先捕获、稳定和保护。

内网用户可能俗称“人兽双通缉”，正式档案必须分别记录人的司法状态与动物的风险、保护状态。

### 6. 星契动物在叙事中的情感功能

星契动物除了体系机制，还需要在叙事中承担多层情感功能：

- **共情载体**：动物的无辜性、被迫处境或受伤状态触发角色和读者的保护欲，成为道德选择和行动意愿的入口；
- **镜像角色**：动物的本能忠诚对照人类的复杂算计，动物在任务中的简单选择映照人类契约者的真实面目；
- **日常调剂**：动物任务带来轻松、温暖或荒诞的场景节奏，为紧张主线提供缓冲；
- **伏笔工具**：动物异常往往是最早被外界注意到的裂缝，管理局或黑市可以通过动物线索追踪到更大事件。

四种功能在不同任务中可以交替出现，不固定优先级。角色对星契动物的态度本身也可以成为人格观察窗口——如何对待一只不理解自己力量的动物，直接暴露角色的价值观、控制欲和道德底线。

### 5. 任务后安置

依次判断：

- 动物是否仍受命令、药剂或控制结构影响；
- 是否能够通过普通行为训练恢复；
- 原主人是否仍构成威胁；
- 家庭中是否有其他可靠照护者；
- 回到原环境是否安全；
- 是否需要暂时或长期保护性照护。

可能结果包括交由其他家庭成员、暂时寄养、更换环境、长期保护性照护或野生放归。主人犯罪不自动导致动物被处死或永久没收。

## 十八、任务与日常、工作、关系的串联

任务体系不应只提供战斗场景。每项任务都可以产生三种连接：

### 1. 同场连接

人物因报名、专业服务、交通、接送、复盘、训练、吃饭和恢复自然出现在同一空间，不要求全员集合。

### 2. 后果连接

一条任务会改变其他人的排期、工作量、住宿、照护、法律流程、职业压力和私人约定，即使其他人物不知道任务秘密，也会承受现实后果。

### 3. 信息连接

管理局核心业务区、契约者内网协作区与普通社会线可以分别限知运行。角色暂时不相遇，读者仍能通过不同视角看到同一城市异常逐步聚合。

任务结束后应回到：

- 请假、补班与误工；
- 车辆维修和装备归还；
- 医疗、复评和恢复；
- 夜宵、接送和共同生活；
- 风险是否说清；
- 约定是否被打乱；
- 谁照顾谁；
- 谁要求独处、暂停或重新排期。

## 十九、阶段一、二的接入原则

### 阶段一

适合低风险、生活化任务：

- 登记支持；
- 普通训练和安全支持；
- 工作室授权、记录和转介流程；
- 不升级为案件的异常筛查；
- 低风险公开暴露善后；
- 小型星兽观察或普通宠物异常；
- 协查后恢复和补助日常。

不得让这些任务使管理局掌握安若曦酒吧事件，不提前建立温婉—晏林协查，不展开赌场、黑市网络和大型抓捕。

### 阶段二

适合加入：

- 单人精神残留筛查；
- 公共场所能力失控处置；
- 新契约者登记与适应；
- 知情普通人备案；
- 一次低风险民间协查试运行；
- 任务授权撤回或程序争议；
- 星契动物目击、迁移或主人知情案件；
- 协查后恢复和工作回归；
- 管理局内部异常下注材料比对。

新增任务必须与异常下注材料分开，不调用晏林处理赌场方向，不让温婉提前参与正式协查，不锁定赌场、云顶或黑市上层。

### 人物接入原则

本文暂不为安若曦、江岚、苏晚乔、苏璃、唐雨薇逐人分配固定任务。后续按每项任务实际需要，从职业、已登记能力、现实资格、当次意愿、关系回避和安全条件出发临时组队。

五位核心女主可以逐步形成各自的任务经验和交叉合作，但不自动组成固定管理局行动队，也不因私人关系共享全部任务、案件和星表权限。

## 二十、当前确认与待确认

### 已经形成的方向

- 管理局任务类型可以参考《诡秘之主》的地方任务、专业拼队、上报转交和善后结构，但任务更松散、更现代。
- 管理局建设并运营统一的封闭内网，内部按核心业务区、契约者协作区和临时任务房间分层授权。
- 只有经过资格核验的契约者能够取得契约者协作区账号；普通知情人不能进入。
- 契约者协作区具有有组织的论坛、聊天、正式任务系统、自由组队和临时任务房间，不另设脱离管理局的半官方圈层网络。
- 论坛帖子和聊天线索必须经过审核，才能转化为有编号、有权限、有责任归属的正式任务。
- 管理局保留正式案件、权限和高风险处置；个人求助、专业服务与低风险任务可以自由组队。
- 地下匿名网络的正式名称确认为“暗色星辰”，俗称地下网络；黑市是依托暗色星辰与现实产业运行的非法交易生态，不是网络本身。
- 暗色星辰没有总运营者、全网后台、全局账号、全局搜索、统一信誉、统一仲裁、统一货币或统一结算；具体可视化服务各有局部经营者和规则。
- 黑市覆盖情报、非法能力、暴力、人员控制、非法色情产业、毒品与药剂、身份掩护、赌博债务等业务，并以黑吃黑和履约不确定为常态风险。
- 网络路径、服务地址和匿名账号不能直接反查现实身份，但现实履约、付款兑付、场所、人员和参与者副本仍可在多案交叉后闭合责任链。
- 裴家是黑市中的家族化综合产业节点和高频使用者，通过不同服务身份发布任务、购买人员与实验资源、出售药剂；它不拥有面向外部的订单后台。
- 存在星辰通缉、风险协寻、物品追索和异常清理任务。
- 少数动物可以缔结星辰契约；契约不帮助动物开智。
- 星契动物本质中立，危险来自本能误用、环境冲突、星辰异变、药剂催化、非法控制或人类利用。
- 主人可能不知道，也可能知道；知道后可以保护、隐瞒或违法利用。
- 动物不是犯罪共犯，主人、训练者、获利者和控制者按现实证据承担责任。
- 星契动物不提供能力掉落、夺星、血统继承和战力升级。
- 契约者协作区具有有温度的社区调性，不是冷冰冰的派任务系统；管理局内网应有灌水、争论、互助、吐槽并存的日常生态。
- 任务体系预设充分的失败空间，组队冲突、任务落空、报酬纠纷、恢复期均可作为关系和日常戏份的素材。
- 星契动物在叙事中可以承担共情载体、镜像角色、日常调剂和伏笔工具四类情感功能，四种均可使用，不固定优先级。
- 管理局整体体制感为松散的实用主义，流程存在但不僵硬，允许基层灵活处理和无为而治，但违规行为仍会被事后追责。

### 仍需确认的重大机制

1. 管理局契约者内网的正式名称、客户端形态和现实入口；运营主体已经确认为管理局，不再待定。
2. “契约存在凭证”的技术与能力机制，以及临时账号是否成立。
3. 网络前台匿名与后台实名的具体隐私、审计和司法调取边界。
4. 任务风险是否采用 0—4 级，以及各级正式名称。
5. “失控映体”是否成为正式机制与正式术语。
6. 哪些动物具备足够稳定的个体意识与持续意向，是否限定物种范围。
7. “星契动物／星兽／星辰怪物”的正式与俗称关系。
8. 家养星契动物的隐秘档案、主人最低告知和强制处置程序。
9. 星契动物专门照护、寄养和长期保护由哪类机构承接。
10. 阶段一、二具体采用哪些任务，是否需要修改正式阶段页和时间线。

暗色星辰、黑市、裴家—白玥使用链与药剂部署已经完成正式迁移。当前事实只从正式世界观、人物卡和剧情节点读取；白玥只能提供第一次市场任务、后续匿名联系和现实履约的局部材料，不能单独由此证明裴家。
