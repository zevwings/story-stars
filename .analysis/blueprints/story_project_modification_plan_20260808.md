## 一、执行结论

不能按“把诊断中的所有问题一次修完，再开始写正文”执行。那会继续扩大整理工作，却不能验证小说是否成立。

推荐顺序是：

```mermaid
flowchart LR
  A["批次 0｜保护当前工作树"] --> B["批次 1｜开篇真源校正"]
  B --> C["作者确认｜晏林阶段一目标"]
  C --> D["批次 2｜拆分施工并建立开篇队列"]
  D --> E["批次 3｜逐章 outline / draft / review"]
  E --> F["批次 4｜阶段一后半段收口"]
  F --> G["批次 5｜解释权与阶段四五远期债"]
```

本轮计划坚持两条原则：

1. **按最迟修复点处理问题**：只先修会污染开篇的冲突；阶段四问题不阻塞第一章。
2. **冻结扩张，不冻结消费**：暂停新增人物、能力、组织和犯罪产业，但允许修正、拆分、绑定、写章和根据正文合并旧库存。

## 四、作者决策门

## 现在必须决定：晏林的阶段一可见目标

当前 [`context/characters/晏林.md`](../../context/characters/晏林.md) 的主目标和主要阻力仍是“待第一卷大纲确立”。没有这个决定，开篇只能展示职业和设定，不能形成男主主动线。

### 推荐口径

> **阶段一主目标**：晏林想守住工作室与普通生活的独立、可控状态；安若曦事件迫使他在不暴露最高机密能力、不替她决定的前提下中止外来干扰。
> **阶段一主要阻力**：异常事件要求他动用普通业务层不公开的能力；他原先相信个人克制和选择性隐瞒足以保护所有人，却开始发现这会删掉当事人作出选择所需的风险信息。

这比“建立一整套合规梦境辅助制度”更适合作为第一卷目标。工作室流程完善是阶段结果，不先升级成全书事业使命，避免作品进一步向制度程序剧偏移。

### 确认后回写目标

- [`context/characters/晏林.md`](../../context/characters/晏林.md)：当前主目标、主要阻力、阶段行为惯性；
- [`story/synopsis.md`](../../story/synopsis.md)：补入男主主动线，而不改变安若曦案件事实；
- [`story/arcs/阶段一.md`](../../story/arcs/阶段一.md)：把“个人克制不足—流程与必要告知形成”写成阶段结果；
- 不修改晏林的静态出身、能力、长期人格和 BIBLE 红线。

### 逐章生产方式

不要先写完五份细纲再一次性写正文。采用逐章闭环：

1. 为当前一章生成 `outline.md`；
2. 绑定该章命中的 `CON-*`；
3. 使用 `chapter-writer` 生成 `draft.md`；
4. 依次做 reader、editor、consistency 组合审读；
5. 只修当前暴露的问题，再决定下一章分界；
6. 只有作者明确触发“定稿第 X 章”时才调用 `chapter-finalizer`；
7. 定稿后再更新 summary、章节索引、动态状态及 PL/CON 生命周期证据。
