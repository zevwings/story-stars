# 剧情线分析

本目录保存尚未拆清的剧情线场景分析、跨线接口、缺口判断与分章参数，不是正式剧情线，也不承担长期故事事实。

## 放入本目录

- 已有剧情线方向，但场景承载、分章位置或跨线接口仍需分析的内容。
- 为正式剧情节点提供拆分依据、缺口说明或阶段衔接判断的材料。
- 尚未确认、且仍需要结合多条剧情线推演的分章方案。

## 不放入本目录

- 正式变化、状态、前后因果与完成判据；这些内容进入 `story/plotlines/`。
- 已确认的场序、章位、对白议程和具体执行规格；这些内容进入 `story/construction/`。
- 已有明确目标、不同选择后果和最迟决策点的延迟选择；这些内容进入 `story/decisions/`。
- 已经被正式剧情节点或施工单元完整吸收的重复内容。

跨阶段顺序以 `story/arcs/` 和 `story/timeline.md` 为准。分析内容确认后应完成正式路由并从本目录删除，避免形成第二套剧情线真源。
