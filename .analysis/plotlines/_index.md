# 剧情线分析索引

本目录保存尚未拆清的剧情线场景分析、缺口与分章参数，不是真源；其中已经确认的长期事实仍以正式目录为准，确认后的具体执行规格应迁入 `story/construction/`。

正式变化、状态与完成判据以 `story/plotlines/` 为准；跨阶段顺序以 `story/arcs/` 和 `story/timeline.md` 为准。分析内容被正式真源或施工真源吸收后，应从本目录删除，不保留第二入口。
