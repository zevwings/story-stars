# 社会关系协议索引

## 核心协议

1. [社会关系场总纲](社会关系场总纲.md): 判断场景是否成立以及哪些变量需要建模。
2. [关系动员与办事链](关系动员与办事链.md): 从需求、选人、递话到结果和回账。
3. [真人反应链](真人反应链.md): 从察觉、归因、表态到私下调整和二次传播。
4. [拒绝推脱与降格办理](拒绝推脱与降格办理.md): 让拒绝不只剩下同意或翻脸。
5. [人情账与关系余波](人情账与关系余波.md): 记录不对称记账、回报窗口和关系位移。
6. [社会关系场写前写后校验](社会关系场写前写后校验.md): 写前约束与写后诊断。
7. [社会关系设计模板](templates/sociology.md): `chapter-prewrite` 写入 `sociology.md` 时使用的稳定结构。
