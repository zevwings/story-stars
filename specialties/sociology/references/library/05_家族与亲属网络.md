# 家族与亲属网络

## 可拆维度

- 法律亲属、共同生活、经济依赖、照护责任、长幼排序、家族声誉和情感亲近并不总是重合。
- “家里决定”要拆成谁先提议、谁掌握钱或信息、谁负责执行、谁承担坏名声、谁有能力不配合。
- 亲属动员常通过照护、婚丧、探望、介绍和共同记忆发生，不只通过命令。
- 家族压力可以真实存在，但人物仍有顺从、拖延、表面应承、寻找盟友、切断资源或公开退出等不同策略。

## 写作问题

1. 哪位亲属拥有实际资源，哪位只有象征性地位。
2. 谁是家庭内部的翻译者、缓冲者或消息节点。
3. 决定若失败，谁会被归责；这个预期怎样影响当场站位。
4. 家庭说“为你好”时，具体保护的是谁的安全、名誉、财产或秩序。
5. 家庭成员在外人面前和私下是否使用不同口径，差异由什么维持。

## 反模板

不要用“传统家庭”一次解释所有行为。相同辈分在不同经济依赖、居住安排、职业资源和既往冲突下，行动权完全可能不同。
