# 中间人与递话

## 中间人的五种功能

1. **入口**: 让原本无法联系的人获得一次被听见的机会。
2. **翻译**: 把直接请求改成对方能接受、能转交或能拒绝的形式。
3. **担保**: 用自己的信用降低陌生请求的不确定性。
4. **缓冲**: 承担拒绝说明、降格处理和双方留面子的工作。
5. **见证**: 证明谁说过什么、谁只答应到哪一步。

## 常见失真

- 中间人删掉了请求者认为关键、但自己不愿背书的部分。
- 中间人为显示能力，把试探说成承诺，或把普通回复说成特殊照顾。
- 资源方只愿意给中间人一个模糊答复，中间人回传时必须选择解释。
- 多层递话使责任变模糊：每个人都“只是帮问”，却共同制造了压力。
- 请求者越过中间人直接联系资源方，可能被理解为不信任、抢功或切割风险。

## 写作问题

删掉中间人后，链条是否仍能成立？若能，此角色只是传声筒。若不能，明确不可替代的是入口、翻译、担保、缓冲还是见证，并让这一功能产生相应成本。
