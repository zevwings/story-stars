# 数字社交与可见边界

## 渠道改变关系动作

当面、电话、私聊、群聊和公开发布的差异，不只在语气，还在受众、留痕、复制、回复节奏与否认空间。数字平台能维持旧关系、建立新关系，也会让原本分开的亲属、同事、客户和朋友进入同一可见场域。

## 四类边界

- **预期受众**：发送者以为自己在对谁说。
- **实际受众**：当下真正能看见的人，包括群成员和共同账号使用者。
- **可扩散受众**：通过转发、截图、口头复述或搜索后来看到的人。
- **噩梦受众**：人物最怕看到内容的上级、家人、伴侣、客户或对手；它会反过来塑造人物发什么、不发什么。

## 写作抓手

- 公开点赞、私下反对；已读不回、只回表情、另开小群，都是关系动作，但含义要靠后续验证。
- 一个人删除消息，不等于别人没有保存；一个人同意分享自己的事，也不自动替共同出镜或被谈论的人决定可见范围。
- “私聊”不是绝对私密保证。冲突可以来自内容本身，也可以来自谁转发给谁、谁没有被提前告知。
- 平台功能会变化。正文只写故事年代和项目已确认的功能，不把当下产品体验当永久规则。

## 研究入口

- Alice Marwick 与 danah boyd，2011，[Context Collapse and the Imagined Audience](https://doi.org/10.1177/1461444810365313)：用于理解多个受众被压进同一场域以及人物怎样想象受众。
- Alice Marwick 与 danah boyd，2014，[Networked Privacy](https://doi.org/10.1177/1461444814543995)：提醒隐私不只是个人开关，信息流还受网络中他人行为影响。
- Tom McDonald，[Social Media in Rural China](https://uclpress.co.uk/book/social-media-in-rural-china/)；Xinyuan Wang，[Social Media in Industrial China](https://uclpress.co.uk/book/social-media-in-industrial-china/)：分别提供乡村与工厂城的长期田野观察，能防止把单一都市白领平台经验冒充“中国数字社交”。

前两项不是中国专门研究，只提供通用机制；后两项也不能覆盖所有地区、阶层与代际。
