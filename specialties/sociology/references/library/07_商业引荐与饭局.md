# 商业引荐与饭局

## 引荐的边界

引荐至少分为转发联系方式、允许同桌、表达愿意听、提供可信背书、参与谈判和承担履约责任。正文必须写清引荐者做到哪一层，避免“一顿饭谈成合作”的结果跳跃。

## 饭局作为场景容器

饭局可以同时承载信息试探、位置排序、公开认可、私下补充、观察随行人员、确认谁为谁买单和给出下一次会面入口。它不是自动生效的关系仪式。

## 可观察细节

- 邀请由谁发出，名单由谁决定，谁迟到或提前离场。
- 正题在桌上、走廊、送客、车上还是次日书面渠道才出现。
- 谁替谁介绍身份，介绍词突出能力、关系还是共同经历。
- 买单、回请和伴手礼是否与交易结果绑定，人物如何理解这种绑定。
- 会后谁主动发材料、建立群聊、安排下一位执行者或保持沉默。

## 反模板

不要把饮酒能力、圆滑话术或座次知识写成商业成功的充分条件。真正的合作仍需要需求匹配、决策权、资源、风险和执行闭环。
