# CLO-ACCESSORY-00403 黑色立体蝴蝶结发夹

## 分类

| 字段 | 值 |
| --- | --- |
| 单件类型 | accessory |
| 搭配方式 | standalone |
| 主要用途 | daily |


## 搭配要求

### 可选角色

- **发型**：半扎发、高马尾或侧边发夹固定。
- **服装**：黑白运动装或日常复古小裙装。

### 约束

- 弹簧鸭嘴夹需防咬发扯发；
- 蝴蝶结布料需防压扁折痕。

## 来源与边界

- **画面确认**：纯黑色立体蝴蝶结弹簧发夹。对称双翼微挺括，蝴蝶结中央配收腰结扣，饰于后脑半扎发处，黑色与深棕发色自然融合。
- **文档明示**：来源记录为黑色立体蝴蝶结发夹；无五金镀层说明。
- **不确定观察**：金属夹芯材质推定为防锈合金弹簧夹。
- **项目设计与边界**：作为经典黑色蝴蝶结发饰单件维护。项目适配判断。

## 结构与使用

档案类型为 `piece`，服装大类为 `accessory`，具体类型为黑色立体蝴蝶结发夹。主导色为纯黑色。

双层厚缎带折叠粘合定型，底部铆接金属弹簧鸭嘴发夹。

按压开合夹持头发，干燥保存。

## 使用条件与叙事作用

适用季节为四季。主审美为甜美俏皮、法式优雅、减龄发饰。点缀于发间，增添头顶高度与面部折叠度，散发甜而不腻的少女气质。
