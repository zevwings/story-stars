# CLO-ACCESSORY-00411 浅色毛绒猫耳发夹

## 分类

| 字段 | 值 |
| --- | --- |
| 单件类型 | accessory |
| 搭配方式 | standalone |
| 主要用途 | daily |

## 搭配要求

### 可选角色

- **发型**：马尾、丸子头或披发随性点缀；居家与运动皆宜。

### 约束

- 鸭嘴夹弹力有限，夹发量过多易滑脱；
- 毛绒材质需防沾水弄湿变形。

## 来源与边界

- **画面确认**：头顶佩戴的浅米粉色仿兔毛猫耳朵造型发夹，立式三角猫耳轮廓毛茸茸，由隐形发夹固定于发间。
- **文档明示**：来源记录为浅色毛绒猫耳发夹；无毛绒材质检测证明。
- **不确定观察**：发夹底座材质为合金或树脂包胶未有特写。
- **项目设计与边界**：作为俏皮猫耳毛绒发饰单件维护。项目适配判断。

## 结构与使用

档案类型为 `piece`，服装大类为 `accessory`，具体类型为浅色毛绒猫耳发夹。主导色为浅米粉色。

立体剪裁毛绒猫耳附着于金属弹簧发夹上，轻轻捏开即可夹入发丝。

手工佩戴，避免水洗，脏污用干布轻拭。

## 使用条件与叙事作用

适用季节为四季日常。主审美为俏皮可爱、萌系减龄、甜美点缀。灵动的毛绒猫耳为严肃的器械运动平添趣味与娇憨少女感。
