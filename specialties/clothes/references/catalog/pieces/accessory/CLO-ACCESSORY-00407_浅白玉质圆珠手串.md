# CLO-ACCESSORY-00407 浅白玉质圆珠手串

## 分类

| 字段 | 值 |
| --- | --- |
| 单件类型 | accessory |
| 搭配方式 | standalone |
| 主要用途 | daily |

## 搭配要求

### 可选角色

- **腕间**：单圈佩戴于左手手腕。
- **衣装**：日常居家服、瑜伽运动连体服或禅意茶服。

### 约束

- 天然矿物/玉石材质需防剧烈撞击与硬物磕碰；
- 高强度剧烈运动中需注意防止弹力绳勾扯断裂。

## 来源与边界

- **画面确认**：单圈浅白色天然玉石/玛瑙圆珠手串。颗颗珠粒圆润饱满，微带天然温润光泽与半透质感，佩戴于左手腕部，极简素雅。
- **文档明示**：来源记录为浅白玉质圆珠手串；无宝玉石鉴定证书。
- **不确定观察**：珠子直径推定约为8mm-10mm，串绳材质推定为透明高弹水晶线。
- **项目设计与边界**：作为素雅单圈玉珠手串单件维护。项目适配判断。

## 结构与使用

档案类型为 `piece`，服装大类为 `accessory`，具体类型为浅白玉质圆珠手串。主导色为温润羊脂白/青白玉色。

精磨圆珠打孔以弹力水晶线串接成环，珠体抛光细腻，滑润贴手。

直接套入腕间佩戴，避开强酸碱洗涤剂，软布擦拭保养。

## 使用条件与叙事作用

适用季节为四季。主审美为温润内敛、古典雅致、素雅点缀。皓白如凝脂的玉珠贴于纤细雪腕，在动静之间折射出东方女子含蓄温婉的清雅灵韵。
