# CLO-ACCESSORY-00409 细银链水滴小吊坠项链

## 分类

| 字段 | 值 |
| --- | --- |
| 单件类型 | accessory |
| 搭配方式 | standalone |
| 主要用途 | daily |

## 搭配要求

### 可选角色

- **颈间**：自然垂落于胸前锁骨窝正中。
- **衣着**：低胸吊带衫、一字领上衣或深V礼服。

### 约束

- 超细十字链身易打结，收纳需悬挂或单独装盒；
- 后颈龙虾扣较小，佩戴需耐心扣合。

## 来源与边界

- **画面确认**：纤细亮银色锁骨项链。细环链身自然垂坠于锁骨凹陷正中，悬挂一颗小巧精致的水滴形银质小坠饰，随呼吸与动作轻微摇曳。
- **文档明示**：来源记录为细银链水滴小吊坠项链；无金属质检证书。
- **不确定观察**：坠饰内部是否镶嵌微型合成立方氧化锆未见微距细节。
- **项目设计与边界**：作为点睛锁骨链单件维护。项目适配判断。

## 结构与使用

档案类型为 `piece`，服装大类为 `accessory`，具体类型为细银链水滴小吊坠项链。主导色为高光亮银色。

约40cm+5cm延长链结构，尾端为微型弹簧扣/龙虾扣，水滴形光面坠饰约6mm*4mm。

解开后颈扣佩戴，避免接触香水与汗水，软布轻拭保养。

## 使用条件与叙事作用

适用季节为四季。主审美为精巧纤细、锁骨点睛、清冷灵动。一抹冷银水滴栖息在温润前胸，呼吸微颤间微光摇曳，成为引诱视线流连的绝妙视觉锚点。
