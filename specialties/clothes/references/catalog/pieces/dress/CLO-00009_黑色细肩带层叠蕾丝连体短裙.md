# CLO-00009 黑色细肩带层叠蕾丝连体短裙

## 分类

| 字段 | 值 |
| --- | --- |
| 单件类型 | dress |
| 搭配方式 | standalone |
| 主要用途 | daily |
| 兼容用途 | stage、intimate |

## 搭配要求

### 可选角色

- **鞋履**：黑色极简细带中跟鞋、尖头细高跟、黑色短靴或玛丽珍鞋
- **外搭**：修身西装短外套、机车皮衣、针织开衫或防风长风衣
- **配饰**：暖金/冷银微型耳饰与极细项链

### 约束

- 本身内置半杯模杯与防走光内衬，**无需且不建议额外内穿肩带胸衣**，以免破坏肩颈平整线条；
- 裙摆为轻蓬层叠蕾丝，外搭外套时建议选择齐腰短款或宽松长款，避免中长紧身外套压坏下摆蕾丝蓬度。

## 来源与边界

**直接可见与正式事实**：有隐藏支撑的黑色细肩带连体短裙，上身贴身收束，裙摆以两至三层软蕾丝形成短促微蓬动态；腰间带少量暖金微饰；俞予安保留自然黑发与偏锐利水红夜装妆面。
**不确定观察**：面料推断为高密锦氨高弹缎布与法式睫毛软蕾丝拼接，透气性与回弹性良好；具体蕾丝编织支数未行检测。
**项目设计与边界**：本单品作为可独立复用的经典甜辣连体短裙收录，可单穿亦可自由搭配各色外套；不增加项圈、硬束腰或过多金属链饰，不替代俞予安本人的正式衣柜资产与当次自愿决定。

## 结构与使用

**款式与廓形**：
**上身胸衣式剪裁**：细肩带抹胸结构，前胸平直内收，紧致贴合胸腰起伏，大面积释放直角肩、深锁骨与上胸线条。
**高腰收窄与短促蓬摆**：高腰线位置收紧，下摆自然接续 2-3 层不规则剪裁的轻软法式蕾丝微蓬短摆（裙长至大腿上 1/3），动态轻盈。
**色彩分布与材质质感**：
**主导色组**：玄黑（主体缎布与层叠蕾丝）、暖金（腰侧微型搭扣）、白皙肤色（肩背、锁骨与大面积裸腿）。
**材质触感**：裙身表面带有法式蕾丝细腻致密的微凹凸浮雕手感，内衬光滑贴肤；模杯鱼骨提供平整贴身的微压塑形感；手掌抚摸腰线与裙侧时有扎实的收束与回弹。
**固定工学、穿脱与防失效**：
**无内衣支撑与防滑**：胸部内置轻薄半杯模杯与侧缝 2 根树脂软鱼骨，无需额外穿内衣；领口上缘内折防滑软胶，前倾俯身不空杯、不移位。
**细肩带可调工法**：双层高弹黑缎扁带配后背金属微调扣，贴合肩部不滑落、不勒肉。
**一体化防走光**：裙内一体化拼接高弹纯棉平角打底短裤，坐下、转身或走动时安全自足。
**声响设计**：
转身或走动时，多层轻软蕾丝短摆发出极其细微的“沙沙”拂动声。
**动作限制**：
适合站立展示、私人约会、踱步与静态摄影；坐下前需顺势压平层叠裙摆。

## 使用条件与叙事作用

**适用场景**：高档都市夜间约会、私人聚会、现代风格展示或特定剧情授权的亲密互动。
**环境条件**：室内恒温、整洁且环境高档的私密或半私密空间。
**叙事功能**：
展现人物清冷利落之下的现代甜辣魅力，纯粹依靠精良剪裁与身体线条主导张力；
突出高挑挺拔的直角肩与优越腰腿比。
**排除项**：不作为正式商务装；不绑定角色扮演或从属道具。

## 张力与互动语法

**核心张力**：细肩带极简露肤与多层蕾丝短摆的轻颤动态，与穿着者清冷锐利的五官神态之间的甜辣反差。
**主导互动路径（身姿展示 $\rightarrow$ 隔料抚摸）**：
*第一阶段（身姿与肩线展示）*：轻抚整理细肩带、扶正高腰线，侧身展现直角肩与锁骨线条。
*第二阶段（隔料抚摸）*：手掌顺着裸露肩背滑至高腰线与层叠蕾丝裙侧，进行轻柔轮廓抚摸，感受蕾丝浮雕纹理与腰身收束回弹。
*第三阶段（坐下与自然复位）*：入座前轻抚压平层叠裙摆，衣物保持完整复位，无位移、无松脱。
**损耗与破坏控制**：严禁暴力拉扯蕾丝花边或扯断细肩带；整套衣物具备良好弹力与抗皱性，互动后完好复位。
**克制边界**：甜辣感来自蕾丝纹理、极细肩带与高腰短摆比例，坚决不增加项圈、硬束腰或过多金属链饰。
