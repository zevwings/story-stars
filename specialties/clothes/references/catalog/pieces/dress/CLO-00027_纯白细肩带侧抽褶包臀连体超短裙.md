# CLO-00027 纯白细肩带侧抽褶包臀连体超短裙

## 分类

| 字段 | 值 |
| --- | --- |
| 单件类型 | dress |
| 搭配方式 | standalone |
| 主要用途 | intimate |
| 兼容用途 | stage |

## 搭配要求

### 可选角色

- **袜类**：纯白过膝袜、浅色丝袜或完整裸腿；一次造型只选择一种腿部层。
- **鞋履**：白色、银白或接近肤色的简洁低体量鞋履。
- **外层**：公共移动时使用能够完整遮覆裙摆的普通外套。

### 约束

- 极细肩带只稳定上沿，不单独承担胸部重量；软杯、胸下承托带、侧面支撑与正确尺码共同维持合体。
- 侧抽绳只调节短距离褶量并在穿着前锁定，不作为牵拉身体或控制穿着者的道具。

## 来源与边界

- **设计来源**：既有纯白细肩带侧抽褶贴身短裙视觉方案；本档保留该单件自身可复用的轮廓与结构。
- **结构确认**：主体为纯白细肩带贴身连衣超短裙，采用浅弧领口、连续腰臀收束、单侧短距离抽褶与腿侧短系带。
- **不确定观察**：鞋履、后背闭合、真实面料、精确骨条数量和隐藏内层没有完整物证，不写成来源事实。
- **项目候选规格**：可按具体穿着者补全薄型软杯、胸下承托、侧面软支撑、隐藏闭合与完全隐藏的安全短层；裙长和抽绳长度须通过落座与行走验证。

## 结构与使用

- **款式与廓形**：一体式贴身包臀连衣超短裙；极细双肩带配浅 U／柔和方圆领，上身经胸省容纳体量，胸下回收到自然腰线，再沿臀线收束至大腿上段。
- **抽褶结构**：一侧侧缝设置短距离抽褶，形成两至三道柔和横褶；局部褶量只改变裙口弧度，不扩展为满幅横向抽褶。
- **色彩与材质**：主体为低反光纯白，外层保持平整、不透底；实际纤维成分未判定，以柔软、回弹和长时贴身不过度勒压为选材条件。
- **固定与穿脱**：肩带可微调，胸下结构和侧面支撑共同防止上沿下滑；通过侧拉链或背部隐形拉链穿脱，侧抽绳在穿着前调节并锁定。
- **动作条件**：落座前整理裙摆，起身后复核侧抽绳和裙口位置；适合室内短距离走动、落座与普通站立，不用于奔跑或大幅动作。

## 使用条件与叙事作用

- **适用季节与环境**：春、夏、秋的恒温室内或有完整外层遮覆的短距离公共移动。
- **主要审美**：纯白极简、贴身成熟；局部侧抽褶提供轻微不对称动态。
- **叙事作用**：白色细肩带、连续胸腰臀轮廓和单侧褶量共同建立简洁的私域夜装识别，同时保留真实承托、隐藏安全层和可控抽绳。
- **排除项**：不作为学生制服、寒冷户外装或高强度行动装；本参考不自动建立人物持有、稳定偏好、穿着经历或当次授权。

## 张力与互动语法

- **核心张力与材质反馈**：低反光纯白表面保持干净克制，柔软回弹的贴身主体沿成年胸腰臀形成连续轮廓，局部抽褶提供可见但不过量的结构变化。
- **主导互动路径**：穿着者自行确认肩带与胸下承托，顺平腰侧和侧抽褶，最后整理裙摆；衣物只发生可复位的轻微位移。
- **衣物结果**：默认保持完整，不以撕裂、断带、抽绳牵拉或承托失效实现张力。
