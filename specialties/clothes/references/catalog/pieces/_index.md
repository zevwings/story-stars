# 基础衣装单元分类索引

> **单件库分类与建库规范**：详见 [README.md](./README.md)。

本页只导航到下一级分类索引；具体衣装条目及检索摘要由各分类 `_index.md` 维护。

| 分类 | 收录范围 | 入口 |

| 内衣与贴体连体衣（bodysuit） | 内衣、塑身衣、贴体连体衣及原生配套内衣 | [分类索引](./bodysuit/_index.md) |
