# CLO-00026 纯白极简低帮帆布鞋

## 分类

| 字段 | 值 |
| --- | --- |
| 单件类型 | footwear |
| 搭配方式 | standalone |
| 主要用途 | daily |
| 兼容用途 | stage、intimate |

## 搭配要求

### 可选角色

- **服装**：纯白法式方领立体收腰压褶连体短裙、纯白细吊带花苞短裙、牛仔超短裙、休闲长裤或百褶裙
- **袜类**：纯白中筒袜、短袜、隐形船袜或裸足

### 约束

- 经典平底低帮帆布鞋，脚踝完全裸露；适合平整室内外硬质地面。

## 来源与边界

- **直接可见与正式事实**：纯白极简低帮帆布鞋，白色 12 盎司全棉帆布鞋面，纯白圆头橡胶包头，白色扁平棉质鞋带，平底硫化橡胶耐磨大底；极简无花哨印花或大标。
- **不确定观察**：面料推断为全棉重磅透气帆布，大底为天然生胶硫化底，内垫为 Ortholite 缓震鞋垫；具体耐折度未行检测。
- **项目设计与边界**：本单品作为全项目通用、高复用度的经典纯白低帮平底帆布鞋收录，专用于构建干净、随性、轻盈自如的现代日常与私域造型；不替代童颜本人的正式衣柜资产与当次自愿决定。

## 结构与使用

- **款式与廓形**：
  - **低帮浅口平底剪裁**：鞋领高度在脚踝骨下方截断，完全释放脚踝纤细线条；
  - **经典圆头包头**：纯白压纹橡胶鞋头，防踢耐磨；配 6 孔纯白铝合金气眼与全棉扁鞋带。
- **色彩分布与材质质感**：
  - **主导色组**：纯白／米白（帆布鞋面、橡胶围条与大底）。
  - **材质触感**：全棉帆布表面带清晰棉织斜纹，质朴干爽；橡胶大底柔韧有弹性。
- **固定工学、穿脱与防失效**：
  - **舒适减震与静音**：前掌内嵌 5mm 高弹乳胶鞋垫，硫化华夫格纹橡胶大底，行走轻盈静音、防滑抓地力强；
  - **防磨脚后跟**：后帮内衬双层纯棉软帆布，久穿不磨脚跟。
- **动作限制**：
  - 行走、慢跑、跳跃、坐立完全自由无拘束。

## 使用条件与叙事作用

- **适用场景**：日常通勤、夏日漫步、校园生活、休闲聚会或特定剧情授权的私人互动。
- **环境条件**：室内外均可适用。
- **叙事功能**：
  - 提供轻快、干净、不设防的日常生活感，与高跟鞋的严谨凌厉形成截然不同的亲近与随性氛围；
  - 纯平底设计凸显真实的身体重心与稳健步伐。
- **排除项**：不作为严肃正式晚宴鞋或专业登山鞋。

## 张力与互动语法

- **核心张力**：纯白帆布鞋所承载的质朴、轻快与真实生活感，与人物成熟身体曲线之间的自然交融。
- **主导互动路径（轻快踱步 $\rightarrow$ 脱鞋踩地）**：
  1. *步态展示*：轻快踱步，帆布鞋在地面发出轻柔干脆的踏地声。
  2. *脱鞋入座*：松开鞋带褪下帆布鞋，白袜包裹的足底自然踩在地毯或床沿。
  3. *衣物复位*：一秒踩入鞋内系好鞋带，复位自如。
- **损耗与破坏控制**：硫化橡胶与重磅帆布耐磨结实，正常使用无损耗。
