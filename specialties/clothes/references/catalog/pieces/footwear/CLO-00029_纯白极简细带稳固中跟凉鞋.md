# CLO-00029 纯白极简细带稳固中跟凉鞋

## 分类

| 字段 | 值 |
| --- | --- |
| 单件类型 | footwear |
| 搭配方式 | standalone |
| 主要用途 | intimate |
| 兼容用途 | daily、stage |

## 搭配要求

### 可选角色

- **服装**：细肩带胸下分割收腰微伞连体短裙（CLO-00030，童颜采用纯白色版）、简洁素色吊带短裙或低饱和度连衣裙
- **袜类**：纯白窄幅蕾丝边自持大腿丝袜（CLO-00031，童颜场景版固定）或裸足

### 约束

- 仅用于平整的室内硬质地面或短毛地毯；不用于长距离步行、快跑、石子路或湿滑路面。
- 细带不得引入学生鞋、制式鞋或低龄化装饰语义。

## 来源与边界

- **已确认的正式事实**：CON-0010 原先只限定白色、银白或接近肤色的简洁低体量鞋履；作者现确认童颜该场完整造型固定使用纯白细带稳固中跟凉鞋。
- **项目设计补全**：双细带鞋面、可调脚踝带、柔和方圆鞋头和约 4.5cm 稳固方跟，是为会所走廊移动、室内落座与场后独立离开补全的可执行结构，不伪装成外部素材观察。
- **自身识别**：露趾双细带鞋面、可调脚踝带、柔和方圆鞋头与约 4.5cm 稳固方跟共同构成该鞋履的结构身份。

## 结构与使用

- **鞋面与鞋头**：前掌两道低光泽纯白细带留出足背，柔和方圆鞋头保留足趾活动空间，不使用水钻、金属链或醒目品牌标识。
- **固定方式**：细脚踝带以小型可调扣闭合，鞋带内侧加柔软衬层，不以紧勒痕迹制造视觉效果。
- **跟型与重心**：约 4.5cm 低重心方形中跟，跟面大于细跟，支持普通站立、走廊慢行、落座和起身。
- **防滑与缓冲**：前掌薄型缓冲垫配细纹防滑橡胶大底，减少室内硬地打滑与高频尖锐踏地声。

## 使用条件与叙事作用

- **适用场景**：会所私域会面、室内夜场造型或需要简洁浅色鞋履的约会。
- **叙事功能**：与纯白裙和白色微透蕾丝边丝袜构成连续浅色系，不用黑鞋截断腿部线条；稳固中跟保留成年夜场造型的挺拔感，又不把童颜写成无法自行移动。
- **排除项**：不作为运动鞋、长途通勤鞋、学生制式鞋或身份标记。

## 张力与互动语法

- **核心张力**：纯白细带与微透蕾丝边丝袜形成同色呼应，裸露的足背和中跟带来的轻微足弓则保留成年造型的利落感。
- **主导交互路径**：稳定慢行 → 自行解开脚踝扣落座 → 重新扣合后独立起身离开。
- **边界**：细带只负责鞋履固定，不作为捆绑、牵引或替代人物选择的道具。
