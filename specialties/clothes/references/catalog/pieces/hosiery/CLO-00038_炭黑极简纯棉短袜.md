# CLO-00038 炭黑极简纯棉短袜

## 分类

| 字段 | 值 |
| --- | --- |
| 单件类型 | hosiery |
| 搭配方式 | standalone |
| 主要用途 | daily |
| 兼容用途 | stage、intimate |

## 搭配要求

### 可选角色

- **服装**：灰黑做旧牛仔短胸衣与短裤套、运动短裤、牛仔短裙、工装裤或各类辣妹/机车日常街头穿搭
- **鞋履**：低帮板鞋、复古滑板鞋、老爹鞋、机车短靴或帆布鞋

### 约束

- 经典及踝短袜（Ankle / Quarter Length），袜口刚好包裹脚踝骨上方 2~3cm；纯棉微弹透气，久穿不卷边、无深勒痕。

## 来源与边界

**直接可见与正式事实**：炭黑不过踝中短棉袜，袜口为 1.5cm 细罗纹无痕收口；袜身贴合足部与脚踝曲线，完全露出修长匀称的小腿与大腿裸肤。
**不确定观察**：面料推断为 50 支精梳棉复合氨纶高弹包覆纱，吸湿排汗抗起球；具体耐磨度未行检测。
**项目设计与边界**：本单品作为全项目通用、高复用度的极简炭黑短袜收录，专用于构建冷硬、随性、街头辣妹与运动下肢造型；不替代任何角色的正式衣柜资产与当次自愿决定。

## 结构与使用

**款式与廓形**：
**及踝短款剪裁**：袜口高度精准收止在脚踝骨上方 2~3cm，利落干脆，完全释放小腿肌肉与跟腱线条；
**立体 Y 型跟与无感缝头**：后跟立体包裹不掉跟，脚尖手工对目缝合无硬梗摩擦。
**色彩分布与材质质感**：
**主导色组**：炭黑（袜身）、白皙温热肤色（脚踝上方大面积裸腿）。
**材质触感**：精梳棉干爽柔软、亲肤透气；脚踝包裹紧致舒适。
**固定工学、穿脱与防失效**：
**防滑防掉跟**：袜口高弹罗纹与足弓微压收束带紧密贴合，行走与运动时不向鞋内下滑脱落。
**动作限制**：
穿着自如，完全适应各种户外活动、走动与私密互动。

## 使用条件与叙事作用

**适用场景**：街头辣妹风格展示、现代都市休闲、私域互动或时尚摄影。
**环境条件**：室内外均可适用。
**叙事功能**：
强化利落、随性、微攻击性的机车辣妹下肢线条，与板鞋组合呈现纯粹健康的大面积裸腿视觉；
消除高跟鞋与丝袜的束缚感，带来完全自主的行动力。
**排除项**：不作为正式礼服配袜。

## 张力与互动语法

**核心张力**：炭黑短袜的干爽紧致与脚踝骨感线条，与向上大面积延伸的白皙温热修长裸腿之间的运动与肉感张力。
**主导互动路径（从容迈步 $\rightarrow$ 脱鞋踩地）**：
*步态展示*：踏着板鞋从容走动，展现紧致修长的小腿与大腿肌肉线条。
*脱鞋互动*：单手踩掉板鞋，炭黑短袜包裹着纤细足弓踩在地面或沙发上。
*衣物复位*：重新踩入鞋内一秒穿好。
**损耗与破坏控制**：精梳棉耐磨抗拉，正常穿戴无损耗。
