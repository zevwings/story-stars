# CLO-00028 纯白防滑过膝袜

## 分类

| 字段 | 值 |
| --- | --- |
| 单件类型 | hosiery |
| 搭配方式 | standalone |
| 主要用途 | intimate |
| 兼容用途 | stage、cos |

## 搭配要求

### 可选角色

- **裙装**：纯白或低对比短裙、简洁主题短裙，以及能够在裙口与袜口之间保留明确肌肤区间的造型。
- **鞋履**：白色、银白、肤色或其它低对比简洁鞋履。

### 约束

- 袜口稳定停在膝上至大腿下段，不得下滑成及膝袜，也不与裙摆直接相接。
- 不与校徽、学生鞋、制式领结、学校姓名牌或完整校服系统组合；纯白过膝结构本身不定义年龄、身份或授权。

## 来源与边界

- **设计来源**：既有纯白过膝袜视觉方案；本档只保留该袜装自身的可复用结构与使用规格。
- **结构确认**：纯白长袜完整覆盖小腿和膝部，袜口延伸至大腿下段；外观无条纹、徽记、蝴蝶结、字样或撞色滚边。
- **不确定观察**：真实纤维成分、精确厚度、袜口内侧结构和鞋内处理没有实物证据，不写成来源事实。
- **项目候选规格**：采用不透明至微透的纯白弹力袜身、低体量无装饰自持袜口和平整袜头；具体尺码按穿着者腿围确定。

## 结构与使用

- **长度与覆盖**：袜口停在大腿下段，完整覆盖小腿、膝部与膝上区域；上方保留连续肌肤区间。
- **色彩与表面**：全袜纯白，表面保持低至中等光泽，不使用强反光涂层。
- **固定与穿脱**：弹力袜身配宽度适中的自持袜口，均匀分散压力；由脚尖向上逐段理顺，不扭转袜身或一次猛拉袜口。
- **动作条件**：适合恒温室内站立、落座与短距离行走；起身后复核袜口高度，出现卷边、下滑或局部麻木时停止继续穿着。

## 使用条件与叙事作用

- **适用季节与环境**：春、秋及夏季恒温室内；不用于炎热户外、雨水环境、粗糙路面或长距离步行。
- **主要审美**：纯白连续、干净贴合；裙口、裸露大腿与袜口形成清楚的分段比例。
- **叙事作用**：为浅色短裙造型补足稳定的腿部层与同色连续性，视觉焦点落在平整袜身和袜口上方的肌肤边界。
- **排除项**：不作为保暖袜、运动袜或学生制服附件；本参考不自动建立人物持有、稳定偏好、穿着经历或当次授权。

## 张力与互动语法

- **核心张力与材质反馈**：弹力袜身以平整、轻微回弹的触感包覆腿部，袜口上方保留清楚的肌肤边界。
- **主导互动路径**：由穿着者从脚尖向上逐段理顺袜身，最后校正袜口高度；后续只允许沿袜面轻抚或重新整理。
- **衣物结果**：默认保持完整并可复位；不设置撕裂、剪开、捆绑或一次性报废路径。
