# CLO-00025 纯白中筒袜

## 分类

| 字段 | 值 |
| --- | --- |
| 单件类型 | hosiery |
| 搭配方式 | standalone |
| 主要用途 | daily |
| 兼容用途 | stage、intimate |

## 搭配要求

### 可选角色

- **服装**：纯白法式方领立体收腰压褶连体短裙、纯白细吊带花苞短裙、牛仔短裙、百褶短裙或运动短裤
- **鞋履**：纯白极简低帮帆布鞋、厚底小白鞋、复古慢跑鞋或平底玛丽珍鞋

### 约束

- 袜筒高度收止在小腿肚上方（小腿中上段，**严格不盖过膝盖**）；纯棉透气微弹，久穿不勒肉、无深勒痕。

## 来源与边界

- **直接可见与正式事实**：纯白不过膝中筒棉袜，袜高至小腿肚上方，袜口为 2cm 宽幅微弹无痕罗纹；袜身平整贴合小腿肌肉起伏，足跟立体 Y 型织造；露出完整膝部与大腿肌肤；不添加任何条纹、刺绣、卡通图标或制服符号。
- **不确定观察**：面料推断为 60 支新疆长绒精梳棉复合氨纶包覆纱，吸湿透气且具备良好弹性回复率；具体克重未行检测。
- **项目设计与边界**：本单品作为全项目通用、高复用度的现代纯白不过膝中筒袜收录，专用于构建干净、清爽、自然的现代日常与私域下肢造型；不使用校服配饰，不替代童颜本人的正式衣柜资产与当次自愿决定。

## 结构与使用

- **款式与廓形**：
  - **不过膝中筒版型（Crew / Mid-Calf Length）**：袜筒平整向上延伸至小腿肚最饱满处上方约 2cm 处直接收止（总筒高约 18~20cm），与膝盖下缘保持 5~8cm 净距，完整露出光洁膝盖；
  - **立体贴合织造**：足跟采用立体 Y 型大圆角织法，脚尖平缝无硬骨摩擦，脚背与小腿平整无堆褶。
- **色彩分布与材质质感**：
  - **主导色组**：纯白／漂白（纯净明亮全白）、白皙温热肤色（裸露的膝盖与大腿）。
  - **材质触感**：精梳棉触感干爽柔软、亲肤透气；小腿包裹轻弹舒适。
- **固定工学、穿脱与防失效**：
  - **2cm 无痕微弹罗纹袜口**：采用双层高弹莱卡氨纶罗纹编织，压力均匀分散，大幅走动、屈膝或漫步时不向下卷边下滑，脱下无明显勒痕。
- **动作限制**：
  - 穿着极其舒适，行走、跑步、入座与屈膝完全自如。

## 使用条件与叙事作用

- **适用场景**：日常通勤、夏日漫步、现代清爽私域展示或特定剧情授权的私人互动。
- **环境条件**：室内外均可适用。
- **叙事功能**：
  - 打造干净、纯粹、自然的现代青年清爽感，与短裙摆之间留出修长匀称的裸腿空间；
  - 严格不过膝的规制彻底排除学生过膝袜符号。
- **排除项**：不作为正式商务袜或过膝防寒袜。

## 张力与互动语法

- **核心张力**：纯白棉袜的干爽素净与小腿利落线条，与袜口上方完全裸露的光洁温热膝盖之间的视觉反差。
- **主导互动路径（端正坐姿 $\rightarrow$ 隔袜轻抚）**：
  1. *身姿展示*：双腿并拢入座，展现不过膝白袜贴合的小腿轮廓与光洁膝盖。
  2. *隔袜轻抚*：手掌抚过光洁膝部滑至白袜罗纹口与脚踝，感受纯棉织物的柔软干爽。
  3. *衣物复位*：轻拉袜口，平整贴合如初。
- **损耗与破坏控制**：精梳棉耐磨抗起球，正常穿洗无损耗。
