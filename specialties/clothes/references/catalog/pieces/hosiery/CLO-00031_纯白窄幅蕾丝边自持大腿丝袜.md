# CLO-00031 纯白窄幅蕾丝边自持大腿丝袜

## 分类

| 字段 | 值 |
| --- | --- |
| 单件类型 | hosiery |
| 搭配方式 | standalone |
| 主要用途 | intimate |
| 兼容用途 | stage、daily |

## 搭配要求

### 可选角色

- **服装**：纯白或低饱和浅色连衣短裙，尤其适合平整微伞摆、低装饰贴身裙与简洁吊带裙。
- **鞋履**：纯白极简细带凉鞋、低体量浅口鞋或其他不遮挡袜身线条的成年化鞋履。

### 约束

- 袜口依靠内侧防滑条自持，不与吊袜带同时使用；若场景另需吊袜带，应改用兼容款而不是破坏本单品结构。
- 不叠加蝴蝶结、条纹、校徽、学生鞋、制式裙或其他低龄化符号。
- 搭配露趾凉鞋时采用无明显加固拼色的 sandal-toe 袜头，趾缝必须平整，不在鞋带下形成压点。

## 来源与边界

- **设计来源**：依据作者提出的“白色蕾丝边丝袜”方向，为童颜的纯白私域造型建立可复用单件；没有外部图片或商品实物作为观察证据。
- **项目设计规格**：纯白／柔白微透袜身、约 15–20D 视觉厚度、4–5cm 同色低装饰哑光花纹蕾丝袜口、内侧柔软防滑条、自持式大腿袜长度及 sandal-toe 袜头，均为项目候选设计，不伪装成外部事实。
- **自身识别**：微透纯白袜身、窄幅低装饰蕾丝袜口和自持式大腿高度共同构成该袜装的核心结构。

## 结构与使用

- **袜身**：纯白／柔白微透均匀袜身，视觉厚度约 15–20D；表面低光泽，不使用亮片、竖向装饰线或撞色拼接。
- **袜口**：4–5cm 同色哑光花纹蕾丝带，图案密度克制，内侧设置柔软防滑条；袜口停在大腿上段，并根据穿着者腿围选择真实尺码。
- **袜头与缝线**：sandal-toe 结构，不设置明显深色加固区；趾部缝线避开露趾凉鞋前掌细带的主要受力点。
- **活动边界**：支持室内慢行、站立、落座和起身；若袜口卷边、下滑、麻木或留下持续压痕，应立即调整、更换尺码或停止穿着。

## 使用条件与叙事作用

- **适用场景**：恒温私域、室内夜场造型、舞台造型或经人物主动选择的浅色约会搭配。
- **叙事功能**：微透袜身延续浅色腿部线条，窄幅蕾丝在裙摆与袜口之间建立明确的成年私域细节；欲感来自材质层次和露肤间隔，不借用校服或幼态符号。
- **排除项**：不作为运动袜、保暖袜、学生制服附件或寒冷户外长时穿着用品。

## 张力与互动语法

- **核心张力**：纯白微透袜身贴近皮肤，窄幅蕾丝袜口提供克制而清楚的私域识别点。
- **主导互动路径**：穿着者由足尖向上均匀提拉袜身，展开蕾丝袜口并检查防滑条，再在起身或走动后自行校正高度与平整度。
- **边界**：袜口不用于牵拉、束缚或代替人物授权；衣物默认完整、可调整、可随时脱下或更换。
