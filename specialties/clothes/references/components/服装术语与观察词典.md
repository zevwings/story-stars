# Story Stars 服装术语与观察词典

本词典保存项目衣装档案反复使用的中文主词、观察口径和易混边界。它不是完整服装工业百科，不保存实际衣物，不分配 `CLO-*`。

## 一、使用规则

- 中文主词是规范名称；英文、旧译和商品俗称只作检索别名。
- 只有画面或可靠来源支持时才使用专业术语；看不清时改用通俗结构描述。
- 词典描述术语通常怎样影响轮廓、动作或触感，不保证每件衣物都产生同样效果。
- 精确纤维比例、克重、丹数、针距、缝份、纸样放码、洗标和商品性能必须有可靠来源。
- 不因“斜裁、鱼骨、吊带、蕾丝”等泛化词建立 `piece`。

## 二、概念层级

| 主词 | 含义 | 容易混淆 |
|---|---|---|
| 款式 | 衣物是什么，例如衬衫、吊带裙、文胸 | 不是廓形或审美效果 |
| 廓形 | 远看时衣物整体外轮廓 | 不等于贴不贴身 |
| 合体度 | 衣物与身体各部位的贴合程度 | 不等于松量或支撑能力 |
| 松量 | 衣物尺寸与身体尺寸之间的空间关系 | 不能只凭单张图片精确计算 |
| 支撑／压缩／塑形 | 承托、收束或重塑局部线条的功能 | 贴体不自动等于有支撑 |
| 结构塑形 | 省道、分割、拼片、褶等形成三维体积的方法 | 不等于表面装饰 |
| 材料 | 制成衣物或部件的物质总称 | 不等于纤维、组织或观感 |
| 纤维成分 | 构成纱线或材料的纤维来源 | “缎面”“蕾丝”不是纤维成分 |
| 面料形成方式 | 梭织、针织、蕾丝、网纱、薄膜等形成类别 | 不等于具体组织结构 |
| 组织结构 | 平纹、斜纹、缎纹、罗纹等结构 | 图片通常只能谨慎推断 |
| 表面整理 | 磨毛、涂层、水洗、压纹等后整理 | 不等于图案主题 |
| 图案主题 | 画面呈现的条纹、花卉、几何等内容 | 不等于印花、提花或刺绣工艺 |
| 视觉效果 | 轮廓、比例、焦点、距离感等观看结果 | 不等于人物意图或关系许可 |

## 三、廓形、合体度与长度

### 廓形

| 主词 | 观察定义 | 常见效果与边界 |
|---|---|---|
| A 型 | 上窄下宽，体积向下展开 | 可稳定下身量感；不自动等于少女感 |
| H 型 | 肩、腰、胯整体接近直线 | 可显利落或松弛，取决于松量和材料 |
| X 型 | 肩胸与胯部有量感，腰部明显收束 | 强调腰线；不自动等于正式或性感 |
| O 型 | 中部体积较圆，边缘向内收 | 可形成包裹感；须区别于单纯尺码过大 |
| 直筒 | 上下宽度变化较小，纵向线条连续 | 常弱化腰胯起伏 |
| 茧型 | 中段外扩、上下端收窄 | 体积感强，可能限制叠穿或动作 |
| 伞形 | 从较高位置明显向下放射展开 | 轻重感取决于材料、长度和褶量 |
| 鱼尾 | 上段贴合，膝部或更低位置向外展开 | 强调腰胯和步态，可能限制步幅 |

### 合体度与松量

| 主词 | 定义 | 观察边界 |
|---|---|---|
| 贴体 | 衣物大面积跟随身体曲线 | 不自动证明负松量或弹性 |
| 修身 | 轮廓接近身体但保留少量空间 | 不等于紧绷 |
| 合体 | 关键部位尺寸与活动空间适当 | 需要结合动作，静态图只能初判 |
| 宽松 | 衣物与身体之间有明显空间 | 不自动等于 oversized |
| 超宽松 | 体积有意明显超过常规合体范围 | 需确认是设计而非尺码错误 |
| 正松量 | 衣物尺寸大于身体尺寸 | 精确数值须有尺寸资料 |
| 零松量 | 衣物与身体尺寸接近 | 图片通常无法精确确认 |
| 负松量 | 衣物尺寸小于身体尺寸，依赖弹性贴合 | 贴体外观不等于已经确认负松量 |

### 长度与身体锚点

规范锚点包括：肩点、胸点、下胸围、自然腰、髋上缘、低髋、裆点、大腿中段、膝上、及膝、小腿中段、踝上、及踝、脚背和曳地。使用身体锚点优先于含混的“很短”“很长”。

## 四、结构线与塑形

| 主词 | 定义与观察点 | 易混边界 |
|---|---|---|
| 省道 | 将平面面料收去余量以形成胸、腰、臀等体积 | 不是普通装饰缝线 |
| 公主线 | 从肩部或袖窿纵向经过胸部的分割塑形线 | 需看线条是否承担裁片分割与塑形 |
| 分割线 | 将衣身分成多个裁片并参与造型的接缝 | 不等于所有明线 |
| 拼片 | 由独立裁片拼接形成结构、颜色或材料变化 | 拼色不一定存在独立裁片 |
| 育克 | 肩背、胸上或腰胯处承担连接与定型的裁片 | 不等于单纯色块 |
| 裆片 | 在裆部增加活动、舒适或结构连接的裁片 | 遮挡时不得推断 |
| 插片 | 插入边缘或接缝以增加体积、活动或装饰的裁片 | 与印花三角形不同 |
| 褶裥 | 折叠后形成有方向或规则的褶结构 | 与自然皱褶、抽皱不同 |
| 刀褶 | 褶向同一方向排列 | 需观察连续方向 |
| 箱褶 | 两侧褶向中心或由中心向外形成箱形 | 不等于普通宽褶 |
| 抽褶 | 将较长边收缩到较短边形成密集小褶 | 通常能看到收拢点 |
| 抽皱 | 用抽绳、松紧或缝线形成可见皱量 | 可能可调，也可能固定 |
| 垂褶 | 面料依靠重力形成连续下垂褶线 | 不能只凭静态造型断言斜裁 |
| 斜裁 | 裁片相对经纬方向斜向裁切以改变垂坠和贴合 | 需要纸样或明显行为证据，图片多为推断 |
| 包裹／交叠 | 裁片跨过身体或彼此覆盖 | 需区分真开合与假交叠装饰 |
| 开衩 | 边缘保留开口以增加活动、露肤或视觉分割 | 说明位置、长度和动作变化 |
| 荷叶边 | 通过弧形或增加边长形成波浪边饰 | 可能兼具体积与装饰作用 |
| 鱼尾摆 | 下摆在膝部或更低位置扩张 | 是局部结构，也可能形成鱼尾廓形 |

其它部位主词：领口、领型、肩线、袖窿、袖山、袖型、袖口、门襟、腰头、裤裆、裤脚、裙摆、后衩、侧衩、滚边、包边、毛边、缝线和明线。使用时说明位置和功能。

## 五、材料、面料与表面

### 材料来源

| 主词 | 定义 | 证据要求 |
|---|---|---|
| 天然纤维 | 来源于植物或动物的纤维类别 | 具体棉、麻、毛、丝须有来源或可靠证据 |
| 再生纤维 | 由原料经加工再生形成的纤维类别 | 不凭“像丝”判断粘胶或莱赛尔 |
| 合成纤维 | 由化学合成聚合物制成的纤维类别 | 不凭弹性直接判断聚酯或锦纶 |
| 非纤维材料 | 皮革、橡胶、金属、薄膜等不以纱线织造成主体的材料 | 区分外观仿制与真实材料 |

### 面料形成与组织

| 主词 | 定义与观察 | 易混边界 |
|---|---|---|
| 梭织 | 经纬纱交织形成，通常结构较稳定 | 不能只凭硬挺确认 |
| 针织 | 线圈结构形成，通常更易伸展 | 弹性不一定只来自针织结构 |
| 蕾丝 | 具有开放纹样的装饰性材料或结构家族 | 不是纤维成分，也不自动等于柔软 |
| 网纱 | 具有规则或不规则网孔的薄透材料 | 与蕾丝纹样和无孔薄纱区分 |
| 无纺 | 纤维非经传统织造形成的片材 | 图片通常难以确认 |
| 薄膜 | 连续膜状材料 | 可能透明、涂层或复合，需说明证据 |
| 复合材料 | 两种或更多材料层结合 | 表面相似不代表已经确认复合结构 |
| 平纹 | 经纬交错最基础的梭织组织 | 画质不足时不判定 |
| 斜纹 | 表面呈连续斜向纹路的组织 | 斜向印花不等于斜纹组织 |
| 缎纹 | 交织点分散、表面浮长较多的组织 | “缎面光泽”是外观，不等于确认缎纹或真丝 |
| 罗纹 | 针织中纵向或横向凸条结构 | 印刷条纹不等于罗纹 |

### 表面整理与性能

受控主词包括：磨毛、起绒、涂层、水洗、做旧、压纹、植绒、褶皱定型、覆膜、透明、半透明、不透明、哑光、柔光、高光、平滑、颗粒、绒感、垂坠、硬挺、伸展、回弹、易皱和皱褶恢复。

观察到表面结果不等于已经确认加工方法。例如可写“表面呈磨砂式低反光”，不能无证据写“经过某种磨毛工艺”。

## 六、图案与装饰

| 主词 | 定义与观察点 | 易混边界 |
|---|---|---|
| 满版图案 | 图案覆盖大部分可见面料 | 说明密度和重复单元 |
| 定位图案 | 图案被设计在明确部位 | 不等于偶然被裁片截断 |
| 边饰 | 图案沿领口、袖口、下摆等边缘展开 | 说明边缘位置和宽度 |
| 连续纹样 | 单元按规则重复延伸 | 说明方向、尺度和接花 |
| 印花 | 色料或墨层在表面形成图案 | 图片不一定能与色织区分 |
| 色织 | 不同颜色纱线在织造中形成图案 | 无近景或来源时谨慎使用 |
| 提花 | 通过织造或针织结构形成纹样 | 不等于所有有凸凹感的花纹 |
| 刺绣 | 以线迹附加形成纹样 | 说明位置、密度和凸起程度 |
| 贴花 | 将独立材料片附着于表面形成图案 | 与印花色块区分 |
| 植绒 | 将短纤维附着形成绒面图案 | 仅凭哑光不能确认 |
| 压纹 | 通过压力形成凸凹纹理 | 与提花或印花阴影区分 |
| 烫钻／珠片 | 以反光小件附着形成焦点 | 说明连接、脱落和勾挂风险 |
| 镂空 | 去除或避开材料形成孔洞 | 与透明网纱覆盖不同 |

常见主题主词：条纹、格纹、圆点、花卉、植物、动物、几何、文字、徽记和抽象。主题必须与形成方式分开写。

## 七、闭合、调节、支撑与辅料

| 主词 | 主要功能 | 必写观察 |
|---|---|---|
| 门襟 | 容纳开合结构 | 位置、真假开合、可见性 |
| 拉链 | 连续齿链闭合 | 普通／隐形／外露、位置和拉动方向 |
| 纽扣 | 穿过扣眼闭合或装饰 | 数量、间距、承力与是否真闭合 |
| 按扣／暗扣 | 通过按压咬合闭合 | 可见性、位置和受力 |
| 钩眼 | 钩与环连接 | 常用于腰头、胸衣和内衣，说明位置 |
| 搭扣 | 扣件相互连接 | 说明承重、调节或装饰作用 |
| 抽绳 | 拉动绳体收束 | 说明出口、调节范围和松开结果 |
| 系带 | 通过打结或交叉固定／调节 | 说明承重、装饰和解开后变化 |
| 松紧带 | 依靠弹性维持贴合 | 说明位置、压力、卷边和疲劳风险 |
| 鸡眼 | 加固孔洞供绳带或五金穿过 | 不等于单纯圆形装饰 |
| D 形环／调节扣 | 连接或调整带长 | 说明受力和滑移风险 |
| 钢圈 | 对罩杯或局部提供刚性支撑 | 不从外轮廓自动推断 |
| 鱼骨 | 纵向支撑、限制卷折并辅助塑形 | 装饰性骨线不等于真实支撑件 |
| 肩带 | 悬挂、承重、调节或装饰 | 宽度、位置、可调性和滑落风险 |

所有辅料都要区分承重、闭合、调节、支撑、塑形和纯装饰功能。

## 八、品类专项主词

### 内衣

- 罩杯：包覆和承托胸部的主体结构；
- 鸡心：两罩杯之间的中央连接区域；
- 侧翼：从罩杯侧面向后延伸的围带区域；
- 下围：胸部下方环绕身体并承担主要稳定作用的结构；
- 杯口：罩杯上缘，与贴合、压痕和张口风险相关；
- 衬垫：罩杯内部可固定或可拆的填充；
- 腰口、腿口、裆片：内裤或连体内衣的腰部、腿部边缘和裆部裁片。

### 袜类

- 袜口：袜类上端固定区域；
- 自持袜口：依靠内侧防滑材料自行固定的袜口；
- 控制腰：连裤袜腰腹处承担压缩或塑形的区域；
- 加固袜头：袜头密度或结构加强；
- 裸趾：袜头不做明显加固、适合露趾鞋的结构方向；
- 后缝：腿后纵向接缝或装饰线，必须区分真实接缝与视觉图案。

### 鞋履

- 鞋头：鞋前端外形；
- 鞋头空间：脚趾所在内部空间，图片通常只能间接判断；
- 鞋面：覆盖脚背的主体部分；
- 后套：包围脚跟的后部结构；
- 鞋跟：承托后足并改变坡度与重心的结构；
- 防水台／厚底：前掌或全掌额外增高结构；
- 外底：直接接触地面的底层；
- 鞋底纹路：影响抓地的底面结构；
- 掉跟、磨脚：穿着中的失配表现，不能仅凭外观断言一定发生。

## 九、穿着表现与失效风险

| 主词 | 含义 |
|---|---|
| 上窜 | 衣物在动作中向上移动 |
| 下滑 | 衣物、袜口、肩带或鞋履向下／脱离原位 |
| 卷边 | 弹性边缘或下摆向内外卷曲 |
| 走位 | 部件偏离设计覆盖位置 |
| 扭转 | 侧缝、裤腿、袜体或带体旋转偏移 |
| 堆积 | 多余长度在局部聚集形成皱量 |
| 张口 | 领口、杯口、门襟或接缝离开身体形成开口 |
| 勒痕／压痕 | 压力在皮肤或内层留下痕迹 |
| 内衣痕 | 贴身衣物边缘或结构透过外层显现 |
| 强光透视 | 强光下透明度或内层轮廓被放大 |
| 汗湿显色 | 吸湿后颜色、透明度或贴肤程度变化 |
| 静电贴附 | 静电导致衣料吸附身体或其它层 |
| 起球 | 表面纤维缠结成小球 |
| 勾丝／抽丝 | 纱线被勾出或沿结构拉移 |
| 松弛 | 弹性或结构恢复不足，贴合减弱 |
| 脱胶 | 粘合层或复合层分离 |

这些词只有在结构、材料、动作或可靠来源支持时使用；不能把风险写成已经发生的事实。

## 十、新增术语格式

词典按需生长。新增条目必须包含：

```markdown
### 中文主词

- 常见别名／英文：
- 所属维度：
- 准确定义：
- 画面观察点：
- 对轮廓、比例、动作或触感的常见影响：
- 不能仅凭图片确认的内容：
- 容易混淆的术语：
```

同一概念不得因中英文、俗称或营销名重复建立。候选术语尚未确认时留在分析层，不直接改写本词典。
