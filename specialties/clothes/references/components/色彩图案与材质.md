# Story Stars 衣装色彩、图案与材质

本文件规定衣装档案怎样记录颜色、色版、图案、材料、表面、触感和维护反馈。它只提供项目观察与设计语言，不保存任何具体衣装。

## 一、证据顺序

1. **画面确认**：可以直接看到的颜色位置、图案、透明边界、反光、纹理和动作反馈。
2. **来源确认**：可靠商品信息、标签、制作说明或作者确认的材料、工艺和色版。
3. **专业推断**：由可见表面和结构推断的面料组织、触感、弹性或维护方向，必须标注“推断”。
4. **项目候选**：为了搭配、角色或场景新增的色版与材料方案，不能伪装成来源事实。

无法确认时写“未判定”及原因。不得为了填满档案虚构品牌、纤维比例、克重、丹数、商品等级和实际触感。

## 二、配色构成

每个色版至少记录：

- 色版性质：画面确认／来源确认／项目候选；
- 色版名称；
- 主导色组：允许一种或多种；
- 辅助色；
- 点睛色；
- 各颜色出现的位置；
- 面积层级和视觉权重；
- 明度、饱和度、冷暖和对比；
- 与肤色、环境、灯光和材料表面的关系；
- 动作或光线变化时的反馈。

没有辅助色或点睛色时明确写“无”，不能留空。

### 主导色组

“主导色组”描述占据主要面积、控制第一印象或决定整体秩序的一个或多个颜色。它不等于只允许一个“主色”。

例如，同一件衣物的大面积黑白分区都承担主体结构时，黑与白共同构成主导色组；少量金属扣件可以是点睛色。

### 颜色维度

- **色相**：颜色类别；
- **明度**：颜色相对明暗；
- **饱和度**：颜色鲜明或灰钝程度；
- **冷暖**：在当前配色与光线中的相对倾向；
- **面积**：颜色占据的可见比例；
- **位置**：颜色靠近脸、胸、腰、胯、腿、脚或边缘；
- **边界**：颜色之间是硬切、渐变、纹样过渡还是材料交界。

颜色效果必须结合面积、位置、材料、透明度、肤色、动作和场景解释。不得使用“红色必然性感”“白色必然清纯”“黑色必然显瘦”等固定公式。

## 三、多色构成与不同色版

### 多色构成

同一件衣物同时具有黑、白、黄、红等多个颜色，这些颜色共同组成**一个色版**。不得把同件衣物上的每种颜色拆成不同色版。

### 不同色版

同一结构设计分别存在黑色版、白色版、黄色版、红色版等替代配色，每个都是该衣物的一个色版。

每个色版必须独立说明：

- 主导色组与颜色分布；
- 轮廓收缩／扩张和比例效果；
- 第一焦点与注意力顺序；
- 人物距离感与正式度；
- 视觉刺激强度和机制；
- 与肤色、材料、灯光的耦合；
- 搭配难度和适用场景。

不能只写“另有黑、白、红三色”。

## 四、同一 `CLO-*` 与拆分条件

只有染色或颜色分布变化，而以下内容均不变时，默认是同一 `CLO-*` 的不同色版：

- 结构与版型；
- 主体和辅助材料；
- 图案主题与形成方式；
- 花边、系带、刺绣、珠饰和五金；
- 透明度、厚薄、弹性与支撑；
- 固定、闭合、覆盖和功能；
- 角色、作品或成套识别身份。

以下任一变化足以改变衣物身份或穿着反馈时，新建 `CLO-*`：

- 主体或贴肤材料改变；
- 透明度、光泽、厚薄、弹性、支撑或摩擦发生实质改变；
- 图案、蕾丝、花边、系带、刺绣、珠饰或五金结构改变；
- 杯型、版型、闭合、覆盖范围或功能改变；
- 垂坠、硬挺、贴肤或动作反馈明显不同；
- 成套识别或角色／作品识别已经改变。

相反，只因纯色不同就重复建立多个 `CLO-*` 也是错误。

正式人物衣装或 Construction 采用时必须选定唯一具体色版，不能保留互斥的颜色备选。

## 五、图案记录

图案必须分开记录以下维度：

| 维度 | 观察内容 |
|---|---|
| 主题 | 条纹、格纹、圆点、花卉、植物、动物、几何、文字、徽记、抽象或无 |
| 位置 | 满版、定位、边饰、局部焦点或跨部件重复 |
| 尺度 | 微小、小、中、大或跨裁片；说明相对身体和衣片的比例 |
| 密度 | 稀疏、均匀、密集、局部聚集 |
| 方向 | 横向、纵向、斜向、放射、无固定方向 |
| 排列 | 连续重复、对称、不对称、镜像、错位 |
| 接花 | 裁片接缝处是否连续对齐；看不清时未判定 |
| 底色关系 | 低对比、同色纹理、中对比、高对比 |
| 形成方式 | 印花、色织、提花、刺绣、贴花、植绒、压纹、烫钻、珠片、镂空或未判定 |

图案主题和形成方式不得混写。例如“花卉”是主题，“刺绣”是形成方式，“蕾丝花卉纹”还要说明其开放结构和透明边界。

## 六、装饰与辅料

对蕾丝、花边、荷叶边、滚边、蝴蝶结、流苏、羽饰、珠饰、亮片、链饰和五金，至少说明：

- 具体位置；
- 尺度、宽度、数量和密度；
- 与主体颜色和材料的关系；
- 是否承担承重、闭合、调节、支撑或塑形；
- 是否只是视觉装饰；
- 动作中的摆动、反光、声音、摩擦和勾挂风险；
- 损坏、脱落或替换是否影响衣物身份。

“有蕾丝”“带系带”“很精致”不足以完成记录。

## 七、材料层级

不得把所有信息统称为“材质”。按以下层级分别写：

1. **材料或纤维成分**：棉、麻、毛、丝、再生纤维、合成纤维、皮革、橡胶、金属等；
2. **面料形成方式**：梭织、针织、蕾丝、网纱、无纺、薄膜、复合；
3. **组织结构**：平纹、斜纹、缎纹、罗纹等；
4. **表面整理**：磨毛、起绒、涂层、水洗、做旧、压纹、植绒、褶皱定型、覆膜；
5. **内部结构**：里布、衬布、贴身层、填充、胸垫、肩垫、钢圈、鱼骨；
6. **可见与可感知表现**：透明度、光泽、纹理、弹性、回弹、厚薄、垂坠、硬挺、摩擦和声音。

“缎面”通常先作为外观描述；只有证据足够时才写“缎纹组织”。“蕾丝”不是纤维成分，“丝滑”也不能证明桑蚕丝。

## 八、画面可以确认什么

通常可以直接观察：

- 连续或零散反光；
- 哑光、柔光或高光表面；
- 可见网孔、绒面、颗粒、褶皱和凸起；
- 透明、半透明和不透明区域；
- 动作中的垂坠、摆动、贴附和恢复；
- 边缘、缝线、花边和五金的可见结构。

通常不能仅凭图片确认：

- 精确纤维成分和比例；
- 商品是否为真丝、真皮或特定等级蕾丝；
- 精确克重、丹数、强度和色牢度；
- 实际透气、吸湿、保暖、速干和静电表现；
- 真实初触温度、柔软度、摩擦和长时舒适度；
- 洗标、耐洗次数和生产工艺参数。

## 九、触感反馈

触感是推断时，必须说明依据和不确定性。至少从相关维度选择：

- 初触温度：偏凉、接近体温、偏暖；
- 柔软度：柔软、中等、偏硬；
- 表面：平滑、颗粒、绒感、网孔、凸起、硬质装饰；
- 摩擦：低、中、高；
- 拉伸阻力和回弹；
- 贴肤、悬离、吸附或滑移；
- 边缘、缝线、花边、钢圈、鱼骨或五金的局部压力；
- 汗水、水分、坐卧、行走和长时穿着后的变化；
- 沙沙、摩擦、摆动、金属碰撞等声音方向。

合格写法：

> 画面确认边缘为开放网孔结构并有细密刺绣凸起；贴肤时可能产生比主体面料更明显的纹理和摩擦，实际软硬与压痕程度未确认。

## 十、穿着表现与维护

按证据记录：

- 上窜、下滑、卷边、走位、扭转、堆积和张口；
- 内衣痕、肩带或闭合件外露、强光透视、汗湿显色和静电贴附；
- 勒痕、压痕、磨脚、掉跟和勾挂；
- 起球、勾丝、抽丝、磨损、褪色、缩水、松弛、变形、脱胶和饰件脱落；
- 清洁、阴干、熨烫、收纳、修补和耗材替换。

风险只表示结构上可能发生，不等于已经发生。护理要求只有来源明确或材料判断足够可靠时才给出；否则写“未判定”。
