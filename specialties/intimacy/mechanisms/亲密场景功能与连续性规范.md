# 亲密场景功能与连续性规范

> 本页规范亲密场景的功能分类、现实约束、详略选择与场后连续性。它不决定场型、人物授权或具体玩法；场型回 `zen/bible.md`，人物授权回 `specialties/intimacy/characters/`，当次执行回场景设计卡。

## 一、场景功能

| 功能 | 主要交付 | 不得替代 |
| --- | --- | --- |
| 首次确认 | 临界、独立选择与关系改写 | 既有隐瞒和现实责任 |
| 熟人快场 | 关系存量、既有默契与短促欲望 | 人物差异 |
| 庆祝 | 共同完成后的释放与偏爱 | 现实奖励和成果本身 |
| 和好 | 重新靠近与愿意继续 | 道歉、说明与问题处理 |
| 嫉妒 | 位置表达、独处需求与权力回摆 | 告知、协商与隐瞒账单 |
| 照护 | 身体回稳、情绪接住与依赖变化 | 医疗、休息与现实恢复 |
| 深色递进 | 新权限的逐项交付与退出 | 永久授权 |
| 多人建序 | 逐关系位置、注意力与共同边界 | 任一双人关系的独立性 |
| 纯欲日常 | 欲望常态与生活质感 | 人物辨识度和现实时间 |

- 每场设一个主功能，最多带一个副功能。
- “纯欲日常”可以没有重大剧情转折，但仍须符合人物、关系阶段和连续性。
- 高频来自场次常态化，不要求每场同强度、同篇幅或同一推进结构。

## 二、现实约束

- **私密度与声响预算**：谁可能进入、隔音如何、声音上限、停止信号是否仍能被听见。
- **时间预算**：硬性结束时间、来访、会议、交通和次日安排。
- **现实打断点**：敲门、电话、设备失控或状态变化时如何立即停止。
- **空间条件**：门窗、家具、承托、遮蔽物、照明、温度和通行动线。
- **结束后的去处**：能否休息、清理、换衣、离开或独处。

场景不能脱离现实时间无限延长；环境限制应进入动作、声音和节奏，而不是只写在设计卡头部。

## 三、详略规则

- **里程碑场**：首次、破防、关系质变、新权限或多人建序，完整呈现关键确认、主过程、退出和余波。
- **日常兑现场**：可短铺垫、选取少数主幕写深，其余含蓄承接；不要求重复走满同一套结构。
- **连续多场**：按关系功能和身体状态错开强度、场域、主动权、镜头与收束方式。
- 设计卡中的幕结构是定位工具，不是平均配额；无功能的幕可以压缩，不能为填模板制造重复。

## 四、场后连续性

只记录后文不知道就可能写错的变化：

- 时间、地点与实际持续范围。
- 身体疲劳、睡眠、清理、照护与可见痕迹。
- 衣装、道具、饰物、家具和空间的损耗、遗落、归属与复原。
- 次日工作、训练、驾驶、社交与共同生活安排。
- 谁知道、谁可能察觉、哪些隐私仍未公开。
- 关系、权限、称呼或默契的新变化。
- 尚未解决的问题与下一次承接位置。

设计卡和独立亲密正文不建立授权日志。只有场景产生需要长期继承的关系、线索或剧情变化时，才按普通章节定稿流程同步对应正式状态。

## 五、物件与线索边界

- 衣装损耗、饰物遗落和消耗品用尽默认只是场景连续性。
- 只有正式大纲或 `clues/` 登记后，物件才承担伏笔与发现链。
- 不因某人可能看见就自动制造争夺、抓包、逼退或名分重排；知情变化必须由后续正式场景兑现。
- 影像、录音与可识别身份材料另走 [亲密影像与录像边界](亲密影像与录像边界.md)。

## 六、章级检查

- 本场主功能是否明确，是否承担了不该由亲密替代的问题？
- 环境和时间是否真实限制了动作、声音与节奏？
- 是否使用了本场家具、地形、遮蔽物和通行动线？
- 是否存在人物化的权力试探或情感对白，而非泛化反应堆积？
- 场后有哪些变化必须被下一章继承？
- 物件变化是普通连续性还是已登记线索，是否分清？
