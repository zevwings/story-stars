# 情趣道具参考索引

> **本模块是参考层，不是真源。** 它只提供可直接写进正文的品类、材质、动作、刺激点与情趣点，不规定任何人物拥有什么、用过什么、偏好什么，也不设场型、档位、授权或安全门禁。
>
> **刺激点**只描述器物主要作用于哪些身体／感官区域、以什么方式形成反馈，不表示人物必然获得某种反应。**情趣点**只描述控制权、预期差、可见性、角色翻转、仪式感与照料等可选写法，不表示人物已经接受、喜欢或实际采用。
>
> 任务实际命中清洁、共享、材质兼容、束缚、持续压力、影像或其它现实安全问题时，按需读取 [亲密道具调用规范](../../mechanisms/亲密道具调用规范.md)；命中拍摄、保存或回看时再读 [亲密影像与录像边界](../../mechanisms/亲密影像与录像边界.md)。人物稳定偏好与避让见 `specialties/intimacy/characters/`，当次采用方式服从正式大纲、施工或章节。
>
> 各页括号内的档位只用于定位规范页中的相邻风险类型，不构成调用许可，也不与衣装、场域机械联动降档。

## 本模块排除项与正式规则入口

- **品牌、型号与市场资料**：本模块不提供现实品牌、型号、价位、功率、转速、尺寸榜单、测评或营销分类。正文若少量引用中性现实消费品牌，服从 [BIBLE](../../../../zen/bible.md#五世界边界)。
- **固定医疗与安全结论**：本模块不规定统一时长、温度、配方、清洁剂、润滑兼容或身体适用性；实际处理服从产品说明、人物事实与 [亲密道具调用规范](../../mechanisms/亲密道具调用规范.md)。
- **工业、训练、办公与医疗器械**：不作为本模块情趣品类素材；正式剧情确有器物事实时，回到相应真源判断，不以近似外形替代身体专用品。
- **联网、摄录与智能设备**：本模块不把 App、云端、自动记录或算法功能写作亲密卖点。场景实际命中设备或影像时，读取正式机制与影像边界，不从本模块反推全书技术事实。
- **AI、虚拟人格与仿真机器人**：不属于本模块器物参考范围；本模块只处理人物之间使用的器物素材，不据此定义世界观是否存在相关技术。
- **修真、异能与数值滤镜**：本模块不提供星力、灵力、识海、增益、回蓝或数值化器物词条，正式口径服从 [BIBLE](../../../../zen/bible.md#亲密非功利化边界) 与 [STYLE](../../../../zen/style.md)。
- **器物堆砌**：相邻场不靠换商品名或增加数量制造差异；具体器物只有改变刺激点、情趣点、控制关系或场后余波时才值得写出。

## 调用顺序

1. 先按 [项目路由](../../项目路由.md) 读取正式大纲、人物事实与任务闭包。
2. 读取 `specialties/intimacy/characters/` 中已经成立的稳定偏好、避让与器物关系语言。
3. 只有大纲实际命中清洁、共享、束缚、持续压力、影像或其它现实机制问题时，才按需读取对应机制页。
4. 最后从本索引进入所需页面，选择品类、材质、刺激点、情趣点与动作词条。
5. 本模块不得反向补出人物偏好、拥有经历、场次授权、关系结果或器物的具体产品参数。
