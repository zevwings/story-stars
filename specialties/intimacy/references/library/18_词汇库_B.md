# 17 词汇库_B

> 处理亲密场景中偏向 B 场（高烈度、直接描写、具象解剖、失控）的词汇选择。仅适用于设计卡明确允许的 B 场。
> 本页只做参考摘录，不作为真源口径; 当前任务够用时就停在这里。
>
> **核心原则**：提供高颗粒度的动作词汇、具象的器官反馈以及失控状态下的语言瓦解。使用时需克制，避免全篇堆砌，以点爆破。

---

## 淫语库

> 只在设计卡明确允许时按需取样。真正决定气味的不是"有没有淫语"，而是角色会不会这样说、在什么时刻说、说完之后有没有符合其人设的回响。

### 轻度
- 身体感受：`身体...好奇怪...` / `停不下来了...` / `那里...不要碰...` / `要...要坏掉了...`
- 状态描述：`好满...` / `好烫...` / `受不了...` / `太深了...`

### 中度
- 直接描述：`里面...好满...` / `被你...填满了...` / `要被...弄坏了...` / `身体...变得好奇怪...`
- 请求表达：`想要...想要你...` / `给我...都给我...` / `要...还要...` / `不要停...继续...`

### 重度
- 器官直接：`肉棒...好大...` / `小穴...要被撑坏了...` / `精液...好烫...` / `被灌满了...`
- 露骨描述：`插得好深...` / `要被顶穿了...` / `射进来...都射进来...` / `要被你弄坏了...`

### 使用提醒
- 不适合整段堆砌; 越重度越要少而准。若本场主型不是肉感视觉型或强支配型, 重度淫语通常只适合当作单点爆破。
- 词汇越直接, 越要有角色语气和场景后果兜住; 不要把词表当自动替换器。
- 正向场可以使用强烈词, 但要保留愿意信号、关系重量和事后回落; 黑暗 / 压迫场则优先写选择权失衡、心理真相和伤害后果。

## 销魂词汇库 (B场意向)

### 极致动作与接触
- **动作**: 贯穿、钉死、研磨、碾压、占有、拓荒、震颤、痉挛、契合无间、深度拓荒、无死角撞击、灵魂深处的叩问。
- **形容词**: 残暴的温柔、毁灭性的快感、窒息的紧致、滚烫的侵略。

### 器官与接触意向
- **雄性意向**: 狰狞、铁器、灼热、昂扬、滚烫、暴虐、器宇、根源。
- **雌性意向**: 温软、深谷、秘境、蕊心、紧窄、湿润、泥泞、层叠。

### 动作分层

- **推进**:压入、抵近、逼近、没入、深入、推进、重重落下。
- **反复**:碾磨、研磨、撞击、抽送、反复叩击、一次比一次更深。
- **停顿**:抵住、停在最深处、压着不动、让她慢慢适应、把呼吸钉在原地。
- **失控**:猛然加重、节奏断裂、力道失衡、几乎压不住、彻底越过临界。

### 声息分层

- **低烈度**:气息不稳、低喘、闷哼、尾音发哑、话说到一半断掉。
- **中烈度**:喘息破碎、哭腔溢出、声音被撞散、求饶和索求混在一起。
- **高烈度**:嘶哑尖叫、近乎崩溃的呼喊、意识震荡中的失声。

---

## 声音与破碎语 (B场爆发)

- **破碎感**: 哭音、破碎的低吟、不成调的喘息、近乎惨烈的呼救。
- **示例**: "杀了我...求你..." / "要...要疯了..." / "把我...填满..." / "呜...不行...太重了..." / "求你...射给我..."
