## 使用原则

1. **每概念单点**：边缘控制归 26，延迟满足归 43，信任建立归 42，具体见各文件指针
2. **基础先于技法**：1X 身体感官词汇优先于 2X 体位动作
3. **结构先于内容**：26 场景结构和 28 节奏先于具体描写
4. **理论补充技法**：4X 情绪心理、关系递进帮助提升场景深度
5. **设计卡为准**：本库是参考素材，A / B / dark 路线只服从本场设计卡，参考页不自行改判
6. **按需读取**：A 场够用就不进 B 场，HD 不需要就不打开
