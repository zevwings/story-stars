# 17 词汇库_A

> 处理亲密场景 A 场(非露骨)和情感向的词汇选择。适用于氛围铺垫、心理博弈与情感递进。
> 本页只做词汇方法参考, 不保存题材专属词表或示范句; 题材专属隐喻、称呼与世界观词汇由接入项目提供。
>
> **核心原则**: 词汇库是**补词、校准口气、避免重复**的工具, 不是正文生成器。一场戏真正有用的通常只是一两个音节、一两种句式或一个称呼变化。优先服从角色人设、关系阶段、设计卡; 不要为了"更色"把人物写成另一张脸。

---

## 称呼库

> 称呼分类按题材选用: 现代题材不用古风称谓, 反之亦然。以项目人设和关系阶段为准。

### 常规称呼
- 男性: 名字、哥哥、以及项目题材内对应的伴侣称谓。
- 女性: 名字、小名、以及项目题材内对应的伴侣称谓。

### 特殊昵称
- 软萌系: 宝贝、乖乖、心肝、甜心。
- 动物系: 小猫、小狐狸、小兔子、小野猫。
- 占有系: 我的、只属于我的、我的人。
- 古风系 / 现代系: 按项目题材二选一, 不混用。

### 情境称呼
- 日常: 正式名字、昵称。
- 亲密开始: 昵称出现、称呼变化。
- 高潮失控: 自称小名、呼喊对方。
- 特殊模式: 主仆、兄妹、夫妻等关系型称谓, 按项目关系设定。

### 使用提醒
- 称呼变化比露骨词更能体现关系推进, 但也最容易写崩人设。
- 优先选角色本来就会说出口的称呼, 不硬塞不合题材的昵称。

## 隐喻库

### 核心原则
- 亲密场景可以借用自然、天象或题材内元素构建隐喻, 既保持文学性又符合世界观。
- 隐喻不是盖掉直白描写, 而是给场景增加第二层气味。
- 一场戏守住 **1 个主意象 + 1 个辅助意象** 就够, 意象过多会互相打架。
- 少用磨平的套话(如"欲火焚身""潮水般涌来""如遭雷击"), 除非刻意翻新。
- 优先选和角色状态、场地、当前情绪真正有关的意象。

### 自然意象(题材中立)
- 雷电: 触电般的战栗、酥麻窜过全身。
- 火焰: 体内有火在烧、热浪席卷。
- 潮汐: 一波接一波的冲击、被浪潮淹没。
- 水: 如溺水般窒息、沉入温柔的深渊。
- 风: 被卷入风暴中心、轻柔如春风拂面。

### 题材专属隐喻
- 修炼、能量、契约、机械或其他世界观专属的隐喻系统, 由项目 `story/genres/` 或专项参考定义, 不在公共层保存。

## 情感心理词汇库

> 本节只提供**心理框架的分型与递进结构**, 具体承载(能量、机制、身份等)由项目填充; 不保存题材专属示范句。

### 心理冲突分型
- **反应与意愿分离**: 身体先出现陌生反应; 角色辨认这种反应后,仍自行决定是否接受和继续。
- **禁忌诱惑与规则突破**: 这段关系在当下秩序里不被鼓励; 选择相信自己的判断而越界。
- **初次体验的陌生与探索**: 从未想过的具象感受; 某种从未开启的反应被唤起。

### 情感四阶段递进
| 阶段 | 心理 | 身体 |
|---|---|---|
| 抗拒 / 警觉 | 陌生、警觉、理性主导、戒备 | 紧绷、僵硬、极力克制 |
| 适应 / 发现 | 察觉身体反应、形成自己的判断、陌生与熟悉交织 | 渐渐放松、呼吸同步、主动调整距离 |
| 沉浸 / 共鸣 | 理性退场、感官过载、意识模糊、完全沉浸 | 感官洪流、临界被突破(具体表现由项目体系落地) |
| 余韵 / 重构 | 自我接纳、认知重构、新的理解、平衡 | 自然放松、主动接纳、新平衡 |

### 禁忌感分型
- **身份禁忌**: 规则森严、身份/辈分差异; 关系一旦成立, 表面身份不再足够。
- **规则/契约禁忌**: 时机未到或有旧誓; 因必要性(伤势、救人)而越界。
- **场所/风险禁忌**: 环境危机、被打断风险、时间压力。

### 权力关系(平等化)
- **主导权动态**: 起初一方引导, 另一方逐渐反客为主。
- **经验差异(非压迫)**: 一方经验更深负责引导, 另一方跟随, 最终找到共鸣。

### 感官心理联动
- **生理触发心理**: 某处传来的反应 → "这才意识到……"的发现时刻。
- **感官过载与意识模糊**: 冲击涌入 → 理性退场 → 临界被突破。
- **心理影响生理**: 紧张导致的心跳、口干; 情绪波动暴露在身体反应上。
- **接纳后放松**: 心理接纳 → 身体自然放松 → 找到新节奏。

## 委婉表达分级

### 核心原则
- "委婉"不是"模糊", 而是让信息换一种更贴人物和文脉的方式出现。是否委婉, 优先由设计卡、人物习惯和场景任务决定。

### 器官与进入分级
- **男性器官**: L1 某处、那里、身体的反应; L2 欲望、炙热、坚硬的存在; L3 性器、阳具、灼热的硬挺。
- **女性器官**: L1 私密处、那里、身体深处; L2 花径、秘处、柔软的入口; L3 花心、蜜穴、温热的甬道。
- **进入动作**: L1 两人合为一体; L2 缓缓进入、没入身体; L3 挺身而入、一寸寸侵入。
