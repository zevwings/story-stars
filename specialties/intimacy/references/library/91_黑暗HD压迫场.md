# 91 黑暗HD压迫场

> 本页是已经由设计卡定型为 dark / 黑暗 HD 的参考总入口，只做素材路由，不参与场型判定。
> 黑暗 HD 沿用 `design.b.dark.md` 与现有 dark planner / writer；规则流程见 [黑暗HD流程](../../protocols/黑暗HD流程.md)。

## 一、定位

黑暗 HD 不是 B 场正向 HD 的加重版，也不是把非自愿场景写成情色奖励。

黑暗 HD 指的是：以高颗粒度写清压迫、强制机制、药性、权力失衡、身体失控、心理断裂、创伤余波和后续清算。它可以有强烈的身体细节、感官细节和压迫感，但叙事重心必须落在“选择权被剥夺”“人物如何承受”“伤害造成什么后果”上。

## 二、黑暗 HD 素材范围

黑暗 HD 设计卡可从以下压迫来源、身体状态和后果方向中选择素材：

- 反派压迫、敌对者胁迫、权力不对等造成无法拒绝。
- 迷药、药性或机制控制（如禁制、诱导术、设备锁、精神控制）导致意识不清、判断受损或身体失控。
- 明确强迫、侵害、被迫承受、无法停止、无法逃离。
- 羞辱、威胁、伤害亲友、以把柄控制、以力量或身份压制。
- 受害方身体有反应，但心理仍处在抗拒、恐惧、羞耻、厌恶、麻木、断裂或求生状态。

## 四、禁止套用

- 不套用 B 场正向 HD 的“关系推进、情绪兑现、甜蜜余韵”逻辑。
- 不套用正向亲密的“双方成全、感情提升”逻辑，除非文本明确写成被夺取、被污染、被破坏或被迫绑定，并承担后果。
- 不套用自愿 BDSM、主奴游戏、情趣束缚、奖惩玩法的完整流程。
- 不把身体反应写成愿意信号。
- 不把失控、语言破碎、高潮、生理反应写成享受、调情、隐秘心动、关系升温或剧情奖励。
- 不让加害者视角替伤害行为洗白。可以写其自我合理化，但文本判断不能跟着合理化。

## 五、结构抓手

黑暗 HD 的结构不以“前戏 - 高潮 - 余韵”为主轴，而以压迫事件的伤害链条为主轴：

1. **入场压迫**：人物为什么无法离开、无法拒绝、无法求救。
2. **控制方式**：药物、强制机制、权力、力量差、威胁或环境如何剥夺选择；幻想题材可具体表现为禁制或术法。
3. **身体失控**：身体如何被影响，但叙述必须持续标明这不是愿意。
4. **心理断裂**：恐惧、羞耻、麻木、厌恶、求生、记忆空白或自我抽离。
5. **事件后果**：痕迹、伤势、身体污染、精神创伤、关系破裂、复仇线、清算线或长期阴影。

## 六、写后自检

- 读者能否清楚知道这是一场伤害、压迫、失衡或暴力事件。
- 受害方的身体反应有没有被误读成愿意、享受或心动。
- 场景是否把侵害写成“高刺激奖励”或“关系升温”。
- 是否写出了后果，而不是在事件后直接切回日常或甜蜜余韵。
- 若后续要写关系变化，是否安排了权力关系重置、伤害清算、选择权恢复与信任重建。
- 是否已经至少选定一种压迫类型、一个心理真相和一个现实后果。
