# 92 黑暗HD类型谱系

> 本页承接已经定型的黑暗 HD 设计卡，用于选择压迫来源、失衡形态和后果落点，不参与场型判定。

## 一、使用方法

每场黑暗 HD 至少先定三件事：

1. **压迫来源**：药物、束缚、权力、力量差异、身份、威胁或空间封锁。
2. **失衡形态**：意识受损、身体失控、无法拒绝、无法停止、无法求救、无法离开。
3. **后果落点**：创伤、污染、证据、清算、复仇、关系断裂或长期阴影。

若只能定“刺激点”，却定不出压迫来源与后果落点，这场还不能进入黑暗 HD。

## 二、药物 / 迷幻失衡

**压迫来源**

- 迷药、致幻药物、催情香气、毒雾、生理发散。
- 药性改变感知、降低判断、放大触觉、干扰身体正常控制。

**写作抓手**

- 身体反应与心理判断分裂：身体被药性推着走，意识仍知道“不该这样”“不能这样”。
- 药性有时间线：发作、加深、失控、短暂清醒、反扑、药退后的空洞。
- 受害方的羞耻和恐惧要和身体反应同时存在，不能让药性把受害方改写成主动享受。

**后果落点**

- 药退后的记忆断片、恶心、虚脱、身体紊乱。
- 对气味、药物、封闭空间产生触发反应。
- 后续可落证据线：药渣、香灰、现场残迹、心理印记。

## 三、束缚 / 工具控制

**压迫来源**

- 物理束缚、器具封声、锁具、精神隔离、行动剥夺。
- 空间被封闭，求救被隔绝，反抗会触发疼痛、惩罚或伤害。

**写作抓手**

- 控制不是“方便推进动作”，而是让读者看见选择权被一层层剥掉。
- 束缚要有可感知表现：勒痕、皮肤灼痕、呼吸停滞、声音被吞没。
- 反抗要有代价：越挣越紧、越喊越静、越用力越痛。

**后果落点**

- 束缚残痕、印痕、声响回声、肌肉刺痛。
- 对类似锁链声、封闭环境产生后续阴影。
- 可引出解脱、追查操控者或施术者、清除工具、重建心理边界。

## 四、力量 / 位阶压制

**压迫来源**

- 能力差异、职位位阶、尊卑身份、组织惩罚、掌权者命令。
- 受害方不是“不想反抗”，而是反抗会造成更严重后果。

**写作抓手**

- 写清能力或身份压制如何进入身体和空间：压低呼吸、限制动作、让膝骨发软或让话语被身份堵住；幻想题材可表现为威压。
- 加害者可以自我合理化，但文本不能替其合理化。
- 受害方的屈从要写成生存策略、创伤反应或被迫权衡，不能写成心甘情愿。

**后果落点**

- 对权威、命令、特定称呼产生厌恶或失控反应。
- 组织/家族/环境关系被污染，后续需要清算权力结构。
- 若后续关系变化，必须另写权力关系重置和伤害清算。

## 五、精神 / 意识侵入

**压迫来源**

- 精神施压、梦境操控、幻境诱导、记忆篡改、心理契约压迫。
- 受害方的边界不只在身体，也在潜意识、记忆和自我认知。

**写作抓手**

- 写“自我边界被碰到”：不是看见私密画面这么简单，而是自己的恐惧、羞耻、记忆被迫暴露。
- 意识层的侵入要有现实反馈：头痛、失声、眼神涣散、记忆断层、精神过载。
- 若出现幻觉中的身体反应，必须标明现实判断受损，不能按真实同意处理。

**后果落点**

- 精神创伤、梦魇、记忆空白、无法分辨幻境与现实。
- 后续需要恢复心理、重建自我边界。

## 六、极端剥夺 / 不对等消耗

**压迫来源**

- 资源剥夺、主体性消耗、不对等利用、生理与精神强制抽取。
- 亲密动作只是伤害链条的一部分，核心是夺取、消耗、物化与伤害。

**写作抓手**

- 写清被夺走的是什么：健康、尊严、自由、记忆、情感稳定性。
- 场面可以高烈度，但落点不是“欲望兑现”，而是“被当作工具使用”。
- 受害方即使有身体反应，也必须保留被物化、被抽取、被消耗的恐惧。

**后果落点**

- 生理跌落、身体伤害、健康亏损、长期精神障碍。
- 后续可落治疗线、复仇线、证据线或长期心理障碍。

## 七、囚禁 / 空间封锁

**压迫来源**

- 密室、地牢、封闭车辇、死角、暗舱。
- 空间本身成为加害者的帮凶。

**写作抓手**

- 写空间如何让人无法逃：门、墙、锁、声音、光线、距离、外界无知。
- 黑暗、狭窄、潮湿、冷硬、香气、回声都可以服务压迫感。
- 重点不是“场景刺激”，而是无路可退、无人可知、无法求救。

**后果落点**

- 对封闭空间、锁门声、脚步声、特定香气产生后续反应。
- 现实回流时，人物如何遮掩痕迹、寻找出口、留下证据或等待救援。

## 八、身份羞辱 / 名誉胁迫

**压迫来源**

- 以身份、清誉、亲友、把柄、影像或公开威胁。
- 以录像作为把柄，或以伤害亲友迫使人物改变行动。
- 加害者用“被看见”“被知道”“被定义”来摧毁受害方自我。

**写作抓手**

- 羞辱要写成压迫工具，不是调情工具。
- 受害方的沉默、配合或失声要写成被逼迫后的生存反应。
- 可以写加害者的羞辱话术，但文本判断不能让羞辱成为浪漫或奖励。

**后果落点**

- 对称呼、身份服饰、特定空间、公开视线产生阴影。
- 后续可能引出名誉修复、公开清算、证据反击或身份重建。

## 九、组合原则

- 一场最多主打一到两个压迫来源，避免药物、束缚、囚禁、羞辱、剥夺全部堆满。
- 压迫来源越多，越要写清后果，否则会变成刺激拼盘。
- 若加入特定机制，必须让机制造成实际后果：健康、心理印记、残留证据或关系撕裂。
