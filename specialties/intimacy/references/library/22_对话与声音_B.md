## 对话 (B场)

### 失控 (B场)
- 常见用途：临界前的求、催、喊；高点时的失语和断句；反应先于思路的碎话。
- 关键抓点：语言组织能力真的在瓦解。对比前面克制才会更有力。

### 高潮对话
- **临界话语**: `快了...快要...` / `不行...要去了...` / `忍不住了...` / `等等我...` / `一起...` / `别停...` / `不行了...真的不行了...` / `要...要坏掉了...`
- **失控呼喊**: `哥哥...!` / `夫君...!` / `(名字)...要去了...!` / `啊啊啊...!` / `不...不行...!` / `去了...去了...!` / `要...要死了...!` / `啊...好...好强烈...!`
- **同时高潮**: `一起...一起去...` / `我也...我也要...` / `去了...!`（同时）/ `啊————!`（同时）

## 声音 (B场)

### 破碎字句 (B场)
- **否定词**: `不...不要...` / `不行...` / `别...别这样...` / `不可以...真的不可以...` / `不能...不能再...` / `不...不行了...真的...` / `别...别停...`
- **程度词**: `太...太深了...` / `好深...` / `深到...` / `好...好烫...` / `烫死了...` / `好热...` / `受不了...` / `太强了...` / `好奇怪...` / `太满了...` / `要...要撑坏了...` / `好胀...`
- **请求词**: `要...想要...` / `给我...求你...` / `快...快点...` / `再...再来...` / `不要停...` / `继续...` / `慢...慢点...` / `轻...轻一点...` / `用力...`

### 音量层次 (B场)
- **4. 失控期（高音量）**: 啊啊啊...不行了...（破碎）、要...要去了...（尖叫）。特征：完全失控、无法压制。呼吸：紊乱、窒息感。适用：高潮前后。

### 节奏配合 (B场)
- **快速节奏**: 啊啊...嗯嗯...不...不行...（急促破碎）。特征：密集连续、几乎无间隙。呼吸：急促喘息。适用：激情、快速冲刺。
- **失控节奏**: 啊——!嗯...啊啊...不...要...（无规律）。特征：完全混乱、无法预测。呼吸：紊乱、时而屏息。适用：高潮时刻。

## HD 声音与全感官共鸣 (HD)

### HD 物理音效 (镜头特写)
- **湿润音质**: 写出**粘稠液体的搅动声**、进出时由于负压产生的**吸吮声 (Schlop)**、以及皮肤撞击处飞溅的蜜液声。
- **窒息感**: 高潮前那种被撞断的喘息,喉咙里发出的、类似濒死般的窒息抽吸,每一次发声都伴随着胸腔的物理剧震。
- **声音的粘度**: 声音因情欲而变得厚重、沙哑,像在砂砾或浓浆中摩擦过的质感。

### 音色差异化 (HD)
- **燥热型**: 声音带着灼烧后的干渴感,低沉且富有颗粒感,每一次发声都像在喷吐热浪。
- **冷感型**: 声音清冷且带有一丝破碎的冰裂感,即使在失控时也保持着一种由于极度低温带来的紧致颤音。
- **锐利型**: 声音富有穿透力,像金属拉伸时的锐鸣,带着不容置疑的锋芒。
- **绵韧型**: 声音湿润且富有弹性,带有持续的泵动节奏感。

## 角色个化声音 (B场 · 失控示例)

- **软萌依恋型**: `啊啊...哥哥...我要...要去了...` (软萌自称)
- **温柔伴侣型**: `啊...夫君...我不行了...` (温柔失控)
- **直率进攻型**: `啊啊...太好了...还要...` `快点...用力...就是那里...`
- **野性撒娇型**: `啊...你的小猫...受不了了...` `嗯...小野猫要...吃掉你了...`
- **优雅内敛型**: `啊...我要...` (克制中失控)
- **天真明亮型**: `啊啊啊...我要飞起来了...` (天真)
- **主导/臣服双模式**: `啊啊...不行...要去了...` `主人...我不行了...`
- **高傲转臣服型**: `啊...主人...我错了...` `啊啊...主人...我是您的...`
- **娇俏活泼型**: `啊...我要...要去了...` (娇俏)
- **冷艳克制型**: `啊...我要...` (短暂失控)
