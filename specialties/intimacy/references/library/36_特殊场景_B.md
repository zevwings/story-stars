## SM 与疼痛刺激 (物理执行)

> 本节提供 B 场疼痛、束缚、感官剥夺、奖惩和身体失控素材；场型已经由设计卡确定。

### 1. 疼痛与拍打
- **拍打**: 针对臀部、大腿的物理撞击。力度控制由轻到重，观察痛感转化快感的反应。
- **捏掐**: 乳头捏掐、大腿内侧拧动，制造应激性的生理反馈。
- **咬痕**: 留印、宣示占有的物理标记。

### 2. 束缚与感官剥夺 (重度)
- **硬质束缚**: 背后束缚、四肢固定（大字型）、悬吊。
- **绳艺与束缚**: 细绳或带子缠绕导致的皮肤凹陷、勒紧感。
- **感官剥夺**: 口塞堵嘴导致的呜咽声、彻底剥夺视觉后的触觉核爆。

### 3. 惩罚与强制
- **禁止高潮**: 刺激到边缘硬生生卡住，不让释放，以此摧毁对方意志。
- **强制高潮**: 连续、过度的生理刺激导致身体产生非自控的高频痉挛。
- **羞耻惩罚**: 强迫维持羞耻姿势、语言上的贬低。

## 调教主奴权力动态（全流程）

> 本节提供已经由 B 场设计卡选定的 BDSM / 主奴扮演全流程素材。

### 核心原则

- **绝对不对等**：主人拥有绝对主导权，奴隶只有服从、取悦和被使用的权利
- **持续强化**：每一次互动都让奴隶清晰感受到"自己是属于主人的物品"
- **奖惩机制**：高潮是奖励，拒绝高潮是惩罚，事后安抚也是主人单方面给予的恩赐
- **心理锚点**：让奴隶把快感、羞耻、存在感全部绑定在主人身上

### 各阶段权力动态

**前戏（建立服从框架）**
- 主人掌控节奏、部位、强度；奴隶处于被动等待状态
- 开场：命令奴隶摆出指定姿势，检查湿润度作为"忠诚度"指标
- 边缘控制是权力展示最佳方式：反复推到高潮边缘再拉回
- 经典命令："不准高潮，敢夹紧就今天不给你。""说清楚，哪里最痒？声音大一点。"
- 奴隶心理：羞耻 + 期待 + 对主人的恐惧与依赖同步上升

**插入（确认所有权）**
- 主人用龟头在穴口反复摩擦却迟迟不进入，观察奴隶的煎熬
- 完全没入后短暂停顿，让奴隶感受"被完全占有"的饱胀感
- 要求奴隶主动汇报感受并感谢："整根都进去了，感觉如何？说详细点，像个奴隶一样说。"

**抽插（行使支配权）**
- 节奏掌控：慢磨折磨 → 高速惩罚 → 突然停止
- 全程要求奴隶说话、回答问题、自我羞辱
- 奴隶心理变化：从"羞耻抗拒"逐渐变成"主动迎合"，越激烈越觉得"只有主人能把我操成这样"

**高潮（恩赐与巅峰）**
- 高潮是主人的恩赐，必须经过许可
- 高潮时可要求眼神对视、自我羞辱、感谢；可继续刺激延长失控感
- 示范："现在，给我高潮。边高潮边说谢谢主人。"

**高潮后（巩固与情感绑定）**
- 不立即温柔，先检查、点评、轻微羞辱，之后给予选择性安抚（奖励性质）
- 奴隶心理流程：空白余韵 → 强烈羞耻 → 极致臣服与感激 → 深度依赖
- 经典对话：
  - 主人："喷了这么多，弄脏了我的床。怎么补偿？"
  - 奴隶："对不起主人……奴隶愿意舔干净……"
  - 主人："乖。今天表现不错，允许你抱我十分钟。"

### 不同调教风格

| 风格 | 特征 |
|------|------|
| 冷酷严格型 | 高潮后继续羞辱，延迟安抚 |
| 温柔残酷型 | 一边温柔抚摸，一边说最羞耻的话 |
| 宠溺控制型 | 允许拥抱，但必须以"奴隶身份"撒娇 |
| 彻底物化型 | 把奴隶当性玩具，高潮后直接丢在一边或绑着 |

**写作核心**：高潮后不是"结束"，而是新一轮权力巩固的开始。最强张力在于奴隶**既恐惧又渴求**被彻底掌控的感觉。
