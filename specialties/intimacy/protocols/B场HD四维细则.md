# B 场 HD 四维细则

> 四维只描述公共写作维度, 不预设任何题材机制。

## 一、身体

- 一段只保留一个主要身体反馈。
- 动作必须有承受方反应、主动方判断和节奏变化。
- 不用动作名称替代发生过程。

## 二、感官

- 每一阶段突出一到两个感官。
- 感官变化与动作、心理和空间变化对位。
- 不全程维持同一强度。

## 三、心理与关系

- 写清谁先越线、谁确认、谁接住、谁改变决定。
- 人物反应必须继承角色卡, 不写成统一模板。
- 权力变化必须有现实关系依据和可停空间。

## 四、项目机制

只有项目真源已经定义时才进入本维度:

- 从 `story/genres/` 确认题材承诺。
- 从 `$SPECIALTY_ROOT/mechanisms/` 确认机制、边界和授权。
- 从 `$SPECIALTY_ROOT/references/` 取得本项目允许的表达素材。
- 从 `worldbuilding/` 和角色卡确认正式事实。

项目机制必须改变人物感受、判断、节奏或后果；若只是替换名词, 应删除。公共规则不提供机制示例、等级或载体。

## 写后检查

- 四维是否围绕同一场景目标服务。
- 是否有某一维抢走人物体验。
- 是否出现项目没有定义的机制或素材。
- 是否留下可追踪的场后变化。
