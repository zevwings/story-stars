# B 场 HD 节奏镜头

> 本页提供题材中立的节奏与镜头协议。具体动作、词汇和项目机制从项目 `$SPECIALTY_ROOT/references/` 读取。

## 五段节奏

| 阶段 | 功能 | 镜头重点 |
|---|---|---|
| 铺垫 | 建立愿意、动机与空间 | 距离、视线、手势、环境 |
| 攀升 | 形成主要节奏 | 动作与回应的往复 |
| 压拍 | 暂停、确认或改变主导权 | 呼吸、停顿、表情、语言 |
| 峰值 | 完成当次主要兑现 | 最少镜头、最高信息密度 |
| 余韵 | 回稳并落后果 | 照料、沉默、关系与现实回流 |

比例由设计卡决定, 不固定套用。

## 与七幕编排的关系

五段是宏观节奏层, 用于检查整场的压力曲线与镜头密度；HD planner 的七幕是执行编排层, 用于把人物选择和状态变化落到设计卡。两者不是两套互斥流程, 按下表映射:

| 五段宏观节奏 | 七幕执行编排 |
|---|---|
| 铺垫 | 起势、定锚 |
| 攀升 | 深入 |
| 压拍 | 律动、攀升 |
| 峰值 | 高点 |
| 余韵 | 收束 |

七幕中的“攀升”是压拍后的再抬升, 属五段“压拍”内部的蓄压与转折, 不等同于五段中从铺垫进入主要节奏的“攀升”。设计时以七幕落节点, 写后以五段查整体曲线。

## 镜头规则

- 全景交代空间、距离与整体姿态。
- 中景承载互动、主动权和人物判断。
- 特写只抓会改变读者判断的局部反应。
- 连续三段使用同一机位、句式或感官时必须切换。
- 峰值前后都要留出完整停顿, 避免全程高强度。

## 项目机制

项目机制参与节奏时, 只按项目设计卡规定的节点出现。公共规则不规定其阶段、外显、等级或镜头形态。

## 禁止

- 不用固定数字节奏代替人物互动。
- 不用高分贝或短句堆叠代替升级。
- 不让环境和项目机制抢走人物反应。
- 不从公共参考库补项目未登记的动作或素材。
