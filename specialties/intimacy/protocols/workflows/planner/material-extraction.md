# 正向 B 场素材提取协议

> 本文件用于从人物卡、亲密档案和主文上下文中提取本场可用素材。素材只服务 `design.b.md`, 不替代正式真源。

## 提取维度

### 1. 人物边界

- 角色当前关系阶段。
- 可接受的主动方式、退让方式和安抚方式。
- 已确认的欲望语法、主导感官通道、停止方式与触底防御。
- 语言受限时已确认的非语言真意信号与身份回归方式。
- 禁写提醒。
- 称呼、语气、沉默和回避方式。

### 2. 项目题材载体

- 项目机制的已确认属性。
- 参与角色的当前机制状态与阶段。
- 项目专项机制目标。
- 项目机制的作用路径、器物或环境反馈；只从项目真源提取。

### 3. 主文衔接

- 入戏点。
- 出戏点。
- 占位符位置。
- 前后段情绪气口。

### 4. 场景感官

- 空间私密度、可能进入者与退出路径。
- 光影。
- 声音预算与另一条可用表达通道。
- 温度。
- 现实时间预算与外部打断点。
- 家具、承托面、门窗、遮蔽物与通行动线。
- 衣料、灯影、风、花、雨、水汽等项目允许且可承接余温的物件。

### 5. 场后连续性

- 身体疲劳、睡眠、清理、照护与可见痕迹。
- 衣装、道具、饰物、家具和空间的损耗、遗落、归属与复原。
- 次日工作、交通、训练、社交与共同生活安排。
- 谁知道、谁可能察觉、关系与权限变化。

## 提取步骤

1. 定位参与角色的静态人物卡、动态状态和已有亲密档案。
2. 从 `design.a.md` 提取大纲已经确认的临界动作、场景功能和人物关系。
3. 从主文上下文提取场景物件和情绪余波。
4. 多人场逐关系提取权限，逐人提取愿意、停止、状态与场后位置，不用群体概括替代。
5. 只保留本场会用到的少量锚点；连续性只记录后文不知道就会写错的变化。
6. 将锚点写入 `design.b.md` 的角色调用摘要、现实约束、逐幕编排、感官调性或场后连续性。

## 禁止项

- 不臆造角色身体设定、状态收益或亲密前史。
- 不从参考素材借事实。
- 不把素材清单膨胀成正文。
- 不把黑暗 / 压迫场素材混入正向 B 场。
