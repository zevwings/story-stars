# 正向 B 场脚本生成协议

> 本文件用于把 `design.a.md` 遗留的关系位移、状态反馈和场面承接整理进 `design.b.md`。不得派生第二份执行大纲。

## 脚本编排原则

- **关系先行**: 先写这场之后关系发生什么变化, 再写亲密如何承载它。
- **项目机制落点**: 若项目机制参与本场, 必须按项目真源写清触发、作用与后果。
- **感官节奏**: 感官描写服务人物状态和场面推进, 不堆砌素材。
- **镜头焦点**: 每个切片只抓一个主要焦点, 避免平均描写。
- **收束回接**: 设计时就写清如何回到主文叙事。

## 编排要求

全案编排以 [choreography logic](choreography-logic.md) 的七幕表（起势 / 定锚 / 深入 / 律动 / 攀升 / 高点 / 收束）为准, `design.b.md` 输出七幕全案。宏观节奏核对以 [B场HD节奏镜头](../../B场HD节奏镜头.md) 的五段映射表为准。

## 输出到 design.b.md

建议整理为:

```markdown
## 【编剧全案】（七幕）
- 起势：
- 定锚：
- 深入：
- 律动：
- 攀升：
- 高点：
- 收束：

## 【写手覆盖指令】
- 本场主抓手：
- 项目题材载体：
- 关系后果：
- 禁写项：
- 回接方式：
```

## 禁止项

- 不把技术脚本写成正文。
- 不生成平行 `outline.md`。
- 不绕过 [亲密边界与红线](../../亲密边界与红线.md)。
- 不把黑暗 / 压迫场纳入正向 B 场。
