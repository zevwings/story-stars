# 黑暗 HD 压迫场正文执行协议

> 本文件保存随项目固定的黑暗场正文细节。触发方式、主入口、写入位置与是否回写主文由当前 runtime Skill 在解析 `$SPECIALTY_ROOT` 后执行。
> 黑暗 HD 的边界、口径、读取顺序与写后收束，以 [黑暗HD流程](../../黑暗HD流程.md) 为最高规则。

## 目标

- 把 `design.b.dark.md` 稳定落成黑暗 HD 18+ 正文。
- 保证与主文占位符前后文、人称、时态、事实一致。
- 让压迫来源、选择权曲线、身体反应来源、心理真相与后果都真正落地。

## 执行顺序

1. 先读 `design.b.dark.md`，再写 `draft.md`；只有作者明确要求定稿时，再落 `final.md`。
2. 按 `design.b.dark.md` 的伤害链条编排推进，不套正向“前戏—高潮—余韵”主轴。
3. 做质量自检并提示必要的后续同步项。

## 正文关注点

- 入场压迫是否成立：人物为什么无法离开、无法拒绝、无法求救。
- 控制方式是否具体：药、强制限制、权力、状态差、项目机制、威胁或环境如何剥夺选择。
- 身体失控是否有来源：外部作用、强制限制、项目机制、作用路径、资源化机制、恐惧应激或身体规律，且持续标明这不是愿意。
- 心理真相是否持续在场：抗拒、羞耻、恐惧、厌恶、麻木、自我抽离或求生，至少一到两个作主轴。
- 双声部是否对位：受害方痛苦（[93_黑暗HD受害方声部与后果](../../../references/library/93_黑暗HD受害方声部与后果.md)）与压迫方快感（[94_黑暗HD压迫方视角](../../../references/library/94_黑暗HD压迫方视角.md)）就同一细节相反赋义，两声部同重量。
- 事件是否留下后果：痕迹、伤势、状态污染、机制层创伤、关系破裂、证据线或清算线。

## 强制写作约束

- **双声部铁律**：快感是压迫方的、账单是受害方的；文本距离不认同压迫方；压迫方写得越自洽，受害方声部越要以同等重量在场。
- **身体反应不等于愿意**：每一段身体失控后，补一处心理真相；不把失控、语言破碎、生理高潮、配合或沉默写成同意、享受或关系升温。
- **压迫方无裂缝为默认**：除非 `design.b.dark.md` 指定“带匮乏”变体，否则不写压迫方良心戏替读者找补。
- **不甜化收尾**：事后是现实回流与伤害落地，不是甜蜜余韵。

## 质量自检

- **对照准则**：对照 [黑暗HD流程](../../黑暗HD流程.md) 的「写后检查」与 [亲密写前写后校验](../../亲密写前写后校验.md) 做最终核对。
- **声部校验**：受害方声部（93_黑暗HD受害方声部与后果）与压迫方声部（94_黑暗HD压迫方视角）是否都在场、是否对位、是否同重量。
- **不洗白校验**：加害者视角是否越过“加害者认知”变成叙述真理；话术是否被误读成情话。
- **后果校验**：是否至少落一个身体 / 心理 / 关系 / 剧情后果。
- **衔接校验**：是否严格依据 `design.b.dark.md`，没有凭空补重大设定。
- **存储校验**：正文是否写到正确路径？是否误回写主文？是否误落成 `design.b.md` 口径？
