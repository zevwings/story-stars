# PL-S-026｜万安影视文化艺人压迫与咨询显影

## 节点信息

- **节点 ID**：`PL-S-026`
- **线路类型**：副线
- **节点形态**：推进节点
- **推进结构**：递进链
- **节点定位**：由程叙的现实危机与咨询入口显影万安影视文化把正常培养与灰黑新人包装并置、利用合同资源压迫艺人并向私人项目和娱乐场所定向提供的模式，再与乔宁、梁予安及何知远的独立案件交叉验证。
- **归属目录**：`story/plotlines/副线/组织/万安影视文化/`
- **主体类型**：势力线
- **归档类型**：组织
- **归档主体**：万安影视文化
- **中心人物**：程叙、白玥及成年艺人
- **当前状态**：pending

## 前置状态

- **人物前置**：裴兰馨负责万安影视文化端人员控制，任群是外部危机公关与有限行止执行者；程叙、乔宁、梁予安与何知远均为成年人，且不合并为同一受害经历；乔宁是万安旗下上升期影视演员，楚辞是第一次被公司安排陪侍、在具体换人后仍作出当次真实选择的新人女艺人，杨柳是外部偶像／综艺艺人，只经项目发行、宣传与选角资源接口同该网络发生交叉。会所外围另保留以包装成本受限的成年新人模特施工位，姓名与最终关系位置另行确认。
- **关系前置**：程叙与裴兰馨之间存在无法有效拒绝的职权与能力压迫；裴兰馨其余利益型自愿关系必须逐段独立判定，不能由程叙一案反推全部关系。
- **世界观 / 势力前置**：林语心理咨询工作室只承担现实风险评估、咨询、转介与授权协作；医疗、管理局和司法分别承担诊断、异常能力核验与取证追责。
- **线索前置**：合同、项目与公关处置形成现实压迫痕迹；不同艺人重复出现求助紧迫感异常衰减或无法完成某个关键发声行为。

## 必须发生

- 程叙自杀未遂后由江州第一医院先完成现实医疗处置，稳定并同意后进入林语心理咨询工作室；晏林是本案的咨询师，但工作室不得以一次咨询直接诊断抑制或行止能力伤害。
- 程叙分阶段提供本人经历与可核验材料；梁予安的正规诊断和治疗记录、何知远的历史材料及乔宁主动外送的证据分别进入交叉验证。
- 调查区分裴兰馨压低既有警觉、愤怒、拒绝勇气与求助紧迫感的“心潮渐息”，以及任群针对少数当下具体行为施加的“令行禁止”，不把二者写成永久封口、群体控心或绝对服从。
- 乔宁拒绝身体换资源后被定向提供并遭受侵害，但她存活并亲自完成关键证据转移；具体接收者、裴兰馨与任群分别按自身知情和行为追责。
- 涉案管理层以短期签约、培训、形象包装和私人项目吸收部分涉世不深的成年艺人、模特，并把其中少数人安排进入顾清言公开经营的娱乐场所；正常商务出席、社交陪伴和具体身体行为分别授权。
- 新人模特可以把包装成本和指定商务理解为公司培养的正常回报，资源断档艺人也可以把交换理解为行业现实；她们不必主动求助、自称受害者或立即停止工作。清醒说法与梦境中真实存在的账单压力、资源撤回和影像恐惧只形成早期异常方向。
- 晏林在会所阶段取得的灰色梦境材料不能替代程叙、乔宁、梁予安、何知远的独立材料，也不能把私人关系、咨询、医疗与司法取证合并。
- 万安影视文化从部分私人项目和共同场所取得收益，但普通艺人培养、正常商业活动与未涉案员工继续真实存在。
- 杨柳的拒绝陪侍订单与后续职业压力证明压迫可以沿外部合作项目和资源接口延伸，但她不并入万安影视文化内部艺人个案，也不能据此把普通合作项目整体犯罪化。
- 受害者可以选择匿名、暂停陈述、继续治疗或拒绝公开；案件显影不以公开创伤、立即复工或与施害者对质为条件。
- 万安影视文化进入清算时，涉案管理层退出，合法项目与工资版权先由江州城市投资集团临时托管接口保全；每名艺人分别决定解约、转签、独立、暂停、退出或自愿进入重组后的普通职业服务。

## 本线变化

- **人物变化**：程叙从被孤立和失去行动紧迫感的受压者，转为能够在医疗、咨询与司法边界内分阶段作出选择的存活当事人；乔宁的主动证据转移获得正式案件位置。
- **关系变化**：裴兰馨与任群不再能以亲密关系、资源交换、危机公关或艺人表面配合遮蔽权力差与直接责任。
- **知情范围变化**：工作室和调查者由单一个案及会所外围的灰色异常方向看到重复方法，但受害者身份、诊断、亲密经历、梦境内容与未授权证言继续受保护。
- **世界观 / 势力变化**：万安影视文化犯罪链由行业传闻转为可由合同、私人项目、场所、公关、医疗、通讯与精神干涉痕迹共同验证的责任结构；合法项目与从业者经托管保全，原人员控制结构不被集团原样继承。

- [ ] 正文或定稿摘要以程叙、梁予安、何知远和乔宁中至少三人的独立材料验证重复压迫方法。
- [ ] 正文或定稿摘要拆分裴兰馨、任群及乔宁案具体接收者的行为与责任，不用单一反派概括整条链。
- [ ] 正文或定稿摘要保留至少一名存活受害者对陈述、公开、治疗与职业路径的自主选择。
- [ ] 正文或定稿摘要没有把抑郁、自伤、自杀风险或死亡单一归因于星辰能力。
- [ ] 正文或定稿摘要区分真实长期培养、灰黑短期包装及进入顾清言场所的少数私人项目。
- [ ] 正文或定稿摘要明确会所外围梦境只提供异常方向，正式显影仍由独立当事人材料和现实记录完成。
- [ ] 正文或定稿摘要明确托管不等于接收艺人人身与职业决定，每名存活当事人的医疗、作证、解约和后续工作分别选择。

- 不描写可模仿的自杀方法，不以自杀未遂或历史死亡制造单纯刺激。
- 不把咨询工作室写成诊断异能、侦讯取证或强迫来访者作证的机构。
- 不把身体反应、求生配合、资源获益或表面主动写成有效同意。
