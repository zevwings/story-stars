# PL-S-121｜风归熟客回流与逐次授权回路

> 本页只保存风归人员由前期轮换转为舒歆、言溪固定双主位，在二人因真实职业档期缺席时调用临时替补，并于会所集中安排结束时关闭固定主位与组织调度的熟客维护回路；每次、每项活动仍须重新授权。两人其后的第二层私人回流分别由 `PL-I-044`、`PL-I-045` 承接；万芳的一次替补和田恬的阶段内校准则随阶段完成，不保留回流接口。

## 节点信息

- **节点 ID**：`PL-S-121`
- **线路类型**：副线
- **阶段归属**：阶段四
- **节点形态**：回路节点
- **节点定位**：第一次止损后，顾清言以正常客户维护、职业项目和场地协调为现实外观，先安排多名风归成年从业者与晏林逐次接触。前几次之后晏林明确不再主动换人，舒歆／猫猫与言溪／梦露成为会所阶段固定双主位；二人因商演、商业拍摄、漫展等真实职业档期缺席时，顾清言才临时调用替补。风归—私域—熟客由一次性介绍转为有固定主位、也保留职业缺席替补的阶段回路；会所集中安排结束时，这套主位、替补和顾清言代为排期的机制一并关闭，不继续充当两人后续私人关系的入口。
- **归属目录**：`story/plotlines/副线/组织/风归/`
- **主体类型**：势力线
- **归档类型**：组织
- **归档主体**：风归
- **中心人物**：顾清言、晏林、舒歆、言溪、田恬及风归成年从业者
- **当前状态**：pending

## 前置状态

- **人物前置**：顾清言是风归创始人、实际控制人兼总经理；进入本回路的具名人员首次出场时均已成年。田恬首次出场时已经年满 18 周岁，以艺名“甜甜”从事甜欲幻想类 Cos、角色短视频及相关商业内容。
- **关系前置**：顾清言与晏林只完成第一次偶发止损，尚未形成稳定同盟；晏林继续出入私域须由真实会所消费、普通熟客身份与正常客户维护共同解释，但场所消费不构成他向当事人支付陪侍费用。
- **世界观 / 势力前置**：风归有真实公开业务，也为顾清言的场所网络提供部分成年职业合作人员；公开项目、场所接收与具体私人行为分别承担责任。
- **线索前置**：晏林只知道风归与私域存在稳定人员接口，不掌握每人的合同、资源处境与完整责任规模。

## 必须发生

- 顾清言反复以正常项目、客户维护、场地与时间协调安排风归成年从业者与晏林接触；这些面向晏林的安排全部由顾清言提出，晏林与当事人之间不存在付费关系。其他客户与从业者之间仍可另行成立有偿陪侍。
- 猫猫是本回路第一名实际接待晏林的人；甜甜及其他具名人物随后进入前期轮换并体现各自边界。甜甜的成人视频模仿与主动服侍偏好按 `PL-I-050` 完成现实校准；此后晏林明确不再主动换人，舒歆／猫猫与言溪／梦露固定承担主要会所陪伴。
- 周语棠／海棠在前期轮换中完成一次逐项边界校准：她可以接受当次 A 档轻度亲密，同时明确不开放 B／C 档与影像权限。该次接受不使她取得固定主位，也不产生再次出现或升档承诺。
- 孔蔓盈／盈盈先在前期轮换中以舞蹈和动态热场完成首次接触，之后至少一次在舒歆或言溪因真实职业档期缺席时临时补位，形成与固定双主位有明确区别的次复现。经过分离的多次接触后，她与晏林实际建立部分 C 档范围；相应权力称呼或情欲自称由她本人主动调用，但不扩张为完整 C、影像、留痕或多人权限。
- 钱韵拒绝固定重复安排并进入三周停排后，万芳／慢慢作为无声替补完成一次面向晏林的非付费接待，并在逐项确认下完成当次 B 档接触。该次只证明风归能够迅速替换人员，也证明替补本人仍有独立选择；不为万芳建立复现、私下联系、其他入口或部分 C 档已经开放的结果。
- 舒歆与言溪继续承接商业拍摄、商演、漫展及其他正常职业项目；一人或两人因真实工作档期缺席时，顾清言可以临时安排既有人员替补。替补只承接当次，不取得固定主位，也不使晏林恢复主动轮换新人。
- 顾清言只能提出人选、协调时间与提供场所，不能替任何人同意公开工作、社交陪同、陪侍、拍摄保存、第三方观看或具体身体行为。
- 晏林与每名从业者分别确认当次事项；既往接受、熟客关系、固定主位和再次出现都不产生后续默认权限。
- 有限同盟形成后，舒歆、言溪的固定主位与职业缺席替补仍可在阶段四其余时间低频运行；会所集中安排结束时，固定主位、临时替补和顾清言代为排期一并停止。
- 会所集中安排结束时，田恬的阶段内有限复现关系和万芳的一次替补接口同时完成；两人不转入第二层、第三层，也不以客串、普通熟人或私人回流方式再出现。
- 组织回路结束后，风归不再代替舒歆、言溪维持与晏林的私人关系；两人须经过真实分离，再分别以本人职业、档期、普通联系和当次意愿独立回归，具体关系变化由 `PL-I-044`、`PL-I-045` 承接。

## 本线变化

- **人物变化**：舒歆、言溪从主要复现人物推进为会所阶段固定双主位；田恬在早期轮换及阶段内有限复现中完成主动服侍偏好与成人视频模仿的现实校准，随后随会所阶段结束退出叙事；周语棠完成一次“部分接受不等于全面开放”的逐项边界显影；孔蔓盈由前期轮换进入一次真实职业缺席替补，并在分离的多次接触中建立部分 C 档范围，但仍不取得固定主位；万芳在钱韵停排后完成一次无声补位与当次 B 档接触，不建立复现结果，并在阶段结束后退出叙事；其他具名人员保留各自的边界显影或替补功能。
- **关系变化**：晏林停止主动换人，顾清言据此固定舒歆与言溪并维持非付费接待接口；该接口只属于会所阶段，结束后不再提供自动排期、主位恢复或私人关系续期。舒歆、言溪其后的第二层关系分别由本人独立回归成立。
- **知情范围变化**：晏林确认人员选择、复现与替换存在组织性，但仍不知道每人的合同细节、受压程度与风归完整责任规模。
- **世界观 / 势力变化**：风归—私域—熟客从背景设定变为有固定主位和职业档期替补的稳定回路；晏林的非付费例外不取消私域面对其他客户仍可能存在的有偿陪侍。
