# PL-S-184｜实验对象筛选标准与接收决定

- **线路类型**：副线
- **阶段归属**：阶段五
- **节点形态**：推进节点
- **推进结构**：递进链
- **节点定位**：裴家四名核心成员共同确定实验对象价值方向、医院接收条件与转运要求；对象来源包括齐心—陆佳凝交付的境内目标、园区按医院方向另行筛出的少数人员，以及前两路受阻后由旅游端临时筛出的疑似高价值契约者。

## 前置状态

- **人物前置**：裴家四人已共同参与金洲医院暗面用途与实验方向决策；具体对象仍由不同来源和执行者分段处理。
- **关系前置**：四人利益一致，分工用于区分责任，不制造受蒙蔽成员、良知派或内部路线冲突。
- **世界观 / 势力前置**：人体实验只接收少数高价值对象；普通艺人、招聘对象或园区人员不会因进入相关网络而自动成为实验对象。
- **线索前置**：`PL-M-022` 已建立至少一次对象改向与医院接收接口，但尚未完成裴家筛选决策责任。

## 必须发生

- 四人共同商议哪些对象具有实验价值、医院接收所需的身体、精神与契约条件、哪些前期资料足以支持接收，以及不同来源对象应进入何种转运接口。
- 裴怀安提出技术价值与医院接收标准，裴怀民把共同决定转化为预算、机构、交通和外部接口安排，裴兰馨提供艺人目标与内部用药反馈，裴崇礼决定方向、对象风险和是否继续投入。
- 对象来源分阶段保留三类：齐心—陆佳凝一侧直接交付的少数高价值目标，境外园区按医院方向另行筛出的少数人员，以及齐陆和园区来源受压后由旅游端临时筛选并转送的疑似高价值契约者。三类来源不要求同批出现，均以方向级价值判断进入医院复筛。
- 具体标记、合法出境、途中交接、园区筛出和医院接收可以由刘秉文、陆佳凝、园区人员与医院人员分段执行；四人共同决策不等于四人亲自押运。

## 本线变化

- **人物变化**：裴家四人分别进入最高决策、技术标准、经营转运与艺人目标接口责任。
- **关系变化**：家族共同决策与外围执行者的具体行为分别成立，任何一方不替另一方吸收责任。
- **知情范围变化**：四人共同知道转送服务违法人体实验；外围执行者只按本人接触的筛选、包装、交接或接收环节认定知情。
- **世界观 / 势力变化**：医院接收形成跨来源、低数量、定向筛选机制；晚期旅游端只承担少量对象的发现、控制与转送。

## 完成判据

- [ ] 四人共同商议对象价值、接收标准和转运结构，并共同知道实验目的。
- [ ] 齐心—陆佳凝直接交付、园区合作筛出与晚期旅游端临时转送三类来源均被正式保留。
- [ ] 共同决策与具体执行分别归责，没有量化评分表或固定配额。
