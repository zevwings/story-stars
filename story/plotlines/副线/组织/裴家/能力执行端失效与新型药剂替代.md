# PL-S-113｜既有境外实验药剂转入国内使用

## 节点信息

- **节点 ID**：`PL-S-113`
- **线路类型**：副线
- **阶段归属**：阶段四
- **节点形态**：推进节点
- **推进结构**：单点
- **节点定位**：白玥执行端在杨柳任务中失败并停止响应长期匿名联系人后，裴家在不知道管理局已经介入的情况下，把此前已在境外研发、试制和小批量生产的未成熟违禁精神药剂转入国内使用，形成万安公司内供与外部客户两条渠道。
- **归属目录**：`story/plotlines/副线/组织/裴家/`
- **主体类型**：势力线
- **归档类型**：组织
- **归档主体**：裴家
- **中心人物**：裴家决策接口、裴兰馨、裴怀民及相关供药参与者
- **当前状态**：pending

## 前置状态

- **人物前置**：白玥只知道本人收到的长期匿名指令，不知道联系人、具体客户、真实上游或本人波动数据的研究用途；她已经停止响应，但未向裴家暴露入案或保护状态。
- **关系前置**：白玥不参与药剂替代，裴家也不能由执行端失联确认管理局、晏林立场或保护地点。
- **世界观 / 势力前置**：药剂在白玥失联前已完成境外研发、试制、小批量生产与人体实验，但没有面向国内终端客户销售；药剂不恢复或增幅星辰之力。
- **线索前置**：私域任务失败、白玥停止响应，使裴家同时失去外部能力执行路径和天然欲望权柄的持续对照数据来源。

## 必须发生

- 裴家只根据任务失败和白玥停止响应判断能力执行端失效与暴露风险，不得由此确认管理局介入。
- 裴家确认持续对照样本中断；这只推动既有药剂转入国内使用与实测，不得倒写成白玥导致药剂诞生或裴家从此才开始研究。
- 裴家把既有实验性药剂转入国内，而不是从此才开始研发、生产或实验。
- 国内形成两条渠道：裴兰馨直接带入万安影视文化的公司内供，以及通过暗色星辰独立药剂服务、分销者或其他局部交易接口提供给外部客户。
- 燕若淇在执行端失效前已受欲望权柄干预，失效后才转入公司内供；杨柳后续遭霍临川用药属于外部客户路径。
- 两条渠道上游可以相同，但流转、虚假说明、直接使用、反馈与后续侵害分别归责。

## 本线变化

- **人物变化**：裴家从同时依赖外部能力执行者与天然权柄对照样本，转为部署既有实验性药剂并扩大现实实测；裴兰馨和裴怀民分别进入公司内供与外部客户接口。
- **关系变化**：白玥与药剂部署彻底分开，她既不知道也不参与后续药剂决策。
- **知情范围变化**：裴家不知道管理局介入；外部客户不自动知道完整上游、配方与长期风险。
- **世界观 / 势力变化**：药剂境外研发实验与国内两路部署的时间线正式闭合。

## 完成判据

- [ ] 药剂在白玥执行端失效前已经存在，失效只触发国内部署。
- [ ] 白玥的天然权柄波动只作为对照样本；样本中断不是药剂诞生原因。
- [ ] 公司内供与外部客户两条渠道分别成立并分别归责。
- [ ] 白玥不知道、未参与且不能单独证明药剂替代与上游。
- [ ] 未恢复训练馆补剂线、旧异常药剂或统一黑市供药平台。
