# PL-S-301｜皮蛋建立有限传念沟通回路

## 节点信息

- **节点 ID**：`PL-S-301`
- **线路类型**：副线
- **阶段归属**：阶段一
- **节点形态**：回路节点
- **节点定位**：皮蛋完成非人契主登记后，在数周以上的共同生活、重复接触和普通学习中逐步适应晏林使用的人类词音，把有限词音与熟悉人物、具体物体、动作、位置及当前身体状态建立稳定对应，并沿灵犀连接使用基础传念形成可反复调用的有限沟通回路。
- **归属目录**：`story/plotlines/副线/人物/晏林/`
- **主体类型**：人物线
- **归档类型**：人物
- **归档主体**：晏林
- **中心人物**：皮蛋、晏林
- **当前状态**：pending

## 前置状态

- **人物前置**：`PL-S-299` 已使皮蛋成为持有灵犀方向的星契动物；初次连接只能呈现原始情绪、感官片段和简单趋避意向。
- **关系前置**：`PL-S-300` 已完成非人契主登记，皮蛋继续由晏林照护；管理局只提供最低安全边界，不把日常语言适应变成强制能力训练或研究项目。
- **世界观 / 势力前置**：星契动物会通过非语言契约自知掌握已经成形能力的操作路径，但不会因结契直接获得人类语言。皮蛋需要通过现实时间中的普通学习建立有限词音—概念对应，再沿已经成立的精神连接以它已经会操作的基础传念表达自己真正理解和能够组织的具体概念。
- **线索前置**：无。

## 必须发生

- 皮蛋从灵犀与基础传念成形时就知道怎样建立、发送和停止自身一端的操作；沟通适应真正需要跨越数周以上的是人类词音、具体概念与现实情境之间的学习，不由一次测试、一次顿悟、一次精神连接或管理局教学直接完成。前期必须存在误解、概念混叠、表达失败或只能依靠现实情境猜测的阶段。
- 晏林从皮蛋已经熟悉的名字、食物、水、家、外出、回来、疼痛、害怕、喜欢和具体位置等现实对象开始，通过语音、动作、物体与结果反复对应，不教授文字、语法或抽象定义。
- 皮蛋逐步学会把少量熟悉词音与自身已有认知对应，并在主动表达时沿灵犀连接调用基础传念，发送人物、物体、动作、位置、身体状态和趋避方向组成的有限概念包。
- 晏林可以沿已经成立的连接以基础传念回应皮蛋能够理解的简单信息，但必须接受皮蛋可能误解、拒绝、分心或只回应其中一部分；传念不等于命令服从。
- 稳定回路形成后，皮蛋可以在熟悉生活情境中主动表达“谁／什么／去或不去／哪里／疼或怕／想要或拒绝”等有限组合，但不能形成完整句法、时间叙事、抽象因果、法律概念、复杂计划或人类式自我解释。
- 许知夏、许知秋及其他熟悉对象可以通过普通语言、动作和既有训练与皮蛋相处；皮蛋是否另行向她们建立灵犀连接由实际互动决定，不因共同生活自动复制与晏林之间的稳定沟通回路。

## 本线变化

- **人物变化**：皮蛋从只能发送原始情绪和趋避意向，推进到能够以有限词音—概念对应主动组织传念；它仍保持犬类认知，不成为会说话的人类意识。
- **关系变化**：晏林与皮蛋建立可在普通生活中反复调用、允许误解与拒绝的有限沟通回路，照护关系因此更准确，但不转化为控制、任务搭档或法律代理关系。
- **知情范围变化**：稳定沟通内容首先只存在于皮蛋与晏林的连接中；晏林对外转述仍是人类解释，不能被视为皮蛋原话、证言或客观事实。
- **世界观 / 势力变化**：星契动物的程序性能力自知与人类语义学习第一次被明确拆开：前者随已成形能力成立，后者仍须长期普通学习；由此验证灵犀连接与基础传念的分工。

## 完成判据

- [ ] 正文或定稿摘要明确沟通适应跨越数周以上，并出现至少一次真实误解或表达失败。
- [ ] 正文或定稿摘要明确皮蛋通过现实语音、动作、物体和结果反复对应，而不是结契后自动理解人类语言。
- [ ] 正文或定稿摘要明确长期学习补足的是词音与概念，不是教皮蛋怎样调用已经成形的灵犀或基础传念。
- [ ] 正文或定稿摘要明确灵犀负责建立跨物种理解连接，主动组织的信息由基础传念沿连接发送。
- [ ] 正文或定稿摘要至少呈现一次由熟悉人物、具体物体、动作、位置或当前状态组成的有限概念包。
- [ ] 正文或定稿摘要没有让皮蛋使用完整句法、解释复杂因果、叙述长段过去、理解制度或提供法律证言。
