# PL-S-158｜保护退出与有限监管印解除

## 节点信息

- **节点 ID**：`PL-S-158`
- **线路类型**：副线
- **阶段归属**：阶段五
- **节点形态**：推进节点
- **推进结构**：单点
- **节点定位**：在白玥完成责任分层、证据合作，并经历裴家独立强制控制事件后，管理局对保护和监管分别复核；即时保护转为本人可选的普通安全支持，有限监管印按预设条件正式解除。

## 前置状态

- **人物前置**：`PL-S-157`已将白玥的主动违规、合作贡献和后续受害事实分开处理；她具备合法收入、独立住所与离开保护环境的能力。
- **关系前置**：`PL-I-096`已建立双星和弦与双向秘密开放，`PL-S-306`已让晏林在裴家强控事件中守住不接管白玥主体的边界；两者都不代替管理局复核。
- **世界观 / 势力前置**：`PL-S-155`已预设印记期限、复核和解除条件；管理局而非晏林个人持有解除责任。
- **线索前置**：`PL-S-156`、`PL-S-159`、`PL-S-161`、`PL-S-162`已使案件证据不再依赖白玥持续处于高暴露保护状态。

## 必须发生

- 管理局分别复核“是否仍需要案件保护”与“有限监管印是否达到解除条件”，不将两者与白玥是否接受晏林的感情或身体关系绑定。
- 即时安全风险已降到可由普通安全方案承接；白玥可主动退出保护，也可保留不依赖私人关系的必要支持。
- 管理局核实白玥已完成条款期限、必要合作与责任处理，期间没有未授权精神连接、欲望施加或黑市接单行为；印记按记录程序解除。
- 晏林只能在技术上配合获批的解除操作，不能以保留印记为关系安全感，也不能以为白玥担心为由延期。
- 印记解除后，白玥的技术性被约束状态结束；她是否真正完成从复合奖励中的自我收束，必须由后续自由选择另行验证。

## 本线变化

- **人物变化**：白玥从被外在技术条款阻止违规，进入必须自己承担欲望、能力与选择后果的自由状态。
- **关系变化**：晏林与白玥之间不再存在技术执行者与被印者的当前关系；后续守界与亲密只能由双方自由选择维持。
- **知情范围变化**：解除结果进入必要程序记录；白玥的具体印记条款与私人关系仍不向外扩散。
- **世界观 / 势力变化**：有限监管印完成“自愿选择—定期复核—达条件解除”的闭环，不变成终身标记。

## 完成判据

- [ ] 保护退出与印记解除由管理局按两套条件分别复核。
- [ ] 白玥不需以接受晏林或任何私人关系换取退出与解除。
- [ ] 印记解除后，白玥具备合法收入、独立住所与实际离开能力。
- [ ] 本节点不以监管期间的“没有违规”直接证明白玥已完成内在自控。
