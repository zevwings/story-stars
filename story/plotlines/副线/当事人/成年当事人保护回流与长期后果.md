# PL-S-048｜成年当事人保护、回流与长期后果

## 节点信息

- **节点 ID**：`PL-S-048`
- **线路类型**：副线
- **节点形态**：回路节点
- **节点定位**：贯穿多案及责任清算前后；以不同成年当事人的医疗、住房、职业、名誉、证言、失联和关系选择，证明离开控制网络或发出求救不等于立即恢复自由。
- **归属目录**：`story/plotlines/副线/当事人/`
- **当前状态**：pending

## 前置状态

- **人物前置**：杨柳经历明确拒绝后的欲望诱导、即时救离与疗养保护，并在自主离院后因职业与收入压力有限接触原经纪及项目资源网络；她后续可以逐次自愿接受新的陪侍交易，但不重新履行最初拒绝的裴怀山订单；周晓莉从人口控制点逃跑并发出有限求救后遭抢先转移；其他成年当事人分别经历药物、精神控制或职权压迫。
- **关系前置**：当事人与主角、管理局、医疗和司法人员的接触不构成感恩、作证或进入私人关系的义务。
- **世界观 / 势力前置**：管理局处理契约危害，普通医疗、住房、劳动、法律与司法系统继续承担现实后果。
- **线索前置**：会所、万安影视文化、江州第一医院、疗养院及裴家切割已经提供多个不同后果入口。

## 必须发生

- 不同成年当事人对医疗、保护、陈述、交证、公开和职业恢复作出不同选择。
- 至少有人接受保护但拒绝正式作证，或只提供场所、中间人等有限信息而拒绝公开私人经历。
- 杨柳自主离院后，为恢复收入、处理既有合同并保住职业位置，与原经纪团队及旧项目资源接口恢复有限工作联系；在清醒、无能力影响、知道具体客户、报酬与基本安排且能够拒绝的前提下，她自愿接受第一笔新的陪侍交易。
- 霍临川作为与核心犯罪链无直接关系的成年富商、非契约者，先后两次通过经纪团队提出独立邀请；杨柳两次明确拒绝，霍临川均当次停止，不以撤资、封杀、合同或名誉后果追罚。第三次以新订单重新提出时，杨柳在仍可拒绝的状态下主动接受。
- 杨柳接受霍临川的重度 C 陪侍时，在入场前作出一次完整总授权：预先排除不可逆伤害、影像把柄和身份公开，场内不逐项确认，由霍临川完全主导，杨柳完全把自己交给对方处置；真实停止信号持续有效，一旦使用必须立即停止。该总授权只覆盖当次，不自动延续到下一次交易。
- 霍临川之外的后续交易同样不重新履行最初被拒绝的裴怀山订单，也不由白玥参与；每次分别确认客户、报酬、总授权范围和退出方式，至少实际出现接受、拒绝、暂停或终止中的不同选择。
- 杨柳持续接受部分陪侍交易直至核心反派责任链落网。她不是调查机关安排的卧底；收入与职业收益不抹除结构失衡，持续交易也不能被用于否定第一次拒绝或已授权陈述。
- 调查只使用杨柳自愿提供的经纪联络、客户安排、项目资源和拒绝后仍被安排等有限材料；她不必停止交易、公开完整私人经历或证明完整犯罪网络，才能取得证言可信度与法律保护。
- 核心反派落网、旧资源网络失去主要控制能力后，杨柳主动停止陪侍、与原经纪团队切割，承担停工、合同、名誉与职业资源损失，随后转入新的普通经纪合作并逐步复工。
- 药物、交易、职业或舆论记录可能被用于质疑当事人可信度，调查不得以此自动否定其陈述。
- 杨柳在第一年第四季度获即时救离，随后分别决定普通医疗、疗养保护、探望、有限陈述与离院；离院后因职业与收入压力逐次自愿接受部分陪侍交易，直至核心反派落网后主动退出并切割旧团队。
- 周晓莉在逃离人口控制点并发出有限求救后，于正式保护闭环前被刘斌文抢先转移；不能立即追回构成持续现实损失。
- 程叙、乔宁或其他代表个案继续提供不同的保护、公开、证言或恢复选择，任何一人都不代表全部成年当事人。
- 核心责任人被追责后，部分生活损失、关系破裂、职业阻断和黑市残链仍然存在。

## 本线变化

- **人物变化**：杨柳取得保护环境中的探望、陈述与离院决定权，在职业回流中保留逐次接受、拒绝、暂停和退出权，并在现实退出条件形成后主动停止陪侍、切割旧团队；周晓莉以主动逃跑和求救留下可追查痕迹；成年当事人不再被统一定义为等待救援或统一作证的人。
- **关系变化**：保护者、医疗者、调查者与当事人的关系建立在授权和分工上，不以救援交换证言或亲密。
- **知情范围变化**：必要证据可以进入程序，当事人的私人经历、身份和公开程度仍由最小必要原则保护。
- **世界观 / 势力变化**：案件处理从单次止损扩展到医疗、职业、住房、名誉与司法后果的长期承接；成人当次自愿交易与结构性不自由可以同时成立，保护和司法支持不以停止交易、重新收容或公开全部经历为门槛。
