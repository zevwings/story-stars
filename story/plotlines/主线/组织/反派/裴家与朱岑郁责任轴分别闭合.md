# PL-M-049｜裴家与朱岑郁责任轴分别闭合

## 节点信息

- **节点 ID**：`PL-M-049`
- **线路类型**：主线
- **阶段归属**：阶段五
- **节点形态**：推进节点
- **推进结构**：递进链
- **节点定位**：齐心、陆佳凝先行被控制且未牵出另外两方后，裴家药剂/人体实验轴与朱岑郁园区/器官/秘密专送轴依靠各自独立证据分别达到责任闭合门槛，为最终个人裁判提供汇合接口。
- **归属目录**：`story/plotlines/主线/组织/反派/`
- **主体类型**：事件线
- **归档类型**：组织
- **归档主体**：反派
- **中心人物**：裴崇礼、裴怀山、裴怀真、裴兰馨、朱岑郁及官方经办系统
- **当前状态**：pending

## 前置状态

- **人物前置**：齐心、陆佳凝已经先行被控制；白玥、药剂个案当事人、实验幸存者和园区幸存者都只提供本人可见的有限材料。
- **关系前置**：任何人的保护、治疗、证言或合作不自动免除其本人责任，也不以加入主角私人关系为交换。
- **世界观 / 势力前置**：黑市是分散交易生态；暗色星辰身份不可直接追溯但现实交易可归责；裴家与朱岑郁不是齐心的下属，也不属于统一犯罪组织。
- **线索前置**：`PL-M-048` 已确认齐心—陆佳凝先倒且没有牵出裴家、朱岑郁；`PL-S-186`、`PL-M-037` 与 `PL-M-024` 分别形成实验药剂、跨境园区和器官贩卖的独立责任闭合结果。

## 必须发生

- 裴家轴由白玥首次市场任务与长期匿名联系的局部材料、万安现实产业记录、公司内供与外部客户药剂材料、实验幸存者、实验编号、药剂/实验记录、资金或结果流转中的独立来源交叉闭合。
- 裴家四名核心成员的共同知情与共同获益成立，同时按裴崇礼的方向和风险授权、裴怀山的经营资源与客户追踪、裴怀真的研发实验与技术控制、裴兰馨的艺人内部用药与职业控制分别证明。
- 朱岑郁轴由华靖移交材料、三名园区幸存者有限陈述、兔子快递秘密专送命令链、园区现场和当地独立材料交叉闭合；器官贩卖、园区经营与秘密专送分别证明，不由“当地黑势力”一词自动推出。
- 齐心、陆佳凝被控制后取得的供述、通讯录、合作事实或资产材料只能作为核验方向，不能成为裴家、朱岑郁责任闭合的唯一来源或决定性捷径。
- 两条责任轴分别达到门槛后才在本节点汇合；本节点不把裴家药剂实验与朱岑郁器官贩卖合并为同一业务、同一技术链或同一责任。

## 本线变化

- **人物变化**：裴家四名核心成员与朱岑郁分别从调查方向进入可具名裁判的责任位置。
- **关系变化**：三方合作被拆成各自行为、控制、收益与证据闭包，任何一方不替另一方吸收责任。
- **知情范围变化**：官方经办系统取得进入个人裁判所需的必要事实；主角与普通社会只接收结果性通报。
- **世界观 / 势力变化**：齐心—陆佳凝先倒未导致案件断链，独立现实证据仍能把裴家与朱岑郁分别归责。

## 完成判据

- [ ] 裴家药剂/人体实验轴与朱岑郁园区/器官/秘密专送轴分别有独立证据组合，不能互相替代。
- [ ] 齐心、陆佳凝的供述或被控制结果没有被写成牵出两方的决定性来源。
- [ ] 裴家四人的共同参与与个人分工均可进入裁判，朱岑郁的三类责任也保持分层。
- [ ] 两轴均达到后续个人裁判门槛，但本节点不展开庭审、罪名或刑期。
