# PL-M-050｜晏林诱饵式探查锁定裴家实验中心

## 前置状态

- **人物前置**：晏林已与管理局建立受控合作，具备自主评估和持续同意本次行动的条件；景雪瑶知道旅行附带风险探查，并持有预定联系接口；姜禾早已作为“金康-17”被拘禁于实验中心。
- **关系前置**：晏林与景雪瑶的长期关系、星辰之桥和知心示警已在前文建立读者认知；穆珂宜提供过本人能够确认的旅行入口、接待变化和路线片段，本节点沿用该既有信息，不改变她的正式设定。
- **世界观 / 势力前置**：`PL-M-048` 与 `PL-M-018` 已使齐心—陆佳凝的稳定人员来源及境内接口失效；朱岑郁一侧仍保留少量旅游接待接口，裴家正在加速既有控制型药剂实测，双方形成低数量、短周期的临时转送合作。
- **线索前置**：管理局掌握旧路线方向和外围现实跟随条件，尚未确定最终实验接收建筑；裴家与朱岑郁的完整历史责任仍需各自证据闭合。

## 必须发生

- 晏林以观看景雪瑶正式演唱会和顺便旅行的真实安排进入目标线路。行动经过风险评估，并预设联络节律、跟随保护、中止条件和紧急介入门槛。
- 一线人员中可以有契约者，只从模糊精神差异估量晏林大概率是契约者，再结合独自出行、表面缺少安保和现场控制成本，作出“值得改道送往医院复筛”的价值判断。
- 旅游端完成发现、控制、第一次转送和临时二次改道；管理局外围跟随保持最后可靠位置、车辆或接收方向，把最终建筑从未知压缩到可快速核验的范围。
- 裴家接收端先把晏林视为普通契约者样本。控制型药剂或精神试探出现无法按普通样本解释的分层、阻滞或延迟反应，促使裴怀安暂停常规处置并亲自接手。
- 严重处置已经扰动晏林的生命状态或精神之海核心边界时，知心向景雪瑶提供危险发生、发展和持续状态。景雪瑶按预案联系管理局，管理局将该时点与最后位置、车辆、接收方向和当地合法实时信息交叉。
- 当地具备权限的行动人员锁定并进入实验接收点，完成物理控制、医疗救援和现场保全；裴怀安在亲自处置异常样本时被控制，晏林、姜禾及少量既有实验对象获救。
- 从晏林被筛中到现场获救控制在数小时至一夜。晏林承担精神自保、延迟和关键时机反制，正式抓捕与现场控制由受训行动人员完成。

## 本线变化

- **人物变化**：晏林以主动承担风险完成一次有意为之的价值诱饵探查；景雪瑶把私人示警准确接入正式救援；姜禾从长期受试状态进入医疗与保护。
- **关系变化**：景雪瑶与晏林的星辰之桥第一次承担终局风险接口，私人关系与组织行动形成清楚接力。
- **知情范围变化**：官方系统取得旅游端当次筛选转送、裴家接收、裴怀安现场实施和既有实验对象存在的直接材料；主角及关系圈只接收与本人安全和选择直接相关的信息。
- **世界观 / 势力变化**：裴朱晚期低数量合作被现场动作证明；旅游转送责任与裴家药剂实验责任保持分段归属。
