# PL-M-026｜内圈完整私人知情

## 节点信息

- **节点 ID**：`PL-M-026`
- **线路类型**：主线
- **阶段归属**：阶段五
- **节点形态**：推进节点
- **推进结构**：递进链
- **节点定位**：六位核心女主分别取得晏林双子星结构与四项权柄分配的完整私人知情；景雪瑶的知情在大学时期建立星辰之桥时已成立，其余五人按风险相关性在当前时间线完成告知。
- **归属目录**：`story/plotlines/主线/人物/晏林/`
- **主体类型**：人物线
- **归档类型**：人物
- **归档主体**：晏林
- **中心人物**：晏林、安若曦、江岚、苏璃、唐雨薇、谢晚乔
- **当前状态**：pending

## 前置状态

- **人物前置**：晏林已经完整报备双子星结构与四项权柄，六位核心女主与他的长期关系分别成立；景雪瑶已因星辰之桥建立取得完整知情。
- **关系前置**：阶段四已经形成四个关系簇的最低危机告知、陪伴与暂停规则，其余五人尚未逐一取得完整双子星知情。
- **世界观 / 势力前置**：晏林的两颗星无主次；一颗承载织梦与绘影，另一颗承载断流与倒卷。管理局最高机密档案知情与私人关系知情分别成立。
- **线索前置**：公共风险与反派试探已经使完整能力结构直接关系六位核心女主的安全选择和危机责任。

## 必须发生

- 景雪瑶的既有完整知情被纳入当前共同秩序；安若曦、江岚、苏璃、唐雨薇、谢晚乔分别取得晏林双子星结构、两星无主次、四项权柄分配及与本人安全和选择直接相关的能力边界完整知情。
- 告知按风险相关性推进：先完成安若曦、江岚两人的分别告知，再完成苏璃、唐雨薇两人的分别告知，最后单独告知谢晚乔。
- 每次告知都允许当事人提出问题、暂停接收并决定自己在后续危机中的参与边界；一次告知不替其他人完成知情。

## 本线变化

- **人物变化**：晏林完成六位核心女主的完整能力结构知情责任；六人分别取得据此判断自身安全与危机参与的条件。
- **关系变化**：完整告知消除五段核心关系中的关键能力信息差，但不生成跨关系观看、共同亲密、共同居住、案件协查或代替他人决策的权限。
- **知情范围变化**：完整双子星知情覆盖六位核心女主；许知夏、许知秋、白玥、童颜、楚辞及其他关系者按本人安全、职业与选择需要取得对应信息。
- **世界观 / 势力变化**：私人完整知情与管理局最高机密档案、普通业务摘要及逐案调用权限继续分层，不把私人告知变成机构档案扩散。

## 完成判据

- [ ] 安若曦、江岚、苏璃、唐雨薇、谢晚乔五人均分别完成一次可独立验证的完整告知。
- [ ] 告知顺序满足“安若曦／江岚 → 苏璃／唐雨薇 → 谢晚乔”，且谢晚乔的告知单独发生。
- [ ] 五人取得双子星结构与四项权柄分配的完整私人知情，但没有因此取得无关伴侣隐私、身体细节、案件材料或完整管理局档案。
- [ ] 本节点没有用多人亲密、关系稳定或共同应急规则反向推定任何人的完整知情。
