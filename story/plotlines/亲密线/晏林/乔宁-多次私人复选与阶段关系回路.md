# PL-I-043｜多次私人复选与阶段关系回路

## 节点信息

- **节点 ID**：`PL-I-043`
- **线路类型**：亲密线
- **阶段归属**：阶段四至阶段五
- **节点形态**：回路节点
- **节点定位**：第一次清醒留宿和职业边界说明以后，乔宁在秘密保护与调查期间仍保有独立私人生活；她与晏林建立由本人自主发起、低频复现、可随时暂停的非排他、非咨询、非案件交换阶段性亲密回路。
- **归属目录**：`story/plotlines/亲密线/晏林/`
- **主体类型**：关系线
- **归档类型**：人物
- **归档主体**：晏林
- **中心人物**：晏林、乔宁
- **当前状态**：pending

## 前置状态

- **人物前置**：乔宁已经进入知情低暴露保护，全部成功用药发生在保护前；她仍保留是否治疗、陈述、公开或调整职业的选择。
- **关系前置**：两人已经完成第一次自愿留宿；晏林已明确不能成为乔宁的正式咨询师，独立案件和持续心理支持均有关系之外的承接入口。
- **世界观 / 势力前置**：私域可以继续提供合法私人空间，但会员消费、项目参与者身份和案件协作都不构成亲密服务或关系续约。
- **线索前置**：助理记忆与现实记录进入独立核验，案件进展不由两人的私人关系决定。

## 必须发生

- 第一次留宿与后续重逢之间存在真实的生活和程序间隔，乔宁能够在没有即时资源、保护或交证压力的情况下重新判断是否联系晏林。
- 两人不把第一次、自愿交证、有限倾听或既往亲密视为自动续约；每次见面、留宿、亲密、暂停和离开均重新确认。
- 乔宁在不同时间再次主动提出或明确接受私人见面，使两人的关系被确认不是一次性应激、求助回报或案件合作附属。
- 多次亲密可以与案件、治疗和职业生活并行，但不发生在正式咨询时段、问询过程、证据交接或保护决定中。
- 阶段四至少完成一次保护期间的独立复选，阶段五再用现实间隔确认关系能够反复调用。
- 两人确认关系保持阶段性和非排他，不进入固定排班、共同生活、公开绑定或长期伴侣秩序。

## 本线变化

- **人物变化**：乔宁能够在案件之外多次重新选择欲望、距离和退出方式，不再由一次受害经历或一次求助决定其全部私人生活。
- **关系变化**：乔宁与晏林建立可间断复现、逐次确认的阶段性双人亲密回路；晏林不取得咨询师、保护人或职业安排者位置。
- **知情范围变化**：两人只共享乔宁主动披露的案件和治疗信息；每次亲密不扩张对未披露材料、诊疗内容或职业决定的知情权。
- **世界观 / 势力变化**：私域的合法私人空间可以被关系调用，但不因多次使用而将乔宁转为会员、固定项目人员或侍奉人员。
- **亲密兑现变化**：第一次自愿留宿被后续多次独立复选承接，形成阶段性回路而非长期伴侣关系。
