# PL-I-045｜言溪会所固定主位结束与职业档期回流伴侣成立

> 本页保存言溪先在会所阶段形成固定主位，再于集中安排结束后脱离职业调度、以本人事业和私人联系独立回流，最终进入第二层非共同生活型回流伴侣关系所必须继承的变化。具体角色、舞蹈、衣装、身体流程、拍摄内容与对白由施工和亲密设计承接。

## 节点信息

- **节点 ID**：`PL-I-045`
- **线路类型**：亲密线
- **节点形态**：回路节点
- **节点定位**：前几次由顾清言轮换安排不同人员后，晏林明确不再主动换人，言溪与舒歆共同成为会所阶段固定双主位。言溪以 Coser 角色转换、舞蹈前奏、镜头表达和逐次授权形成阶段位置；她因漫展、角色拍摄、商演等真实工作缺席时允许临时替补，返回后仍恢复原位。阶段四的会所集中安排结束后，固定主位和顾清言代为调度同时结束；经过真实分离，言溪再以漫展、角色拍摄、商演或本人想见为现实入口，由本人主动联系并重新选择晏林，形成可长期持续但不固定排期、不共同居住、不进入完整内圈的第二层回流伴侣关系。
- **当前状态**：pending

## 前置状态

- **人物前置**：言溪 23 岁，主要是 Coser，舞蹈专业毕业并具备专业基础，但不直播舞蹈。
- **关系前置**：`PL-S-121` 已推进至前期人员显影、晏林停止主动换人及固定双主位；本节点与该组织回路后半程共同承接会所调度关闭，不能把 `PL-S-121` 整体完成作为本节点启动门槛。`PL-S-127` 已确认晏林守住私密影像边界。
- **世界观 / 势力前置**：顾清言可以安排会所接待并推掉言溪面对其他客户的陪侍，但不能替言溪授权；晏林与言溪之间不存在付费关系。

## 必须发生

- 晏林在前几次人员接触后明确不再主动换人，言溪进入固定双主位之一。
- 言溪第一次面向晏林的角色化接触使用“貂蝉·马年限定”完整 COS 战袍；衣装、妆造及现实穿脱边界由 `CON-0038` 承接，当次角色展示不自动授权亲密或影像。
- 言溪继续保有漫展、角色拍摄、商演及其他正常职业行程；因工作缺席时可以由顾清言临时安排替补，替补不取得长期位置。
- 言溪返回会所后恢复固定主位，不需要通过排他竞争、再次付费或“重新被选中”证明位置。
- 会所集中安排结束后，固定主位、替补机制和顾清言代为排期一并停止；既有会所位置不自动延长为私人关系。
- 经过一段真实分离，言溪以漫展、角色拍摄、商演或普通私人联系重新接入晏林的生活，并至少一次由本人主动联系、提出见面或明确接受不经顾清言安排的私人邀约。
- 两人确认第二层非共同生活型回流伴侣关系可以长期持续；回归由言溪自己的事业、档期和想见晏林的意愿驱动，不设固定排期、共同居住权、完整内圈知情或默认危机决策权。
- 每次角色、舞蹈、拍摄、录像与具体身体范围仍分别确认；职业合作、既往固定主位和长期关系定位都不产生当次默认许可。
- 经过分离的多次接触后，两人实际建立部分 C 档范围；相应权力称呼或情欲自称由言溪本人主动调用，退出角色或身份层后恢复日常称呼。该范围不外推为完整 C、影像、留痕、多人或女女互动权限。

## 本线变化

- **人物变化**：言溪从风归主要复现人物推进为有稳定 Coser 职业、经历过会所固定位置且能在组织调度结束后独立决定回归节律的第二层人物。
- **关系变化**：晏林与言溪先形成固定、非付费、允许职业缺席与临时替补的会所阶段关系，再切断固定主位和组织排期，转为可长期持续但不连续陪伴的职业／档期回流伴侣关系。
- **知情范围变化**：无新增案件、能力或内圈知情；固定位置不授予言溪其他关系名单、会所记录或顾清言完整责任材料。
- **亲密兑现变化**：言溪由首次角色化接触进入分离的多次调用，并与晏林实际建立部分 C 档范围；影像及具体项目继续逐次确认。
