# PL-I-037｜连续三晚付费亲密、创伤吐露与边界拒绝

> 本页只保存阿九经云顶接口连续三晚被晏林点选并带离场所，在三次分别确认的付费亲密与事后陪伴中逐渐说出债务处境，并在第三晚崩溃索取伤害时被晏林拒绝执行所必须继承的关系变化。具体身体流程、对白、离场安排和章号留施工或亲密场设计。

## 前置状态

- **人物前置**：阿九已经被云顶接收并规训为债务性服务人员，以“阿九”向晏林自我介绍；她对熟练服务和服从脚本非常熟悉，却常把真实选择压缩成“都行”“随便”。
- **关系前置**：阿九与晏林此前没有恋爱、救助、咨询、协查或长期身体关系；云顶安排、付费、离场和脚本化主动均不等于她同意晏林本人及全部具体行为。
- **世界观 / 势力前置**：三晚均属于结构失衡真实在场的自愿交换场；阿九当次愿意不抹除债务控制，债务环境也不自动取消她针对具体对象和行为作出选择的能力。
- **线索前置**：晏林起初只知道阿九是经云顶接触的成年交易对象，不知道赌场签贷、“那个人”、章绍衡真实身份、于静规训和完整责任网络。

## 必须发生

- 三晚均由晏林通过云顶接口点选阿九并带离场所；云顶只知道重复消费与离场，不知道两人的谈话、阿九的吐露和晏林后续准备提供的帮助。
- 每晚的成年人身份、付费关系、地点、身体范围、语言身份、强度、暂停与停止分别确认；晏林持续使用“可以吗”“还继续吗”“要不要停”等询问，不用命令替代阿九的答案。
- 第一晚亲密后，晏林发现阿九始终紧绷并等待下一项要求；他不盘问赌场和云顶，只让她确认当晚已经结束。阿九只泄露“债还没有清”这一最小事实。
- 第二晚仍发生分别确认的付费亲密；晏林在她迟疑时真实停下，使阿九发现拒绝不会带来惩罚。事后聊天中，她说出债务是在地下赌场现场签下，并说账目始终没有明显减少。
- 第三晚先发生分别确认的付费亲密；事后阿九以“那个人”指代施害与转送者，说出赌场签贷、催逼、被送入云顶及店级接收规训的顺序，但不知道对方姓名和完整身份。
- 阿九说到被送入云顶和后续规训时可以哭泣、伤心与崩溃；晏林从这一刻停止继续询问，不利用她失控时补齐证词，只抱住她、允许她停止和反复确认自己不会伤害她。
- 崩溃中的阿九会索取被“糟蹋”的 C 档伤害，并可能主动、闹、拉扯或使用受训话术试图把晏林推回她熟悉的支配者位置；该请求属于创伤性复演与自我惩罚冲动，不作为自由状态下的稳定偏好确认。
- 晏林明确拒绝执行该 C 档请求，同时不羞辱、不抛下、不撤回拥抱和陪伴；他允许阿九索取拥抱、留下与普通安抚，但不以继续亲密覆盖她的崩溃。
- 三晚结束后，阿九只形成“这个男人会询问、会停下、拒绝伤害后仍愿意留下”的初步信任；关系尚未进入恋爱、长期伴侣或稳定私人回路。

## 本线变化

- **人物变化**：阿九由只会执行脚本、等待命令，推进为能够在晏林真实兑现停止与拒绝伤害后，逐层说出债务来源和本人经历，并第一次把“想被伤害”与“真正被温柔留下”区分开。
- **关系变化**：两人完成连续三晚、每晚分别确认的付费亲密；晏林从普通消费者推进为阿九愿意向其说出最低事实、接受拥抱并考虑求助的人。
- **知情范围变化**：晏林知道阿九在赌场签贷、被“那个人”催逼并送入云顶，也知道于静所在的店级规训链存在；他仍不知道章绍衡姓名、罗东海能力与完整上层责任网络。
- **世界观 / 势力变化**：无。
- **亲密兑现变化**：三晚均保留当次真实选择与结构失衡；第三晚的 C 档请求只出现并被拒绝，不落成男主对崩溃对象的伤害场。
