# 成人欲望与偶遇逻辑

> 本页是普通成年社交、快速吸引、短期关系与秘密反差类情节的正向生成口径。硬底线服从 [BIBLE.md](../../BIBLE.md)；本页负责回答“这件事为什么可以发生、怎样写得有爽感”，不为未发生的风险预设审判流程。

## 1. 核心承诺

成年角色可以因为外貌、气味、谈吐、孤独、虚荣、身份反差、秘密一面或单纯好奇而相互靠近。欲望不必先证明高尚，亲密不必先兑换信任，一夜情也不必伪装成长期关系的预告。人物选择状态与场型边界服从 `BIBLE.md`。

本页不把性限定为“偶遇之后的大事件”。社会前提见 [伴侣与关系形态](../../worldbuilding/society/伴侣与关系形态.md)；叙事中，性话题、吸引力与私人经验可以塑造声音、社交气氛和人物间的熟悉程度，不必每次升级为床戏或关系节点。

## 2. 常用爽文回路

1. **机会出现**：酒吧搭讪、临时同行、酒店偶遇、错拿物品、意外看见自拍或反差身份。
2. **欲望被点亮**：人物具体被什么吸引，谁先看懂，谁先主动，谁故意把机会留下。
3. **快速选择**：接受、试探、加码、改主意或离开；选择用动作和对白呈现，不插入作者道德答辩。
4. **当场兑现**：满足好奇、带人离场、发生一夜情、交换秘密或改变彼此印象。兑现可以是本场终点，不强制升级为救赎与承诺。
5. **余波按需**：尴尬、回味、再次联系、身份揭晓或互不打扰都可以。只有本场实际制造了后续事实，才要求后文继承。

## 3. 正向生成原则

- 先写“她／他想要什么”和“为什么偏偏是这个人”，再检查现实动线是否通顺。
- 女性主动、快速上头、享受被看、主动自拍、主动邀约或只想要一次，都可以是主体性，不自动视为被利用或缺乏人物功能。
- 偶然发现私人一面可以制造惊喜、反差、好奇与秘密同盟；看见、心动、想继续看是心理与叙事事实，不等于已经偷拍、窃取或传播。
- 微醺、疲惫、失恋与情绪波动可以成为情节压力；选择状态和场型判断服从 `BIBLE.md`。
- 身份、财富、职业、合同、生计、债务、把柄与利益交换可以提供动机、反差与张力；具体责任另按实际行为处理。
- 偶遇与一夜情也要有人物差异：主动方式、审美偏好、冒险程度、事后态度和是否再联系，应能反映角色，而不是把所有人写成同一套流程。
- 不把“敢谈性”和“愿意发生性”混为一谈，也不把“选择保密”和“以性为耻”混为一谈。开放程度、当次欲望和具体隐私分别写。
- 性话题可以停留在玩笑、经验、审美、回味或直接邀约，不要求每次都升级为床戏；反过来，人物已经想要并抓住机会时，也不为显得深刻而强行绕开兑现。
- **有限知情**：不知道对方完整职业、债务、合同、受控状态或场外安排，不反向取消当次真实成立的意愿；正文只按当前视角可知内容表达，后续发现改变责任认识而不自动重写场型。

## 4. 何时转入边界或案件线

命中 `BIBLE.md` 的亲密边界时转入相应场型或责任线；灰黑产业、债务与药剂的分账见 [灰黑产业叙事](灰黑产业叙事.md)，能力、影像及其他附加行为按正式责任线处理，亲密被强迫发生或继续时的场型与立场见 [黑暗压迫场](黑暗压迫场.md)。转入后只处理实际发生的行为，不把整个欲望场景反向定性为错误。

## 5. 写前四问

- [ ] 这场最直接的欲望或好奇是什么？
- [ ] 谁先主动，机会怎样被抓住？
- [ ] 本场准备兑现哪个爽点，而不是只讨论能不能？
- [ ] 是否真的发生了需要转入责任线的具体行为？若没有，就按普通成年选择继续写。
