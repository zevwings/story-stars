# 都市星辰契约题材口径

> 本文件是本项目实际采用的都市超凡题材口径正典。它定义了现代秩序与隐秘星辰契约超凡的融合规则、主角心理咨询师的咨询循环以及星辰契约能力的局限性。具体世界观设定、角色关系、历史因果与专名，以 `BIBLE.md` 与 `worldbuilding/` 为准。

## 1. 核心承诺
都市星辰契约的叙事承诺是：**冰冷的星辰契约超凡力量嵌套于高度写实的现代都市中；超凡秘密既能制造对抗与救援，也能制造身份反差、意外窥见、欲望放大和快速亲密。**

它不同于传统“装逼打脸”的都市高武，超凡能力并非直接的杀戮武器，而是进入隐秘世界、探寻人心与制造关系机会的工具。人物不必先受创再被救，普通生活中的吸引、好奇与一时冲动同样能够启动故事。

---

## 2. 双主循环

卷与故事弧线可以调用两条并行循环，不要求每条人物线都先走咨询、创伤与救赎。

### 2.1 异常事件循环

1. **现代日常／咨询切入**：在工作、学院、夜生活或依法登记的心理咨询中遇到异常。
2. **异变显影**：精神海动荡、星辰异变或黑暗契约控制留下痕迹。
3. **限知介入**：晏林以现实身份调查，以双子星权柄做受限探查或反制。
4. **博弈与兑现**：解决当下冲突，付出现实成本，并让秘密、关系或势力格局发生变化。

### 2.2 成人欲望循环

1. **偶遇与反差**：酒吧、酒店、同行、私人空间或超凡身份错位提供机会。
2. **吸引与好奇**：外貌、谈吐、主动自拍、偶然看见的秘密一面或危险感点亮欲望。
3. **主动选择**：一方邀约、另一方接住；可以试探、加码、拒绝或改主意，不预设长期关系。
4. **快速兑现**：一夜情、秘密共享、身体关系或下一次邀约直接落地。
5. **余波回响**：身份揭晓、意外重逢、持续关系或互不打扰均可；只有实际留下的新事实才进入后续继承。

两条循环可以交叉，例如一次普通邂逅意外撞开超凡秘密，也可以各自独立完成。亲密可以来自长期信任，也可以先由欲望成立，再在后续相处中决定有没有信任与共同秩序。

## 3. 与传统都市玄幻的对比

| 维度 | 传统都市玄幻 | 都市星辰契约（本项目） |
| :--- | :--- | :--- |
| **力量源泉** | 灵气、天地元气、功法修炼 | **星空结契**：一星一契，目视结契，主动权在星辰侧 |
| **战力体系** | 筑基/金丹等境界，升级换地图 | **无综合修炼境界**：精神海五境仅描述承载状态，无“破境”仪式 |
| **战斗机制** | 肉体强化、法术对轰、法宝飞天 | **物理层结算**：星辰契约不提供肉搏强化，动作伤害靠物理对抗结算 |
| **主角定位** | 最强战神、仙帝重修、杀伐果断 | **感知/辅助流**：隐秘双子星契约者，医生身份，非正面最强战士 |
| **亲密关系** | **战力附庸**：为变强去收集女主，亲密兑现成数值奖励 | **亲密驱动**：先有情感与欲望才有亲密——亲密既是救赎异变的唯一防线，也是精神之海承载成长的入口；但成长只落**承载上限**、不兑现战斗胜负，女主是独立的人而非资源位 |

## 4. 核心设定边界与红线

### 4.1 结契与星辰之力
*   **一星一契与双契例外**：同一颗星同一时间只回应一名契主。绝大多数契主只有一颗星；双契结构以两颗先天互为伴星、只作为整体回应的“双子星契约”为主要形态，两颗独立星辰同次回应形成的“双星契约”反而更罕见。安若曦与江岚都是两权柄双子星契约者；齐心持有两颗均呈黑暗倾向的塑心／孤悬双子星；晏林是全书唯一的四权柄双子星契约者，一颗星持织梦／绘影，另一颗持断流／倒卷，两星不设明暗或主次。
*   **起源模糊**：不解释星辰契约的宇宙起源，不设定正典起源史。
*   **星表与隐秘**：管理局维护的“星表”仅是事后登记工具，而非结契通道。男主在大学登记时完整报备双子星与四项权柄，完整资料进入最高机密档案；普通业务摘要只显示织梦方向。关键剧情张力来自“高层知道完整结构，但普通经办人员、家族、黑市与反派只能接触错误或残缺模型”，以及机密调用中的访问权、保护责任与利用压力。
*   **星契动物例外**：极少数具备稳定个体意识、持续自身意向与足够精神承载结构的动物也可能结契，但结契不开智。正式称“星契动物”，圈内可俗称“星兽”；“星辰怪物”只作为普通舆论、猎奇媒体、黑市猎手或敌意人物的污名用语，不作为旁白事实或管理局任务分类。

### 4.2 战斗语法与物理限制
*   **星辰契约不强化肉体**：不存在能让人跑得像火车、一拳打穿钢板的肉体强化星辰契约。近身搏斗完全依赖现实物理格斗。
*   **药剂限制**：药剂是受管制的肉体兴奋剂（有严重副作用），只短时刺激身体机能，不介入精神层战斗。
*   **精神系收敛**：精神能力的交锋是双向的。男主的绘影只覆盖清醒状态下的当下感知，不修改人格、不改记忆；倒卷和断流只能对正在攻击或已暴露的通道生效。

### 4.3 精神海五境定义
精神之海按承载分为：**泉境、湖境、川境、海境、浩瀚境**。
*   此境界只描述承载深广状态，不是修炼阶段，不存在境界壁垒和“破境”仪式。
*   战力高低由精神海状态、控制力、权柄及现场条件综合决定，不可用境界高低直接判定输赢。

## 5. 现代化改造与势力层级
*   **表层（日常/官方）**：普通市民社会，对超凡力量基本无知；星辰管理局作为官方监管机构，负责信息外泄管控。
*   **中层（民间/交易）**：私人心理咨询工作室、特殊药剂流通渠道、黑市交易网络。
*   **深层（传统/敌对）**：掌握血缘与星表资源的传统星辰家族，以及进行非法精神实验或掠夺的黑暗契约者。

---

## 6. 禁区
1.  **禁“修仙化”描写**：禁止出现“御剑飞行”、“打坐吐纳一整天”、“破境雷劫”等传统修仙词汇和桥段。
2.  **禁越界操控**：男主绝对不能使用织梦或绘影非法操纵、篡改自己人或女主角的意识。
3.  **禁脱离法律与痕迹**：超凡争斗绝非无法无天，每次出手必须考虑管理局的干预、警方的刑事调查以及社交网络的外泄风险。
4.  **禁战斗数值化**：不要在战斗中出现具体的战力值、灵力百分比或功法层数，多写现场感知与精神消耗的疲惫感。
5.  **禁怪物讨伐化**：星契动物不是妖族、刷新怪、异能宠物资源或掉落来源；出现动物异常时必须承接现实照护、风险、责任、保密与后果链。
