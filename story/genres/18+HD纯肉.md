# 18+ HD 纯肉题材口径

> 本文件是本项目 18+ HD 场景（B 场正向 HD 为主体）的题材口径。全局边界以 [BIBLE.md](../../BIBLE.md) 为准，文风三基调（写实＋美感修辞、纯写实不用异能滤镜、张弛结合）以 [STYLE.md](../../STYLE.md) 为准；具体写法素材只按需读取项目 [亲密参考索引](../../intimacy/references/_index.md)，专项规范读取 [亲密机制索引](../../intimacy/mechanisms/_index.md)。本文不依赖 story-writer 公共参考或离线 packs。

## 1. 核心承诺
本题材的叙事承诺是：**极致的感官细节还原、随着本能交互而步步失陷的性心理状态，以及压在这一切之下的关系重量。**

**B 场（正向 HD）是全书的主色带与兑现主体，也是最高频、最高优先的场型**：兑现要多、要连续、要有美感，是常态而非稀客。HD 可以承担关系质变，也可以只兑现当下欲望、视觉反差、身份秘密、主动征服或一次性快感；一夜情写完后互不承诺，同样是完整交付。场景必须与具体人物相连，但不强制每场先积累信任、写完都升级关系。拒绝空洞生硬的流水账式生理动作描写，也拒绝没有人物偏好与互动差异的纯器官特写。

## 2. 场型分流
写前先判场型，本文件只直接约束 B 场：

*   **A 场（高暧昧 / 软切黑 / 正文亲密，非 HD）**：走正文亲密设计流程；具体美学、张力与场域素材只读取项目 `intimacy/references/`。不适用本文件的完整兑现节奏。**A 场保留为连续兑现里的呼吸留白、过渡与过场**——重点场写满 B 场，过渡场用软切黑或写实含蓄承接，靠详略搭配做节奏，而不是拿软切黑当偷懒默认。
*   **B 场（正向 HD，男主 × 女主正向线）**：本文件直接约束的完整兑现场型。身体、衣装、道具和场域素材只读取项目 `intimacy/references/`；调用条件与风险边界读取项目 `intimacy/mechanisms/`。
*   **深色情欲带（正向线暗色情趣）**：支配 / 臣服 / 蒙眼 / 绝对主导 / 暗色情趣；A / B / C 仅作强度参考，具体采用由大纲和写作者决定。
*   **黑暗 HD / 压迫场（仅对敌 / 反派，可按需常规使用，不落男主对女主）**：必须先走黑暗 HD 流程与黑暗设计卡，执行双声部铁律（快感是施暴方的、账单是受害方的、必落后果）；**严禁**套用本文件的正向节奏、迎合心理与温存余韵。**立场、边界与词汇口径详见 `黑暗压迫场.md`。**

**少数色带纪律**：非男主情欲不与主色抢频率。每场检查三问：①是否服务世界、人物或主题；②承场配角是否有足够人物量，而非 PWP；③是否位于主色的呼吸位，不与同章男主 × 女主兑现争高潮。某阶段非男主情欲场次逼近该阶段男主 × 女主兑现场次时仅作预警，不设硬性比例。

**项目排除项**：本项目不采用功利性双修；亲密描写纯写实，星辰之力不做性爱滤镜。此项是项目自身口径，不以剔除某个公共参考页的方式维护。

## 3. 五感感官矩阵
为了避免干瘪的动作描写，必须在每一幕中交叉使用五感细节：
*   **触觉**：皮肤的温差（微凉与滚烫）、汗水的黏腻、指甲掐入肌肉的力度、压迫感与包裹感。
*   **视觉**：局部特写（泛红的眼角、因紧绷而起伏的锁骨）、光影的投射（阴影下的交缠）、体液折射的微光。
*   **听觉**：呼吸的粗重与短促、低声的喘息、无法自抑的呜咽、黏潮的碰撞声、被刻意压低的求饶或命令。
*   **嗅味**：汗味与体温烘出的气息、发间与颈侧的味道、亲吻里的津液与呼吸交换。
*   **温度与重量**：体温上升的过程、呼出热气的吐息、交界处的滚烫；肢体压迫的沉重感、掌控与被掌控的实体力量对比。

## 4. 性心理双向轴
性爱不仅仅是生理碰撞，更是心理防线的拉扯与交互。写作时需在以下心理状态中切换：
*   **主导方**：占有欲的膨胀、恶劣的试探、看对方失控的愉悦、克制之后的爆发、怜惜与掌控的夹杂。
*   **被动方**：心理防线的崩溃、羞耻感的挣扎、感官超载的迷失、被迫承受的顺从、主动迎合的羞涩。
*   **交互状态**：别扭、拉扯、求饶与不予、理智崩塌前的最后一次推拒。

**可拒绝可喊停底线（正向线专属）**：女主的推拒只来自羞耻、别扭与情趣拉扯，不是真实非自愿；绝对主导可以成立，但那是双方成立的情趣，不是压迫。归属遵守 `BIBLE.md` 的全局亲密边界：真实不愿意、撤回或完全不能判断与选择时仍被强迫发生或继续，才进入黑暗压迫场，不得渗入 B 场。偷拍、传播、勒索、合同控制、债务控制和精神越权分别定性，不自动改写双方真实自愿的亲密场型。

**利益与身份背景不另设场型**：利益交换、生计压力、身份落差、债务、把柄或职业压力出现时，先判断当次选择是否真实成立以及是否发生具体强迫、欺骗或侵害。当次自愿且无实际侵害时仍可使用本文件节奏，人物也可以享受、主动和温存；真实发生的外围违法与控制责任再分别进入对应剧情线。

## 5. HD 场景推进线与节奏
推进线：**前奏 → 确认 → 升级 → 收束 → 余波**。不必每场走满，但每场都要能说清当前在哪一步。具体素材按需读取项目 `intimacy/references/`。

**连续兑现的详略节奏**：当多场亲密连续发生时，按关系节点分详略——里程碑场（首次、破防、关系质变）写满五步兑现；之间的日常兑现可只取前奏 → 升级 → 余波的骨架，或用软切黑 / 写实含蓄承接，避免每场同强度堆到底。高频靠的是“常发生”，不是“每场都最重”。

*   **前奏（边缘试探）**
    *   *动作*：亲吻、抚摸敏感带、衣物半褪、呼吸变调。
    *   *心理*：心跳失速、羞耻感累积、目光试探与躲闪。
*   **确认**：关键接触前后要有意愿信号在场——不一定是语言，可以是动作、停顿、眼神或主动靠近；一方退缩就降速改写。
*   **升级（防线破裂 → 感官超载）**
    *   *动作*：关键的结合与切入、物理阻力、身体的适应与接纳；持续的物理撞击、体位转换、生理失控（战栗、痉挛）。
    *   *心理*：强烈的异物感与充实感并存，心理防线瞬间失陷，羞耻被本能的潮水淹没；意识模糊，除了快感与对方的体温外失去一切感知。
    *   *节奏*：走波浪式（上升 → 小高潮 → 回落 → 再上升），用故意中断、体位变换、刺激叠加制造起伏，不写匀速到底的直线。
*   **收束（余韵温存）**
    *   *动作*：肢体瘫软、汗水交融的拥抱、温存清理与照顾。
    *   *心理*：极度疲惫后的心安、依恋感倍增、理智回归时的微弱羞涩。
    *   *要求*：优先写人物怎么缓下来，不重复前面的强度；身体负担要交代照顾与恢复。
*   **余波**：用动作、对白或沉默交付本场结果。结果可以是关系变化，也可以是欲望满足、秘密加深、一次性告别或留下再次相遇的钩子。

**句式与呼吸感**：句式长短随烈度联动——铺垫用长句沉浸，冲刺用短句密集，极致高潮允许碎片化断句；高压段善用“压拍点”（动作峰值处硬生生停住，写静止里的心跳与汗珠）与声音延迟（动作先发、那声破碎的呻吟慢半拍才溢出）。

## 6. 高风险旧网文词、禁用词与写实替换词表

| :--- | :--- | :--- |
| **娇躯、玉体、酥胸、雪肤** | 高风险：容易成为悬浮、失去实感的身体代称；仅在符合人物语气、特定审美或有意反讽的语境中少量使用 | *写实部位*：肩膀、后背、腰肢、绷紧的大腿、脚踝，或当场可见的肤色与光线变化 |
| **樱唇、檀口** | 高风险：容易陈腐、同质化；限上述明确语境，不作常规嘴唇代称 | *动作细节*：微张的唇缝、被咬出白印的下唇、唇齿厮磨 |
| **电流窜过、酥麻** | 高风险：容易成为不分强度与部位的模板反应；身体感觉确实命中时可以低频使用 | *生理反应*：脊背不可自抑地战栗、指尖发麻、头皮炸开、物理颤抖 |
| **花蕊、幽径** | 高风险：带有传统情色意象，适合审美与叙述距离相符的局部描写，不作全程解剖代称 | *写实/借代*：结合处、入口、最深处、湿软的内里 |
| **分身、巨龙** | 禁用：夸饰粗俗，容易破坏人物感与身体实感 | 按人物视角写具体部位、尺寸感、温度与动作造成的反应 |
| **娇喘连连** | 高风险：可以在需要快速概括一段连续声音时低频使用；重点场仍应写出声音变化与人物反应 | *具体声音*：细碎的呜咽、压在喉咙里的闷哼、带哭腔的急喘、断续的呼吸 |
| **巨乳** | 高风险：可以在人物视角、对白或确需突出体型时低频使用，不反复充当人物标签 | 写当场可见的重量、轮廓、动作反馈及人物对此的真实注意点 |
| **罩杯、尺寸数字** | 场景限定：试衣、购买、量体、衣装适配、人物自述或有具体用意的调侃中可以使用；不作性爱场景的身体评分 | 若尺寸本身不承担情节功能，改写衣装是否合身、支撑感、压痕与动作反馈 |
| **蜜穴、花穴、花径、肉刃** | 高风险：可以在审美、人物语气与场景烈度相符时使用；不连续替代准确部位和动作 | 结合具体位置、触感与动作，避免只靠更换借代词制造烈度 |
| **淫穴、肉穴、肉棒、大屌** | 重度淫语：双方成立的淫语、羞辱式情趣或角色扮演中可以进入正向线；只进符合人物的对白或贴身声部，不作中性叙述的默认命名 | 先让人物关系、当场意图与说完后的反应成立，再决定是否使用 |

**高风险词使用口径**：不把高风险词当作常规身体代称，不成串堆叠，也不靠偶尔换一个旧词制造文采。人物语气、特定审美、感觉或节奏确实命中、有意反讽等理由能够为该词提供明确语境时，才允许少量出现；离开这些语境仍优先使用具体部位、动作与触感。词的雅俗不决定场型，粗俗词也不自动属于反派。

**淫语使用口径**：允许分级使用，默认少而准、以点爆破；正式大纲或人物关系明确把淫语作为本场互动轴时，可以形成短段连续交锋，但仍须有角色语气与人设兜住，说完要有符合人物的回响，不当作器官名称的自动替换器。具体词汇服从本节、项目参考与人物口径。

项目 `intimacy/references/library/` 中“反派专用”“主角叙事禁用”等标签只是 package 素材的原始分类，不构成本项目词汇边界；与本节冲突时，以本节和 [STYLE](../../STYLE.md) 为准。

## 7. 禁区
1.  **年龄边界**：继承 `BIBLE.md` 的年龄硬底线；本页不另设年龄标准，也不得借正邪场分流改变该标准。
2.  **禁功利性爱**：亲密首先服务欲望、关系与救赎，不得为了恢复星辰之力、涨战力、提数值或任何收益索取亲密；不提供战斗收益，也不由单场即时兑现机制变化。精神之海承载与相性机制见 [精神之海](../../worldbuilding/systems/精神之海.md) 与 [星辰相性](../../worldbuilding/systems/星辰相性.md)。
3.  **动机必须具体**：快速主动、一见钟情和一夜情可以成立，但要写清人物被什么吸引、此刻想得到什么；不以统一的“日常相处或危机累积”作为前置门槛。
4.  **禁场型混用**：男主不对自己的女主施真实非自愿压迫；黑暗场不得借用本文件的迎合心理与甜蜜余韵收尾。
5.  **词汇边界**：严格遵守禁用项；高风险词、场景限定词与重度淫语分别按 §6 调用，不作为自动替换器或成串堆叠。粗俗不自动等于反派，典雅也不自动等于有效。不得回退读取 story-writer 公共亲密参考或离线 packs。
