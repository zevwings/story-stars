# 决策门

本目录保存当前可以延后、但在明确剧情节点、施工单元或章节执行前必须由作者解决的问题。它是写作流程门禁，不是故事事实；候选方案不得被正文或正式真源直接继承。

## 收录条件

一项问题只有同时满足以下条件，才进入本目录：

- 存在至少两个会产生不同执行后果的可行选择。
- 当前不阻塞无关线路，但在明确目标启动前不能继续留空。
- 能指向具体 `PL-*`、`CON-*` 或章节。
- 写明最迟决策时点与正式回写目标。

可以安全留给章纲或正文临场决定的普通对白、衣装、微动作、项目名和无连续性影响的场景纹理不进入本目录。已经确认、只待机械回写的内容也不进入本目录。

## 状态与索引

- `scheduled`：尚未到最迟决策点，不阻塞无关任务。
- `blocking`：已经到最迟决策点，命中的规划或写作必须停止。
- `_index.md` 是当前决策门的唯一入口；未登记文件不得参与门禁。

每份文件使用稳定 `DEC-xxxx` ID，写明目标、待决问题、可行方案、推荐方案、影响范围、最迟决策点与正式回写目标。决策文件不得设置“正式真源引用”小节。

## 引用与清理

- 决策文件以 `decision_gate` 单向指向正式剧情节点、施工单元或章节。
- `plotlines/`、`construction/`、`chapters/` 不得反向引用本目录。
- 作者确认后，先把结果写入正式剧情节点、施工单元或目标章纲，再删除索引行和决策文件。
- 不保留 `resolved` 状态，也不把本目录作为决策历史档案；确有长期论证价值的过程另行整理到 `.analysis/archived/`。
