# CON-0028｜秦瑶连续三晚求助与临行回声施工

> 本页承接 `PL-I-089、PL-I-090、PL-I-091`、`PL-S-096`、`PL-S-179、PL-S-178、PL-S-177` 与 `PL-I-062、PL-I-063`，固定阿九从连续三晚付费亲密、逐层吐露、第三晚崩溃与边界拒绝，到有限陈述、正式保护，再到关停安排形成后的个人脱离，以及云顶实际关停后的告别共餐、一次非交易亲密与清醒分别。正式人物事实、关系变化与完成判据以对应剧情节点及人物卡为准。

## 使用边界

- 本页不记录生命周期状态；当前状态只从 `story/construction/_status/` 读取。
- 具体章号仍留待分章时确定。
- 三晚都先发生真实的开包、酒水／饮品、点歌、停留与陪伴消费，包厢内可以发生另行确认的有限亲密；是否离开包厢及后续场外亲密须另外确认，不把云顶写成到场即带走的中转点。
- 三晚均发生亲密，但每晚分别确认；事后聊天只在阿九愿意继续时推进，哭泣崩溃后立即停止询问。
- 云顶知道晏林连续三晚点选阿九、完成真实包厢消费，并在另行确认后与她离场，不知道谈话、求助和帮助内容。
- 正式保护接入后可以先停止阿九继续受害，但个人赌债与云顶直接控制解除必须等待关停决定及执行安排形成。
- 告别性非交易亲密必须同时晚于个人债务和云顶直接控制解除、以及云顶实体关停；与第三晚崩溃中的 C 档索取分别定性。

## 三晚的询问边界

- 晏林可以询问是否愿意、是否继续、是否停下，以及阿九是否愿意说明债务从哪里开始。
- 他不主动点出章绍衡、于静或罗东海的姓名，不用答案选项替她补完责任人。
- 阿九可以只说“赌场”“那个人”“接收我的人”；她不知道的姓名和身份由现实材料核验。
- 第三晚哭泣后只安抚，不再继续问；后续有限陈述必须在她重新稳定并愿意继续时另行成立。

## 第三晚与关停后告别性非交易亲密的回声

- 第三晚，阿九索取的是熟悉的伤害方式，用来覆盖痛苦、证明自己有用或测试晏林是否最终也会变成“那个人”；晏林拒绝的是在她崩溃时利用这一请求。
- 云顶关停安排形成后，阿九先解除赌场债务与云顶服务义务；实体实际关停后，她才由本人主动约见并说出“想要”。这是她第一次不靠服务脚本表达当下欲望。
- 关停后的非交易亲密只是一次告别性自由选择，不启动稳定“主人／母狗”私人回路，也不为后续复选保留自动入口。

## 不得写偏

- 不把性爱写成取证工具，不把温柔写成审讯技巧。
- 不把三晚付费、阿九主动或身体回应写成债务控制已经不存在。
- 不让晏林在阿九崩溃中继续追问或执行 C 档伤害。
- 不让有限陈述直接证明章绍衡姓名、罗东海能力或顾清言—章绍衡完整往来。
- 不把帮助、债务解除、云顶关停和非交易告别亲密写成一项交换。
- 不把关停后的一次非交易告别亲密升级为恋爱、长期伴侣、稳定联系或预设职业终局。

## 当前结论

阿九的关系变化按“**阶段三连续三晚付费亲密 → 事后逐层吐露 → 第三晚崩溃 → C 档索取被拒绝并获得安抚 → 有限陈述与正式保护 → 阶段四关停决定及执行安排形成 → 个人赌债和云顶直接控制解除 → 云顶实体实际关停 → 主动告别邀约与共餐 → 一次非交易亲密 → 清醒分别并离开**”执行。此后城市、职业、住处、关系与是否重逢均保持开放，不再设置奶茶店重逢或持续私人回路。
