# CON-0005｜第五场｜俞予安＋王诗悦双人 COS ②：黑白双天使

### 场次作用

这是小鱼儿与悦悦第二次共同 COS。它不沿用上一场女仆装的同款制服感，而改成最直接的镜像配对：小鱼儿为黑天使，悦悦为白天使。两人使用相同结构、相反颜色，站在一起时完成主题，拆下翅膀后又立刻回到能够正常活动的抹胸短裤造型。

本场的复杂度只集中在一件物品——翅膀。衣装本体不增加长裙、披风、盔甲、光环和多层配饰，也不要求两人承担具体角色名或完整天使剧情。

### 场次接口

- 本单元只承接云顶第 05 次亲密消费场；参与者为晏林、小鱼儿与悦悦。
- 这是小鱼儿与悦悦连续共同参与的第三场，也是两人的第二次双人 COS 共同场；黑白角色分配不改变两人都参与当次亲密的场次结构。
- 镜像造型、共同揭示与共同拆翼只统一画面节奏，不合并两人的费用、离场、身体范围、停止点与影像授权；两人继续分别确认。
- 本场继续承接 `PL-I-034` 的有限共同付费回路；不承担悦悦的职业压力显影，下一场 `CON-0006` 才切换为悦悦首次不与小鱼儿同组的独立场。

### 可拆翅膀

#### 外形

- 视频翅膀接近舞台级大翼，单人已经占据较宽空间。云顶版本缩为中型双翼：展开后仍明显宽于肩线，但两人能够依次通过门口，也能在包厢内短暂停留。
- 单侧羽翼由上方较密的短羽片和外缘较长的尖羽组成，根部厚、末端薄；两人的层数和外形一致。
- 小鱼儿使用低光泽黑羽，边缘可有极轻的枪灰反光；悦悦使用柔和白羽，根部允许少量冷灰阴影。两套都不使用灯带、发光纤维或自动扇动机构。
- 材料采用轻质骨架、布面羽片或仿羽，避免真正重型金属骨架与大量易脱落羽毛。

#### 固定与卸除

- 翅膀装在独立的轻量背架上，背架通过两条肩下固定带和一条腰后固定带受力，不让重量直接挂在抹胸上衣上。
- 固定带使用与衣装同色的窄弹力带，正面尽量藏在腋下和上衣边缘；它们属于翅膀组件，不是抹胸的一部分。
- 三处固定点都使用可单手确认的插扣／按扣，但真正拆卸时优先由本人双手或另一人从背后协助，避免拉扯头发和上衣。
- 卸下时先合拢两翼，再解腰后固定点，最后松开肩下两点，将“翅膀＋背架＋固定带”整体向后移走。拆完以后身体上不留下硬板、外露金属杆或长吊带。
- 两套翅膀分别存放，不把黑白羽片叠压在同一袋内；包厢内预留靠墙的软套或立架，避免随手丢在沙发和通道上。

### 抹胸上衣

- 两人使用同版短抹胸，上沿平直或只有轻微弧度，下缘停在上腹，完整露出腰线。
- 参考视频的斜向裹布感保留为一至两道浅褶，不保留单侧长带、腹部垂链或绕身多圈的复杂结构。
- 面料采用双层弹力布或低光泽弹力缎，内部带防滑条、软杯和短侧骨。即使翅膀固定带受力，上衣也不会被向后拖移。
- 颜色保持纯黑／纯白。小鱼儿的黑色依靠褶皱阴影分层；悦悦的白色增加现实内衬，避免强光下失去遮挡。
- 闭合采用一侧短隐形拉链或两至三枚软排扣。它与翅膀背架相互独立，卸下翅膀后可以直接处理上衣，不必先寻找被背架压住的后背绑带。

### 贴身短裤

- 两人使用同版中腰贴身超短裤，裤腰在肚脐下方，和抹胸之间保留完整腰腹。
- 主体面料与抹胸同色同光泽，前后保持实穿层，不使用只有薄纱覆盖的舞台底裤结构。
- 裤脚外侧各留一小段同色轻羽片或软薄纱，长度不超过手掌宽，只负责把短裤与翅膀联系起来；不扩张成羽毛短裙。
- 腰头采用弹力内带，侧面增加一枚短隐形拉链。没有复杂绑带、腿环、吊袜带或需要逐条解开的腰链。
- 小鱼儿的黑色短裤用黑色内衬和黑羽；悦悦的白色短裤用肤色／白色双层内衬和白羽，不能因颜色不同而降低现实完整性。

### 腿部与鞋履

- 视频腿部保持裸露，鞋履为细带高跟凉鞋。双人版沿用简洁方向，不增加长袜、腿甲或羽毛绑带。
- 小鱼儿使用黑色细带中跟凉鞋，悦悦使用白色或银白细带中跟凉鞋；鞋跟控制在能够走过云顶走廊和独立离场的高度。
- 踝带使用普通扣合或暗扣，不使用缠绕至小腿的长绳。需要换鞋时可以单独处理，不与短裤或翅膀连接。

### 妆发

#### 小鱼儿｜黑天使

- 自然深黑发做高束或利落半束，避免黑发、黑翼和黑上衣在背面完全粘成一块。
- 眼妆使用烟灰、黑色细长眼线和少量冷银眼头提亮；唇色偏深莓红或冷红。
- 不使用纯黑瞳片、黑色泪痕、裂纹妆或恶魔角，暗色感由黑羽和妆面完成。

#### 悦悦｜白天使

- 深色长发保持中分或轻偏分披发，与白翼和白抹胸形成最直接的明暗边界。
- 眼妆使用浅灰粉、细眼线和珍珠色眼头／锁骨提亮，唇色为低饱和水红。
- 不使用白色假发、蓝色瞳片和实体光环，保留本人清冷而柔和的辨识。

### 衣装拆解顺序

本场只保留一条清楚、现实的拆解线：

1. **完整揭示**：两人带翼依次通过门口，在包厢内并排展开一次黑白双翼。
2. **先收翼**：各自合拢羽翼，避免外缘扫到另一人、桌面或灯具。
3. **卸下翅膀**：解开腰后与肩下固定点，将翅膀连同背架整体取下并放入软套。
4. **留下基础装**：翅膀移走以后，两人分别只剩黑色／白色抹胸、同色短裤与细带鞋，轮廓干净，不残留背板和主题挂件。
5. **继续减装时分别处理**：抹胸通过侧拉链／排扣解除，短裤通过侧拉链和弹力腰头处理；黑白两套结构相同，但每个人各自决定是否、何时继续。

拆翼是角色造型从“天使”回到“黑白极简夜装”的视觉转折，不自动代表后续衣装或身体范围已经获得同意。

- 视频中的剑完全删除。包厢内不增加长柄、尖端或需要专门摆放的大型道具。
- KTV 消费结束并分别确认外出后，两人可以卸翼、重新扣好各自外套，继续穿着同一套黑白抹胸短裤主体前往酒店等当次确认的私人场所；不要求在云顶换回普通通勤衣物。

### 双人画面顺序

1. **先见颜色**：小鱼儿一侧是完整的黑，悦悦一侧是完整的白。
2. **再见轮廓**：两对同形羽翼向相反色块外展开，使两人形成镜像而不是主从。
3. **拆掉主题件**：羽翼被依次合拢、卸下，画面从宽大的幻想轮廓迅速收回两套极简抹胸短裤。
4. **保留本人差异**：小鱼儿的束发和冷锐妆面更紧，悦悦的深色披发与浅色衣装更松；不靠额外饰品重新堆复杂度。

### 正文优先锚点

每次调用只取一至两个：

1. 同样大小的黑翼与白翼在暗光中一沉一亮。
2. 小鱼儿的黑色抹胸和悦悦的白色抹胸采用完全相同的浅褶。
3. 短裤外侧只有一小簇同色软羽，没有延伸成裙摆。
4. 两人先后合拢羽翼，羽尖避开彼此和桌沿。
5. 背架整体移走以后，肩背重新变得干净，只剩抹胸与短裤。
6. 黑白两只翅膀被分别放入软套，不作为散落在包厢里的背景摆设。

### 与相邻衣装的区分

- 与双人女仆 COS 相比，本场移除翻领、短袖、围裙、伞裙、发箍和过膝袜，把唯一大体量从裙装转移到可一次卸下的背部羽翼。
- 与前一场普通黑白抹胸短裤相比，本场虽然拆翼后的基础轮廓相近，但采用上下同色：小鱼儿全黑、悦悦全白；面料、外侧羽片、妆面和首次带翼揭示共同建立天使主题。
- 后续普通夜场装若再次使用黑白镜像，必须移除翅膀、羽片与幻想妆造，并以裙装替换短裤、反转人物颜色分配；不能把本场拆翼后的基础装直接重复一次。

### 执行边界

- 黑白天使是舞台化幻想主题，不借用现实宗教服制、神职身份或真实信仰象征。
- 翅膀、抹胸和短裤的易拆结构只说明衣装施工便利，不替代任何身体、拍摄、保存或传播授权。
- 两人可以在任何阶段停止减装，也可以只拆翅膀、保留完整基础衣装继续社交。
- 同版反色、同时展开翅膀和共同拆翼不构成共同报价或共同后续决定；小鱼儿与悦悦分别确认自己的范围。

### 当前结论

云顶第 05 次亲密消费场的衣装锁定为“**小鱼儿黑天使＋悦悦白天使**”：同版反色的中型可拆羽翼、纯色短抹胸、同色贴身短裤和细带中跟鞋。小鱼儿从羽翼到衣装全部使用黑色，悦悦全部使用白色，金属小件分别压为枪灰与冷银。

完整拆解只有三层：**先整体卸下翅膀，再独立处理抹胸，最后处理短裤**。不设置长剑、光环、长裙、腰腹链条和复杂绑带，确保双人 COS ②比视觉上完整、实际操作仍然简单。
