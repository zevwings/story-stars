# CON-0007｜第七场｜何雯娜大胆现代夜装：黑色吊带抹胸与水洗黑牛仔短裤

这是娜娜第一次单独进入云顶 KTV 衣装序列。她不承担 COS，造型需要从前面小鱼儿、悦悦的角色服中退回现实都市夜装，同时保持足够大胆、贴身和有镜头完成度。

### 黑色层次

| 部位 | 色彩 | 材质与作用 |
| --- | --- | --- |
| 吊带抹胸 | 深黑 | 哑光双层弹力布，建立最实的黑色主体 |
| 牛仔短裤 | 水洗黑／炭灰黑 | 牛仔纹理、褪色边缘和银色五金切开上下纯黑 |
| 短罩衫 | 烟灰半透 | 最轻的一层黑，移动时显出肩带和手臂 |
| 鞋履／小配件 | 黑与冷银 | 收住下身，只留少量城市金属感 |

不能把三层统一成漆黑亮面。包厢暗光中应先看见烟灰罩衫的轮廓，再看见实黑上衣，由腰腹裸露过渡到有洗色纹理的牛仔短裤。

### 黑色细吊带抹胸

- 上衣采用细肩带与偏方形低领，介于短背心和抹胸之间；肩带只负责稳定，不扩大成普通吊带衫。
- 下缘停在肚脐上方，完整露出一段腰腹；长度比第 03 场的平直筒形抹胸略长，但贴合度更高。
- 胸前保持纯黑，不使用文字、蕾丝、亮片、镂空和撞色滚边。
- 腰侧保留一至两道轻微抽褶，使上衣从胸线向下收窄，也能在抬臂后自然产生小幅皱折。
- 使用双层哑光弹力布，内部有现实承托和防滑结构。肩带可以调节，但调节扣压为黑色，不做明显银色装饰。

### 水洗黑牛仔超短裤

- 下装使用低至中腰贴身牛仔超短裤，裤腰落在肚脐下方，与短上衣之间保留完整腰线。
- 黑色经过轻度水洗，裤腰、口袋边和裤脚呈炭灰层次；不是与上衣完全一致的纯黑，也不漂成浅灰。
- 保留真实五袋结构、腰袢、银灰裤扣和短拉链。五金只承担牛仔裤结构，不增加腰链、腿链或垂挂饰物。
- 裤脚短并沿大腿根部略向上收，以窄毛边结束；毛边控制长度，不做大面积破洞和垂落线头。
- 面料含少量弹力但仍保留牛仔厚度。坐下和起身时裤脚会产生位移，不能写成薄贴舞台底裤。

### 烟灰半透短罩衫

- 外层沿用视频的宽松短罩衫结构，颜色改为烟灰，材质使用轻薄网纱、雪纺或低光泽薄针织。
- 罩衫长度停在腰部附近，前襟不设纽扣，可以自然敞开；衣摆不覆盖整条短裤。
- 袖子宽松，长度到前臂或手腕之间。肩部允许自然滑到上臂，露出黑色细吊带，但滑落由娜娜自己整理，不固定成永远半脱状态。
- 罩衫是本场唯一外层，不能再叠黑西装、皮衣、披肩或主题袖套。
- 需要减装时可以直接从肩臂退出并完整脱下，不与抹胸肩带、短裤或首饰连接。

### 妆发与配件

- 深色长发不使用视频中的持续湿发。云顶版本做松散低髻或低束，保留八字刘海和脸侧碎发；少量发丝可以在抬臂后松落。
- 妆面保持白净、低阴影，以灰粉／浅棕压在睫毛根部，下眼睑和眼头只做少量提亮。
- 唇色使用玫瑰豆沙或低饱和水红，不用浓黑眼妆加正红唇把她推向小鱼儿的暗色角色妆。
- 配饰只留一对小型冷银耳饰，或一枚简洁银色裤扣作为远近呼应；不加项圈、腰链、长项链和成套手饰。
- 手包选黑色或银灰小包，能够放手机、补妆物和个人物品，不作为镜头道具反复展示。

### 腿部、鞋履与通勤外层

- 腿部保持裸露，不使用丝袜、过膝袜或腿环，突出牛仔短裤的现实都市感。
- 视频没有提供鞋履依据。云顶版本可使用黑色细带中跟鞋、简洁黑色短靴或银灰短跟鞋；优先选择能够正常走廊移动和独立离场的款式。
- 对外通勤另备一件长度足以覆盖短上衣和短裤的轻薄外套。进入包厢后先脱通勤外套，再保留烟灰短罩衫作为造型层。
- 通勤外套不进入本场主要视觉锚点，也不把娜娜写成只穿抹胸短裤穿过所有公共区域。

### 云顶 KTV 适配

- 暗光中用三种黑色明度保持层次：烟灰罩衫最浅，水洗短裤居中，哑光上衣最深。
- 抬臂、拢发或靠坐时，罩衫会从肩头滑向上臂；娜娜可以重新提回，也可以直接脱下，不把滑落强行解释为邀请。
- 低腰短裤落座后需要确认裤腰和裤脚位置。她起身时可以顺手拉平毛边，体现职业模特对衣装的熟悉。
- 上衣肩带、罩衫和手包彼此独立，避免三条细带在肩部缠绕。
- 不继承视频中的淋湿状态；包厢内的面料透明度以干燥实物为准。

### 衣装拆解顺序

1. **先处理公共外层**：进入独立空间后脱下通勤外套。
2. **保留完整夜装**：烟灰罩衫、黑色吊带抹胸与水洗黑短裤共同形成第一次完整揭示。
3. **去掉轻外层**：罩衫可以从肩臂直接退出，留下最简洁的黑色短上衣与牛仔短裤。
4. **分别处理主体**：抹胸由肩带和侧部闭合解除，短裤由裤扣与拉链处理；两件互不连接。

方便穿脱只属于现代夜装结构，不预设后续行为。娜娜可以始终保留罩衫，也可以只脱通勤外套，不由衣装顺序替她作决定。

### 正文优先锚点

每次调用只取一至两个：

1. 烟灰罩衫从肩头滑下，露出下面一根实黑细肩带。
2. 哑光黑上衣与水洗黑牛仔之间隔着一段清楚腰线。
3. 银灰裤扣和炭灰裤边使黑色短裤没有消失在暗光里。
4. 娜娜抬臂重束头发，罩衫宽袖随动作向前臂堆起。
5. 落座后她拉平一侧毛边裤脚，再把小包放回手边。
6. 罩衫完整脱下后，没有角色配件，只剩现实的吊带短装。

### 与相邻衣装的区分

- 与第 03 场小鱼儿、悦悦的同款抹胸短裤相比，本场使用细吊带方领、腰侧抽褶、低至中腰水洗毛边牛仔裤和烟灰罩衫；不是平直无肩带上衣配纯黑同款短裤。
- 与小鱼儿的黑天使基础装相比，本场没有翅膀、羽片、反色配对和幻想妆面，黑色通过牛仔洗色与半透罩衫表现现实材质。
- 与悦悦 OL 相比，本场没有衬衣、包臀裙、眼镜和身份道具，视觉重心从职业符号转回肩颈、腰线与牛仔结构。
- 后续小鱼儿＋悠悠的深浅双人夜装不应复用烟灰罩衫与水洗毛边短裤组合。

### 执行边界

- 这是娜娜自己选择的大胆现代夜装，不是 COS、车展制服或云顶固定工作服。
- 衣装贴身、露腰、短裤和罩衫滑落都不构成续场、离场、拍摄或身体授权。
- 视频只提供衣装结构，不继承湿身表演、瀑布环境和社交平台语境。
- 娜娜可以按温度、行动和个人判断重新穿上罩衫或通勤外套，不把重新覆盖写成角色中断或扫兴。

### 当前结论

第七次衣装锁定为“**黑色细吊带方领短抹胸＋水洗黑低腰牛仔超短裤＋烟灰半透短罩衫**”。整体采用深黑、炭灰与烟灰三层明度，在云顶暗光中保留纯黑夜装的利落感，又避免上衣和短裤糊成一个色块。

本场不使用湿发、丝袜、腰链和主题配件。娜娜以现实剪裁、干燥材质和整理肩带／裤脚的职业动作成立，明确与小鱼儿、悦悦承担的 COS 场分开。
