# 云顶 KTV 会所线施工

> 本页是云顶 KTV 集中段的统一施工入口，不再按服装、人物关系或其他执行类型拆分子包。人物身份、长期关系变化与跨场景衣装锚点仍以正式人物文件和 `story/plotlines/` 节点为准。

## 使用边界

- 云顶 KTV 到场、衣装展示、离场、亲密、拍摄、保存与传播分别判断；衣装大胆或带有情趣感，不替任何行为授权。
- 商 K 场次先保留真实的开包、酒水／饮品、点歌、停留与陪伴消费；包厢内可以发生另行确认的有限亲密，但消费、饮酒、包厢内亲密、是否离场及后续场外亲密分别成立，不从人物到场直接跳到“被带走”。
- COS 场次允许参与者在出发前穿好服装主体，再以可正常闭合、足以覆盖公共暴露部位的外套通过车辆、前厅与走廊；高冠、长纱、翅膀等易损或妨碍通行的部件可以装袋携带，到包厢或其他安全室内再完成装配。KTV 消费结束并另行确认外出后，可以重新扣好外套，穿着同一套 COS 主体前往酒店或其他当次确认的私人场所，不强制先换回普通衣服；提前穿着不替代真实消费，也不自动生成离场与后续亲密。
- 第 01—14 场的真实开台、酒水账单、付款与正常离场共同形成云顶经营记录；单场正文只需调用一至两个消费锚点，不必重复完整流程。记录累积后可供于静判断晏林是否为稳定熟客，但任一单场、任一服务人员或任一次场外亲密都不自动产生私域递名与会员资格。
- 当前固定十四次亲密消费场的施工顺序；前九场沿用 `CON-0001`—`CON-0009`，第十至十二场由 `CON-0012`、`CON-0042`、`CON-0043` 连续承接阿九三晚，第十三场回到 `CON-0011`，第十四场由 `CON-0010` 以童颜独立入口收束。衣装是每场的主要执行锚点，但不替代该场的参与者、关系职责与授权边界。不设置“一个月”“第几天”等时间参数；关系施工只固定已经确认的进入顺序、关系边界与退出接口。
- 视觉参考只提取服装结构、材质、颜色、比例和动态效果，不继承参考人物的面容、身体数据、身份、动作表演、拍摄地点或账号信息。
- 本目录所称“会所线”是当前云顶 KTV 集中段的施工简称，不表示人物已经进入只面向权贵与最高质量陪侍的私域。
- 生命周期状态以 [`../_status/`](../_status/active.md) 为唯一真源；本表只登记稳定 ID 与当前执行规格。
