# CON-0033｜乔宁亲密入梦、秘密介入与多次复选施工

> 本页承接 `PL-I-042`、`PL-S-112`、`PL-S-128` 与 `PL-I-043`，固定乔宁的私宴主动选择、第一次亲密、入梦取得部分破碎记忆、云梦号之后管理局秘密介入及后续多次复选顺序。正式事实与完成判据以对应剧情节点和人物卡为准。

阶段四完成第一次自主亲密、破碎记忆入口与管理局、警方秘密调查启动；阶段五在现实间隔后完成多次私人复选和阶段性关系回路。两阶段之间不以案件进度自动续接身体权限。

本线以杨柳拒绝与白玥完整逆流的共享事件为相对时间起点：乔宁的行业私宴约位于其后四个半月，云梦号结束后的系统性秘密介入约位于其后第五个月。该间隔只固定跨线因果尺度，不绑定精确日期或章号；药剂侵害、零散医疗后果与个人记录在介入前已经交织出现，不能把乔宁的入梦写成这些事件第一次发生。

## 执行顺序

| 阶段 / 顺序 | 场景功能 | 必须发生 | 执行边界 |
| --- | --- | --- | --- |
| 行业私宴入场 | 建立乔宁独立于会员和固定人员的参与身份 | 普通推荐后一至两周，乔宁以万安项目参与者身份进入思语承接的行业品牌私宴或项目庆功宴 | 不由顾清言专门引荐；万安只提供项目入口，不能替她授权私人关系 |
| 主动观察与选择 | 让乔宁成为关系发起者 | 乔宁观察晏林如何回应工作人员、项目参与者和拒绝信号，随后主动接近并试探 | 不由顾清言、万安或私域点名分配；晏林不知道她的完整前史 |
| 私人同行与第一次留宿 | 完成第一次当次自愿关系 | 两人分别确认离开公共区域、进入私人空间、留宿与亲密；乔宁始终可以停下、换房或离开 | 不谈证据、保护、资源和正式咨询，不把项目身份当同意 |
| 亲密后的入梦 | 打开异常记忆入口 | 晏林在当次近距离接触中入梦，只取得破碎、缺页的部分记忆 | 入梦不构成侦讯、完整证言或现实证据，不要求乔宁随后递交材料 |
| 次日清醒确认 | 固定职业边界 | 乔宁确认晏林从事心理咨询；晏林不与已有私人关系的她建立正式咨询关系 | 不诊断、不治疗、不建咨询记录，不以职业身份解释梦境结论 |
| 云梦号间隔 | 保持事件线独立 | 云梦号按原有公开慈善、人物汇合与跨境重组功能发生 | 不把云梦号改成管理局或警方取证行动 |
| 管理局秘密介入 | 取得部分遗失记忆 | 云梦号后、距杨柳—白玥共享事件约五个月，晏林经最高机密渠道上送；管理局以低暴露方式介入并取得部分遗失记忆 | 具体授权方式另行承接；不公开晏林完整能力档案；系统介入不等于药剂侵害此时才开始 |
| 双系统秘密调查 | 让案件脱离私人关系运行 | 管理局负责异常核验，警方负责现实违法调查；晏林继续潜伏 | 不组织艺人集体递材料，不让晏林兼任调查负责人 |
| 现实间隔 | 验证关系不是即时求助回报 | 乔宁恢复自己的工作、治疗或生活安排；案件继续独立推进 | 不用案件进展催促关系，也不要求她公开或立即解约 |
| 后续再次联系 | 建立多次私人复选 | 乔宁或双方在不同时间重新提出见面，每次重新确认留宿和亲密 | 不从第一次、交证或有限倾听推定后续权限 |
| 阶段关系成立 | 固定长期可继承边界 | 两人形成非排他、非固定频率、可间断回归的阶段性私人关系 | 不进入长期伴侣、共同生活、固定排班、公开绑定或风归归属 |

## 对白议程

- 乔宁先确认晏林的职业，再决定是否继续说；“听说你是心理医生？”只承担试探功能。
- 晏林的回应必须同时表达两点：他愿意听她当下想说的内容；他不能成为她的正式咨询师。
- 后续交证由乔宁主动提出，不用“只有把证据给我，我才能帮你”之类条件句。
- 再次联系时不复盘她是否“被治好”，只确认当次想见、想留或想离开的真实意愿。

## 不得写偏

- 不把第一次亲密写成乔宁用身体换安全，也不把晏林写成借职业身份取得她。
- 不把有限私人谈话写成正式心理咨询，不让晏林兼任咨询师、讯问者和案件责任判断者。
- 不在亲密场中完成证据验真、口供整理或调查推演。
- 不因乔宁后续多次主动便抹去她对边界、隐私和退出的持续需要。
- 不把多次关系写成固定服务、公司输送、私域排班、风归收编或等待转正。

## 当前结论

乔宁线按“**行业私宴独立入场 → 主动选择晏林并第一次自愿亲密 → 晏林入梦取得部分破碎记忆 → 云梦号 → 管理局秘密介入并取得部分遗失记忆 → 管理局与警方秘密调查 → 晏林继续潜伏 → 现实间隔 → 多次私人复选**”执行。乔宁不承担首批材料或艺人集体递交材料职责；私人关系、异常核验、警务调查与职业选择始终分流。
