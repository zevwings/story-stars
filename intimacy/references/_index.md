# 专项参考索引

本目录存放本专项的**写作参考素材**——可直接取用的样式、材质、感官与词条。

## 与其他目录的分工

- `mechanisms/` 是**规范层**：边界、禁区、授权与风险分级，有事实约束力。
- 本目录根层文件是项目自有的**专项速查层**；`library/` 是随 intimacy package vendoring 的**通用素材库**。
- 两类参考都只提供词条与写法素材，**不构成任何事实、不规定任何人物的偏好与经历**。
- 两者冲突时，一律以 `mechanisms/` 为准。

## 读取规则

- 先读对应 `mechanisms/` 规范页确认档位与边界，再读角色档案确认人物事实，最后来本目录取词条。
- 本目录的词条不得反向补出人物偏好、经历或关系事实。
- 本目录不参与一致性检查，也不作为设定冲突的判据。
- 本目录是项目亲密素材的唯一运行时参考入口；不得回退读取 story-writer 公共亲密参考或离线 packs。
- 需要通用身体、感官、语言、动作、结构或场景素材时，从 [通用素材库索引](library/_index.md) 按需进入，不全量读取。
