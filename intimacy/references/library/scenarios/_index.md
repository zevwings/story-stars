# scenarios · 情境专项索引

> 本目录只负责亲密参考库里的情境专项跳转。这里是题材中立的情境方法参考, 不保存示范片段、人物关系、剧情事实或世界观真源; 常规主文默认不读, 只有亲密专项 skill 或作者明示时才按需进入。

## 使用边界

- 先遵守 `BIBLE.md`、亲密规则目录和上级亲密参考总索引。
- 场型、关系事实、授权性质与正向 / dark 定性已经由项目真源、正式大纲或作者指令确定后，只有本场明确命中情境且需要补充方法时，才从本索引选择专项。
- 每场先确定一个主要情境专项；只有项目真源已经同时确认第二情境，且它直接影响本场关系结构、空间限制或动作逻辑时，才允许补读一个次要专项。
- 本目录只提供情境方法骨架; 具体世界观载体与正文由接入项目提供。
- 本目录内容不得反向污染 `$SPECIALTY_ROOT/` 场景设计卡、角色关系档案或正式剧情。
- 不得用本目录推导人物关系或第三方事实，不得决定正向 / dark，不得把身体反应解释为同意。
- 不得添加项目未确认的协议、偏好、机制或后果，不得从参考库自行拼出复合关系或复合情境。

## 编号规则

按情境类型分组, 组号 + 序号: `1X` 关系驱动、`2X` 权力与调教、`3X` 心理与特殊。组内新增只在本组末尾续号, 不影响其他组。
