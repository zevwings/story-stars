# 多人亲密场调用规范

> 本页规范正向多人亲密场的逐关系授权、镜头、位置、状态切换和场后承接。它不把多人同场本身视为关系成立，也不产生任何永久授权。

## 一、逐关系闭包

| 关系 | 已成立事实 | 当次允许 | 当次不允许 | 双人隐私 |
| --- | --- | --- | --- | --- |
| A—B |  |  |  |  |
| A—C |  |  |  |  |
| B—C |  |  |  |  |

- 同意进入同一空间，不等于同意观看。
- 同意观看，不等于同意接触、命令、留痕、拍摄或传播。
- 同意某人与自己互动，不等于同意另一参与者加入。
- 已成立女女关系或共同伴侣关系，也不自动开放任何一条双人关系的隐私。
- 每次共同场重新确认，不从上一次复制。

## 二、逐人必答

每名参与者分别写明：

- 为什么参加。
- 如何主动表达愿意。
- 语言停止、非语言停止与降速信号。
- 当次允许观看、接触、命令、痕迹、衣装、物件和影像的范围。
- 暂停后希望独处、旁观、照护还是离场。
- 场后希望与谁分别复盘。

任何一人要求整体停止，本场结束；不得换房或重组剩余参与者规避。若只是退出自己参与，是否允许其余人继续必须由该人事前或当场明确表达，不从沉默推出。

## 三、人物状态

每一幕中，每个人只能处于一个主要状态：

- **主动参与**：主动推进本幕关系动作。
- **回应承接**：回应另一人的推进，仍保有独立选择。
- **观察旁观**：在已授权范围内观看，不自动取得加入权。
- **暂停**：停止自己的参与，先处理状态与边界。
- **照护**：退出主要互动，承担已同意的回稳和协助。
- **物理退场**：离开当前空间；设计卡记录去处与是否返回。

状态变化必须有触发点和可见动作。暂停或退场人物不得从画面凭空消失，也不得被背景化后继续承担默认观看。

## 四、POV 与镜头

- 每一幕只设一个主要 POV，遵守项目第三人称限知。
- 当前 POV 只能写其可见、可听、可触和已经知道的事实。
- 切换 POV 必须经过段落、场面、位置变化或明确的镜头交接。
- 主要 POV 不等于本幕唯一重要人物；其他人的选择通过动作、语言和可观察反应在场。
- 不为展示所有人的感受而连续跳进多人内心。

## 五、位置与注意力

每幕记录：

- 每个人的物理位置与移动路径。
- 当前互动关系和未参与关系。
- 注意力从谁转向谁，谁主动要求独处或重新加入。
- 家具、承托面、门窗、遮蔽物和退出路径。
- 谁在主场、谁回应、谁观察、谁暂停或照护。

禁止固定“主攻 / 辅攻 / 承接”模板贯穿全场。角色位置应随人物意愿和关系回摆动态变化。

## 六、场后承接

- 分别确认每个人的身体和情绪状态。
- 分别复盘当次愿意、暂停、越界疑虑与下次是否愿意再谈。
- 共同余温不能吞掉独处需求、嫉妒、隐瞒账单或双人关系后果。
- 记录当次新增权限，但明确它不自动延续。
- 记录谁知道了什么、谁仍不知道什么，以及哪些双人隐私继续封闭。

## 七、写前写后检查

- 是否逐组确认每条关系，而不是只写“全员同意”？
- 每个人是否都有独立参加理由、停止方式与场后位置？
- 每幕主要 POV 是否唯一且限知？
- 暂停、旁观、照护和退场是否有明确状态切换？
- 每个人是否都有不可替代的动作、语言与关系位置？
- 是否保留了所有双人关系的独立性和隐私？
- 是否把共同身体层误写成稳定关系或永久授权？
