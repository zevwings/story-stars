# 言溪（梦露）｜角色舞步入镜

- **关系档（A 场层）**：[晏林 → 言溪](../../../characters/major/晏林/关系/言溪.md)

> 本卡只保存言溪与晏林关系的 HD 露骨层最小底盘。会所阶段关系定位、Coser／舞蹈职业边界、影像授权与替补边界以关系档为准；C 档表示已确认的可调用上限，不等于所有 C 档项目已经概括授权。

## 【HD 角色定调】

- **核心方向**：角色转换与舞蹈前奏。言溪可以用完整角色、音乐和身体控制打开私密气氛，但退出角色后必须立即回到本人称呼和本人边界。
- **权力格局**：她整体主动性很高，先决定角色、舞蹈与镜头语言，再主动推进已经开放的亲密内容；晏林负责辨认角色表达与本人意愿，不用“演得很投入”代替确认。
- **B 场调用重点**：从专业完整度进入真实失序，再清楚退出角色；不把她写成持续执行脚本的服务者。
- **禁写提醒**：不把舞蹈专业写成舞蹈主播，不把公开 Coser 账号、商演妆造或职业镜头自动转作私密材料。

## 玩具锚点

- 本卡暂不固定具体器物、疼痛、束缚或身体项目。
- 角色衣装、音乐、镜面、机位与录像只按当次角色和本人双重确认调用；停止角色即同步暂停所有依赖该角色成立的内容。

## 深色带适配（速查）

- **档位**：部分 C；上限由双方互动逐步解锁，不一次性开放完整 C 档。
- **入口情趣**：Coser 角色化、前奏舞蹈、镜头表现与双方共同确认的深度角色控制。
- **内核·触发**：言溪主动选择一个愿意进入的角色，并确认晏林能在她退出角色时立即放下角色权力。
- **解锁方式**：晏林在多次互动中持续辨认她的角色表达、本人意愿、降速与停止信号；言溪确认这一点后，由本人主动开放下一层，而不是由晏林单方面升级。
- **称呼方式**：进入已经解锁的身份层后，相关权力称呼或情欲自称由言溪主动喊出；具体词语仍须当场成立，退出角色或身份层后恢复日常称呼。
- **禁忌**：偷拍视频、外传、直播、第三方观看、角色永久化、职业资源施压，以及由 C 档自动补全未经确认的具体项目。
- **特异点**：她拥有明确的“入角／出角”切换；停止舞蹈、恢复普通称呼或要求关机，均优先解释为本人重新确认，而不是表演中的欲拒还迎。
