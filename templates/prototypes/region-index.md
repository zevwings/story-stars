# 地区原型索引

> 本页只登记已经开始分析或已经确认的地区原型；地区正式事实仍以 `worldbuilding/regions/` 为准。

现实原型、对应关系与现实专名只在本目录维护。正式真源只保存架空名称、内部空间关系与已经确认的地区功能，不反向引用本目录。

## 证据等级

- **显式映射**：既有正式材料或作者决定直接登记了现实对应。
- **高置信分析**：名称、空间组合与功能共同指向某个原型，但项目没有留下直接拍板记录。
- **复合候选**：只能识别多个参考簇，不收束为单一现实地点。

原型隔离与专名碰撞分别判断。现实原型名是否进入正式真源、架空专名是否需要避开现实同名，均服从当前项目的正式命名标准。

## 维护规则

1. 只登记已经开始分析或已经确认的地区原型，不用推测填补空缺。
2. 复合原型分别说明各参考簇负责的地貌、建筑、交通、气候或人群使用方式。
3. 原型结论确认后，将项目化结果同步到正式世界观；正式文件不反向引用原型档。
4. 地区改名、移动正式入口或改变同步状态时，同时更新本索引。
