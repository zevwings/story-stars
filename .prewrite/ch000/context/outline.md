### 本章目标
- 本章功能位（项目使用时）：楔子 / 世界入口 / 既有伴侣关系的第一次异常共处。
- 本章阅读契约及依据：先让读者看见一对已经在交往的年轻情侣夜爬看日出，再让异常从两人的身体反应、行动和有限互证中出现；制度只通过公开救援、内部转介和最低必要说明进入，不用世界观讲解替代现场。正式剧情依据为 `PL-S-303`，`CON-0046` 只提供本次施工边界。
- 主任务：连成“普通夜爬—分别结契—现实异常—公开救援—非公开转介—最低必要揭密—分别决定接受后续评估”的完整因果链。
- 次任务：写出晏林与景雪瑶面对同一未知事件时不同但都具有主体性的真人反应；让有限发现链体现为有人观察、判断、转介和反馈，而不是系统自动识别。
- 章末状态 / 后续接口：两人知道自身异常可能属于需要保密的星辰契约现象，也知道评估、登记、支持与信息代价的大致边界；两人分别决定接受后续评估与登记安排。正式登记、评级、能力复核、控制训练、机密报备和星辰之桥均未发生。

### 视角与信息边界
- 中心视角：晏林，第三人称限知。
- 本章能够确认的事实：晏林直接感知到自己的两颗星辰、两份契约、精神之海与当时已成形的操作路径；他只能从景雪瑶的可见反应、主动表达和有限传念确认她也发生了独立异常；轮值协作者先按现实安全问题处置，随后才启动异常评估转介；管理局联络人只说明最低必要事实与可选后续。
- 本章保持为推断或开放的问题：星辰回应的客观意志；两人在契约者体系中的相对位置；星辰与能力的完整名称、等级和社会后果；管理局的完整结构、星表和其他契约者信息。
- 章末信息状态：两人获得“发生了什么、眼下有什么风险、可以得到什么支持、登记要付出什么信息代价”的最低知识，没有获得全知解释；两人对各自第一人称体验仍拥有最终解释权。

### 人物欲望与现场压力
- 中心人物当前想得到 / 保住 / 摆脱：晏林首先要确认景雪瑶是否安全，同时控制自身双重结构带来的负荷；他想弄清下一步，却不替景雪瑶回答或选择。
- 其他人物或环境当前推动的不同结果：景雪瑶要自己核对新出现的感知，并直接追问异常和后续；轮值协作者要先排除失温、疲惫、药物、疾病或意外；管理局联络人要在不公开泄密、不越过当事人选择的前提下建立评估入口。
- 中心人物率先采取的动作：依照契约自知收束自己的负荷，观察并询问景雪瑶的状态，接受普通安全检查，同时留意救援人员公开说法与实际动作之间的变化。
- 对方 / 关系 / 环境的可见反馈：景雪瑶不只接受照看，也给出自己的感知和判断，必要时纠正晏林的概括；轮值协作者先做普通救援，再把需要保密的判断收进内部联络；联络人给出范围有限但可执行的下一步。
- 双方实际发生的碰撞或拉扯：两人都想迅速理解异常，却必须在身体负荷、公共环境和信息不足中克制试探；机构需要降低现实风险，却不能把救助直接升级为强制检测或登记。
- 章末仍在生效的压力或关系距离：两人的信任仍成立，但任何一方都不能替另一方解释契约或承诺后续；接受评估意味着他们将主动进入一段带有保密与信息代价的制度关系。

### 局面变化
- 改变局面的主动动作：两人分别完成星辰回应并依照自身可知路径收束负荷；轮值协作者在完成公开救援后，把无法用普通风险完全解释的迹象转入异常评估接口。
- 动作引发的可见反馈：公开现场仍按游客身体不适处理，私下联络链开始运作；两人由被动承受异常转为主动核对自身体验并评估制度选项。
- 不能兼得的目标：既不暴露异常又立即获得完整解释；既取得专业支持又完全不留下任何身份或评估痕迹。
- 人物选择与实际代价：两人没有在公共现场逞强离开，也没有把决定合并成情侣共同表态；他们分别接受后续安排，代价是承认风险并允许必要信息进入受限的评估链。
- 形成的新状态：两人从普通观星者变成已被有限发现链接触的疑似新契约者，并拥有一个可继续但尚未实际完成的评估与登记入口。

### 本章兑现
- 情绪或人物落点：惊异不以宏大宣告落地，而以两人仍能互相询问、校正和分别作出决定落地；制度的可信度来自边界清楚的行动，而不是权威口号。
- 本章获得 / 失去 / 暴露 / 确认的结果：确认两份独立回应与晏林的双子星结构；确认异常不是普通幻觉可以完全解释；暴露足以启动最低转介的迹象，但不暴露完整能力结构。
- 兑现结果的动作、物件、反馈或关系变化：呼吸、步态、手部动作、保暖休息、下山安排、公开问话与私下联络共同承载现实层；两人用各自的描述完成有限互证，联络人用选项、代价和停止线完成最低说明。
- 局部结果留下的后果：轮值链和管理局获得处理后续评估所需的最低接触信息；两人记住这套制度第一次对待自己的方式，但不因此欠下私人恩情，也不因此预先信任整个机构。
